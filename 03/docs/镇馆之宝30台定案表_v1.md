## 一、定案规则（四条，写入表头）

1. **每厅保底**：计算机黎明厅 ≥3、大型机与小型机厅 ≥4、个人计算机厅 ≥10、游戏机厅 ≥5、手机厅 ≥2、通用设备厅 ≥1、工作站 ≥1。
2. **年代切片全覆盖**：1940s（早期计算机）、1950–60s（大型机）、1970s（小型机 + 三杰）、1980s（个人机/游戏机黄金期）、1990s（掌机/街机）、2000s（智能机）均有代表。
3. **模拟器可行性加权**：有成熟模拟器（GPL 开源、可合规获取 ROM）的机型优先入表；无模拟器的机型须以"镇馆分量"（历史地位）支撑，演示走"静态 + 原理动画"。
4. **史实可考**：每台须有 Wikipedia / CHM / 官方手册等可考来源，年代、参数拿不准的一律标「需核实」，不编造。
