## 五、逐条可达性与复评说明（关键条目）

**S02/S03（官方手册）**：这是整份证据包里最"重"的两条——Apple II Reference Manual 的 1979 与 1981 两个扫描版，分属 archive.org 与 apple2.org.za 镜像。二者均为 Apple 版权物，只能"仅视觉参考"，本包从未把任何一页 PDF 或其中图片放入仓库；它们的作用是让建模者核对结构、让文案者转述事实。可达性方面，archive.org 在线翻阅稳定，apple2.org.za 镜像在本次检索中依然活跃（其 Disk II 手册已在 2026 年 9 月被社区重新引用为权威），两条均判"页面可达"。

**S05（CHM）与 S06（CHM Software Gems）**：同为 CHM，但授权性质不同。S05 的展项页面文本版权归 CHM，只能转述、不得复制，故复评为"仅视觉参考"；S06 是 Apple 明确授权、仅限非商业使用的 1978 DOS 源码，是证据包里唯一"官方授权"的一手材料，复评为"授权许可"。二者是本包历史叙事与磁盘系统讲解的主要依据。

**S07/S08（MAME）与 S09（AppleWin）**：这三条是"运行配置要素"的依据。MAME 官方立场页明确"ROM 均为版权物、未经许可不得分发"，与 Apple v. Franklin 判例（S11）共同构成"绝不内置 ROM"的合规双保险；MAME 源码（apple2.cpp/a2bus）同时是硬件时序的最权威技术文档。AppleWin 的 GPLv2 与机型覆盖（II/II Plus/IIe）作为备选模拟器的许可核实依据。

**S12/S13（尺寸交叉）与 oldcomputers.net（新增）**：这是"整机三围"的核心证据链。S12（15.25×4.25×17.5 in）与 S13（38.7×45.7×11.3 cm，即约 15.24×18×4.45 in）在**深度**上相差约 0.5 in（17.5 vs 18），此前被标"需核实"。本份新增 oldcomputers.net（被 retrotechwiki 引证）再次确认 15.25×4.25×17.5 in，使"17.5 in 深度"获得三源中的两源独立支持，倾向以 15.25×4.25×17.5 in（387×108×445 mm）定值；MacDB 的 18 in 深度判为孤立异常。最终仍建议实机实测闭环。

**S17（FCC OET）**：检索页可达，但 Apple II 的具体 FCC ID 仍未在公开索引中锁定（Apple 早期设备 FCC ID 常以 BCG 前缀登记，Apple II 的申请主体与 ID 需按 "Apple Computer Inc" 逐条翻查）。此条维持"待核"，不影响当前建模（内部照片已有 S03 手册照片兜底）。

## 六、缺口补列详细说明

**整机三围（V1）**：从"两源矛盾"推进到"两源一致 + 一孤立异常"，补列 oldcomputers.net 后已可定值 15.25×4.25×17.5 in，仅剩实机复核。这是本份对 11 号 production brief 最直接的一处推进。

**Disk II 软驱三维（V2）**：新增 Museums Victoria（155×220×96 mm，CC BY 4.0 照片可复用）与 MacDB Disk II（146×203×83 mm，1.36 kg），加上 RetroTechCollection 的 ~215×180×90 mm，三源差异明显。Museums Victoria 是实物馆藏实测、且有 CC BY 4.0 授权照片，权威性最高，建议以其为准；三源差异源于"是否含提手/前脸/后接插件"的测量口径不同，建模前需统一口径。

**键盘键帽弧面（V4）**：手册只给"52 键大写键盘"，无逐键弧面数据。键帽弧面是建模"易错点"（11 号 brief 已列），但无公开尺寸源，维持"待实测"，建议以社区实物特写或 iFixit 拆解图为参照。此缺口不阻断建模——键帽弧面可按"顶部约 0.5mm 内凹"的通用量级先做，定稿前复核。

**ROM 授权条款（V8/V9）**：本份补列 CSA2 FAQ（apple2.org）作为 DOS 3.3"无合法在线渠道"的直接出处，并发现 Apple 官方旧软件页（info.apple.com）曾有 GS/OS 6.0.1 分发记录——但该页与 ftp.apple.com 的现可达性待核，且**不覆盖原版 II 的 DOS 3.3**。这是对 12 号运行向导文案里"合法渠道列表"的一处事实校准：原版 II 的运行档（DOS 3.3）实际上**没有**官方免费渠道，向导应更明确地把"自备实机备份"标为唯一路径，而非与 GS 系混为一谈。

## 九、本轮方法局限与自我评估

本份可达性结论基于"检索快照命中 + 域名活跃度 + 权威性"的间接评估，**未逐条发起真实 HTTP 请求**（红线禁止下载大文件，且部分 URL 为 PDF/FTP 协议不便探测）。因此"页面可达"应理解为"近期仍活跃、大概率可访问"，最终以人工逐条点击 + 抓取确认为准；其中 S17（FCC ID 检索）、S23（Apple 旧软件页）与 15 号 V8 的 ftp.apple.com 是否退役，是三个最需要人工复核的点，已在 §一 与 15 号 V6/V8 登记。授权分档的复评以页面明示许可为准，无明示许可的一律保守归入"仅视觉参考"，宁可偏严不冒进，符合项目"版权存疑素材不进仓库"的一贯纪律。本轮把整机三围从"两源矛盾"推进到"两源一致 + 一孤立异常"、把软驱三维从"无源"推进到"一权威 + 一交叉"，并锁定了 DOS 3.3"无官方免费渠道"的关键事实——这是本份对 TASK-05 底稿最有价值的三处推进。
