## 一、三台「有明确模拟器」的 GPL 隔离口径

> 三台有明确 GPL 模拟器，逐台标 **GPL 隔离形态**（emulator 写具体名 + 独立进程接入 + 二进制不进仓库），
> 与第二批 amiga-1000（`uae` GPL 已核实）同款形态，但三台**尚未在 01 线登记槽位**，故标「隔离形态」非
> 「bone 已登记」。

### 1.1 IBM System/370 → `hercules`

- **GPL 隔离**：Hercules 是 System/360/370/390 开源模拟器（许可需核实，标 GPL 隔离）；对 S/370 的支持
  成熟度**需核实**，产包时 emulator 写 `hercules`、THIRD_PARTY 标「Hercules GPL 隔离、S/370 支持需核实、
  二进制不进仓库」。
- **备选**：若核实 S/370 支持不足，降为 `emulator="none"`（静态+原理动画），候选记 THIRD_PARTY。

### 1.2 MSX2 → `openmsx`

- **GPLv2 隔离（明确）**：openMSX 是 GPLv2 明确许可的 MSX 模拟器（名单已标「openMSX（GPLv2）」），
  emulator 写 `openmsx`、二进制不进仓库（GPL 隔离、用户自备进 slots）；参数/销量需核实。

### 1.3 Macintosh Plus → `mini-vmac`

- **GPL-2.0 隔离（需核实）**：Mini vMac 是 GPL-2.0 许可的 Mac 68k 模拟器（名单标「Mini vMac（需核实）」），
  emulator 写 `mini-vmac`、THIRD_PARTY 标「GPL-2.0 隔离、二进制不进仓库」；许可与 Macintosh Plus 支持
  需核实。

## 二、七台「无成熟模拟器」口径（emulator="none"）

> 七台（IBM PC XT / Acorn Archimedes / Sinclair ZX81 / SGI Indigo / Compaq Portable / Whirlwind /
> Apple Newton）模拟器可行性均标「需核实」、无明确开源后端，按分档口径 S/A/B 三档通用的「无 bone →
> emulator="none" 静态+动画」口径：`emulator="none"` + `media_hint` 按介质形态，模拟器候选记 THIRD_PARTY，
> 缺失作 NOTE 级提示（不算缺口、不进失败判定）。

- **分档归属**：7 A + 3 B（A 档 7 台件清单全规格 + 百科；B 档 3 台最小件 + 百科可留缺口），三档硬底线
  （validate 0 FAIL / REF 四查 0 / THIRD_PARTY 三件套 / id 唯一 / 反链 REF-02）不变。

## 三、校验器放行结论（schema 实测）

- **`emulator="none"` 已放行**：schema pattern `^[a-z][a-z0-9_-]*$` 匹配 `none`；既有 eniac/edvac/
  univac-1/nokia-3310 等均 `none` 且 0 FAIL。
- **`emulator="hercules"/"openmsx"/"mini-vmac"` 已放行**：三值均为小写字母/数字/连字符，匹配同一 pattern；
  与既有 `uae`/`mame`/`simh-altair8800` 同形态（schema 不校验后端是否登记槽位，槽位登记属 01 线门禁，
  非 validate）。
- **`emulator=null` 不放行**：schema required + type=string，触发 R-003。

## 四、给第三批产包的落地清单（逐台通用）

1. `runtime.emulator` 按 §〇 总表取值（三台 GPL 隔离写具体名 + 七台 `none`）；
2. `media_hint` 按介质形态：大型机/小型机/个人机 → `disk` 或 `tape`；PDA/手机 → `firmware`；
3. 三台 GPL 隔离模拟器在 THIRD_PARTY 标「GPL 隔离 + 二进制不进仓库 + 用户自备」；
4. 过闸自测：`validate.py` 0 FAIL + `catalog_ref_check` REF 四查 0 + 目录反链 done。

## 五、与任务书的漂移（如实）

1. **三台 GPL 隔离的 emulator 写法**：任务书说「有 GPL 模拟器 → 隔离形态」，本卡按此把三台
   （System/370→`hercules`、MSX2→`openmsx`、Macintosh Plus→`mini-vmac`）写具体名 + GPL 隔离声明；
   但三台均**尚未在 01 线登记槽位**（Hercules/Mini vMac 许可仍需核实），故与第二批 `uae`（GPL 已核实）
   区分，标「隔离形态」非「bone 已登记」，并给「核实不足则降 `none`」的备选。
2. **其余七台模拟器可行性均「需核实」**（无明确后端），统一 `emulator="none"`，候选记 THIRD_PARTY。
3. 目录 id 均为占位（`0xx`），本卡不 allocate（产包前由 02 线 id_registry 分配）。
