- 时长判据：每条 ≥15 s（第二批 §5 底线不降低）；分段结构按 §1 表（引入段/主体段）；
- 音效判据：挂接点 id 交付时与 08 线转档联动（新增待登记 → OK）；挂接缺失 = 退回；
- 形态判据：全部「静态+动画」循环可点播/点播两形态；不设真跑用例（4 台有模拟器 + 6 台 none 口径不变）；
- 交付即验：交付当日按 135 号缺件验收执行用例卡 v2 逐条执行（本卡只预标）。
