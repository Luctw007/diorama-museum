## 2. 规格通则（十六条共用）

- 格式通则：解说轨 180 字/分口播（≈3 字/秒），可转 AI 配音；BGM 循环段 ≥60 s、淡入淡出 2 s；短音效 ≤0.5 s、双向变体可区分两态；
- 挂接通则：进半径自动播/离半径 1 s 渐弱停（16 号全程规则同口径）；闪避规则沿用 24 号（vo 起时 bgm −8 dB、bed −6 dB、0.3 s ramp）；
- 史实通则：解说轨文案只引台本 §2 与研究卡已登记口径、「需核实」照标，不新增史实断言。

## 3. 与 97/98/99 号 §5 判据对齐声明

- **规格不降低判据、只细化**：97 号 T-659（7 条 id 对照 + 40 号转档）、98 号 T-663（2 条 id 对照）、99 号 T-666（7 条 id 对照）全部保留为本表「验收演示口径」列；
- 音效 id 对齐 08 线既有编号口径（vo_厅_站 / bgm_厅_01 / sfx_厅_功能 命名，40 号「新增待登记 → OK」转档联动）；
- 交付后 83/84/75 号音频断言自「新增待登记」口径升全量复验（各档音频边界行）。
