## 2. 三模式页签状态机（全流程状态图，不缩写）

```
任意模式页签
  PageIdle ──(点 CaptureBtn)──▶ Capturing
  Capturing ──(收到有效键/轴/按钮)──▶ 查重
      查重无冲突 ──▶ Writing ──▶ PageIdle（BindingDisplay 更新 + 0.5 s 高亮）
      查重有冲突 ──▶ ConflictPopup ──┬─(ReplaceBtn)─▶ Writing ──▶ PageIdle（旧行解除 + toast）
                                     └─(CancelBtn)─▶ PageIdle（丢弃本次）
  Capturing ──(Esc/右键)──▶ PageIdle（丢弃）
  Capturing ──(8 s 键鼠 / 10 s 手柄超时)──▶ PageIdle（丢弃）
  PageIdle ──(点 PresetBtn)──▶ PresetMenu(PopupMenu) ──┬─(选 P1/P2/P3/edsac)──▶ ConfirmPreset
                                                        └─(取消)──▶ PageIdle
  ConfirmPreset(PopupPanel 二次确认) ──(确认)──▶ ApplyPreset（逐行写 + 冲突规则：预设覆盖旧值并 mark）
       ApplyPreset 任一行写入失败 ──▶ Rollback（整区回滚，事务语义）──▶ PageIdle + toast「套用失败已回滚」
       ApplyPreset 全部成功 ──▶ PageIdle + `sfx_slider_snap`
  PageIdle ──(点 ZoneCaptureBtn)──▶ ZoneCapture（连续 N 击）──(Esc)─▶ Rollback ──▶ PageIdle
       ZoneCapture 收集满 N ──▶ Writing(批量) ──▶ PageIdle
  PageIdle ──(点 RestoreDefaultBtn)──▶ ConfirmRestore(PopupPanel) ──(确认)──▶ Writing(gen 等价覆盖) ──▶ PageIdle
  PageIdle ──(切换 DeviceSelect)──▶ Reload ──▶ PageIdle（未保存提示若 dirty）
  PageIdle ──(切换 ModeTabs / 关闭页)──▶ Flush（自动保存，写文件失败 → ErrorToast `sfx_error`）
```

**状态间公共约束**：Capturing 期间第 1 层输入被捕捉层独占（14 号 §2.2 输入屏蔽）；任何写文件路径失败不静默（ErrorToast 红字）；Writing 状态不可重入（按钮置 disabled）。

## 3. 数据契约（字段级读写映射 + 排序 + 预设 JSON 全文）

### 3.1 字段级读写映射表

| input_profile.json 键 | 读（渲染来源） | 写（保存时） | 规则 |
|---|---|---|---|
| `actions` | 动作行集（该区段） | 由行编辑结果回写 | 空串 → 该动作进 unbound；绑定串 ∈ joy_*/游戏动作域 |
| `keyboard` | 键鼠行的键名集合 | 同上 | 绑定串 ∈ `key_*` 小写蛇形；区段迁移时删旧区段键 |
| `mouse` | 鼠标行 | 同上 | 绑定串 ∈ mouse_button_*/mouse_wheel_* |
| `unbound` | 只读重算输入 | **重算写回**（三表中空串/缺失动作名） | 不手动编辑；与置顶排序共用同一重算结果 |
| `note` | 只读展示 | 保存时追加 `" · 用户已自定义"`（幂等，不重复追加） | loader 忽略，安全（sync §3④） |

**写回顺序**：先合并三表快照 → 重算 unbound →（可选 hash 对比外部改动，改动则 Reload 提示）→ 序列化五键 → 写文件。禁止写出 input_map。

### 3.2 unbound 置顶排序规则（全量）

1. 主排序：unbound 动作在前（三表值为空串或缺失）→ 已绑动作在后；
2. 次排序：按分区表（系统 0 → 位开关 A~D 1~4 → 字母 5 → 功能 6 → 鼠标 7）→ 区内按动作名字典序；
3. 稳定：排序键组合 `(is_unbound?0:1, zone_rank, action) `三元组；切设备/改绑定后重算不改变其余相对顺序。
