# 03 — Commodore VIC-20 预研卡

> 03 线 TASK-93B 交付。定案表 27# VIC-20 的预研卡，为 93-A 设备包备料。体例对齐同批研究卡。

## 一、史实

**Commodore VIC-20** 是 Commodore 于 1980 年发布（日本版 VIC-1001）/ 1981 年欧美上市（VIC-20）的 8 位家用电脑。它是**首台销量突破 100 万台的个人电脑**（1983 年达成），是 Commodore 把"电脑当作家用电器卖"战略的开端。

| 项 | 值 | 来源 |
|---|---|---|
| 发布 | 1980（日本）/ 1981（欧美） | [S87] |
| 处理器 | MOS Technology 6502，1.02 MHz | [S87] |
| 内存 | 5KB（3.5KB 用户可用，可扩） | [S87] |
| 图形 | VIC 图形芯片（彩色，22 列文本） | [S87] |
| 键盘 | 键盘主机一体 | [S87] |
| 售价 | 299.95 美元（面向家庭） | [S87] |
| 存储 | 外置数据磁带机（Datasette） | [S87] |
| 显示 | 接电视 | [S87] |

**叙事锚点**：
1. **销量破百万**：VIC-20 是首台销量破百万的个人电脑，验证了"低价家用电脑"市场的存在。
2. **面向家庭的价格**：299.95 美元的定价，把电脑第一次压到了普通家庭预算内。
3. **彩色图形**：VIC 芯片带来彩色显示与游戏能力，是 C64 的直系前身。
4. **键盘主机一体**：延续 PET 的一体式设计，但更小、更便宜。

## 二、尺寸依据（标「需核实」）

## 四、L1-L3 拆解要点

- **L1（外观层）**：一体机身、键盘、外置磁带机、接电视——静态展陈完整呈现"低价家用电脑"形态。
- **L2（结构层）**：机身打开 → 主板、键盘矩阵、电源——拆解展示"300 美元里装了什么"。
- **L3（芯片层）**：6502、VIC 图形芯片、BASIC ROM——原理讲解用（VIC 芯片的彩色图形与精灵是讲点）。

## 五、模拟器行

**VICE xvic（GPLv2，许可需核实）**，槽位 dedicated 预留，不下载二进制。VICE 主项目已登记于 02 线 registry（sim_id=vice），xvic 是其 VIC-20 子驱动。真跑需 ROM（BASIC ROM + 字符 ROM）合规获取。
