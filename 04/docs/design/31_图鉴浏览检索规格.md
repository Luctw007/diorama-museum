### 1.2 时间轴条（1890–今 · 滑杆档位表）

| 档 | 区间 | 步进 | 说明 |
|---|---|---|---|
| 0（默认） | 1890–2026 全段 | 连续 | 总览；刻度仅标 1890/1940/1970/1990/2007/2026 六档大字 |
| 1 | 1890–1945 先驱 | 1 年 | 机械/机电计算器 |
| 2 | 1945–1975 黎明~大型机 | 1 年 | 三厅主体 |
| 3 | 1975–1990 个人机勃发 | 1 年 | 1977/1981/1982 锚点徽章 |
| 4 | 1990–2007 移动前夜 | 1 年 | — |
| 5 | 2007–今 智能时代 | 1 年 | iPhone 徽章 |

- 双头滑杆：始/终两头拖动过滤 `era ∈ [start, end]`；与分类树/搜索是 AND 关系；档位切换即跨度预设、可再微调。

### 1.3 搜索框

| 项 | 规则 |
|---|---|
| 命中域 | `name.zh`、`name.en`、`aliases[]`（别名表，meta 扩展字段）三域 |
| 联想 | 输入 ≥1 字符即联想；**结果 ≤8 条**（按 中分类热度权重排序）；回车直达第 1 条详情 |
| 无结果态 | 「没有找到『xxx』。试试：年代筛选 / 分类浏览 / 查看全部预订中条目」+ [重置筛选] 按钮（沿用 05 号 T-064 图鉴空态语义） |
| 别名命中示例 | 「大砖头」→ Motorola DynaTAC；「水果机」→ Apple II（别名表由 03 线维护） |

### 1.4 分页 vs 惰性加载裁决（万级数据）

**裁决：树 + 虚拟滚动（惰性加载），禁止全量渲染。** 分页按钮只在测试入口保留（不做主打）。

| 预算项 | 值 |
|---|---|
| 可视行上限（桌面） | 24 行/屏（行高 64 px） |
| overscan 预渲染 | 上下各 8 行（池 40 行复用） |
| 缩略图 | 列表 48×48，惰性 texture（距可视区 <2 屏才加载）；VR 墙卡 64×64 |
| 卡片数组分片 | 按中分类分片 `catalog/c_<mid>.json`（§4）；单片 ≤500 条 |
| 回收策略 | 行对象池复用（`Name/Year/BadgeIcon` 三件套重建上限 5 ms/帧）；滚出可视+500 px 的行立即回池 |
| 性能目标 | **10k 条目录下滚动 ≥60 fps**（桌面 2K）、VR 走廊 ≥72 fps（T-367/T-368） |

## 2. 卡片与详情

### 2.1 列表卡（token 全引 26 号）

```
┌────────────────────────────────────┐ c-panel-2 底 · radius-s · border-1
│ [缩略 48²] Name  ·  1977            │ t-body / 年代 t-small m-blue
│            [小分类角标 c8]          │ 角标 c-accent-2 底黑字
│            [状态徽章] planned…      │ 五色徽章（下表）
└────────────────────────────────────┘
```

| 状态徽章 | 色（26 号 token） | 语义 |
|---|---|---|
| planned | c-dim | 仅登记，无内容 |
| researching | m-blue | 调研中 |
| package | c-accent-2 | 内容包已产 |
| wip | c-warn | 制作中 |
| done | c-ok | 可开放参观 |

**规则**：状态徽章 = 色 + 文字双通道（04 号 §5.1 三通道，灰度可辨）；done 卡才可点进展厅；非 done 卡点击 = 详情页目录态。

### 2.2 详情页（锚定 C1 百科结构）

| 区段 | 内容（C1 对齐） | 目录态差异 |
|---|---|---|
| 摘要区 | `meta.name`（中/英）、intro ≤2 行、来源脚注（C1 字段） | 无内容时显示「该设备条目尚在编写中」 |
| 快速摘要 | 已有内容全文 | 目录态显示「快速摘要：<一句话>」（由 era+category 例行生成） |
| 预约提示 | —（done 无） | 「想看这台机器？点 [预约] 我们会优先补件」+ 预约计数徽章 |
| 动作 | [进入展厅]（done）/ [查看进度]（非 done） | 同上 |
| 关联 | 同一中分类下相邻条目横滑（≤10） | 同 |

## 3. VR 形态（展墙式图鉴）

### 3.1 分类走廊（贴墙卡片阵列 + LOD 规则表）

| LOD 级 | 触发距离 | 呈现 | 卡片数 |
|---|---|---|---|
| L0 聚合 | >6 m | 每个中分类 = 1 面聚合牌（0.9×0.9 m，标名称+计数） | 一屏 ≤12 面 |
| L1 展开 | 2–6 m | 该分类墙展开为卡片阵列（卡 0.3×0.24 m，4 列） | ≤40 卡 |
| L2 详情 | <2 m | 选中卡放大至 0.7×0.9 讲解板（12 号 §4 导览卡行参数） | 1 |

- LOD 切换 0.3 s 淡入；聚合牌用 26 号 m-paper 底 + m-stamp 边框（手册风）；走廊动线 = 六厅门类六段墙，PlayerRig 弧线传送点在每段墙头（12 号 §5.1）。

### 3.2 手柄快速筛选（手背菜单链）

```
手背菜单呼出（非持握手柄 primary_btn，12 号 §3）
 └─ 链 1：大分类 6 选 → 链 2：时间档 6 选 → 链 3：状态徽章 5 选 → [应用]
     每链 = 竖排列卡（选项高 0.05 m，热区 ≥0.04 m）＋ 当前选中 c-accent 边框
```

## 4. 与引擎数据接口（对 01 线 catalog 的读取契约提案）

### 4.1 API 名与返回结构（在 ExhibitIndex 上扩展，字段名全给）

```json
// EpisodeIndex v2（提案）：GET-like 语义，同步内存+分片文件混合
{
  "get_page": {
    "in":  {"hall": "computer", "mid_category": "c8", "offset": 0, "limit": 500,
            "era_start": 1975, "era_end": 1990, "status": "done"},
    "out": {"items": [{"id":"apple-ii","name_zh":"Apple II","name_en":"Apple II",
                       "era":1977,"mid_category":"c8","status":"done",
                       "thumb":"res://content/thumbs/apple-ii.ctex",
                       "aliases":["水果机"]}],
            "total": 42, "next_offset": 500}
  },
  "search": {
    "in":  {"q": "apple", "limit": 8},
    "out": {"suggestions": [{"id":"apple-ii","name_zh":"Apple II","hall":"个人计算机厅"}]}
  },
  "detail": {
    "in":  {"id": "apple-ii"},
    "out": {"id":"apple-ii","meta":{"name":{"zh":"Apple II","en":"Apple II"},
            "intro":"…","sources":["…"]},"status":"done","hall":"个人计算机厅",
            "booking_count": 0}
  }
}
```

### 4.2 分片文件布局提案

```
godot/content/catalog/c_<mid>.json     ←按中分类分片 ≤500 条/片
godot/content/catalog/index.json       ←{mids:[{id,name,count,era_min,era_max}]}
godot/content/thumbs/<device-id>.ctex  ←48²/64² 缩略（生成器增强 gen_exhibit_index）
```

- 现行 `exhibit_index.json` 继续作为小规模总览留存；万级化后由 catalog/ 分片接管，`ExhibitIndex` 保持向后兼容（未改动 01 线文件，提案待 01 线评审）。
