## (a) 概述与历史地位

VCD（Video CD，视频光盘）是一种采用 MPEG-1 视频压缩标准、以 CD-ROM 为载体存储视频的光盘格式，标准于 1993 年由飞利浦、索尼、JVC 等联合制定（"白皮书"标准）[S66][S70]。VCD 播放器则在 1993–94 年兴起，并在中国掀起了一场席卷全国的"VCD 浪潮"。

VCD 的历史地位，在中国尤为特殊 [S66]：1990 年代中期，中国家庭迅速普及了 VCD 播放机，价格从数千元一路降到数百元，让"在家看电影"第一次成为大众消费。VCD 浪潮催生了爱多、步步高、新科、万利达等一大批国产品牌，也把"万燕 CDK-320"推上了"世界第一台 VCD 播放机"的史册 [S66]（「需核实」——此说存在争议，见下）。

VCD 的技术本质，是"把计算机的解码芯片装进一台家用影音设备" [S66][S70]：它用 MPEG-1 解码芯片，把压缩在光盘上的视频数据还原成电视画面。对玩家而言，VCD 播放器是理解"计算机化如何走进家电"的最佳样本。

## (c) 工作原理

### 系统框图（ASCII，MPEG-1 解码芯片链路 + CD-ROM 伺服）

```
  ┌────────────┐       ┌────────────┐       ┌────────────┐       ┌────────────┐
  │  光盘(CD)   │ ────▶ │  CD-ROM    │ ────▶ │  MPEG-1     │ ────▶ │  视频输出    │
  │ (VCD 碟片) │ 读取  │  伺服/读头  │ 数据流 │  解码芯片    │ 还原  │ (复合/分量) │
  └────────────┘       └────────────┘       └────────────┘       └────────────┘
                                                     │
                                                     │ 音频解码
                                                     ▼
                                             ┌────────────┐
                                             │  音频输出    │
                                             │ (左右声道)   │
                                             └────────────┘
```

### 数据流说明

1. **读盘**：激光头读取 VCD 光盘上的数据坑点，经 CD-ROM 伺服系统稳定地读出数据流。
2. **解复用**：解码芯片把数据流分离成视频流（MPEG-1）与音频流（MPEG-1 Layer II）。
3. **解码**：MPEG-1 解码芯片把压缩的视频/音频还原成连续的画面与声音 [S70]。
4. **输出**：还原后的画面经视频端口输出到电视，声音经音频端口输出到功放/电视。

### 关键子系统职能

- **激光头 + CD-ROM 伺服**：读取光盘数据，并精确控制光头聚焦与寻道，是"读盘"的机械核心。
- **MPEG-1 解码芯片**：把压缩的视频/音频流实时还原，是整台机器的"大脑"，也是"计算机化"的体现 [S70]。
- **音视频输出电路**：把解码后的信号转换为电视/功放可接收的模拟信号。

> 以上职能描述即未来 FR-C 原理标注素材底稿；家电类主芯片链路已按任务要求画出 ASCII 框图。

## (e) 百科卡全文（C1 级成品文案）

**VCD 播放器 —— 那台让中国人第一次"在家看电影"的机器**

1990 年代中期，中国家庭突然多了一样东西——VCD 播放机。插上电视、放一张光盘，就能在家里看上一部电影。这在今天看来稀松平常，在当年却是一场席卷全国的消费浪潮 [S66]。而承载这场浪潮的，正是一台看似普通、却藏着"计算机技术"的机器——VCD 播放器。

VCD（Video CD）用 MPEG-1 技术，把一整部电影的影像压缩进一张普通的光盘里 [S66][S70]。在 VCD 之前，人们在家看电影主要靠录像带（VHS）——磁带笨重、画质一般、还容易绞带；而 VCD 用一张薄薄的光盘，就装下了约 74 分钟的视频，画质约与录像带相当，却更耐用、更好保存。这张"会放电影的光盘"，让"在家看电影"第一次变得简单而廉价。

VCD 播放器的技术本质，是"把计算机的解码芯片装进一台家用影音设备" [S70]。它肚子里那块 MPEG-1 解码芯片，把光盘上压缩的视频数据，实时还原成电视上的画面与声音。这台看似是"家电"的机器，其实是一台专做一件事的"计算机"——这正是"计算机化"走进日常生活的生动写照。

VCD 在中国的故事尤其传奇 [S66]。关于"世界第一台 VCD 播放机"，流传着"万燕 CDK-320"的说法——合肥的万燕公司 1993 年造出了第一台 VCD 机（此说存在争议，须「需核实」）。但无论首台归属，VCD 在中国掀起的浪潮是真实的：爱多、步步高、新科、万利达等一批国产品牌迅速崛起，价格从数千元一路降到数百元，VCD 机走进了千家万户。这场浪潮，也成了中国消费电子产业崛起的一个缩影。

VCD 的画质放在今天看当然粗糙——约 352×240 的分辨率，和今天的 4K 不可同日而语 [S70]。但正是这台"粗糙"的机器，让整整一代中国人第一次体验到了"在家看电影"的乐趣。从 VCD 到 DVD，再到今天的流媒体，家庭影音的进化之路，正是从这块小小的解码芯片开始的。

## 深度解读一：MPEG-1——把电影"压"进光盘的魔法

VCD 能在一张普通光盘里装下一部电影，靠的是 MPEG-1 压缩技术 [S70]。一部电影的画面数据是天文数字级的——如果一帧帧原样存储，一张光盘根本装不下几分钟。MPEG-1 的聪明之处在于"压缩冗余"：视频画面里，前后两帧往往只有很小的变化（比如背景不动、只有人物在动），于是它只记录"变化的部分"，把"不变的部分"复用。这样一来，数据量被压缩了几十倍，一整部电影才能塞进一张 CD。这种"只记变化、复用不变"的思想，正是今天所有视频压缩（从 MPEG-1 到 H.264/HEVC）的共同源头。

## 深度解读二：中国 VCD 浪潮——一场大众消费的奇迹

VCD 在中国掀起的那场浪潮，堪称消费电子史上的一段奇观 [S66]。关于"世界第一台 VCD 播放机"，流传着"万燕 CDK-320"的说法——合肥的万燕公司 1993 年造出了第一台 VCD 机（此说存在争议，须「需核实」）。但无论首台归属，VCD 在中国的普及是真实的：爱多、步步高、新科、万利达等一批国产品牌迅速崛起，价格从数千元一路降到数百元，短短几年间，VCD 机走进了千家万户。这场浪潮的背后，是中国制造与大众消费的第一次大规模合流——一个"几亿家庭都能在家看电影"的时代，就此开启。它也为后来中国成为全球消费电子制造中心，埋下了伏笔。

**关键参数（面向玩家）：** MPEG-1 视频 · CD-ROM 载体 · 约 74 分钟/张 · 约 352×240 分辨率 · 1993–94 [S66][S70]。

**参考来源：** [S66][S70]。

## 在展厅里怎么看它

VCD 播放器是"通用与手持设备厅"里"家电里的计算机化"这条主线的起点。看它的时候，请把目光停在那块 MPEG-1 解码芯片上——它才是这台"家电"里真正的"计算机"。"盒子里的科技"这句话，正是它的写照：计算机技术不再待在机房里，而是悄悄藏进了一件摆进客厅的家电。而它在中国掀起的那场"千家万户在家看电影"的浪潮，更是"大众消费"最生动的注脚。看懂这台机器，你就看懂了"计算机化如何进入日常生活"的另一面。

VCD 播放器之所以值得记住，在于它用一块 MPEG-1 解码芯片，把"在家看电影"第一次变成了大众消费，也让"计算机化"悄悄走进了千家万户的客厅。
