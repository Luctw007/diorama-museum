## MVS 键位对齐比对

Neo Geo MVS（本表第 1 台）键位与已入库内容包比对：

- `neo-geo-mvs/runtime.json` `input_map` 共 20 动作 = 双人 ×（上/下/左/右 + A/B/C/D 四键 + Start + Coin），与本表"各 1 摇杆 + 4 键 + Start + 投币"**一致**。
- `control_panel.gltf` 节点名仅 `control_panel`（单节点占位，未细分到按钮），本表"4 键 A/B/C/D 布局"对应 runtime 的 `p1_btn_a~d`，具体按钮物理位置**需核实**（占位盒未标注）。
