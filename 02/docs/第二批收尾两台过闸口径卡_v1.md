## 一、SPARCstation 1（第 10 台）过闸口径

### 1.1 `emulator` 字段「QEMU sparc 需核实 → 保守 none」裁决

| 候选 | 裁决 | 理由 |
|---|---|---|
| `emulator="none"` | **采纳（推荐）** | ① 208-B 已裁决「QEMU sparc 许可与成熟度需核实、01 线无 qemu 槽位（无 bone）」，按分档口径 S 档「无 bone → none 静态」；② 既有先例 eniac/edvac/univac-1/nokia-3310 均 `"none"` 且 validate 0 FAIL 已证放行 |
| `emulator="qemu"` | **否决（现时）** | QEMU sparc 许可未核实、01 线 `slots/emulators/` 无 qemu 槽位，写 `qemu` 会声称不存在的已登记后端，重蹈 apple-ii「槽位未建立」误导；QEMU 许可核实 + 01 线登记槽位后，可升 `emulator="qemu"`（走「占位 → 正式」升级） |
| `emulator=null` | **否决** | schema `runtime.emulator` required + type=string + pattern `^[a-z][a-z0-9_-]*$`，`null` 触发 R-003 FAIL |

### 1.2 建议写法（供 03 线照抄）

```json
{
  "emulator": "none",
  "version": "0.0.0",
  "system": "Sun SPARCstation 1（静态展示）",
  "media_hint": "disk",
  "bios_required": false,
  "bios_guide_url": null,
  "output_sinks": [ { "id": "external_crt_0", "surface": "external_crt", "type": "video" },
                    { "id": "terminal_0", "surface": "terminal", "type": "text" } ],
  "input_map": { ... }
}
```

- `system` 写「Sun SPARCstation 1（静态展示）」，与 eniac/edvac/univac-1 先例一致。
- `media_hint="disk"`（内置硬盘，208-B 口径卡 §三）。
- QEMU sparc 候选**不进 `emulator` 字段**，改记 `THIRD_PARTY.md` / `encyclopedia.md` 的「模拟器可行性」段
  （「QEMU sparc 候选、许可需核实、GPL 隔离独立进程、二进制不进仓库」）。

### 1.3 SunOS/Solaris 镜像红线（208-B §二）

- **SunOS/Solaris 系统镜像不入库、不下载、不提供、不再分发**——版权保护，只做**清单级引用**。
- 真跑时 SunOS/Solaris 安装镜像由用户按合规渠道自备、放入本地 slots，不入仓库、不进 git。
- 参照 01 线既有 ROM/固件红线惯例（MAME Romset / Apple II ROM / Kickstart ROM 均不入库）。

### 1.4 件清单与「待接后端」归属

- **件清单照 S 档全规格**：meta/runtime + assemblies 6 件（case/motherboard/power_supply/disk/io_ports/monitor，
  208-B §三）+ annotations ≥30（flow ≥10）+ encyclopedia ≥2500 汉字 + THIRD_PARTY 三件套。
- **模拟器缺失作 NOTE 级提示**（不算缺口、不算 WIP、不进失败判定），判定仍按 S 档过闸、反链 done 照常。

## 二、Nokia 8110（第 11 台）过闸口径

### 2.1 `emulator` 字段「无成熟模拟器」裁决

| 候选 | 裁决 | 理由 |
|---|---|---|
| `emulator="none"` | **采纳（推荐）** | ① 研究卡 §(g) 明说「8110/3310 无成熟专用模拟器，固件受版权保护，基本只能静态 + 原理动画」；② Symbian 模拟器 / MAME 手持驱动均「需核实」，写它们会声称不存在/未核实的后端 |
| `emulator=null` | **否决** | schema required string，`null` 触发 R-003 FAIL |
| `emulator="symbian"` 等 | **否决** | 8110 是功能机（非 Symbian），无对应模拟器；研究卡已明说 |

### 2.2 建议写法（供 05 线照抄，参照 nokia-3310 先例）

```json
{
  "emulator": "none",
  "version": "0.0.0",
  "system": "Nokia 8110（静态展示）",
  "media_hint": "firmware",
  "bios_required": false,
  "bios_guide_url": null,
  "output_sinks": [ { "id": "handheld_lcd_0", "surface": "handheld_lcd", "type": "video", "format": "mono" },
                    { "id": "speaker_0", "surface": "speaker", "type": "audio", "format": "pcm16" } ],
  "input_map": { "power": {"map":"keyboard","key":"KEY_POWER"}, ... }
}
```

- `media_hint="firmware"`：手机内置固件、**无可插拔介质**（无卡带/磁盘/光盘），与 nokia-3310 先例一致
  （nokia-3310 `media_hint="firmware"`）。「无介质形态」是**物理形态**描述，不代表 `media_class` 取
  `none`——手机类 `media_class` 归 **firmware**（内置固件）；若后续确认按「无介质」解读，`media_class="none"`
  （191-A 已落地 9 值枚举）也合法，产包时二选一、以目录条目 `media_class` 字段为准。
- 滑盖动画属**演示向**，不依赖原机固件；「贪吃蛇 II」可用自研复刻承载可玩（研究卡 §(g)）。

### 2.3 分档归属（以 173-A 名单为准）

Nokia 8110 是 173-A 名单 **38 号、S 档**（「弧形滑盖『香蕉机』、《黑客帝国》出镜」叙事锚点）；`M-MP-000014`
是定案表 v2 草案已定的目录 id（非占位）。S 档「无 bone → emulator=none 静态」口径同样适用（§二 S 档无成熟
模拟器形态）。

### 2.4 件清单与落地

- 件清单照 S 档：meta（category=phone / era=1996）+ runtime + assemblies（外壳/滑盖/键盘/单色 LCD/主板/电池/
  天线，研究卡 §(d) 约 6-8 节点）+ annotations（短信链路 + 换壳 + 滑盖 flow）+ encyclopedia + THIRD_PARTY。
- 「贪吃蛇 II」自研复刻注意与原作表达区分（研究卡 §(g) 红线）。

## 三、校验器放行口径（实测依据）

- **`emulator="none"` 已放行**：schema `runtime.emulator` pattern `^[a-z][a-z0-9_-]*$` 匹配 `none`；既有
  eniac/edvac/univac-1/nokia-3310 均 `"none"` 且 validate 0 FAIL，实证放行。
- **`emulator=null` 不放行**：schema required + type=string，触发 R-003。
- **结论**：**无需改校验器**；若未来需「待核实模拟器」新枚举值（如 `pending`），属改校验器（另开任务），
  本卡不预占。
