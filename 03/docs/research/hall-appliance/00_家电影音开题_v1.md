# 家电影音（家用电器厅）开题 v1

> 03 线 TASK-173-A 交付。家用电器厅开题卡（跨线提名 + 边界声明）。该品类目录归属 05 线，03 线本轮只做提名与开题，**不代改 05 线目录、不代排生产**。

## (a) 开题定位与边界

家用电器厅是 1.0 新增厅，对应项目总愿景中的「电视机、VCD/DVD、随身听」等品类。定位为「影音娱乐与生活电器的普及史」——从收音机、留声机，到电视、录像机，再到 VCD/DVD 与随身听，讲述「科技如何走进客厅、如何随身携带」的叙事。03 线已产 VCD/DVD 调研（hall-generic/01/02），可复用为素材底稿。
