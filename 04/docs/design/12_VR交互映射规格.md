### 1.2 手柄实体键位双列对照（Quest 2/3 ｜ SteamVR Index）

| 语义角色 | Quest 2/3（Touch 类手柄） | SteamVR Index（Knuckles） |
|---|---|---|

## 2. 三大原语 → OpenXR 手柄映射（输入 → 处理 → 反馈）

> 每原语三要素：**输入**（第 1 层事件名与行程）→ **处理**（输入适配层合成算法与参数）→ **反馈**（视觉/听觉/触觉，对齐 01 号 §3.4 时序与 04 号音效名）。

### 2.1 Inspect — 旋转（握持按钮 + 摇杆）

**输入**：`grip_pose_left/right` 按住 `grab_squeeze`（悬停命中非可抓对象或整机）；`stick_vector` 备用微调。

**处理**：

| 模式 | 合成算法 | 参数与边界 |
|---|---|---|
| 单手旋转（主路径） | 握持键按下瞬间记录柄位姿 P0；拖动中每帧取 ΔP = P_t − P_0（世界系），映射为增量：Δyaw = ΔP_x × 2.5°/cm；Δpitch = ΔP_y × 2.5°/cm [需实机核对：桌面当量 ORBIT_SPEED 0.3°/像素 × 换算] | 设备级：绕 Y 无线、绕 X/Z ±90°（01 号 §2.1）；达限播 `sfx_boundary` + 触觉轻震 10 ms |
| 摇杆微调（副路径） | 右摇杆 Y 上下 = pitch 连续微调（±2°/s 满杆 [需实机核对]）；按下摇杆 = 视角复位（等同桌面 R 键 reset_view） | 与主路径同边界；摇杆输入时主路径忽略，防双源冲突 |
| 双手扭转（手势语义，见 §3.1） | 双手各 grab 设备两个把手点，`angle_delta = 两柄连线段绕设备枢轴 Y 的转角差` | 见 §3.1 状态机手势表；任一柄 `squeeze` 释放 → 回落单手模式（01 号 §2.1 镜射回落） |

**反馈**：旋转全程无额外反馈（防噪，01 号 §3.4）；达边界时 `sfx_boundary`（0.06 s）+ 非持握手柄轻震 10 ms；抓手点处设备高亮描边（c-accent #FFC859，01 号 §2.3 选中态）。

### 2.2 Inspect — 缩放（双手拉距 pinch → 半径公式）

**输入**：双手同时 `grab_squeeze_left + _right` 且两 `grip_pose` 均命中「设备把手点」（01 号 §2.1 VR 双手镜射）。

**处理（半径公式）**：

```
双手抓取建立：记录初始双柄距离 d0 = ‖P_left − P_right‖（米）、初始相机半径 R0
每帧计算：    d = ‖P_left_t − P_right_t‖
             R' = R0 × (d0 / d)                      // 拉开(d↑) → R'↓ → 近观放大
             R' = clamp(R', 0.5 × R0, 3.0 × R0)     // 等价显示倍率 s = d/d0 ∈ [0.5, 3.0]
防抖：        |d_t − d_{t−0.1s}| < 0.02 m 时冻结 R'；跨度过小（d0 或 d < 0.05 m）锁定缩放（01 号 §2.4）
```

**反馈**：缩放达 0.5×/3.0× 极值时 `sfx_boundary` + 双柄轻震 10 ms；每次跨越整数倍率（1.0×/2.0×）播放 `sfx_slider_tick`（0.03 s）作刻度感；HUD 准星旁浮出「×n.nn」缩放读数 1.5 s。

### 2.3 Grab — 扳机抓取 / 力度回弹

**输入**：`point_trigger_click`（扳机点击）与 `grab_squeeze`+`grab_squeeze_value`（握持与力度）双通道。

**处理**：

| 阶段 | 判定规则 |
|---|---|
| 拾取 | 目标 ∈ 允许脱离集合（01 号 §2.2）且非动画占用：扳机按下或 squeeze>0.6 → 吸附至 `grab_pose`（§1.1）；握持瞬间放大 1.05×（视觉确认） |
| 移动 | 对象跟随柄位姿；阻尼按 `mass_class`（小零件 1.0 / 上盖 0.4，01 号 §2.4）；碰撞盒约束不穿透 |
| 力度回弹（松手） | squeeze value < 0.3（Index 力度回弹）/ 扳机松开（Quest）→ 回装判定：距原位 ≤0.15 m 且姿态差 ≤30° 且无遮挡 → 0.4 s 卡合动画 + `sfx_snap`；否则落座散件 + 下沉动画；进入 0.3 m 判定区播放 `sfx_approach` 连续滑音 |

**反馈**：拾取瞬间高亮 + 放大 1.05× + 轻震 10 ms；移动中无触觉；卡合 `sfx_snap` + 轻震 10 ms；违禁抓取（运行中）= 准星 ⦸ + `sfx_deny` + 长震 80 ms，持续 2 s 出「运行中不可拆解」条幅（01 号 §4.5）。

### 2.4 Point — 射线 + 扳机点选

**输入**：`point_aim_pose_right`（右手主射线）/`point_aim_pose_left`（副射线）；`point_trigger_click` + `point_trigger_value`；`secondary_btn` 取消。

**处理**：

| 判定项 | 规则 |
|---|---|
| 射线 | 主射线长度 10 m；UI 面板命中时射线隐去、面板显示虚拟光标（01 号 §2.3）；3D 命中处准星 + 外轮廓发光描边（c-accent） |
| 热区 | VR 最小热区 ≥0.04 m 直径（3 m 距离）；桌面同判定函数异尺寸（01 号 §3.3 检查表第 3 条） |
| 点选 | 扳机短按（< 0.5 s，`point_trigger_value` 行程计时）且按下-释放位移 ≤0.02 m → Point；位移 >0.02 m → 转交 Grab/Inspect（Fine rule，01 号 §2.3） |
| 长按取消 | 扳机 ≥0.5 s = 取消（等同 Esc，01 号 §2.3/§4.6 打断）→ 长按触达时轻震 |
| 平台取消键 | `secondary_btn`（Quest Y/B；Index 触摸板缘 [需实机核对]）= 取消层 / 复原动画打断 |

**反馈**：命中可点目标即时描边（FUNC-003）；确认点击 `sfx_confirm` + 短震 10 ms；空点 = 空操作无音（01 号 §2.4）。

## 3. 设备状态机 VR 表达（手势语义表）

> 状态集合与迁移规则以 01 号 §4 冻结版为准；本节只规范每类迁移在 VR 下的手势合成。过渡锁时长沿用：开盖 0.8 s / 关盖 0.8 s / 单件 0.4 s / 复原 ~2.5 s / 开机 1.2 s / 关机 0.6 s（动画期间所有手柄输入被忽略，T-030 复核）。

| 迁移 | 桌面表达 | VR 手势语义（输入 → 合成 → 判定） |
|---|---|---|
| 完整 → 开盖 | 抓上盖把手区斜上拖（T-007） | **单手抬升**：`grab_select` 命中最上盖把手区，沿铰链法向抬升 >0.10 m 即触发（T-008）；**双手拧盖**：双手 grab 把手区，两柄连线绕铰链轴转角超 25° 触发 [需实机核对]；两者并存任一满足即开盖，动画期铰链示意线显现（01 号 §3.4） |
| 开盖 → 拆解中 | 点选零件拖离（T-017） | Grab 零件沿装配轴反向拉出 >0.15 m 松手 → 散件 + 虚线连原位（T-017 桌面同源语义，虚影线照 01 号 §4.3） |
| 拆解中 → 完整（一键复原） | 拆解面板按钮（T-029） | 面板 [复原] 按钮 Point；或手势区快捷：双手掌心相对握拳于胸前双击扳机 [需实机核对]；动画期间手柄输入被忽略（T-030 过渡锁） |
| 爆炸图滑杆 | 拖滑杆（T-019/020） | ① 主路径：拆解面板滑杆（热区 ≥0.04 m）扳机拖拽，每档吸附 `sfx_slider_tick`；② 摇杆路径：右摇杆 Y 上/下 = 展开/收拢连续驱动（每满 0.1 系数一档吸附）；③ 手背菜单：非持握手柄 `primary_btn` 呼出腕部快捷滑杆（竖向 0.25 m），扳机拨动。三路径同写 `explode_value ∈ [0,1]`，冲突时后操作者胜 |
| 拆解中 → 开机禁止 | 运行入口置灰 | 与桌面同判定（状态机红线）；VR 下准星落在置灰入口 → `sfx_deny` + toast「请先复原再开机」（01 号 §4.5） |
| 运行中禁 Grab | 光标 ⦸ | 运行中任何抓取意图 → 准星 ⦸ + `sfx_deny` + 长震 80 ms（01 号 §4.5）；运行 HUD 改腕部面板（07 号 §3） |
| 运行中 → 完整（退出） | 退出确认二次层（T-028/071） | 腕部 HUD [退出确认] → 空间警示牌确认 → 关机 0.6 s；Esc 键序（弹层栈秩序）VR 等价 `secondary_btn` ×2 层叠（对齐 T-071 语义） |

## 5. 舒适模式（传送 / 快速转向 / 晕动选项）

### 5.1 传送（弧线 / 直线）

| 档 | 参数 | 判定与反馈 |
|---|---|---|
| 弧线（默认） | 抛物线射程 6 m、弧高 0.5 m [需实机核对]；落点半径 0.3 m 吸附功能区脚垫（03 号 §5 瞬移点位） | 合法落点：青色环 + 脚垫高亮；不可落点：红环 + `sfx_deny`；确认 = `stick_click`（或扳机短按） |
| 直线（备选） | 射程 4 m；与弧线同落点规则 | 设置页可切换；低天花板场景直线在 2.2 m 处自动转弧线 [需实机核对] |
