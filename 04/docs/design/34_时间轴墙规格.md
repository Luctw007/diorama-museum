## 1. 时间轴墙结构（1890–今）

### 1.1 分段与聚合规则

| 项 | 规格 |
|---|---|
| 分段 | 1890 起每 **5 年一格**，至 2025 共 28 格（2025 兜底「今」） |
| 投影 | 每条目录按 `year` 入格；无 year 条目入「未标年」附录格（现数据 0 条，容错预留） |
| 密度规则 | 格内条目数 ≤40 = 单排气泡（每泡 φ0.04 m）；>40 = **波峰格**：自动堆叠 + 横滚动画 |
| 波峰堆叠 | 波峰格呈现「三排堆叠 + 格顶计数器」：第 1 排平铺 24 泡，第 2/3 排各平铺 16 泡，余量走 8 s/圈横滚动画；格前立 0.35 m 迷你标尺可抓（Inspect-Grab，29 号 §4） |
| 浮层展开 | 波峰格被点选 → 浮层放大为 1.2 m 宽明细板（60 泡分页，页 3×20），非波峰格无浮层 |
| 格铭牌 | 每格下沿年代大字（t-h2）；波峰格加 m-stamp 红章「密集」（26 号手册 token） |

## 2. 漫步体验

### 2.1 走道动线（正序 vs 倒叙回望）

| 模式 | 动线 | 说明 |
|---|---|---|
| 正序（默认） | 入口 1890 → 沿墙向右走到 2025 → 出口 | 时间前进叙事 |
| 倒叙回望 | 出口侧反向启步：从 2025 走回 1890 | 每格解说词切换为「回望口吻」（§2.2 文案双态） |

- 走道宽 2.0 m，墙高 3.2 m，格宽 0.9 m；每格地面脚垫指引（12 号 §5.1 传送到格）。

### 2.2 年份标尺交互

| 交互 | 规格 |
|---|---|
| 标尺造型 | 墙脚通长手摇标尺（0.9 m 高）；拨针 = 年份值 |
| 拨到 1984 | **该年及前后各 2 格（1980–1990）的光点同步跳动一下（0.4 s 呼吸）**；若为波峰格则同时轮转一圈 |
| 光点跳动规则 | 拨针落入哪年，哪年的全部气泡光点跳 1 次；年份=立牌年时立牌底座灯同步闪 |
| 解说 | 拨针触发一句年限讲解（模板：「<year> 年，<当年代表事件/条数>」按当年条目数动态填） |

### 2.4 每十年年代牌叙事语表（正序/倒叙双态，全量）

> 每十年立一面年代牌（0.5×1.0 m，m-paper 底 m-masthead 字，26 号手册 token）；过牌即播 8 s 双态句。

| 十年 | 正序句 | 倒叙回望句 |
|---|---|---|
| 1940s | 「战争催生的计算：从火炮弹道到第一台电子机。」 | 「回头看 1940 年代：炮火逼出了计算机的啼哭。」 |
| 1950s | 「晶体管上岗，电子管让位——机器开始变小、变稳。」 | 「1950 年代在倒车镜里：机器第一次学会了安静。」 |
| 1960s | 「集成电路登场，小型机走出机房，走进实验室。」 | 「回望 1960 年代：计算机第一次离开了玻璃房子。」 |
| 1970s | 「微处理器诞生——把一台电脑装进一片硅。」 | 「倒着走回 1970 年代：楼下那台苹果，在这里发芽。」 |
| 1980s | 「个人电脑爆发，游戏机入客厅——本墙的最高密度带。」 | 「回望 1980 年代：270 台机器挤在这十年，电子史最热闹的一条街。」 |
| 1990s | 「互联网前夜：Windows 与互联网把世界接线。」 | 「倒带 1990 年代：248 台机器在等待世纪之交的光纤。」 |
| 2000s | 「手机吃掉相机、MP3、地图——一切开始朝掌心汇聚。」 | 「回望 2000 年代：谁也没想到，终点是一块玻璃。」 |
| 2010s | 「智能互联——万物开始插电上网。」 | 「倒带 2010 年代：效率与监视，同一项发明的两面。」 |

- 句长短 ≤40 字；数字与 §1.2 实测一致（1980s=270）；过牌免打扰（无 interrupt 其他站口播）。

## 3. 接入数据契约（对 01 线 bundle 的 by_decade API 提案）

```json
{ "by_decade": {
    "in":  {"decade": 1980},                     // 10 年档；边界含 1980–1989
    "out": { "decade": 1980, "count": 270,
             "buckets": [ {"year5": 1980, "count": 151},
                          {"year5": 1985, "count": 119} ],
             "items": [ {"id":"c64","name":"Commodore 64","year":1982,
                          "status":"done","device_id":"commodore64"} ],
             "top_year": {"year": 1982, "count": 39} } } }
```

- 复用 `catalog_index` 分片：时间轴墙仅需 `year/status/device_id/name` 四字段 → 建议 bundle 内出专用轻量索引 `timeline_index.json`（一次载入，888 级 ≈200 KB [需实机核对：实测体积]）。
- 万级防御：按 decade 分包 `tl_<decade>.json`，进格即载（34 号与 31 号 §4 分片同思路）。

## 5. 与 33 号筛选器联调衔接

时间轴墙的年份标尺与 33 号年代档 token 共用同一 `year` 数据域：拨针落点即写入 era token（双端注入），图鉴页与本墙的结果集在任何一端变更后 300 ms 内互相同步刷新（33 号 §2.1 防抖栅复用），保证两处口径一致。
