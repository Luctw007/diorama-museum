> 03 线 TASK-228-A 交付。第三批第 2 台（个人机，目录占位 `C-PC-0000xx`）的预研卡，为后续设备包领取备料。本卡为第二批体例（「一二三四五六七」七节）浓缩版，史实复用 `02_MSX2代表.md`（68-A 已产，证据 S78/S79/S80）；openMSX 许可 GPLv2 已核实（68-A 检索确认），参数/销量标「需核实」。不下发二进制、不下 BIOS ROM/卡带镜像。

## 一、史实

**MSX** 是日本 ASCII（西和彦）与微软于 1983 年联合制定的**家用电脑工业标准**，规定统一的 CPU、图形芯片、BASIC 与卡带接口，任何厂商（索尼、松下、三洋、雅马哈等）照着做即可造出互相兼容的机器，是「统一标准、多家生产」在个人电脑史上的独特实践 [S78]。MSX 历经 MSX1（1983）、MSX2（1985）、MSX2+（1988）、turboR（1990）多代，其中 **MSX2+ 是图形能力最成熟、最能代表「MSX 黄金时代」的一代** [S79]。本卡选取 MSX2+ 代表机 **Panasonic FS-A1**（1988）为对象。

| 项 | 值 | 来源 |
|---|---|---|
| 标准发布 | 1983（MSX1）/ 1985（MSX2）/ 1988（MSX2+） | [S78][S79] |
| 代表机 | Panasonic FS-A1（MSX2+） | [S79] |
| CPU | Zilog Z80，3.58 MHz | [S78] |
| 图形 | Yamaha V9958（19268 色，YJK 模式） | [S79] |
| 声音 | YM2149 PSG + FMPAC（YM2413 OPLL） | [S79] |
| 内存 | 64KB 主内存 + 128KB VRAM | [S79] |
| 软件载体 | 卡带（ROM cartridge，即插即玩） | [S78] |

**叙事锚点**：
1. **标准横贯线**：MSX 是「开放标准、多家生产」在个人电脑史上最早的实践，横跨索尼/松下/三洋/雅马哈等厂商，生态遍布日本、欧洲、南美 [S78]。
2. **YJK 模式的「真彩」**：MSX2+ 的 V9958 芯片用 YJK 模式在 8 位机上显示 19268 色，是「用聪明编码塞进更多颜色」的图形技巧 [S79]。
3. **卡带即插即玩**：MSX 的卡带接口让「运行软件」变成「插上就玩」，深刻影响后来的游戏机交互 [S78]。
4. **微软的第一课**：微软为 MSX 开发 MSX-BASIC，是微软第一次深度参与家用电脑标准，为其日后主导 PC 软件生态埋下伏笔 [S78]。

## 四、L1-L3 拆解要点

- **L1（外观层）**：主机 + 分体键盘 + 卡带插槽——静态呈现「家用电器式电脑」的造型。
- **L2（结构层）**：打开主机 → 主板、Z80、V9958、FMPAC——拆解展示「标准机里装了什么」。
- **L3（元件层）**：V9958 图形芯片（YJK 模式）、FMPAC FM 合成、卡带 ROM 直读——原理讲解用（19268 色如何编码、FM 音色如何合成、卡带如何即插即玩）。

## 五、模拟器行

**openMSX（GPLv2，已核实）——MSX 的「尽可能精确」模拟器** [S80]。

- **openMSX**：开源 MSX 模拟器，覆盖 MSX1/MSX2/MSX2+/turboR 及大量真实机型配置（含 Panasonic FS-A1），官网 `https://openmsx.org/`。
- **许可**：**GPLv2**（已核实，68-A 检索确认 Wikipedia 与官网一致记载）。
- **免 ROM 优势**：openMSX 内置 C-BIOS（MSX BIOS 的开源替代实现），可不依赖原厂 BIOS ROM 直接运行部分卡带游戏；更完整兼容性需用户自备原厂 BIOS ROM。
- **隔离口径**：参照 01 线「独立进程（ADR D1）经 stdio 设备通道接入网关、不链接不派生」惯例；GPL 二进制不入库。
- **需核实**：MSX2+ 具体销量、部分参数细节（内存组织、外设扩展）。
- **红线**：不下发二进制、不下原厂 BIOS ROM 与商业卡带镜像；「可玩」以「卡带即插即玩 + FM 音乐播放 + MSX-BASIC 演示」承载。

## 七、展呈叙事建议（三行）

1. **标准的力量**：用「插座与插头」比喻讲 MSX 标准如何让不同厂商机器互相兼容，是「开放标准 vs 私有架构」两条路线的最佳案例。
2. **8 位机上的真彩**：用 YJK 模式对比 16 色/256 色/19268 色的三代演进，讲「换一颗芯片就换一代标准」的清晰升级。
3. **卡带即插即玩**：用「插卡带就启动」讲家用娱乐设备的零门槛交互，追溯今天 Switch 插卡带的源头。
