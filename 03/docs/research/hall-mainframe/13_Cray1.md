# 13 — Cray-1 研究卡

> 03 线 TASK-188-B 交付。第二批第 7 台（目录 `C-SC-000003`）的预研卡，为后续设备包领取备料。体例对齐 hall-mainframe 研究卡。模拟器可行性标「需核实」，不下发二进制、不下 ROM。

## 一、史实

**Cray-1** 是 Cray Research 于 1976 年推出的向量超级计算机，由 Seymour Cray 设计，是「超级计算机」这个词最经典的视觉符号。它以标志性的**环形机柜**（立柱围成半圆，形成「C」形，据说灵感来自设计师的姓氏首字母）与配套的 C 形座椅闻名，峰值性能遥遥领先于同时代机器。首台 Cray-1 交付给了洛斯阿拉莫斯国家实验室，此后成为全球顶尖科研与国防机构的标配。

| 设计者 | Seymour Cray | [S108] |
| 架构 | 向量处理（vector processing） | [S108] |

**叙事锚点**：
1. **超级计算机的象征**：Cray-1 的环形机柜是「超级计算机」最深入人心的形象，是一代人对「算力巅峰」的共同记忆 [S108]。
2. **向量处理的革命**：Cray-1 用向量处理大幅提升科学计算吞吐，开创了超算架构的新范式 [S108]。
3. **Seymour Cray 的巅峰**：继 CDC 6600 之后，Cray-1 是设计师 Seymour Cray 最耀眼的作品，把「Cray 传奇」推向顶峰 [S108]。
4. **科学与国防的算力底座**：Cray-1 服务于顶尖科研与国防，是「超级计算机改变科学」的实体见证 [S108]。

## 二、尺寸依据（标「需核实」）

- 主机：环形机柜，约 1.9 m 高，外径约 2.6 m（「需核实」）。
- 立柱：12 根立柱围成 270 度圆弧（「需核实」）。
- 座椅：C 形皮革座椅，嵌于机柜内侧（「需核实」）。
- 重量：约 5.5 吨（「需核实」）。

## 三、部件分解草图清单

```
Cray-1（整机系统）
├── 环形机柜（ring_cabinet，12 立柱围成 C 形）
├── 向量处理单元（vector_unit，向量运算核心）
├── 内存（memory，高速内存）
├── 冷却系统（cooling，氟利昂循环冷却）
└── C 形座椅（seat，操作员座椅，嵌于机柜内侧）
```

## 四、L1-L3 拆解要点

- **L1（外观层）**：环形机柜 + C 形座椅——静态呈现「超级计算机最经典的工业设计」。
- **L2（结构层）**：机柜打开 → 向量处理单元、内存模块、冷却管道——拆解展示「环形机柜里装了什么」。
- **L3（元件层）**：向量处理逻辑、内存模块、冷却循环——原理讲解用（向量处理如何提速、氟利昂如何冷却是讲点）。

## 五、模拟器行

**无成熟模拟器**（需核实，槽位 dedicated 预留，不下发二进制）。Cray-1 结构专有、复杂度极高，现无广泛可用的开源模拟器；展厅以「静态 + 原理动画（向量处理/环形机柜）」为主。若后续有可考模拟器，再走合规流程接入。

## 七、展呈叙事建议（三行）

1. **超算的视觉图腾**：用 Cray-1 的环形机柜与 C 形座椅，做一段「超级计算机长什么样」的视觉叙事，是超算厅的镇馆之宝。
2. **Cray 传奇的巅峰**：把 CDC 6600 与 Cray-1 连成「从首台超算到超算象征」的完整血脉，串起 Seymour Cray 一生的设计传奇。
3. **向量处理的革命**：用向量处理对比标量计算，讲「一条指令如何算一串数据」，是理解现代高性能计算的入门钥匙。
