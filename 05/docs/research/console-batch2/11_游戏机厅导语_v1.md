## 一、导语主线（≥1500 字成稿）

### 1.1 主线一句话

**游戏机厅讲的是"客厅与街机之间的一场往返战争"——家用机一次次想把街机厅的体验搬回家，街机厅又一次次用更强的性能、更浓的氛围反超，两股力量来回拉锯，写成了电子游戏四十年最精彩的一段竞争史。**

### 1.2 主线全文

欢迎来到游戏机厅。这个厅讲的故事，要从一个"搬"字说起。

1972 年，第一台街机 Pong 摆进酒吧，人们第一次为"对着屏幕打球"投币。那一刻，游戏属于街机厅——你必须走出家门、投下硬币，才能玩到它。但几乎同一时间，有人开始琢磨：能不能把这台机器搬回家？

这就是游戏机厅主线故事的起点：**客厅与街机之间，展开了一场持续四十年的"往返战争"**。

第一回合，是"搬回家"的胜利。1977 年的 Atari 2600 把"换卡带换游戏"做成了大众商品——你不用再去街机厅，在家就能玩《太空侵略者》。家用机第一次把街机体验搬进了客厅。可这次搬家也埋下了隐患：开放失控的生态产出了海量垃圾游戏，1983 年，整个北美游戏业轰然倒塌。

第二回合，是任天堂的"重建秩序"。1983 年的 Famicom 用严格的授权体系与过硬的游戏，把行业从废墟里拉了起来。它把街机厅里"手感爽快、画面流畅"的体验，第一次真正高品质地搬回了客厅——《超级马力欧兄弟》让无数人发现，原来在家也能玩到街机级别的游戏。

第三回合，是"16 位争霸"。1988 年，世嘉 Mega Drive 把街机基板的那颗 68000 与 FM 音源原样塞进家用机，喊出"把街机厅搬回家"；1990 年，任天堂 Super Famicom 用 Mode 7 与采样音源，把家用机的画面与音乐推到了街机厅都未必有的艺术高度。两台机器面对面，打响了"速度与态度"对"色彩与声音"的著名主机战争。这一回合，家用机似乎彻底赢了——它把街机厅最宝贵的东西，几乎都搬回了家。

但街机厅没有认输。1990 年，SNK 的 Neo Geo MVS 街机柜站了出来，打出了第四回合的"反超"。它用多槽位基板与"换卡不停机"，用天价也不惜的"街机家用同源"大卡，用 68000 加专门图形音源堆出来的性能，重新把玩家拉回了街机厅。更重要的是，它守住了街机厅最无法被"搬回家"的东西——**投币文化**。投一枚硬币，听投币音、看 CREDIT 亮起、进入游戏，这一连串仪式感，是客厅里永远复制不了的。而街机厅里投币、对战、围观、呐喊的社交氛围，更是任何一台家用机都无法提供的"现场"。

于是这场往返战争，最终打成了一种微妙的平衡：**家用机搬走了游戏，街机厅留住了体验**。前者让你在家独享，后者让你出门共享。而这，恰恰是游戏机厅最想讲给你听的——它不是一台台机器的陈列，而是一段"人如何在不同空间里玩游戏"的变迁史。

### 1.3 两条社交线的合流

这场"往返战争"的背后，其实藏着两种截然不同的"游戏社交"，它们最终在游戏机厅里合流。

一种，是**合租客厅文化**。家用机把游戏搬回家后，"一起打游戏"从街机厅的肩并肩，变成了客厅里的坐沙发——两个人挤在电视机前，一人一个手柄，轮流或同时对战。Famicom 的双手柄、MD 和 SFC 的两人同屏，都是为这种"客厅社交"设计的。尤其在日本，"合租公寓里一群人围着红白机打《马力欧》"是整整一代人的青春记忆。家用机让游戏社交从"出门"变成了"在家"，从"投币"变成了"邀请"。

另一种，是**投币文化**。街机厅的社交，是投币、排队、围观、挑战、呐喊——它需要"现场"，需要"观众"，需要"陌生人之间的切磋"。你投下一枚硬币，进入的不只是一局游戏，而是一个公共空间里的短暂仪式。这种"现场感"，是客厅里的沙发永远给不了的。

于是，这场往返战争最终的结局，不是谁消灭了谁，而是两种社交方式的并存与合流：**想独享时，你在客厅开机；想共享时，你走进街机厅投币**。游戏机厅把这两种体验摆在一起，就是想让你在几步之间，走完"从客厅到街机"的这段路，重新体会那个"游戏曾经是一种出门活动"的年代。

接下来的五台机器，就是这场往返战争里五个关键的"回合见证"。请跟着动线，从 1977 年的客厅，走到 1990 年的街机厅，亲眼看这场战争如何一步步展开。

## 二、五台入门（每台 150–200 字，可口语化）

### 2.1 Atari 2600（1977）· 奠基区

这是把街机厅"第一次搬回家"的那台机器。1977 年，它把"换卡带换游戏"做成了大众商品——你不再需要去街机厅，在家插上一张卡，就能玩《太空侵略者》。它只有 128 字节内存、画面是"追着电子束跑"画出来的，但它证明了"家用游戏机"这个品类能成立。也别忘了它后来的教训：开放失控、垃圾游戏泛滥，亲手把行业送进了 1983 年的大崩溃。这台机器，既是家用机的奠基者，也是它的第一声警钟。

### 2.2 Famicom（1983）· 复苏区

这是把行业"从废墟里拉起来"的那台机器。1983 年，北美游戏业刚经历大崩溃，没人相信游戏机还能卖。任天堂用两样东西翻了盘：一样是《超级马力欧兄弟》——它第一次让"在家玩到街机级体验"成为现实；另一样是严格的授权体系——它从制度上杜绝了垃圾游戏。它的 PPU 让横版卷轴成为可能，它的十字键成了所有手柄的标配。这台机器，是家用机从"奠基"走向"成熟"的那一步。

### 2.3 Mega Drive（1988）· 16 位主机战争区

这是"把街机厅原样搬回家"的那台机器。世嘉把街机基板的 68000 处理器和 FM 音源直接塞进了家用机，所以它的游戏又快又硬、声音又锐又响——一听就是"街机味"。它靠《索尼克》的高速卷轴和那句"Genesis does what Nintendon't"，跟任天堂打响了著名的"主机战争"。插上它的耳机孔，你能听到 16 位时代最锋利的声音。这台机器，讲的是"速度与态度"。

### 2.4 Super Famicom（1990）· 16 位主机战争区

这是"把游戏画成油画"的那台机器。它没有 MD 那么快，但它有 Mode 7——能把一张 2D 背景旋转、缩放，画出伪 3D 的赛道；它有采样音源——能把游戏音乐从"电子哔哔声"变成管弦交响。它的四键菱形手柄和肩键，成了今天所有手柄的鼻祖。靠《塞尔达》《最终幻想》《时空之轮》这些封神之作，它赢下了 16 位战争的后半程。这台机器，讲的是"色彩与声音"。

### 2.5 Neo Geo MVS（1990）· 街机区

这是街机厅"反超家用机"的那台机器。当家用机把街机体验搬得差不多时，SNK 用 MVS 守住了街机厅最后的地盘——多槽位基板能"换卡不停机"，天价大卡让街机和家用机共享同一份程序，68000 加专门芯片堆出的性能让家用机望尘莫及。但它真正守住的是投币文化：投一枚硬币、听投币音、进入游戏，这份仪式感，是客厅永远复制不了的。这台机器，讲的是"现场"——街机厅里投币、对战、围观的社交体验。

## 三、五机展呈动线建议（年代序 vs 体验序双方案）

### 3.1 双方案对照表

| 维度 | 方案 A：年代序 | 方案 B：体验序（操作直观度） |
|---|---|---|
| 动线顺序 | 2600(1977)→FC(1983)→MD(1988)→SFC(1990)→MVS(1990) | 2600→FC→MD/SFC→MVS |
| 叙事逻辑 | 严格按时间讲"往返战争"的五回合 | 按"从简单到复杂、从家用机到街机"的体验递进 |
| 优点 | 时间线清晰，历史感强 | 观众先易后难，上手体验更顺 |
| 缺点 | 观众需先理解历史背景 | 时间线略乱（MD/SFC/MVS 同年代） |
| 适用 | 成人观众、历史向导览 | 亲子观众、体验向导览 |

**建议**：以**方案 A（年代序）为默认动线**（契合"往返战争"主线的时间叙事），但在 MD/SFC 两台之间设"双雄对比台"（并列摆放），在 MVS 设"投币体验点"（观众可投币体验），用两个"体验锚点"弥补年代序在体验上的不足。即"年代序骨架 + 体验锚点点缀"。

### 3.2 给 04 线台本化的移交说明

- 主线"客厅→街机的往返战争"五回合（搬回家→重建秩序→16 位争霸→街机反超→平衡），可直接作展厅导语与分区导语的文字底本。
