- **来源**：S197–S198。

### 2. IBM 7090（C-MF-000007）

- **定位**：晶体管化科学计算主力，登月时代算盘。
- **年代**：1959 年。
- **参数**：36 位字长，晶体管，磁芯存储（「需核实」）。
- **镇馆分量**：B 档——「科学计算主力」，FORTRAN 舞台。
- **来源**：S199–S200。

### 3. IBM 7030 Stretch（C-MF-000009）

- **定位**：超级计算机先驱，超标量/流水线先行者。
- **年代**：1961 年。
- **参数**：流水线 + 指令前瞻 + 纠错内存（「需核实」）。
- **镇馆分量**：B 档——「超前设计」，影响 System/360 与现代 CPU。
- **来源**：S201–S202。

### 4. Ferranti Atlas（C-MF-000084）

- **定位**：虚拟内存与分页先驱，欧洲最强计算机之一。
- **年代**：1962 年。
- **参数**：一级存储 + 分页 + 页面替换（「需核实」）。
- **镇馆分量**：B 档——「虚拟内存先驱」，启发 Multics/现代 OS。

### 5. Cray-2（C-SC-000006）
