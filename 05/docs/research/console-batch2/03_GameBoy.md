## (a) 概述与历史地位

### a.1 地位一句话

Game Boy 是任天堂于 1989 年 4 月 21 日在日本发售的 8 位掌上游戏机，是横井军平"枯萎技术的水平思考"哲学的集大成之作 [S44]。它以"够用的硬件 + 杀手级软件"开辟了手提机这一全新品类，靠《俄罗斯方块》捆绑版与《宝可梦》系列席卷全球，累计销量约 1.18 亿台（含 Game Boy Color），是有史以来最畅销的掌机之一 [S44]。

## (c) 工作原理（框图 + 数据流 + 关键芯片职能）

### c.1 系统框图（ASCII）

### c.2 数据流（FR-C 信号流动画素材）

1. **开机**：上电 → LR35902 从卡带程序入口启动，初始化屏幕与声音。
2. **游戏主循环**：LR35902 执行游戏逻辑，把画面数据写入 VRAM（背景图 + 精灵）。
3. **屏幕渲染（LCD 控制器）**：LCD 控制器读 VRAM，逐行刷新 160×144 点阵、4 级灰度画面。
4. **声音**：LR35902 写声音寄存器，4 声道合成音效，经扬声器/耳机输出。
5. **输入/联机**：十字键与按键读入；Game Link 口与另一台 GB 通信（对战/交换）。

## (e) 百科卡（≥2500 字成品文案）

### e.1 标题区

**Game Boy**
1989 年 · Nintendo（日本）
掌上游戏机 · 8 位 · 卡带式

### e.2 正文文案

**把游戏装进口袋的机器。** Game Boy 是任天堂于 1989 年 4 月 21 日在日本发售的 8 位掌上游戏机。它是横井军平"枯萎技术的水平思考"哲学最完美的体现——用早已成熟、成本低廉的技术（单色点阵屏、4 级灰度、8 位定制 CPU），组合出一台耐用、省电、便宜的掌机，再配上《俄罗斯方块》这样的杀手级游戏，硬是开辟出"手提机"这一全新的游戏品类 [S44]。

Game Boy 的硬件，在今天看来朴素得近乎简陋：一块 2.6 英寸、160×144 像素、4 级灰度的无背光点阵屏，一颗 Sharp LR35902 定制 CPU，4 声道声音，4 节 AA 电池供电。但正是这份"克制"，成就了它的传奇。横井军平深知，掌机的胜负不在硬件参数的堆砌，而在"能不能随时随地带在身上玩"——于是 Game Boy 做到了：坚固耐摔、电池续航十几到几十小时、价格亲民，成为无数孩子书包里、口袋里、被窝里的第一台游戏机 [S44]。

而让 Game Boy 真正起飞、并让它成为文化现象的，是**《俄罗斯方块》的捆绑**。1989 年，任天堂拿下《俄罗斯方块》在家用机与掌机的版权，把这款由苏联程序员阿列克谢·帕基特诺夫发明的拼图游戏随 Game Boy 捆绑发售。这一商业决策堪称神来之笔——《俄罗斯方块》规则极简、上手即玩、永不过时，又完美契合掌机"碎片时间消遣"的场景。无数原本不玩游戏的人，为了在通勤路上、午休时玩一局《俄罗斯方块》而买下了 Game Boy。"Game Boy + 俄罗斯方块"从此成为电子游戏史上最著名的捆绑组合之一 [S44]。

Game Boy 的生命力，远超它朴素的硬件。1996 年，《宝可梦 红/绿》在日本发售，靠"收集、对战、交换"的玩法与 Game Link 联机线，让 Game Boy 的销量在发售七年后再次爆发，也定义了"掌机联机对战"的范式。《宝可梦》与《俄罗斯方块》一先一后，把 Game Boy 从"一台能玩的掌机"推向了"一代人的共同记忆" [S44]。

商业上，Game Boy 系列（含后期的 Game Boy Color）累计销量约 1.18 亿台，是电子游戏史上最畅销的掌机之一，也奠定了任天堂在掌机市场长达三十年的统治地位。它与家用机 SFC 并肩，让任天堂在 16 位时代同时掌控了"客厅"与"口袋"两个战场 [S44]。

对一座电子博物馆而言，Game Boy 是"手提机破题"叙事的开篇：它以"枯萎技术的水平思考"证明了掌机的成功不靠参数而靠"恰到好处"，以《俄罗斯方块》捆绑证明了"软件定义硬件价值"的真理，以《宝可梦》联机证明了"掌机社交"的可能。它与 MD、SFC 三台并置，构成游戏机厅"16 位竞争 + 掌机兴起"的完整第二段故事。

#### e.2.1 馆方展示定位

在博物馆环境中，Game Boy 建议**独立成区**（"手提机破题"专区），与 MD/SFC 的"16 位主机战争"专区并列。GB 的展示重点在**点阵屏与《俄罗斯方块》捆绑**——观众可点选 LR35902 芯片与 LCD 控制器，看 160×144 点阵 4 级灰度屏如何逐行刷新；一台可玩的 Game Boy 模拟器让观众亲手玩一局《俄罗斯方块》，体会"规则极简 + 碎片时间"的掌机魅力。Game Link 联机线可展示两台 GB 对战《宝可梦》的场景，是"掌机社交"叙事的物理锚点。

#### e.2.2 型号沿革

Game Boy 系列在十四年的生产史中经历了多次迭代：最早的 **初代（DMG-01，1989）** 灰白机身、无背光绿屏，icon 性最强；**Pocket（1996）** 小型化、屏幕更清晰；**Light（1998）** 增加背光；**Color（1998）** 升级为彩色屏。这些迭代的核心（LR35902 + 点阵屏）一脉相承，差异集中在机身尺寸、屏幕背光与彩色。本设备包垂直切片选定初代 DMG-01 造型，最贴近"1989 年手提机破题"的叙事定位 [S44]。初代 Game Boy 那灰白机身与无背光绿屏，是无数人第一台掌机的共同记忆，其"够用就好"的硬件哲学至今仍是掌机设计的经典案例，也是"手提机破题"叙事最具辨识度的视觉符号，值得在展厅中保留一台原机作为镇区之物。

（文案依据 S44/S45；发布前由人工审查核准。）
