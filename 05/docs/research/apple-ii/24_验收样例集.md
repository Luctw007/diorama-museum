# 24 · Apple II 建模验收样例集（通过 / 不过 判定标尺）

> 任务：TASK-35B（05 线 2/2）· 里程碑 M1 · 每个装配体的"通过 / 不过"样例描述集（几何级），作为**人工审查标尺**。
> 用法：审查者对着生成结果，逐条对照下表判断"通过"或"不过"；任何一条命中"不过"即退回。描述为几何级文字，不附图。

## 一、case 机箱（上盖 lid / 下盖 bottom）· 8 条判定描述

| # | 判定维度 | 通过 | 不过 |
|---|---|---|---|
| C1 | 造型圆润 | 四侧角为大半径圆角平滑过渡，前脸/后板无锐利折角，整体"像厨房电器一样平滑" | 直角方盒；或"软化方盒"（小倒角仍显方）；或现代轻薄本式扁平造型 |
| C2 | 合缝线真实 | 上盖与底壳之间是一条**真实的分型缝**（两个独立体的接缝，可分离），合盖后对齐无错位 | 一体成型、用贴图画出假缝（不可分离）；或合缝错位 |
| C3 | 面板卡口配合 | 前脸开孔与键盘外框匹配，四周留约 0.5 mm 装配间隙，边缘倒角 | 卡口比键盘小（嵌不进）；或比键盘大很多（漏大缝）；或卡口无倒角 |
| C4 | 铰链轴 | 上盖绕机箱后缘 +X 轴（Y=+108mm、Z=−222.5mm）掀起 | 上盖绕自身几何中心旋转（掀盖时"飞起"或"穿进机身"） |
| C5 | 内壁厚度 | 上盖有 2–3 mm 实体厚度，掀起后能看到内壁（非背面镂空） | 上盖是单面"纸片壳"，掀起后看到背面镂空/穿帮 |
| C6 | 铭牌凹槽 | 铭牌位只做凹陷的空白槽位，无任何图案 | 铭牌位渲染了彩虹苹果 logo 或 "apple ][" 字样（FR-J2 红线） |
| C7 | 材质 | 米黄 ABS 哑光（metallic≈0、roughness≈0.85），年代感轻微发黄 | 高光塑料（roughness 过低）；或 metallic>0 的金属质感；或纯白/纯灰无年代感 |
| C8 | 面数预算 | LOD1 观察档 ≤800 三角面（lid ≤500、bottom ≤500） | 超预算 1.5 倍（model_check FAIL） |

## 二、keyboard 键盘（键帽阵列 / 底板）· 8 条判定描述

| # | 判定维度 | 通过 | 不过 |
|---|---|---|---|
| K1 | 键数正确 | **52 键**大写（含 RESET，无数字键区、无方向键），行列数符合 52 键布局 | 键数不是 52（如 61 键、63 键）；或多了数字键区/方向键 |
| K2 | 键帽弧面 | 键帽顶面约 0.5 mm 内凹弧面，非平面 | 键帽顶面做平；或做成凸起 |
| K3 | 字符自绘 | 键帽字符为自绘丝印（深色压深米黄底），大写字母/数字/标点/ESC | 用了版权字体；或字符缺失/错位/镜像 |
| K4 | 实例化 | 52 键帽为同一 mesh 的 52 个 node 引用（单键帽 ≤300 面） | 52 键帽逐个独立建模，面数爆炸 |
| K5 | 行列对齐 | 键帽行列严格对齐，行弧（row curvature）自然，无错位/歪斜 | 键帽行列歪斜、间距不均、行弧缺失 |
| K6 | 底板焊盘对应 | 键盘底板 52 个焊盘位与键开关一一对应，无悬空 | 焊盘位与键开关错位，或数量不是 52 |
| K7 | 走线丝印 | 走线用丝印贴图表达（绿色基色 + 金色焊盘 + 白丝印） | 逐根走线做成几何；或走线缺失 |
| K8 | 卡口干涉 | 键盘整块能无干涉嵌入 case 前脸卡口 | 键盘外框比卡口大（嵌不进）或明显过小 |

## 六、样例集用法说明

1. 本样例集是**人工审查标尺**，与自动校验（validate.py R-090 + model_check MR-01~04）互补：自动校验卡"结构/预算/命名"，本样例集卡"像不像、对不对"。
2. 审查者逐条对照，任何一条命中"不过"列即退回，并引用该条编号（如"K1 键数错误"）作为退回原因。
3. case 与 keyboard 各 8 条是 35-B 任务的硬性下限，mainboard/disk_ii/power 的判定描述为补充（第二批建模时再扩充）。
4. 本样例集的"通过"描述与 23 号提示词库的"主提示词"、"不过"描述与"负提示词"一一对应——提示词生成意图、样例集标尺验收，二者同源。
