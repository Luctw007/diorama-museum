## 3. 调度约定

### 3.1 站间迁移条件（三选一，优先级从高到低）

1. **走到触发区**：进入下一站半径（各台本动线总谱半径列）即推进（默认，16 号全程规则语义）；
2. **手动下一步**：HUD [下一步] 按钮（c-accent 主按钮，26 号 token）即推；
3. **超时自动推进**：本站停留时长 +15 s 无交互 → 提示「我们继续」（3 s，sfx_ui_hint_toast）→ 推至下一站触发区（可在设置→导览页关闭；超时推进不打断当时口播，等句末再推）。

- 推进粒度：主站间的推进按 3.1；主站内的子站推进沿用各台本自身触发半径，馆长模式不改变台本既有半径表。

### 3.2 可跳过 / 可回看（与 28 号 demo 状态机一致）

- [跳过]：中断当前站口播（20 号 narr 打断语义：渐弱停+字幕同断）、置本站 visited 灰标、按 3.1 推下一站。
- [回看]：重播本站 C1 解说；或玩家步行返回触发区即可重复触发（同站冷却 5 s 防抖）。
- demo 状态机（28 号三幕）本路线不改造：三幕逐幕 [下一步] 确认、允许逐幕 skip、skip 后该幕演示状态复位（28 号 §5 T-277~T-293 语义沿用）。

### 3.3 馆长路线模式 ↔ 自由漫游一键切换

| 项 | 进入馆长模式 | 退出（回自由漫游） |
|---|---|---|
| 切换入口 | 设置→导览页开关（23 号设置行样式）；或入口 HUD 徽标长按 | 同开关；或连点三次退出钮 |
| 站标 | 亮起当前站/灰未来站（26 号 c-accent/c-dim） | 清空全部站标 |
| 播报 | 按动线序列锁序（后触发打断先触发，16 号规则） | 保留当前口播至句末后停 |
| 自动推进 timer | 启动（§3.1 第 3 项开关生效） | 停止并复位 |
| 三原语 | Inspect/Grab/Point 闭集不变（12 号） | 不变 |
| 状态复位 | — | 触发半径冷却清零、引导语卡隐藏、总结卡保留在出口 |

- 两模式互切不打断已播声音（10 s 内自然收束），不重置参观足迹（35 号 profile.json 不变）。
