# 17 · 电子宠物谱系研究卡（手持谱系补缺）

> 任务 170-A（05 线）· 完成日期：2026-11-08。
> 主题：**电子宠物 / 虚拟养成设备**，非游戏掌机、非输入控制器（与 90-B 掌机谱系、165-B 手柄研究卡不重复）。
> 史实合规：首创/年代/销量等敏感值一律「需核实」；模拟器仅清单级，电子宠物多无成熟开源模拟器，走展示向。

## 一、演进主线导语

电子宠物从「**段码按键养成 → 竞争热潮 → 拟真/毛绒交互 → 机器宠物可动 → 计步+养成融合 → 实体+虚拟账号**」一路走来：从一块段码屏养一只像素宠物，到 1997 年的全球热潮，到会说话会动的毛绒与机器宠物，到把养成装进计步器，再到把实体玩具与虚拟账号绑定。这条线讲的是"人如何把情感寄托在越来越逼真的电子伙伴上"。

## 三、模拟器（清单级）

电子宠物类**多无成熟开源模拟器**，馆内以静态展示 + 原理动画为主；个别有 fan sim / Web 仿真（许可不一，标「需核实」），仅作清单级参考，不下载 ROM / 固件 / 二进制。

## 四、说明
- 每台厂商/年代与游戏机 v2（Tamagotchi/Digimon）及电子宠物增补 v1（G-EP 条）一致，不一致处标「需核实」。
- 本卡为掌机谱系（90-B，止于 GBA）的纵深补缺，与手柄研究卡（165-B，输入控制器）主题不重复。
