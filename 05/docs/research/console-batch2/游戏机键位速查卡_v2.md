# 游戏机键位对照速查卡 v2（2026-11-24）

> 用途：供 04 线台本 / 42 号用例 / 01 线 keymap 生成直接引用，免反复翻各包 runtime。
> 动作名与各包 `runtime.json` 的 `input_map` 完全一致；`map` 为 joystick/keyboard，`key` 为 hat/btn/KEY。
> 本版 v2 在原卡（2026-11-05，7 机）基础上新增 **N64 / Dreamcast / PS2 三机键盘键位**（产包 275-A / 285-A / 295-A 实测），并补登同序列 **PlayStation / Sega Saturn** 两机。

## 一、新增三机键位表（N64 / Dreamcast / PS2）

| 动作 | Nintendo 64 | Sega Dreamcast | PlayStation 2 |
|---|---|---|---|
| 上 | d_pad_up → KEY_UP | d_pad_up → KEY_UP | d_pad_up → KEY_UP |
| 下 | d_pad_down → KEY_DOWN | d_pad_down → KEY_DOWN | d_pad_down → KEY_DOWN |
| 左 | d_pad_left → KEY_LEFT | d_pad_left → KEY_LEFT | d_pad_left → KEY_LEFT |
| 右 | d_pad_right → KEY_RIGHT | d_pad_right → KEY_RIGHT | d_pad_right → KEY_RIGHT |
| 主键 1 | button_a → KEY_A | button_a → KEY_A | button_triangle → KEY_A |
| 主键 2 | button_b → KEY_B | button_b → KEY_B | button_circle → KEY_B |
| 主键 3 | button_c → KEY_C | button_x → KEY_X | button_cross → KEY_X |
| 开始 | start → KEY_ENTER | start → KEY_ENTER | start → KEY_ENTER |

> 三机键名均符合 `^KEY_[A-Z0-9_]+$`；动作名与各包 runtime.json 逐键核对一致。

## 二、补充登记（PlayStation / Sega Saturn）

| 动作 | PlayStation | Sega Saturn |
|---|---|---|
| 方向 | d_pad_up/down/left/right → KEY_UP/DOWN/LEFT/RIGHT | d_pad_up/down/left/right → KEY_UP/DOWN/LEFT/RIGHT |
| 主键 | triangle → KEY_T / circle → KEY_C / cross → KEY_X | button_a/b/c → KEY_A/B/C |
| 开始 | start → KEY_ENTER | start → KEY_ENTER |

> PlayStation 为键盘键位（KEY_T/C/X），与其他键盘机的 KEY_A/B/X 口径不同；Sega Saturn 沿用 button_a/b/c → KEY_A/B/C。

## 三、既有条目沿用核对（原卡 7 机）

原卡 7 机（apple-ii / atari-2600 / famicom / sega-md / neo-geo-mvs / sfc / game-boy）键位沿用不变，逐键核对无误（抽查 atari-2600 / sega-md / game-boy 三台 input_map 动作名与原卡一致）。
