## 2. 三台一页纸结论

| 设备 | 结论 |
|---|---|
| Motorola DynaTAC | 只能静态 + 原理动画。无模拟器；"蜂窝通话链 + 首通电话"为核心讲点；代表"手机史起点"。 |
| Nokia 8110/3310 | 基本只能静态 + 动画（可玩受限）。无成熟功能机模拟器（Symbian/MAME 驱动「需核实」）；"短信 + 换壳 + 贪吃蛇"文化为核心讲点；贪吃蛇可自研复刻。 |
| iPhone 初代 | 只能静态 + 原理动画。无模拟器、iOS 固件红线；"多点触控 + 无键盘"为核心讲点；代表"手机即掌上计算机"。 |

## 3. 给槽位系统的 media_class 建议（手机类）

| 设备 | 建议 media_class | 说明 |
|---|---|---|
| Motorola DynaTAC | `firmware` | 1G 模拟机，无独立介质，通信功能由固件承载 |
| Nokia 8110/3310 | `firmware` | 功能机固件 + SIM 卡；无独立游戏介质 |
| iPhone 初代 | `app_package` | 智能手机，应用以"包"（app package）形态分发 |

> 建议：手机类整体落入 `firmware`（功能机）与 `app_package`（智能机）两档；若需区分，可加 `sim`（SIM 卡）作为通信类辅助介质。

## 4. 开放问题

1. **手机模拟器稀缺**：DynaTAC/iPhone 无模拟器，Nokia 功能机专用模拟器稀少（Symbian/MAME 驱动「需核实」）；"可玩"出口整体依赖"原理动画 + 自研交互演示"。
2. **固件/ROM 红线**：Symbian/iOS 系统镜像受版权保护，本任务只做清单级引用、未下载任何固件；真跑须单独走合规流程。
3. **「需核实」事实**：各台待机/充电时间、体积、分辨率、售价、处理器型号等已集中列出（见各章 (b) 末）。
4. **"信号进化长廊"构思**：本厅独特的"1G→2G→3G 信号进化"叙事主线，建议后续展陈设计落地为"信号进化长廊"展项（详见 00 总览）。
