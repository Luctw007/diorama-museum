## 三、镜像收口要求

1. **内容包 + 目录 jsonl 同步镜像**：镜像 univac-1 / cdc-6600 / cray-1 时，`sync_monorepo.py` 须同时
   收口内容包目录与 `计算机大类_目录_v2.jsonl`（含反链行），不能只镜像内容包漏镜像目录反链。
2. **cray-1 反链前置**：cray-1 目录条目（C-SC-000003）须先由 03 线回填 `device_id=cray-1` +
   `status=done`，镜像后才 catalog_ref 0 FAIL；未回填即镜像 → REF-02 反链缺失 1、门禁红。
3. **镜像后 catalog_ref 预期**：univac-1 / cdc-6600 已反链，cray-1 回填后，镜像 catalog_ref 应
   REF-01~04 全 0 · FAIL 0；镜像门禁 `pkg:*` 从 34 台增至 37 台 ready（+3）。
4. **REF-03 台账漂移说明**：registry 1583 含刚 allocate 的 `C-PC-000208`（Apple IIe，TASK-202-A），
   尚未回填目录（目录使用 1582），故"未使用 1 条"；待 05 线产 Apple IIe 包回填目录条目后归零。
5. **降级口径**：镜像期若 cray-1 反链确未回填、又必须镜像，`catalog_ref` 可临时降级为"仅报告不硬判"
   （REF-02 的 cray-1 一项提示不计 FAIL），**cray-1 反链回填后须立即转回硬判**——降级窗口不得跨轮次。
