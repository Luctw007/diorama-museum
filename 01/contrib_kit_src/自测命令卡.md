# 自测命令卡（contrib_kit v1）

> 三行命令，跑通即达包级及格线。Windows PowerShell 与其它平台同义替换路径即可。

## 1. 校验内容包（核心）

```powershell
python tools/validate/validate.py <你的包路径>
# 期望输出末行：总计 N 条：PASS N，FAIL 0
# 退出码 0 = 通过；1 = 有 FAIL（逐条读报告修复）
```

正例参考（内置样例的话术）：包内应含 meta.json / runtime.json / THIRD_PARTY.md /
annotations/annotations.json（目录结构见《提交清单.md》）。

## 2. 专项目查（可选但建议）

```powershell
python tools/validate/model_check.py <你的包路径>   # 网格/节点名检查
python tools/validate/audio_check.py <你的包路径>   # 音频资产检查
python tools/validate/catalog_check.py <你的目录jsonl路径>   # 目录条目检查
```

## 3. 常见 FAIL 对照表

| FAIL 规则 | 常见原因 | 修法 |
|---|---|---|
| R-001/R-0xx id 类 | device-id 非 kebab-case（大写/下划线/中文） | 改 id 为 `^[a-z][a-z0-9]*(-[a-z0-9]+)*$` |
| R-089 era | era 不在声明范围 | 核对年代字段取值 |
| R-090 gltf | glTF 网格节点名与 node_id 不对应 | 节点名 = 部件 id（一字不差） |
| R-091 THIRD_PARTY | 三件套缺分档或 URL 或日期 | 按《提交清单.md》补全每一行 |
| R-086 键名 | input_map 键名/动作名非法 | 用 KEY_*(键盘)/axis_*/btn*(摇杆) 等合法形态 |

跑不通过不要提交；任何一行「需核实」不构成 FAIL，但请留在文档里不要删除。
