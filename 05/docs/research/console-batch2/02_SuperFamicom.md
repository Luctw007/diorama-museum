## (a) 概述与历史地位

### a.1 地位一句话

Super Famicom（Super Family Computer，简称 SFC，北美名 Super NES/SNES）是任天堂于 1990 年 11 月 21 日在日本发售的 16 位家用游戏机，是 16 位时代的巅峰之作 [S41]。它以 Mode 7 旋转缩放与 S-SMP 采样音源重新定义了"游戏可以多好看、多好听"，全球销量约 4910 万台，反超先发的 Mega Drive，成为 16 位时代最畅销主机 [S41]。

| 宫本茂 | 主导《超级马力欧世界》《塞尔达传说：众神的三角力量》 |

### a.4 版本差异（垂直切片选定建议）

SFC/SNES 有多个硬件修订（初代 SHVC → 后期单芯片 1CHIP），核心（5A22 + S-PPU + S-SMP）不变。本批建议垂直切片选定**初代 Super Famicom（1990）**：灰白配色 + 四色 logo，icon 性最强；运行档 NTSC 60Hz。`[TBD]` 由作者拍板。

## (c) 工作原理（框图 + 数据流 + 关键芯片职能）

### c.1 系统框图（ASCII）

```
              卡带（62 针 ROM，可含增强芯片 Super FX 等）
                        │
  ┌─────────────────────▼─────────────────────┐
  │                  主机主板                    │
  │                                            │
  │  ┌──────────┐    ┌─────────────────┐        │

  │  │  5A22    │    │ (图像处理器×2)  │        │
  │  │ (主 CPU) │    └─────────────────┘        │
  │  └────┬─────┘                               │
  │       │                                     │
  │  ┌────▼─────┐    ┌───────────────┐          │
  │  │  S-SMP   │───►│   S-DSP      │──► 立体声  │
  │  │(SPC700)  │    │ (8通道 PCM)  │          │
```

### c.2 数据流（FR-C 信号流动画素材）

1. **开机**：上电 → 5A22 执行卡带程序入口，初始化 PPU 与声音。
2. **游戏主循环**：5A22 执行游戏逻辑，把背景/精灵数据写入 VRAM（经 S-PPU）。
3. **图形渲染（S-PPU）**：S-PPU1 与 S-PPU2 协作，按 Mode 0–7 渲染背景层与精灵；**Mode 7** 对单背景层做仿射变换（旋转/缩放），产生"伪 3D"效果 [S42]。
4. **声音（S-SMP）**：5A22 把音乐数据交给 S-SMP（SPC700 内核），S-SMP 驱动 S-DSP 播放 8 通道 PCM 采样（ADPCM），输出立体声 [S42]。
5. **输入**：手柄按键经串行口读入，5A22 读取判定。

### c.3 关键芯片职能（C2/C3 标注文案素材）

| 芯片/子系统 | 职能（一句话草稿） | 来源 |
|---|---|---|
| Ricoh 5A22 | 主 CPU：执行游戏逻辑，含 DMA/乘除辅助 | S41/S42 |
| S-PPU1/S-PPU2 | 图像处理器：Mode 0–7 渲染，Mode 7 旋转缩放 | S42 |
| S-SMP（SPC700） | 声音处理器：驱动采样音源 | S41/S42 |
| S-DSP | 8 通道 PCM 采样回放（ADPCM） | S42 |
| 增强芯片（卡带内） | Super FX/SA-1/DSP 扩展图形与逻辑能力 | S41/S42 |

## (e) 百科卡（≥2500 字成品文案）

### e.1 标题区

**Super Famicom**（北美名 Super NES / SNES）
1990 年 · Nintendo（日本）
家用游戏机 · 16 位 · 卡带式

### e.2 正文文案

**把游戏画成油画的机器。** Super Famicom 是任天堂于 1990 年 11 月 21 日在日本发售的 16 位家用游戏机，在北美叫 Super NES（SNES）。它是 Famicom 的正统继承者，也是 16 位时代的巅峰之作。发售当天，30 万台的初期出货在几小时内被抢购一空，甚至有报道称连黑社会都盯上了这批稀缺的机器——人们对任天堂下一代的期待可见一斑 [S41]。

SFC 的开发哲学，与它的对手世嘉 Mega Drive 截然不同。世嘉追求"原始的速度"，而任天堂选择了一条更内敛、更注重"平衡与美学"的道路。他们没有盲目追求最快的 CPU，而是选了一颗主频温和的 Ricoh 5A22（基于 65C816 内核），把真正的宝押在了两个领域：**图形与声音** [S41]。

图形上，SFC 的双图像处理器（S-PPU1 + S-PPU2）带来了 32768 色的调色板与 256 色同屏显示——画面从 FC 时代明快但略显单调的色块，一跃进入细腻过渡、柔和光影的"油画"时代。而最石破天惊的，是被称为 **Mode 7** 的图形功能：它能对单个 2D 背景层做实时缩放、旋转和扭曲，在 3D 技术尚未普及的年代制造出"伪 3D"的视觉幻术。当玩家在《F-Zero》里驾驶飞船于立体赛道上飞驰、在《超级马力欧赛车》里体验漂移过弯的离心力时，那种前所未有的空间感与沉浸感，正是 Mode 7 创造的 [S41][S42]。

声音上，SFC 搭载了由索尼工程师久夛良木健设计的 **S-SMP 采样音源**：一个 8 通道的 PCM 采样系统，能回放真实的乐器采样（ADPCM 压缩）。游戏的背景音乐从此告别了 FC 时代单调的电子音，进化为可以媲美 CD 音质的管弦乐、钢琴与合成器交织的交响。当《最终幻想 VI》的序曲响起，那融合管风琴与合成器、充满宿命感的旋律，宣告电子游戏音乐正式步入艺术殿堂 [S41][S42]。

SFC 的游戏库，被普遍认为是史上最伟大的阵容之一。《超级马力欧世界》定义了横版平台跳跃的新高度，《塞尔达传说：众神的三角力量》确立了俯视动作冒险的范式，《超级银河战士》《超级恶魔城》《最终幻想 VI》《时空之轮》各自封神。它的手柄也确立了现代手柄的基本布局——四键菱形（A/B/X/Y）+ 左右肩键（L/R），这个设计至今仍是几乎所有手柄的标配 [S41]。

商业上，SFC 以约 4910 万台的全球销量，最终反超了先发的 Mega Drive，成为 16 位时代最畅销的主机。它与 Mega Drive 的那场"主机战争"，被后世视为电子游戏史上最经典、最富戏剧性的竞争之一 [S41]。

对一座电子博物馆而言，Super Famicom 是"16 位时代"叙事的巅峰：它以 Mode 7 展示了"专用图形硬件的魔力"，以采样音源展示了"游戏音乐的艺术化"，以四键菱形 + 肩键的手柄奠定了现代控制器的基础。它与 Mega Drive 一前一后，一台讲速度与态度、一台讲色彩与声音，共同构成游戏机厅"16 位双子星"的完整故事。

#### e.2.1 馆方展示定位

在博物馆环境中，Super Famicom 与 Mega Drive 建议**并列展示**，构成"16 位主机战争"专区。SFC 的展示重点在**Mode 7 与采样音源**——观众可点选 S-PPU 芯片看 Mode 7 的旋转缩放原理，或点选 S-SMP 芯片看采样音源如何回放乐器采样；CRT 演示位轮播《超级马力欧赛车》的 Mode 7 赛道与《最终幻想 VI》的管弦配乐，让观众直观感受"色彩与声音"的 16 位美学。四键菱形 + 肩键手柄是"现代手柄鼻祖"，可作为独立交互件展示，与 Mega Drive 的 6 键格斗手柄形成对照。

#### e.2.2 型号沿革

Super Famicom 在十余年的生产史中经历了多次改款：最早的 **初代 SFC（1990）** 灰白配色、圆润边角、四色 logo，icon 性最强；后期有小型化的 **Super Famicom Jr.（1998）** 与北美的"New-Style SNES"，以及把 S-SMP/S-DSP 合并为单芯片的 1CHIP 版。这些改款的核心（5A22 + S-PPU + S-SMP）自始至终未变，差异集中在机箱造型与主板集成度。本设备包垂直切片选定初代 SFC 造型，最贴近"1990 年 16 位时代巅峰"的叙事定位 [S41]。

## (f) 原理大纲 + C4 动画选题

### f.1 原理大纲

1. **Mode 7 伪 3D**：单背景层仿射变换如何制造旋转缩放的"伪 3D"。
2. **采样音源**：S-SMP 如何回放 8 通道 PCM 采样。
3. **双 PPU 协作**：S-PPU1/S-PPU2 如何分工渲染。
4. **增强芯片**：卡带内 Super FX/SA-1 如何扩展能力。

### f.2 C4 动画选题（≥1 支，含分镜轮廓）

**选题 1 ·《Mode 7：二维材料搭出三维景深》**（核心）

| 分镜 | 画面 | 解说要点 |
|---|---|---|
| 1 | 一张平面的赛道俯视图 | "Mode 7 处理的只是一张 2D 背景" |
| 2 | 背景开始旋转、缩放、拉伸 | "S-PPU 对这张背景做仿射变换" |
| 3 | 玩家视角看赛道扑面而来 | "旋转 + 缩放 = 伪 3D 的赛道" |
| 4 | 《F-Zero》《超级马力欧赛车》画面 | "这就是 16 位时代的空间魔术" |

**选题 2 ·《采样音源：从电子音到交响乐》**（备选）

分镜轮廓：FC 的方波电子音 → S-SMP 载入乐器采样 → 8 通道叠加 → 管弦乐式配乐 → 收束到"游戏音乐的艺术化"。

## (g) 模拟器结论

### g.1 选型结论

**首选 Snes9x，MAME `snes` 作交叉验证。**

- **Snes9x**：**类 MIT + 非商业限制**（custom license，MIT-like with non-commercial clause）· 官网 https://www.snes9x.com · 仓库 https://github.com/snes9xgit/snes9x 。成熟、兼容性极广的 SFC 模拟器 [S43]。
- **MAME `snes`**：GPL-2.0/BSD-3，与 gw 网关架构同构。

> **许可核实**：Snes9x 的许可为"类 MIT + 非商业使用限制"（Wikipedia 与官方 license 均确认），任务 40-B 书"[需核实]"现已核实为**非商业限制确认**。因含非商业条款，本项目以"独立进程 + 协议"调用、不自带、不重分发，发布前需按许可复核（记入 04 号开放问题）。

### g.2 ROM/卡带合法获取渠道文案草稿（FR-E3 风格）

> 运行一台 Super Famicom 需要卡带 ROM，这些游戏多数仍受版权保护，本项目**绝不内置、也不提供任何卡带 ROM**。合法途径：① 从你合法拥有的 SFC 卡带上提取 ROM 作个人备份；② 版权方授权渠道（如任天堂官方合集、Virtual Console / Switch Online 会员库）；③ 明确授权的自制游戏。向导只负责"解释 + 引导导入"，不提供盗版下载点。
