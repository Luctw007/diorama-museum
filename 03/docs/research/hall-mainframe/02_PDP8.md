## (a) 概述与历史地位

PDP-8（Programmed Data Processor-8）由数字设备公司（Digital Equipment Corporation，DEC）于 1965 年推出，被普遍认为是**第一台取得商业成功的小型计算机（minicomputer）** [S35][S31]。它最直接的冲击在于价格：基础配置仅约 18,000 美元，把此前动辄数十万美元的"计算机"第一次拉到了一个实验室、一条产线、一间教室也买得起的价位 [S35]。1966 年推出的简化版 PDP-8/S 甚至跌破 10,000 美元，进一步把计算机从"机房里的稀缺资源"变成"可以单机专用的小型工具" [S35]。

PDP-8 的"小"是全方位的：12 位字长、仅 4,096 字的磁芯内存、前面板上一排拨动开关与指示灯。它没有操作系统（早期型号），程序员直接通过面板开关逐字键入机器码，或用汇编器（PAL，Program Assembly Language）写好程序后经纸带加载。这种"赤裸裸、看得见、摸得着"的机器，反而成了整整一代计算机教育者的最爱——因为学生可以直接看到每一根数据线、每一个状态灯的变化 [S35]。

PDP-8 的遗产远超它的体量 [S35]：

1. **普及了"小型机"这一品类**：它证明存在一个介于大型机与专用控制器之间的巨大市场，直接催生了随后爆发的 DEC PDP-11、Data General Nova、HP 2100 等竞争机型。
2. **把计算机带入实时控制与实验室自动化**：得益于便宜、可单机专用，PDP-8 被广泛用于核物理实验数据采集、过程控制、医学检测、工业测控等"计算机与真实世界对话"的场景 [S35]。
3. **教育普及**：DEC 的"Edusystem"以 PDP-8 为平台，让大量学生第一次亲手编写并运行程序，成为早期计算机教育的标志 [S35]。
4. **技术思想传承**：其 OMNIBUS 总线（PDP-8/I 起）与 Flip Chip 模块化插卡设计，为后来 PDP-11 的 Unibus 与更模块化的小型机设计铺路 [S35]。

从大型机到 PDP-8，计算机完成了一次意义深远的"下放"：它不再是少数机构才能拥有的庞然大物，而开始走进普通实验室、工厂车间和课堂。

## (c) 工作原理

### 系统框图（ASCII）

```

                        │        PDP-8 整机             │
                        └──────────────────────────────┘
                                  │
        ┌─────────────────────────┼─────────────────────────┐
        │                         │                         │
        ▼                         ▼                         ▼
 ┌──────────────┐        ┌────────────────┐        ┌────────────────┐
 │   累加器 AC    │◀──────▶│   磁芯存储器     │        │  前面板         │
 │   (12 位)      │  数据  │   4,096 字 × 12  │◀──────▶│  · 拨动开关      │

 └──────────────┘        └────────────────┘  键入  └────────────────┘
        │  ▲                                             │  ▲

        ▼  │                                            ▼  │
 ┌──────────────────────────────────────────────┐   ┌────────────────┐
 │           控制逻辑 / 微程序译码                │   │  I/O 设备        │

 └──────────────────────────────────────────────┘   └────────────────┘
                                  │
                                  ▼

                        │  OMNIBUS 总线(I 起) │  ← 统一背板，插卡扩展
                        └────────────────────┘
```

### 数据流说明

1. **面板键入（手动引导）**：早期无 ROM 引导，操作员用前面板拨动开关设定地址（Load Address），再逐字拨入指令（Deposit），最后按 Run 启动——这是 PDP-8 最具"仪式感"的交互 [S35]。
2. **取指—译码—执行**：程序计数器 PC 给出当前指令地址，12 位指令字被取出；指令分"存储器访问类 / 操作类 / I/O 类"三族，经微程序译码后执行 [S35]。
3. **累加器与链接位**：几乎所有运算都围绕唯一的累加器 AC 与 1 位链接 L 进行；TAD（补码加）、AND 等指令直接操作 AC [S35]。
4. **纸带 I/O**：程序与数据经高速纸带读入机加载，结果经穿孔或电传打字机输出 [S35]。

### 关键子系统职能

- **磁芯存储器（Core Memory）**：以电流写入、破坏性读出 + 回写的磁芯阵列，是 12 位字的存储载体；断电不丢失 [S35]。
- **累加器 + 链接位（AC / L）**：单一累加器架构的典型代表，链接位承载进位/溢出，是理解"极简 CPU"的最佳教具。
- **微程序译码逻辑**：把 12 位指令的高 3 位操作码展开为控制信号序列，驱动数据通路。
- **前面板（Front Panel）**：拨键与指示灯构成的"人机接口"，是早期小型机"看得见的运行状态"的核心展陈亮点 [S35]。
- **OMNIBUS 总线（PDP-8/I 起）**：统一背板总线，让 CPU、内存、I/O 以标准化插卡方式互联，是模块化小型机设计的代表 [S35]。

> 以上职能描述即未来 FR-C 原理标注素材底稿。

## (d) 装配体层级树草案

```
PDP-8 整机（桌面/机架式机箱）
├── 机箱结构（Chassis / 前面板 + 机架 + 电源笼）
├── 电源子系统（+5V 逻辑、磁芯驱动电源）
├── CPU 板组
│   ├── 累加器/链接位板
│   ├── 程序计数器 + 存储地址寄存器板
│   ├── 指令译码/微程序控制板
│   └── 算术逻辑（TAD/AND 逻辑板）
├── 存储器子系统
│   ├── 磁芯存储体（4K×12 磁芯板 ×N）
│   └── 磁芯驱动/读出放大板（X/Y 驱动、检测放大）
├── 前面板子系统
│   ├── 开关阵列（地址/数据拨键）
│   └── 指示灯阵列（AC/PC/状态灯）
└── I/O 子系统（OMNIBUS 插卡）
    ├── 纸带读入/穿孔接口卡
    ├── 电传打字机接口卡
    └── 其他外设控制器（扩展）
```

**逐层要点与建模拆解预算评估：**

- **整机→板卡**（约 10–20 节点）：PDP-8 体量小，Flip Chip 插卡是天然的"板级组合体"，拆解动画可在整机与板卡两层间流畅切换。
- **板卡→元器件**（每板数十至数百元件）：PDP-8 用 TTL 与分立元件，磁芯板更有上千磁芯孔；**建议**：磁芯板用"磁芯阵列纹理 + 少量放大特写"表现，逻辑板以"板级组合体"呈现，仅 1 块教学板（如累加器板）做逐元件展开。
- **难度点**：① 磁芯存储的微观读写原理抽象，需动画（电流 → 磁化翻转 → 读出脉冲）；② 前面板拨键交互是"可玩"灵魂，建议保留有限的"拨键 → 状态灯联动"交互；③ OMNIBUS 背板走线密集，需在真实感与可读性间取舍。

## (e) 百科卡全文（C1 级成品文案）

**DEC PDP-8 —— 把计算机从机房搬进实验室的那台机器**

1965 年，一家名叫 DEC 的公司卖出了一台标价约 18,000 美元的计算机 [S35]。在今天，这个价格连一台普通笔记本都未必买得到；但在当时，它意味着一个前所未有的转折——计算机第一次便宜到**一个实验室、一条产线、一间教室就能单独拥有一台**。

这台机器叫 PDP-8，字长只有 12 位，内存只有 4,096 个字。它小到能放进一个机柜，前面板上是一排排拨动开关和红绿指示灯。要让它跑起来，你得亲手拨动开关、一个地址一个地址地把程序"敲"进去，再看着那排灯随着运算一闪一闪 [S35]。和它同代的 IBM 大型机相比，PDP-8 简直像个玩具。

但恰恰是这种"小"，带来了革命。过去，计算机是稀缺资源，几十个科学家排队申请机时，还要靠专业的操作员代劳。PDP-8 让"计算机属于使用者本人"成为可能：做实验的物理学家、管产线的工程师、教编程的老师，都可以把 PDP-8 直接搬到自己的实验室或教室，随时用、自己用 [S35][S31]。DEC 把这种机器叫做"小型机"（minicomputer），一个新品类就此诞生。

PDP-8 为什么能这么便宜？秘密在于它把"通用性"换成了"专一性"。大型机要同时伺候几十个用户、跑各种复杂任务，所以必须又大又贵；而 PDP-8 一次只服务一件事——采集一次实验数据、控制一条产线、教一个学生写程序。既然任务单一，机器就可以做得极小、极简。这种"够用就好"的务实哲学，正是小型机商业成功的底层逻辑 [S35]。

PDP-8 的指令集简朴得近乎诗意：一个累加器（AC）加一个 1 位的链接位（L），几条基本指令就能写程序。它没有操作系统（早期型号），程序就靠前面板拨键或纸带一点点喂进去。但正是这种"极简"和"裸露"，反而成了最好的教材——学生们第一次能真正理解"取指、译码、执行"到底在硬件里怎么发生，因为每一盏灯、每一根数据线都清清楚楚 [S35]。DEC 顺势推出的"Edusystem"，让整整一代程序员是在 PDP-8 上写下人生第一行代码的。

它的应用同样接地气：核物理实验室用它采集粒子数据，工厂用它控制生产线，医院用它做检测分析，甚至早期的分时系统、文字处理、棋类游戏也都在这台小机器上出现过 [S35]。PDP-8 证明了一件事——计算机的价值，不在于它有多大，而在于它能不能"正好"解决你的问题。

从大型机到 PDP-8，计算机完成了一次"下放"：它不再属于少数机构，而开始属于每一个用它解决问题的人。今天，当你桌上的电脑、车里的芯片、工厂里的控制器各自独立运转时，别忘了那第一台"便宜到能搬回家"的 PDP-8，正是这一切的开始。

**可以这样玩**：站在前面板前，试着像当年的程序员一样，拨动一排开关，把一小段程序"敲"进去，再按下启动，看着那排灯随着你的程序一闪一闪——那一瞬间，你会第一次真正"看见"计算机在工作。

---

**深度解读一：磁芯，是"看得见的记忆"。** PDP-8 的主存是一块磁芯板——上面密密麻麻布满了成千上万个小磁环，每个磁环用两条细线穿过，一条是行线、一条是列线。要写入一个"1"，就通电流把磁环磁化到某个方向；要写入"0"，就磁化到反方向；要读出来，就反过来感应磁环翻转时发出的微弱脉冲 [S35]。最妙的是，磁芯断电也不丢数据——你关了机器，那些"0"和"1"还静静地待在磁环里。这种"看得见、摸得着、还断电不丢"的记忆，是今天用惯了闪存的人难以想象的物理直观。

**深度解读二：前面板，是最早的"人机界面"。** PDP-8 前面板上一排排的拨动开关和指示灯，是那个年代计算机与人类对话的唯一方式 [S35]。没有屏幕、没有键盘（早期连键盘都没有），程序员要"写程序"，就得记住每条指令的二进制编码，一个地址一个地址地拨进去。这听起来笨拙，却有一种奇妙的"透明"：你能亲眼看到程序计数器在走、累加器在变、状态灯在闪——计算机的"思考"过程，赤裸裸地摊开在你面前。对学习者来说，没有比这更直观的教材了。

**深度解读三：LINC、PDP-12 与"实验室计算机"的血脉。** PDP-8 并非孤立存在，它身后是一整条"实验室计算机"的血脉。DEC 后来把 PDP-8 与 LINC（一台早期为生物医学实验设计的机器）融合成了 PDP-12，把"计算机直接连上实验仪器、实时采集数据"这一理念发扬光大 [S35]。今天医疗设备、科学仪器里嵌入的专用计算机，其"计算机与真实世界对话"的源头，正是这条血脉。

**深度解读四："小型机"这个词，改变了计算机的定位。** PDP-8 之前，人们问的是"我们机构要不要买台计算机？"；PDP-8 之后，问题变成了"我们的实验室、车间、教室，各自该买哪台？" [S35]。它把计算机从"集中共享的稀缺资源"变成了"分散专用的日常工具"。这一转变的影响延续至今——今天你家里每一个"各自独立"的智能设备、车里的每一颗控制芯片，都是 PDP-8 开创的"专用小型化"路线的远房后代。

**关键参数（面向玩家）：** 12 位字 · 磁芯内存 4,096 字 · 累加器 + 链接位 · 前面板拨键编程 · 约 18,000 美元起 · 1965 [S35]。

**参考来源：** [S31][S35][S39]。

## (f) 原理讲解大纲（C2/C3/C4）

- **C2（框图层）**：标注"CPU / 磁芯存储 / 前面板 / I/O"四大功能区；高亮"累加器 + 链接位"这一极简数据通路。
- **C3（信号流层）**：标注三类信号——① 数据通路（磁芯 ↔ AC，12 位）；② 控制信号（取指/译码/执行时序）；③ 面板信号（拨键写地址/数据、状态灯回读）。建议做"一次加法"逐拍动画：从磁芯取数 → 累加器相加 → 结果写回。
- **C4（原理动画）**（分镜轮廓见下）：

**分镜 1《拨出来的程序》**：特写前面板，一双手拨动开关逐字键入一段程序，指示灯随键入逐位亮起，字幕解释"这是最早的'编程'方式之一"。

**分镜 2《磁芯里的 0 和 1》**：镜头"钻进"磁芯板，放大单个磁芯环，展示电流穿过 → 磁化翻转 → 读出脉冲的微观过程，点题"断电也不丢的记忆"。

**分镜 3《一次加法》**：数据通路动画——磁芯取数点亮、累加器翻转、结果写回磁芯，配合逐拍高亮。

**分镜 4《从机房到实验室》**：分屏对照大型机机房与 PDP-8 实验室场景，字幕点题"计算机的下放"。

## (g) 模拟器/演示可行性

**已有开源/可用模拟器现状：**

1. **SIMH "Classic"（Bob Supnik 维护的 3.x 流）**：SIMH 是覆盖历史计算机的多系统模拟器，其中 PDP-8 模拟器成熟、文档齐全，可运行 FOCAL、引导程序及大量历史软件 [S40][S43]。**许可：MIT-style（modified MIT）开源许可** [S40]。
2. **Open SIMH（V4 流）**：SIMH V4 的治理化后续项目，同样包含 PDP-8 模拟器，仓库 `https://github.com/open-simh/simh` [S41]。**许可：MIT-style / BSD** [S41][S42]。
3. **其他 PDP-8 实现**：存在若干独立 PDP-8 模拟器/仿真器（如各类教育用实现），成熟度与许可各异，此处仅列清单级参考，**「需核实」** 具体项目名与许可。

**结论：能跑（生态成熟，入门友好）。**

- **能跑**：用 SIMH 的 PDP-8 模拟器，可真实运行 FOCAL（DEC 的解释型语言）与纸带引导程序，体验"拨键/纸带加载 + 电传打印"的完整流程 [S40]。
- **不能跑/不建议**：宣称"逐拍仿真磁芯读写微时序"——SIMH 是功能级（指令级）模拟，非周期级；且 PDP-8 指令集极简，可玩内容需围绕 FOCAL/引导程序设计，避免"裸机一片空白"。
