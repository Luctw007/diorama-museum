## 一、引擎实装需求（字段定义 + 挂载位置）

| 项 | 口径 |
|---|---|
| 字段名 | `co_active_max`（snake_case，与既有 `max_running` 同风格） |
| 语义 | **同屏激活上限**：同一画面内同时处于「激活态」（拆解中 / 运行中）的设备数上限 |
| 默认值 | **3**（规范 v0.7 章 B 现默认，未实测前保持占位） |
| 类型/导出 | `@export_range(1, 6) var co_active_max: int = 3`（建议上限 6，供实测梯度放宽） |
| 与 `max_running` 显式区分 | `max_running` = **同厅运行配额**（全厅同时接模拟器真跑的台数，`@export_range(1,4) var max_running=1`，exhibit_layout_spec §3，B-03 已 PASS）；`co_active_max` = **同屏激活上限**（拆解/激活态并发，与真跑无关）。两者**独立**、不合并、不互相覆盖 |
| 挂载位置建议 | 设备激活管理路径：`exhibit_host.gd`（展厅宿主，持有 `_running_id`/激活计数，见 L157-198）——新增同屏激活计数 `_active_ids`（或复用 portal_hub 大厅聚合），当同屏激活数达到 `co_active_max` 时拒绝新增激活（提示「同屏激活已达上限」） |
| 计数口径 | 激活态 = 进入拆解/运行且未退出的设备；退出激活态即释放名额（对齐 261-A `get_depth_level` 退出时分档记录语义） |
