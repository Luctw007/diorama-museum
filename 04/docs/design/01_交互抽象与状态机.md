## 1. 三层输入抽象

ADR D2 规定桌面与 VR 共用同一套交互抽象，平台差异只存在于输入适配层。本规格将输入管线固定为三层：

```
┌─────────────────────────────────────────────────────────────┐
│ 第 3 层  玩法动作（Gameplay Actions）                        │
│   开盖 / 拆下零件 / 回装零件 / 一键复原 / 开导览卡 /          │
│   高亮原理 / 开机 / 关机 / 快照 / 打开设置 ……               │
│   由内容与功能需求（FR-*）定义，与平台无关                    │
├─────────────────────────────────────────────────────────────┤
│ 第 2 层  交互原语（Interaction Primitives）★ ADR D2          │
│   Inspect（观察） / Grab（抓取） / Point（点选）             │
│   全平台唯一、仅三条；UI 与 3D 场景共用                       │
├─────────────────────────────────────────────────────────────┤
│ 第 1 层  设备输入（Raw Device Input）                        │
│   桌面：鼠标移动/按键/滚轮/键盘                              │
│   VR：左右手柄 6DoF 位姿/扳机/握持/摇杆/按钮                │
│   本层唯一允许平台分歧的地方                                  │
└─────────────────────────────────────────────────────────────┘
```

**映射方向**：设备输入 →（输入适配层合成为原语参数）→ 交互原语 →（玩法层按当前状态与命中目标解释）→ 玩法动作。玩法层**不得**直接读取第 1 层信号；新增平台只改第 1→2 层适配，第 2→3 层零改动。

**原语合成示例**：
- 桌面「拖动画面」= 鼠标左键按住 + 光标位移 → 合成为一条 `grab(起始命中物, 拖拽增量)` 或 `inspect(旋转增量)`，取决于按住时命中的目标类型。
- VR「转动设备」= 双手对设备同时 `grab` → 输入适配层合并两柄的相对位姿变化 → 合成为 `inspect(双手联合旋转)`。**桌面没有双手概念，但第 3 层看到的仍是同一条 inspect 旋转意图**——这正是 ADR D2 的落点。

## 2. 三条交互原语规格

### 2.1 Inspect（观察）

**定义**：对场景或设备进行不改变其状态的观察操作——旋转、缩放、平移（桌面译为围绕目标/相机运动；VR 译为双手空间操作）。

| 属性 | 规格 |
|---|---|
| 目标类型 | 整机设备（任意状态）、开盖后的内部装配体（不可拾取观察时）、展厅环境（空点处） |
| 触发 | 桌面：对设备按住左键拖动（或空点处中键拖动/右键拖动平移）；VR：单手对准设备按住「握持键」拖动，或双手同时握住设备后做拉开/并拢（缩放）、扭转（旋转） |
| 旋转轴与范围 | 设备级：绕设备局部 Y 轴（竖轴）无线旋转；绕 X/Z 轴 ±90°；缩放 0.5×–3.0×（以设备包围盒为基准）[TBD/建议值]。展厅级：不限制绕 Y 角，俯仰 −30°–+60° [TBD/建议值] |
| 与 Grab 的区别 | Inspect 中对象**保持装配约束**（零件不随观察分离），只有视点/姿态变化；Grab 中对象**离开约束**（零件被拿起） |
| VR 双手镜射 | 双手各握设备两个「把手点」，系统把两手相对位姿变化实时映射为模型旋转/缩放/平移；任一柄中断（如握持解锁）即回落到单手 Inspect 模式 |

**状态机约束**：`运行中` 状态下 Inspect 可用但禁止「缩放进入机箱内部碰撞体」的穿模视角（见 §4.4）。

### 2.2 Grab（抓取）

**定义**：对可拾取对象（零件、开盖后的上盖、介质盘片）做拾取—移动—放回/脱离装配的操作。

| 属性 | 规格 |
|---|---|
| 可抓对象 | ①设备上盖（`开盖`状态的对象）；②当前拆解层级暴露的装配体/元器件（`拆解中`状态）；③虚拟介质（软盘等，见 02 章运行向导）；④VR 下展厅内少量「可拾物」（导览卡壳体等，桌面以点选等价） |
| 拾取规则 | 一次只能握持一个对象；对象处于「允许脱离」集合且未被动画占用时才可拾取；握持瞬间对象高亮并轻微放大 1.05×（视觉确认） |
| 抓取点 | 内容包在装配体上提供若干 `grab_slot` [TBD：内容包 v0.2 字段，暂以包围盒面心+法向自动推导]（建议值）；桌面不显示抓取点，VR 显示轻微凹槽提示 |
| 移动约束 | 对象随光标/手柄在水平操控面（桌面）或空间自由位（VR）移动；运动受简单物理约束：不与其它装配体发生穿越（碰撞盒），重量感以阻尼系数表现（小零件灵敏、整机上盖迟缓）[TBD/建议值] |
| 松手回弹 | 若松手位置满足「回装判定」（距原位 ≤ 0.15 m 且姿态偏差 ≤ 30° [TBD/建议值]，且遮挡物已清空），播放 0.4 s 卡合动画（平移+旋转插值 + 卡合音效）回装；否则留在当前位置（成为「散件」，见拆解面板）并有轻微下沉/落座动画 |
| VR 抓取姿态 | 手掌对准零件按下握持键即吸附到手部锚点；握持姿态以零件拟合手型的最近标准姿态呈现（水平板件=掌心朝下托举，立面=掌心朝前）；松开握持键即松手 |

### 2.3 Point（点选）

**定义**：以指针（桌面光标 / VR 射线/准星）选定 UI 元素或 3D 目标并触发动作。

| 属性 | 规格 |
|---|---|
| 指针形态 | 桌面：系统光标（UI 上为箭头；3D 标的上为十字+热点圈）。VR：右柄出射线，命中处显示准星；UI 面板命中时射线隐去、面板显示虚拟光标 |
| 选中态视觉规范 | UI：描边高亮 2 px + 底色提亮 8%（色弱安全，见 04 章）。3D 目标：外轮廓发光描边（默认琥珀 #FFC859，见 04 章色弱规范）+ 名称标签浮现；未命中但可点选的目标在首次入视线时做一次 0.3 s 呼吸提示（可关闭，属 H3 舒适性） |
| 触发方式 | 桌面：左键单击（按钮）/左键双击（设备打开导览卡 [TBD：单击双击均可配置]）。VR：扳机短按；长按扳机 0.5 s = 取消 [TBD/建议值] |
| 平台差异 | VR 无「悬停光标记忆」问题，射线抖动大，命中区最小热区 ≥ 0.04 m 直径（3 m 距离）；桌面热区可小至 24 px。同一按钮两个平台的逻辑命中判定一致，仅热区尺寸平台化 |

**Fine rule（防止误触）**：VR 下 Point 扳机按下时，若指针在按下瞬间移动 > 0.02 m [TBD/建议值]，视为「意图拖动」而非点选——交给 Grab/Inspect 处理；桌面同理，鼠标按下后移动 > 5 px 即取消点击语义。

### 2.4 原语参数 / 边界 / 取消规则总表 [v1.0 新增]

| 原语 | 参数（输入适配层产出） | 边界（限额与夹紧） | 取消规则 | 越界反馈 |
|---|---|---|---|---|
| Inspect-桌面旋转 | `delta_px: Vector2` | 俯仰 ±30°（展厅级）；设备绕 X/Z ±90°；缩放 [0.5, 3.0] | 松开左键；切换 UI 层开启（弹层出现时旋转中止） | 达限额播「边界音」+ 光标短暂抖动 [TBD] |
| Inspect-滚轮缩放 | `wheel: float`（格） | 同缩放范围，指数步进 0.1/格 | 离开目标命中保持当前倍率 | 达极值不缩放（音效提示） |
| Inspect-VR 双手 | `span_delta, angle_delta, mid_delta` | 同上；跨度过小（<0.05 m）时锁定缩放（防抖） | 任一柄握持解锁 → 回落到单手旋转 | 手柄轻微震感 10 ms |
| Grab-拾取 | `hit: Node3D` | 一次一件；对象 ∈ 允许脱离集合；非动画占用 | 拾取中按 Esc/取消键 → 放回原处（不产生散件） | 拒办：拒止音 + 光标 ⦸ |
| Grab-移动 | `delta: Vector3` | 碰撞盒约束（不穿透其余装配体）；阻尼按 mass_class 查表（小件 1.0/上盖 0.4） | 同拾取取消 | 碰撞阻挡时沿切面滑动（无反馈） |
| Grab-松手 | `pos, rot` | 回装判定：距原位 ≤0.15 m 且姿态差 ≤30° 且无遮挡 | 动画期间不可取消（过渡锁）；复原动画可 Esc 跳过 | 不满足判定 → 落座为散件（下沉动画） |
| Point-点击 | `press_pos, release_pos, target` | 桌面热区 ≥24 px；VR ≥0.04 m（3 m 处）；移动阈值 5 px / 0.02 m | 移动超阈值 → 转交 Grab/Inspect；Esc → 取消层 | 无目标命中时点击=空操作（无音） |
| Point-长按（VR） | `press_duration` | 0.5 s 判定长按 | 长按 = 取消（同 Esc） | 长按触达时轻震 |

## 3. 输入映射表（第 1→2 层适配）

### 3.1 桌面（键盘 + 鼠标）

| 设备输入 | 合成为 | 在场景中的语义 |
|---|---|---|
| 鼠标左键按住（标的上）+ 拖动 | Inspect | 旋转/调整观察视角 |
| 鼠标左键按住（空处）+ 拖动 | Inspect | 平移观察（相机平移） |
| 鼠标滚轮 | Inspect | 缩放（以指针热点为中心） |
| 鼠标中键/右键按住 + 拖动 | Inspect | 平移/环绕（备用方案） |
| 鼠标左键按住（可抓对象上）+ 拖动 | Grab | 拾取并移动零件 |
| 鼠标左键单击（纽/目标） | Point | 点选/确认 |
| `Esc` | Point(取消) | 关闭顶层弹层/取消动作；运行退出的确认入口 |
| `Tab` | Point(焦点) | UI 焦点切换（键盘可达性） |
| `空格`/`Enter` | Point(确认) | 激活焦点元素 |

> 键盘作为设备本体输入（Apple II 键盘映射）不属于本表，见 02 章「运行 HUD 与输入映射可视化」。

### 3.2 VR（双 6DoF 手柄）

| 设备输入 | 合成为 | 在场景中的语义 |
|---|---|---|
| 右柄扳机短按 | Point | 点选/确认 |
| 右柄扳机按住 + 柄移动（标的上） | Grab | 抓取物件 |
| 左/右柄按住握持键 + 拖动（非可抓对象） | Inspect | 观察旋转（单手） |

### 3.4 输入-反馈时序表 [v1.0 新增]

> 时序单位为毫秒；「反馈」= 视觉/听觉/触觉中至少二者；用例引用：T-005/006/017/062。

| 事件（0 ms 起点） | 视觉反馈 | 听觉反馈 | 触觉（VR） |
|---|---|---|---|
| 0 输入按下（可点目标） | 即刻选中描边（FUNC-003 highlight） | — | — |
| 0 输入按下（可抓目标） | 放大 1.05×（拾取确认） | — | 轻震 10 ms |
| ≤50 确认点击释放 | 按钮按下态 50 ms 后回弹 | 确认音（04 章 sfx_confirm） | 短震 10 ms |
| 50–200 抓取移动中 | 对象跟随（每帧） | 无（防噪） | 无 |
| 200 开盖/关盖动画启动 | 铰链示意线（VR） | 开盖音 | 中震 30 ms |
| 400 单件回装卡合动画完成 | 回位+状态点 ● | 卡合音 | 轻震 10 ms |
| 0→800 分层滑杆拖动 | 爆炸位移实时跟随 | 滑杆吸附音（每档） | 无 |
| 1000 越界/违禁操作 | 光标 ⦸ 或 toast | 拒止音 | 长震 80 ms |
| ≥2000 持续违禁（运行中抓取） | 「运行中不可拆解」条幅 | 拒止音重复一次 | — |
| 1200 开机过渡完成 | 输出画面亮起+HUD 出现 | 开机音尾段衔接运行声 | — |

**同步规则**：视觉先于声音 ≤100 ms；触觉与听觉同步 ≤30 ms 容差；字幕（若开）与声音起始对齐。

## 4. 设备展示状态机（设计文档 §3.3）

状态集合：`完整 Complete` → `开盖 Opened` → `拆解中 Disassembling` → `运行中 Running`。附带「运行就绪」正交状态流（§5）。

```
                 ┌──────────[关机]──────────┐
                 ▼                          │
  ┌───────┐  开盖   ┌──────┐  拆下首个零件   ┌────────┐
  │ 完整  │───────▶│ 开盖 │──────────────▶ │ 拆解中 │
  └───────┘◀───────┴──────┘◀───────────────┴────────┘
      ▲         关盖/复原        一键复原(全体回装+关盖)
      │
      │  开机(仅就绪)
      ▼
  ┌────────┐  退出/关机   ┌───────┐
  │ 运行中 │────────────▶│ 完整  │（关机后总回到完整）
  └────────┘              └───────┘
```

**迁移总规则**：
1. `拆解中` 禁止直接开机（运行入口置灰，选设备提示「请先复原」）——保证「运行」永远发生在整机/开盖可复原语境下。
2. `运行中` 禁止 Grab（任何抓取被拒，设备若有已拆散件则必须先复原才能开机，故运行时无散件）。
3. 任意状态间不跳级：复原动画结束态 = `完整`（盖合），或按「回到最近一次开盖前」规则 [TBD]。
4. 状态迁移播放过渡动画并完成后才切换状态机变量；动画期间输入进入「过渡锁」（见 4.7）。

### 4.1 `完整`（整机、顶盖闭合）

- **能做什么**：Inspect（任意旋转/缩放）；Point 设备开导览卡、开图鉴、进入设置；Grab → 对「上盖把手区」执行开盖；Point 运行区（若就绪）开机。
- **看到什么**：整机全貌、基座名牌、导览卡入口图标（呼吸提示）、运行入口（就绪=亮起/未就绪=灰+指引）。
- **听到什么**：展厅环境声；开盖触发「开盖音」。
- **迁移**：开盖动作 → `开盖`；开机（就绪）→ `运行中`。

### 4.2 `开盖`（顶盖掀起，内部可见但装配完整）

- **能做什么**：Inspect 内部结构；Point 内部装配体触发原理浮层（C2）；Grab 上盖（掀开状态下的上盖可独立轻移 [TBD]）或首个可拆零件；Point 关盖。
- **看到什么**：机箱内部完整装配（主板、槽位、电源）、可拆零件轮廓呼吸高亮一次；导览卡自动切换为「内部结构」页签 [TBD]。
- **听到什么**：开盖音（上盖收束）+ 内部空间感的环境混响轻微变化（VR）。
- **迁移**：关盖 → `完整`；拆下首个零件 → `拆解中`。

### 4.3 `拆解中`（≥1 个零件脱离装配约束）

- **能做什么**：Grab 拆/装零件；Point 选中原理（C2/C3）；Inspect 已拆散组合；Point 一键复原；剖切/透视开关（D3）；**不可**：开机（运行入口置灰）。
- **看到什么**：拆解面板（D3）展开（零件清单、层级滑杆、复原按钮、剖切/透视开关）；已拆零件在空间中的「散件」形态与虚影原位的连线提示（每散件一条淡虚线连回原位，色弱友好）。
- **听到什么**：卡合/分离音；把零件移入判定区时的「接近音」（见 04 章）。
- **迁移**：一键复原 → `完整`（动画各零件飞回+卡合+关盖）；手动全部回装且关盖 → `完整`。

### 4.4 `运行中`（已开机，模拟器渲染输出）

- **能做什么**：Point 运行 HUD（E6：输入映射提示、快照、退出确认）；Inspect 观察设备外壳（禁止内窥穿模）；键盘/映射输入注入模拟器；**不可**：Grab、拆解、导览编辑。
- **看到什么**：设备输出画面（Apple II：外接 CRT 演示位屏幕同步显示，见 03 章）；HUD 状态条（就绪/媒体名/模拟器负载）；被禁止对象的锁定小标（🔒 图形化处理）。
- **听到什么**：设备运行声（程序化/实录混合，见 04 章）+ 模拟器原生音频。
- **迁移**：关机/退出 → `完整`；崩溃 → 进入「运行就绪」支线崩溃恢复（§5.4）。

### 4.5 禁止动作的提示方式（统一规范）

| 情形 | 视觉 | 文字 | 声音 |
|---|---|---|---|
| 拆解中试图开机 | 运行入口灰色+锁标 | 「请先复原再开机」toast 3 s | 拒止音（低沉短促） |
| 运行中试图抓取零件 | 光标/准星变为「禁止」图标（⦸） | 无需文字（若持续 2 s 显示「运行中不可拆解」） | 拒止音 |
| 未就绪试图开机 | 运行入口灰+引导标 | 「运行未就绪，点此打开向导」 | 提示音 |
| 过渡动画中输入 | 输入忽略 | 不提示（动画短于 1 s） | — |

### 4.6 一键复原（动画与撤销规则）

- **触发**：拆解面板「复原」按钮 / VR 手势区按钮（拆解面板上同一控件）。
- **动画**（总时长 ~2.5 s [TBD/建议值]）：① 各散件依装配树自叶向根、由远及近飞回原位（0.15 s/件并行，24 件封顶 ~1.8 s）→ ② 每件归位播放 80 ms 卡合音 → ③ 上盖回落合盖（0.5 s）→ ④ 状态置 `完整`。
- **撤销规则**：动画期间**不可撤销**（过渡锁）；复原完成后**不提供撤销**（拆解状态不会被历史保存——符合「快照只存运行态」的边界）。若玩家误触，重新拆解即可；在待决策建议中列为需作者拍板项。
- **打断**：Esc/取消键可跳过动画（直接切到终态），VR 扳机长按取消同义 [TBD]。

### 4.7 过渡锁（Transition Lock）

任何状态迁移的动画期间，第 2 层原语输入被缓存或丢弃（不进入第 3 层）；UI 不弹任何新层。时长表：开盖 0.8 s / 关盖 0.8 s / 单件拆装 0.4 s / 一键复原见上 / 开机 1.2 s（含 ROM 载入进度）/ 关机 0.6 s。

## 5. 运行就绪状态流（FR-E 交互呈现）

正交于展示状态机的「运行就绪」流：

```
  ┌────────┐  检查通过   ┌──────┐  玩家开机   ┌──────┐  正常退出   ┌──────┐
  │ 未就绪 │───────────▶│ 就绪 │───────────▶│运行中│───────────▶│ 已退出 │
  └────────┘             └──────┘             └──┬───┘             （=完整）
       ▲                                        │崩溃
       │缺ROM/缺模拟器/                       ▼
       │内容包版本不符              ┌──────────────────┐
       └── 引导向导(运行向导E3)─── │ 崩溃恢复(见5.4)    │
                                   └──────────────────┘
```

### 5.1 `未就绪` 判定

对当前设备运行三查：① 模拟器引擎是否安装/可用（RuntimeProfile.emulator）；② 所需 ROM/BIOS 是否已定位（bios_required 及介质文件）；③ 内容包版本 ≥ engine_min_version 且受支持（FR-F2 反向）。任一不满足即 `未就绪`。

### 5.2 引导向导流程线（运行向导 E3，详细版面见 02 章 §6）

```
选择介质（media_hint=floppy 等；任务书 E3 原文作「选择媒体」，全篇统一为「介质」）
  → 若 bios_required：引导合法获取渠道说明（官方/授权来源说明页，含 bios_guide_url 展示）
  → 本地文件选择（定位 ROM/介质文件；桌面=系统文件对话框，VR=虚拟文件架）
  → 文件校验（哈希/魔数；失败→重试与说明）
  → 就绪确认（显示设备名+介质名+来源标注）
  → 回到展厅（运行入口转亮）
```

- 玩家在任何一步可「取消」返回 `未就绪`；已完成步骤保留进度（下次进入向导从断点继续）。
- 缺失项在向导中以「待办列表」形式呈现（缺 ROM / 缺介质 / 版本不符各一行 + 各自修复按钮）。

### 5.3 `就绪`

- 展示状态机内表现：运行入口亮起；导览卡运行页显示「可运行」徽标；HUD 常驻区显示就绪态图标。
- 迁移：开机 → `运行中`；内容包被替换/删除 → 回 `未就绪`。

### 5.4 崩溃恢复（FR-E8）

- 崩溃表现：模拟器进程异常退出 → 弹「模拟器异常」异常弹层（02 章 §10）→ 设备输出画面冻结为最后帧并加斜纹遮罩 → 设备状态回 `完整`。
- 恢复选项：`重试`（回到就绪检查→自动开机）/ `返回展厅`（丢弃本次运行态）/ `查看日志`；若连续 3 次崩溃（FR-E8b 连续失败降级），向导出现「降低精度/更换模拟器配置」的建议页（联动 I1 画质分级）。
- **[v1.0 修改] 自动恢复分支（FR-E8c，03 线 Baby 接线后启用）**：崩溃后若自动恢复开启且失败计数 ≤3，5 s 内自动重启模拟器并从最近自动快照续接，HUD 回绿；恢复失败累计 3 次才落入手动弹层流程。联动用例 T-051/T-052，伪码 FUNC-007。
- 快照损失说明：崩溃前最近一次快照仍有效，弹层中明示（见 02 章存档管理）。

## 8. 待决策建议（本节相关）

1. 一键复原是否提供「撤销复原」——本规格定为不提供，需作者拍板。
2. 关机后是否总回 `完整`（而非保留开盖）——本规格定为回 `完整`。
3. 开盖状态下上盖是否可独立移动（Grab）——本规格定为可轻移。
4. 双击/单击打开导览卡的取舍 [TBD]。
5. Inspect 缩放/角度限额的具体数值均为建议值，待实机手感调优。
