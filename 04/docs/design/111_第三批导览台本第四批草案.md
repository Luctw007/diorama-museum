## 1. Newton 草案（导览口播要点 / 展项动线 / 互动提示）

### 1.1 Apple Newton MessagePad（手机厅 PDA 线，1993）

- **口播要点**（[S135]）：1993 年 Apple 推出 Newton MessagePad；**「PDA」这个词本身就是 Apple 发布 Newton 时提出的**——个人数字助理品类的先驱；ARM 610 处理器（20MHz）+ Newton OS；核心交互 = 触控笔 + 手写识别；概念超前（笔输入、无线通信、个人助手，几乎预告智能手机），但因手写识别不成熟、体积偏大、价格偏高而商业失败，1998 年停产；「早熟的先知」——提前十年描绘掌上智能设备图景；
- **展项动线**：拟入手机厅 PDA 展区（与 82 号站 3B Nokia 8110 并置「移动设备进化线」，台前 1.2 m，停留 45 s）；展厅归属按定案表 PDA 线、手机厅落位标 [需核实]（是否并入 82 号 v3 或独立 PDA 线，待定稿裁决）；
- **互动提示**：手写识别演示动画（触控笔书写→识别成字，1-2 段，静态+动画）；无成熟模拟器（Einstein 候选，许可与成熟度 [需核实]），真跑不设用例、Newton OS ROM 红线不入库；
- **需核实**：尺寸（约 18.4×11.4×1.9 cm、约 410 g）、Einstein 许可/成熟度、展厅落位（研究卡原标照引）。

### 1.2 口播摘要段草稿（草案，180 字/分口径）

- **Apple Newton**：「1993 年，Apple 发布了 Newton——连『PDA』这个词，都是它发明的 [S135]。触控笔在屏幕上写字，机器把它认成文字；笔输入、个人助手、无线通信，它几乎预告了十几年后的智能手机 [S135]。它输给了不成熟的手写识别，但概念赢在了前面——早熟的先知 [S135]。」
