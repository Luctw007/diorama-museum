## (a) 概述与历史地位

### a.1 地位一句话

Mega Drive（北美名 Genesis）是世嘉于 1988 年 10 月 29 日在日本发售的 16 位家用游戏机，是第四世代主机的开篇之作 [S38]。它把世嘉 System 16 街机基板的 68000 架构搬进客厅，以"速度与态度"对抗任天堂，掀起了 1990 年代初著名的"主机战争"（console war），并靠《索尼克》系列在北美、欧洲、巴西等地取得巨大成功，全球销量约 3075 万台 [S38]。

### a.2 关键人物与分工

| 人物 | 分工 |
|---|---|
| 佐藤秀树（Hideki Sato）/ 石川雅美 | 研发团队负责人，把 System 16 街机基板改造为家用机 [S38] |
| 中裕司（Yuji Naka） | 主导《索尼克》开发，定义了 MD 的"速度"身份 |
| 古代祐三（Yuzo Koshiro） | 利用 YM2612 FM 音源创作标志性配乐 |

### a.4 版本差异（垂直切片选定建议）

MD/Genesis 有多个硬件修订（Model 1 → Model 2 → 32X/CD 扩展），核心（68000 + Z80 + YM2612）自始至终未变。本批建议垂直切片选定 **Model 1（初代，1988）**：耳机孔 + 音量滑杆 + 金色"16-BIT"铭牌，icon 性最强；运行档 NTSC 60Hz。`[TBD]` 由作者拍板。

## (c) 工作原理（框图 + 数据流 + 关键芯片职能）

### c.1 系统框图（ASCII）

```
  │  │  68000   │    │ (视频处理) │              │
  │  │ (主 CPU) │    └───────────┘              │
  │  └────┬─────┘                               │
  │       │                                     │
  │  ┌────▼─────┐    ┌───────────┐              │
  │  │  Zilog   │◄──►│ YM2612 FM │              │
  │  │  Z80     │    │ +SN76489  │──► 耳机/AV 音频│

  │  └──────────┘    └───────────┘              │
  └────────────────────────────────────────────┘
```

### c.2 数据流（FR-C 信号流动画素材）

1. **开机**：上电 → 68000 执行卡带程序入口（早期无 TMSS，后期有版权检查 ROM）[S39]。
2. **游戏主循环**：68000 执行游戏逻辑（角色、关卡、碰撞），把画面数据写入 VRAM（经 VDP）。
3. **图形渲染（VDP）**：VDP 读 VRAM 合成多层卷轴 + 精灵，输出 AV/RF 信号 [S39]。
4. **声音（Z80 控制）**：68000 把音乐/音效数据交给 Z80，Z80 驱动 YM2612（FM 六通道）与 SN76489（PSG 四通道）发声 [S39]。
5. **输入**：手柄按键经 9 针口读入，68000 读取判定。

### c.3 关键芯片职能（C2/C3 标注文案素材）

| 芯片/子系统 | 职能（一句话草稿） | 来源 |
|---|---|---|
| Motorola 68000 | 主 CPU：执行游戏逻辑，协调整机 | S38/S39 |
| Zilog Z80 | 副 CPU：控制 PSG 与 FM 音源，MS 兼容 | S38/S39 |
| VDP | 视频处理器：多层卷轴 + 精灵合成画面 | S39 |
| YM2612 | 六通道 FM 合成器：MD 标志性金属音色 | S38/S39 |
| SN76489 | 四通道 PSG：方波/噪声补充音源 | S38/S39 |

## (e) 百科卡（≥2500 字成品文案）

### e.1 标题区

**Sega Mega Drive**（北美名 Genesis）
1988 年 · Sega（日本）
家用游戏机 · 16 位 · 卡带式

### e.2 正文文案

**把街机厅搬进客厅的机器。** Mega Drive 是世嘉于 1988 年 10 月 29 日在日本发售的 16 位家用游戏机，在北美它有个更响亮的名字——Genesis。它是第四世代主机的开篇之作，也是世嘉从"任天堂的挑战者"变成"能与任天堂正面对抗的力量"的关键一步。它的硬件直接脱胎于世嘉自己的 System 16 街机基板：把街机厅里那颗 Motorola 68000 处理器、那套多层卷轴加精灵的图形系统、那枚 Yamaha FM 合成音源，原样搬进了客厅。这决定了 Mega Drive 的性格——它不是一台"家用玩具"，而是一台"街机味道十足"的机器 [S38][S39]。

Mega Drive 的架构，是典型的"双 CPU 分工"：一颗 16 位的 Motorola 68000 做主 CPU，负责游戏逻辑与画面数据的生成；一颗 8 位的 Zilog Z80 做副 CPU，专门驱动声音芯片（Yamaha YM2612 FM 合成器 + SN76489 PSG），同时兼任世嘉上一代 Master System 的兼容。这种"主 CPU 算、副 CPU 响"的分工，加上 YM2612 那六个 FM 通道发出的尖锐、金属感十足的音色，构成了 Mega Drive 标志性的"声画风格"——后世玩家一听到那种锋利的 FM 贝斯与鼓点，就知道"这是 MD 的声音" [S38][S39]。

Mega Drive 最辉煌的时刻，是它与任天堂 Super Famicom 之间那场著名的"主机战争"。世嘉在北美用一句极具挑衅的广告语"Genesis does what Nintendon't"（Genesis 能做到任天堂做不到的），把家用机竞争变成了一场文化对决。而真正让 Mega Drive 站稳脚跟的，是 1991 年《索尼克》的横空出世——这只蓝色刺猬用超高速的卷轴与流畅的关卡，定义了 Mega Drive"速度与态度"的品牌形象，也终于给了世嘉一个能与马里奥分庭抗礼的吉祥物 [S38]。

Mega Drive 的游戏库，是"街机移植 + 原创神作"的双线。《街头霸王 II》《怒之铁拳》《战斧》《雷神传说》等街机味十足的作品，加上《索尼克》《梦幻之星》《光明力量》等世嘉原创，构成了一个偏硬朗、偏动作、偏速度的阵容。后期世嘉还推出了 6 键手柄（A/B/C/X/Y/Z），专门为格斗游戏的复杂搓招而设计——这也是家用机手柄向"格斗友好"演进的重要一步 [S38]。

然而 Mega Drive 的后期，也成了世嘉"扩展策略"混乱的缩影：Sega CD、32X、LaserActive 等一堆扩展外设让硬件生态变得支离破碎，最终在 16 位时代末期被 Super Famicom 反超。全球累计销量约 3075 万台，虽然不及对手，却足以让它成为世嘉历史上最成功、最具文化符号意义的一代主机 [S38]。

对一座电子博物馆而言，Mega Drive 是"16 位时代"叙事里绕不开的开篇：它以 68000 + FM 音源定义了"街机味家用机"的硬件范式，以《索尼克》定义了"速度"的品牌范式，以"主机战争"定义了整个 16 位时代的竞争格局。它与 Super Famicom 一前一后，构成游戏机厅"16 位双子星"的完整故事——一台讲速度与态度，一台讲色彩与声音。

#### e.2.1 馆方展示定位

在博物馆环境中，Mega Drive 与 Super Famicom 建议**并列展示**，构成"16 位主机战争"专区：两台主机面对面摆放，中间一台 CRT 演示位轮播《索尼克》的高速卷轴与《超级马力欧世界》的 Mode 7 关卡，让观众直观感受"速度"与"色彩"两种 16 位美学的对决。Mega Drive 的展示重点在**双 CPU + FM 音源**——观众可点选 68000 与 Z80 两颗芯片，看"一颗算、一颗响"的分工；耳机孔（Model 1 特有）可让观众插上耳机，亲耳听 YM2612 那标志性的金属音色。这是"可看、可拆、可懂、可玩"四可标准在 16 位主机上的落点。

#### e.2.2 型号沿革

Mega Drive 在近十年的生产史中经历了多次改款：最早的 **Model 1（1988）** 机身圆润、带耳机孔与音量滑杆、金色"16-BIT"铭牌，icon 性最强；**Model 2（1993）** 小型化、去掉耳机孔、改用 AV 输出；此外还有 Sega CD、32X 等扩展外设与 Genesis 3、Nomad 掌机等变体。这些改款的核心（68000 + Z80 + YM2612）自始至终未变，差异集中在机箱造型、输出接口与扩展生态。本设备包垂直切片选定 Model 1 造型，最贴近"1988 年 16 位时代开篇"的叙事定位 [S38]。Model 1 特有的耳机孔与音量滑杆，是当时家用机少见的"音频发烧"设计，也是 MD 声画风格的一处实物注脚。

## (f) 原理大纲 + C4 动画选题

### f.1 原理大纲

1. **双 CPU 分工**：68000 算、Z80 响，主副 CPU 各司其职。
2. **FM 音源**：YM2612 六通道 FM 合成如何发出标志性金属音色。
3. **多层卷轴 + 精灵**：VDP 如何合成 320×224 的画面。
4. **卡带即内容**：卡带 ROM + bank switching 如何扩展容量。

## (g) 模拟器结论（BlastEm = MAME?）

### g.1 选型结论

**首选 BlastEm，MAME `genesis` 作交叉验证。**

- **BlastEm**：**GPL-3.0** · 官网 https://www.retrodev.com/blastem/ · 作者 Michael Pavone。以"高精度 + 弱硬件也能全速"著称，通过大量硬件测试，是 MD 精度最高的模拟器之一 [S40]。
- **MAME `genesis`**：GPL-2.0/BSD-3 双许可，与本项目 gw 网关架构同构。

> **许可纠正**：任务 40-B 书"BlastEm(MIT)"有误——BlastEm 本体为 **GPL-3.0**（其 MCP wrapper 才是 MIT），已在 04 号汇总中纠正并标注。

### g.2 ROM/卡带合法获取渠道文案草稿（FR-E3 风格）

> 运行一台 Mega Drive 需要卡带 ROM，这些游戏多数仍受版权保护，本项目**绝不内置、也不提供任何卡带 ROM**。合法途径：① 从你合法拥有的 MD 卡带上提取 ROM 作个人备份；② 版权方授权渠道（如官方合集、官方重发行）；③ 明确授权的自制游戏（homebrew）。向导只负责"解释 + 引导导入"，不提供盗版下载点。
