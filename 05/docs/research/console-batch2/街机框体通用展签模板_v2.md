# 街机框体通用展签模板 v2

> 任务 153（05 线）· 完成日期：2026-11-06。
> 授权说明：本模板与示例**供 04 线 41 号台本无偿取用**，无需再查出处；史实以 05 线史实库（console-batch2 / emu-eco / neo-geo-mvs 百科）为准。

## 一、模板（固定字段）

| 字段 | 说明 |
|---|---|
| 标题 | ≤10 字，点出本框体/基板一句话记忆点 |
| 一句话史实 | 2–3 句，讲清"这是什么 / 为什么重要" |
| 对应框体或基板 | 归属（框体名 / 基板名 / 驱动名） |
| 可配交互建议 | 一句，对应 32 拆解 / 41 台本交互清单 |
| 史实敏感标注 | 年代、厂商、参数等敏感值一律「需核实」 |

## 二、填充示例（Neo Geo MVS）

- **标题**：换卡不停机
- **一句话史实**：Neo Geo MVS 是 SNK 于 1990 年推出的街机基板（年代「需核实」），双卡槽设计让一台框体可装多张游戏卡、换卡不停机，孕育了拳皇、侍魂、合金弹头等格斗与射击名作。
- **对应框体或基板**：Neo Geo MVS 框体 / MAME `neogeo` 驱动
- **可配交互建议**：观众按切换键，看两台 CRT 画面在两张卡带间切换。
- **史实敏感标注**：年代 1990、厂商 SNK 均「需核实」。

## 三、使用说明
- 每台街机框体按此模板填一张展签；标题取"一句话记忆点"（如换卡不停机、街机的大卡、竖屏弹幕），正文与 v1 展签资材（`街机暗房展签资材_10条.md`）口径一致。
- 史实敏感句一律标「需核实」，不编造年代、厂商、参数。
