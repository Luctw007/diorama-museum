## ② 切厅路径现状核对（switch_hall 调用链 / 清场顺序 / 与 291-B 衔接）

**调用链（触发源 → switch_hall）**：

1. PortalHub.activate_portal（点选 _pick_portal 18px / 碰撞 body_entered 玩家过滤）→ ExhibitHost.switch_hall；
2. HallNavPanel._switch_to / _nav（next_hall/prev_hall 循环）→ switch_hall；
3. EncyclopediaPanel._on_locate_pressed（F-7 图鉴→大厅定位）→ _find_hall_for 扫布局 → switch_hall + 高亮；
4. 291-B NarrTourController：站迁移**不直接切厅**——厅站讲解经 play_hall_narr（F-9 通道）；导览镜头
   站间迁移即切厅的接线点（next_station → switch_hall）**待实机**（与 39 号 §3.1 迁移三条件一并核对）。

**switch_hall 内部顺序（exhibit_host.gd）**：

```
clear_devices()（O(N) remove_child+queue_free；清 _placed/_running_id/_active_ids/_layout）
→ load_layout（文件打开 + JSON 校验）
→ spawn_devices（N 台 DeviceLoader 惰性加载，L-02 门禁保证 id 存在）
→ _hall_cursor 更新（hall_files 命中时）
→ _debug_circles_on 重放（TASK-114 跨切厅保留）
→ _notify_portal_hub()（refresh_portals 同帧重建门框 → _resume_highlight_check F-7 → _notify_hall_narr F-9）
→ 返回 placed > 0
```

- 清场要点：旧厅设备同帧 queue_free（帧末释放）；PortalHub._clear_portals 立即 remove_child 防同帧同名冲突；
  运行配额（_running_id 重设为空）与激活名额（_active_ids 清空，291-A）随清场释放；真跑进程不因切厅被杀
  （网关独立进程，F-3 §二收口）。
- 同帧峰值口径（246-A ①）：切厅瞬时旧厅 N + 新厅 N 同帧在内存——白模阶段 N≤4，预算内无风险（B-01/B-02 PASS）。
