## 1. 定位与入口

绑定设置界面是 **02 号「界面 8：设置」的新增第五分页「输入绑定」**，替换现有设置页侧栏分页为：`[画质][舒适性][音量][内容管理][输入绑定]`（02 号增量补丁见独立文件 `02号_增量补丁_绑定设置页.md`）。

- 桌面：全屏模态内分页（沿用 02 号设置模态坐标：720p 160,72,960,576 / 2K 320,140,1920,1160）。
- VR：设置悬浮面板（12 号 §4 设置行 1.2×1.0 m）内新增「输入绑定」竖排列卡。
- 数据源：`godot/content/<device-id>/input_profile.json`（玩家层配置，gen 工具生成的骨架为初始值）。

## 2. 数据模型与读写契约（以 01 线产物为唯一事实）

### 2.1 JSON 结构（五包实测）

```json
{
  "actions":   { "动作名": "绑定字符串（可为空串=unbound）", ... },
  "keyboard":  { "动作名": "Godot 键名（key_w 等小写蛇形）", ... },
  "mouse":     { "动作名": "mouse_button_left 等", ... },
  "unbound":   ["动作名", ...],
  "note":      "生成说明/用户编辑标记"
}
```

### 2.2 loader 约束（`input_profile.gd` 事实）

- `load_from_json` 只读 `actions/keyboard/mouse` 三表；`binding(action)` 查询序 = actions → keyboard → mouse；空字符串视为未绑定。
- 额外顶层键（unbound/note）对 loader 安全——设置界面写回时必须先保证三表自洽，再重算 unbound。

### 2.3 五包实况总表（设置界面初始渲染的事实输入）

| 包 | actions 表 | keyboard 表 | mouse 表 | unbound 数 | 重点 |
|---|---|---|---|---|---|
| apple-ii | 7（paddle_axis_0~3、paddle_btn_0~2，已绑 joy_*） | 50（key_a…power 全自绑定） | 0 | 0 | 面板机全自动；paddle_axis_2/3 与 _0/_1 复绑同摇杆待分流 |
| manchester-baby | 36（power/reset/start/stop + **store_bit_00~31**） | 0 | 0 | 36 | 32 位开关批量绑定重点 |
| eniac | 4（power/reset/demo_next/demo_pause） | 0 | 0 | 4 | demo 模式静态机 |
| edsac | 16（含 tape_load/tape_rewind/tape_punch/clock_slow/clock_fast…） | 0 | 0 | 16 | 磁带与时钟控制键 |
| edvac | 4（power/reset/demo_next/demo_pause） | 0 | 0 | 4 | demo 模式静态机 |

## 3. 三模式布局（每模式一屏，全表不缩写）

> 模式切换 = 分页内二级标签 `[键鼠][手柄][VR 手势]`，与「每设备」选择器（设备下拉）正交。所有三模式共享同一份 input_profile.json（写回时合并，不互相覆盖区段外的字段）。

### 3.1 模式一：键鼠（桌面）

| 区域 | 控件（Godot 既有类） | 内容 |
|---|---|---|
| 顶栏 | OptionButton（设备下拉）+ Label（包版本） | 设备选择；切设备即换读写文件 |
| 动作列表 | ScrollContainer + VBoxContainer，行 = HBoxContainer | 按 2.3 表渲染；**unbound 行置顶**（01 线 sync §3 移交要求），行首 c-warn 圆点 |
| 每个动作行 | Label（动作名，如 `store_bit_07`）+ 设备副标签 Label（如 `panel.switch.bit_07`）+ Button（绑定捕捉钮，显示当前绑定串或「未绑定」）+ Button（清除） | 动作名与设备侧逻辑名同显（两层键名模型） |
| 捕捉态 | PopupPanel + Label | 按任意键后回填 Godot 键名（`key_` 小写蛇形）；等待 8 s 超时自动关 |
| 鼠标行 | 同动作行，绑定串 ∈ `mouse_button_left/middle/right`、`mouse_wheel_up/down`、`mouse_motion` | 滚轮作为绑定时捕捉「滚上/滚下」两次输入 |
| 分组折叠 | PanelContainer + CheckButton（分区开关） | 分区 = 系统 / 面板开关区 / 字母区 / 功能键 / 鼠标；折叠后整分区隐藏 |
| 动作区 | Button [还原默认] [恢复本设备生成值] [关闭] | 还原默认 = 重置为 gen_input_profile.py 的等价输出 |

**键鼠模式交互规则（全量）**：捕捉期间屏蔽游戏内输入（弹出捕捉层）；同键重复绑定时转入 §5 冲突流程；Esc 关闭捕捉层不产生绑定；被绑动作行右端显示绑定串 + c-accent 高亮 0.5 s。

### 3.2 模式二：手柄

| 区域 | 控件 | 内容 |
|---|---|---|
| 手柄示意 | TextureRect + 描述 Label | 当前连接手柄型号探测文案（Quest Touch / Index / XInput 手柄 [需实机核对：Godot 设备名探测]） |
| 摇杆轴行 | 同动作行，绑定串 ∈ `joy_axis_x/y`（另有 hat 表 `joy_hat_0~3`） | 捕捉 = 推动摇杆轴，自动判别轴名与方向（带方向后缀 `joy_axis_x+/-` [需实机核对]） |
| 按钮行 | 同动作行，绑定串 ∈ `joy_button_0~15` | 捕捉 = 按手柄键，回填编号 |
| 扳机行 | 同动作行，绑定串 ∈ `joy_trigger_l/r` [需实机核对：Godot joypad 扳机暴露形式] | 半按（>50% 行程）记一次捕捉 |
| 批量预设 | Button ×3（预设 P1~P3，§4.3） | 一键套用后逐行可再改 |

**手柄模式交互规则**：未连接手柄时全表灰置 + 提示「未检测到手柄」；捕捉中 10 s 无输入回到待捕捉；`joy_hat_*` 四方向分别捕捉 [需实机核对]。

### 3.3 模式三：VR 手势（待实机档）

> VR 动作域只允许映射到 12 号 §1.1 的 14 个 OpenXR action + 2 个 haptic 之外的「手势组合动作」（见下）。本屏桌面可配置（生成本地 VR 手势档），实机执行才生效。

| 区域 | 控件 | 内容 |
|---|---|---|
| 手势组列表 | ScrollContainer + 行 | 手势组 = 面板开关组专用（baby store_bit_00~31 可绑 1~4 个手势组） |
| 单动作手势行 | 同动作行，绑定串 ∈ `grip_left/right`、`trigger_left/right`、`primary_left/right`、`secondary_left/right`、`stick_click_left/right`、`hand_menu_tap`（手背菜单+扳机复合） | 与 12 号 action 名一一对应 |
| 手背菜单开关 | CheckButton | 「手背菜单呼出快捷拨档」（12 号 §3 爆炸图滑杆第三路径的泛化：32 位开关在手背菜单上呈 4×8 矩阵） |
| 演示区 | 只读按钮 [佩戴预览] | [需实机核对：编辑时无法直接佩戴，实机轮再验] |

**VR 手势模式交互规则**：一台设备同屏最多两柄介入；手势捕捉必须在实机进行（桌面只能**预填**，见 15 号用例 T-131）；套用预设时 VR 侧自动跳过不可达的键盘键。

## 4. 面板开关分区批量绑定（重点：baby 32 个 store_bit）

### 4.1 分区折叠规则

| 分区 | 成员动作 | 折叠态 |
|---|---|---|
| 系统 | power / reset / start / stop | 默认展开（4 行） |
| 位开关 A 组 | store_bit_00 ~ store_bit_07 | 默认折叠，标题带计数徽标「8 未绑定」 |
| 位开关 B 组 | store_bit_08 ~ store_bit_15 | 同上 |
| 位开关 C 组 | store_bit_16 ~ store_bit_23 | 同上 |
| 位开关 D 组 | store_bit_24 ~ store_bit_31 | 同上 |

折叠标题区右侧常驻 `[套用预设]` 按钮与 `[整区绑定]`（对该分区连续捕捉：依次按下 N 个键，依次绑定 store_bit_00→N）。整区绑定中途 Esc 取消并回滚该区。

### 4.2 整面板套用预设（3 套模板，全量）

| 预设 | 名称 | 适用包 | 绑定布局（逐位列出） |
|---|---|---|---|
| P1 | QWERTY 两行 | baby | 行 1 = `store_bit_00`…`store_bit_15` → 依次绑 `key_q,w,e,r,t,y,u,i,o,p,a,s,d,f,g,h`；行 2 = `store_bit_16`…`store_bit_31` → 依次绑 `key_z,x,c,v,b,n,m,comma,period,slash,j,k,l,semicolon,quote,enter,shift` [需实机核对：Godot 键名 `key_comma` 等拼写] |
| P2 | 手柄十字+肩键 | baby/eniac/edsac/edvac | 前 4 位 → `joy_hat_0` 四方向（or `joy_axis_x/y±`）；位 4~7 → `joy_button_0~3`；位 8~11 → `joy_button_4~7`（肩键/扳机按 [需实机核对]）；位 12~31 → 循环复用 `joy_button_0~3` + 长按修饰（`长按+btn` 复合动作，见 §6.2） |
| P3 | 数字行+功能键 | edsac/baby | 位 00~09 → `key_0`…`key_9`；位 10~21 → `key_f1`…`key_f12`；位 22~31 → 循环 `key_0`…`key_9` |

### 4.3 edsac 磁带控制键快捷模板（附赠第 4 套，供通用）

| 动作 | 建议默认（可改） |
|---|---|
| tape_load / tape_rewind / tape_punch | `key_f5 / key_f6 / key_f7` |
| clock_slow / clock_fast | `key_f8 / key_f9` |
| initial_orders | `key_f10` |
| display_crt / aux_a / aux_b | `key_f11 / key_f12 / key_insert` |

## 5. 冲突检测与提示交互（全量规则）

| 情形 | 检测 | 提示与处理 |
|---|---|---|
| 同键多动作（键鼠/手柄） | 捕捉完成时在**同一设备档案**内查重 | 弹 PopupPanel：「`key_w` 已绑定到 `key_w`（apple-ii 字母区）。[替换] [取消]」——替换 = 旧行解除绑定（旧行标「已被替换」toast 3 s）；取消 = 丢弃本次捕捉 |
| 跨设备同键 | 允许（每设备档案独立），不提示 | 行尾 c-text-2 小字「另 N 台设备亦用此键」 |
| 同动作多键 | 允许组合（最多 2 键，第二键需按「修饰键」输入：按住第一键再按第二键 [需实机核对]） | 行显示 `key_ctrl + key_q` 形式 |
| unbound 高亮 | 每次打开页面/切设备时重算 | unbound 行置顶 + c-warn 圆点 + 分区标题计数徽标；页脚统计条：「共 X 动作 · 已绑定 Y · 未绑定 Z」 |
| 还原默认 | 按钮确认 | 二次确认 PopupPanel：[确认] 后以 gen_input_profile 等价输出覆盖三表并重算 unbound |
| 保存失败 | 写文件异常 | `sfx_error` + 红字「保存失败，本次修改未生效」；不静默丢弃 |

**冲突音反馈**：冲突弹出 `sfx_deny`（0.25 s）；替换成功 `sfx_confirm`；绑定成功 `sfx_key_single`（0.03 s）；整区套用完成 `sfx_slider_snap`。

## 6. 与 input_profile.json 的读写映射表（控件 ↔ 字段一一对应）

| 界面控件/交互 | JSON 字段 | 写值规则 |
|---|---|---|
| 设备下拉（OptionButton 选中项） | （决定文件路径） | 切设备 = 换读写 `godot/content/<id>/input_profile.json` |
| 动作行 · 绑定捕捉（keyboard 区段动作） | `keyboard[动作名]` | 写入 Godot 键名 `key_*` 小写蛇形；原属 actions 的行移区段时同步删除旧区段条目 |
| 动作行 · 绑定捕捉（mouse/摇杆/按钮） | `mouse[动作名]` / `actions[动作名]` | 同上；滚轮/轴/按钮值按 §3.2 合法集 |
| 动作行 · 清除 | 对应区段删键 | 删除后动作落入 `unbound`（重算） |
| unbound 统计条 | `unbound[]` | 由「三表中所有空串/缺失的动作名」重算生成，**不手动编辑** |
| 组合键（修饰+主键） | 该区段绑定串 = `"key_ctrl + key_q"` | [需实机核对：loader 是否支持组合串，否则退回单独键并标 RED] |
| 整区绑定 N 连击 | 连续写 N 个区段条目 | 任一捕捉失败即回滚该区（事务语义） |
| 预设套用 | 批量写三表 | 先备份旧值（内存快照）供取消 |
| 还原默认 | 三表 + unbound + note | 以 gen_input_profile.py 等价输出覆盖；note 改 `"用户已还原默认"` |
| 保存按钮/关闭时自动保存 | 写文件 | 保留 `note` 用户编辑标记行；写前对比 hash 发现外部改动则提示冲突重载（可选） |

**loader 兼容性约定**：写回文件始终包含五键（actions/keyboard/mouse/unbound/note）；禁止写 input_map（那是内容包字段，玩家层无权改）。

## 7. 与 12 号 VR 原语表达法衔接

- VR 手势屏的绑定候选闭集 = 12 号 §1.1 的 action 名集合 + `hand_menu_tap` 复合手势；不得自行发明新 OpenXR action（12 号红线）。
- 手背菜单 4×8 矩阵与 12 号 §3「爆炸图滑杆手背菜单路径」共用同一呼出键（非持握手柄 `primary_btn`）。
- VR 模式下「整区绑定」= 手背菜单矩阵上逐格 Point 依次点亮 32 格（热区 ≥0.04 m，12 号 §2.4）。
