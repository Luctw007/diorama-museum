# 03 · Apple II 装配体层级树草案

> 任务：TASK-05 · 用途：作为 DeviceSpec `assemblies` 骨架，及 3D 资产生产（TASK-未来）的层级契约
> 精度分级对齐 ADR D4：L1 外观 / L2 拆解 / L3 运行 / L4 信号（选做）。本设备目标 **L2+L3**，L4 信号级只做"数据流动画标注"，不做电气仿真。

---

## 1. 层级树（整机 → 元器件）

```
apple2 (整机 · L1)
├─ case 机箱组件
│   ├─ lid 上盖（含通风栅格、苹果 logo 槽位）
│   ├─ bottom 底壳（含机脚、序列号/铭牌位）
│   └─ badge 铭牌组（彩虹 logo + "apple ][" 字样）〔商标元素，J2 登记〕
├─ power_supply 电源模块（金属屏蔽盒，左后侧）
│   ├─ psu_case 电源金属外壳
│   ├─ power_switch 电源开关（早期拨杆 / 后期船型）
│   ├─ psu_board 电源板
│   │   ├─ transformer 高频变压器
│   │   ├─ rectifier_group 整流/滤波组（电容、RIFA 安规电容、保险丝 → 板级组合体）
│   │   └─ output_wire 输出线束（+5/−5.2/+11.8/−12 V）
│   └─ power_cord 电源线 + 后板插座
├─ keyboard 键盘组件
│   ├─ keycaps 键帽组（52 键 → 板级组合体，可选单拆 RESET/空格）
│   ├─ keyswitches 键开关阵列（Datanetics 机械开关 → 板级组合体）
│   ├─ keyboard_pcb 键盘电路板
│   │   └─ key_encoder 键盘编码器（A1026 型，需核实型号）
│   └─ reset_key 复位键
├─ mainboard 主板（4 层 PCB，占据底壳大部）
│   ├─ cpu 6502 微处理器（Synertek/MOS）★元器件级
│   ├─ rom_array ROM 区（6 插座 × 9316B 2K×8；Integer BASIC + Monitor + chargen）
│   │   ├─ rom_monitor Monitor ROM（板级组合体）
│   │   ├─ rom_basic Integer BASIC ROM（板级组合体）
│   │   └─ chargen 字符发生器 ROM（2513/341-0036）★元器件级
│   ├─ ram_array RAM 区（3 行 × 8 插座；4K 或 16K DRAM）
│   │   ├─ ram_row_c / ram_row_d / ram_row_e（每行一个板级组合体）
│   ├─ clock 时钟（14.318 MHz 晶振）★元器件级
│   ├─ video_logic 视频逻辑（74 系列 TTL + 视频放大 → NTSC 合成）
│   │   ├─ video_ttl_group 视频 TTL 芯片组（板级组合体）
│   │   └─ video_connector 视频 RCA 输出座
│   ├─ bus_logic 总线/译码逻辑（74 系列 TTL → 板级组合体）
│   ├─ slots 扩展槽阵列（8 × 50-pin）
│   │   ├─ slot_0 … slot_7（各槽一个占位节点；默认空，可选插卡）
│   ├─ io_connectors 后板接口（磁带 in/out、游戏 I/O、电源）
│   ├─ decoupling_group 去耦电容/电阻网络（板级组合体）
│   └─ speaker_conn 喇叭接口
├─ speaker 扬声器（8 Ω，顶壳内前方）★元器件级
└─ peripherals 外设（可选，独立设备包，默认不含）
    ├─ disk2 Drive II 5.25" 软驱（选配）
    └─ monitor 9" 单色监视器（选配）
```

## 2. 关键节点职能与建模难度

| 节点 ID | 名称 | 职能（一句话草稿） | 建模难度 | 精度级 |
|---|---|---|---|---|
| cpu | 6502 微处理器 | 中央处理器，取指/译码/执行，协调整机 | 中（DIP40，表面丝印） | L2★ |
| chargen | 字符发生器 | 把字符码转成点阵字形供视频电路 | 低（DIP 封装） | L2★ |
| clock | 晶振 | 14.318 MHz 基准，分频出 CPU 与视频时钟 | 低 | L2★ |
| rom_array | ROM 区 | 开机即用的固件（Monitor/BASIC/字符） | 中（6 芯片阵列） | L2 |
| ram_array | RAM 区 | 运行程序与数据暂存 | 中（24 芯片阵列） | L2 |
| video_logic | 视频逻辑 | 把显存转成 NTSC 电视信号 | 高（TTL 密集 + 模拟输出） | L2（L4 数据流标注） |
| slots | 扩展槽阵列 | 开放式外设总线 | 低（8 连接器） | L2 |
| keyboard | 键盘组件 | 按键编码输入 | 高（键帽曲面 + 开关阵列） | L2 |
| power_supply | 电源 | 市电转多路直流 | 高（金属盒 + 内部线束） | L2 |
| case | 机箱 | 整机外壳（含铭牌/栅格） | 高（曲面 + 铭牌） | L1/L2 |
| speaker | 扬声器 | 1-bit 发声 | 低 | L2★ |

## 3. 节点预算与"板级组合体"合并策略（对齐 FR-D/FR-I）

**设计预算区间**：FR-D 典型 100–1000 节点/设备。本设备粗估：

| 层级 | 未合并节点数（估） | 合并后节点数（估） |
|---|---|---|
| 整机/机箱/电源/键盘/喇叭 | ~18 | ~18 |
| 主板功能区块 | ~15 | ~15 |
| 关键元器件（6502/晶振/chargen/连接器） | ~12 | ~12 |
| 分立电容/电阻/74 系列 TTL（若逐个建） | ~150+ | 合并为 3–5 个组合体 |
| **合计** | **~200** | **~45–50（L2 可拆节点）** |

**合并策略（"板级组合体"）**：
1. **分立阻容**：去耦电容、电阻网络 → 合并为 `decoupling_group`，不逐个建模（FR-I 实例化可在此处生效）。
2. **74 系列 TTL 逻辑**：视频/总线逻辑芯片 → 按功能区块合并为 `video_ttl_group` / `bus_logic`，仅保留硅片丝印作为贴图。
3. **RAM 三行**：每行一个 `ram_row_*` 组合体（而非 24 个芯片）。
4. **ROM 六槽**：按功能合并为 `rom_monitor` / `rom_basic` / `chargen` 三组，其中 `chargen` 保留为单独元器件级（有独立职能与故事性）。
5. **键盘 52 键**：键帽+开关合并为 `keycaps` / `keyswitches`，仅 `reset_key`、空格可单拆。

**保留到元器件级（★）的"明星件"**：`cpu`（6502）、`chargen`（字符发生器）、`clock`（晶振）、`speaker`（扬声器）、`power_switch`、`video_connector`、8 个 `slot_*`。这些是 FR-C3"点选看作用"的核心对象，故事性强、职能清晰。

**L4 信号级（选做）**：不建电气仿真；仅给 `mainboard`、`cpu`、`video_logic` 挂 `type:"flow"` 的数据流动画标注（开机自检 → 加载 → 显示 → 键盘 → 磁盘，见 02 章 §3.2）。
