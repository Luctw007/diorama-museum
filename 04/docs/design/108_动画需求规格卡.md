## 1.1 规格通则（八条共用）

- 时长通则：每条合计 ≥15 s（97/98/99 号判据底线），分段按 §1 表执行；循环动画循环周期 = 全片长，点播动画播完驻留末帧；
- 形态通则：全部「静态+动画」（无模拟器口径），循环可点播/点播两形态按 §1 表；动画文件随产包 annotations 挂接（不独立建包）；
- 音效通则：挂接点 id 一律用 81/82/74 号 §4 新增待登记 id，交付时与 08 线转档联动（T-659/T-663/T-666）；
- 史实通则：画面文案只引已登记口径与 [需核实] 标注，不新增史实断言。

## 2. 与 97/98/99 号 §5 判据对齐声明

- **规格不降低判据、只细化**：97 号 T-658（各 ≥15 s + 音效挂接）、98 号 T-662（滑开至顶 ≥3 s + 连滑 4 次无卡死）、99 号 T-665（各 ≥15 s + 音效挂接）全部保留为本表「验收演示口径」列，规格细分（时长/内容/挂接点）在其上展开；
- 判据升级联动：动画按本规格交付后，83 号 T-612/614、84 号 T-620/621、75 号 T-592/593/594 自「动画制作中」占位降级升全量判据复验（各档 §2.2 动画边界行）；
- 音效挂接点 id 与 81/82/74 号 §4 音频清单一致（sfx_workstation_*/sfx_phone_slide/sfx_supercomputer_*，新增待登记口径不变）。
