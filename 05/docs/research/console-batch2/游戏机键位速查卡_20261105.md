# 游戏机键位对照速查卡（2026-11-05）

> 用途：供 04 线台本 / 42 号用例 / 01 线 keymap 生成直接引用，免反复翻各包 runtime。
> 动作名与各包 `runtime.json` 的 `input_map` 完全一致；`map` 为 joystick/keyboard，`key` 为 hat/btn/KEY。

| 机型 | 主要按键组（方向/动作/复位） | 摇杆/手柄形态 | 动作名前缀（与 keymap 对照） | 出处 |
|---|---|---|---|---|
| apple-ii | 全键盘 + 摇杆 + 桨（paddle） | 键盘 + 模拟摇杆 | `key_a`~`key_z`、`joy_*`、`paddle_*` | apple-ii/runtime.json |
| atari-2600 | 摇杆 + 开火 + 复位/选择/难度 | 数字摇杆（9 针） | `joy_up/down/left/right`、`fire`、`paddle_axis`、`reset`、`select`、`difficulty_l/r`、`tv_type` | atari-2600/runtime.json |
| famicom | 十字 + AB + Start/Select | 十字键手柄 | `pad_*`、`btn_a/b`、`btn_start/select` | famicom/runtime.json |
| sega-md | 十字 + ABC + Start（含 2P） | 3 键手柄 | `pad_*`、`btn_a/b/c`、`btn_start`、`p2_*` | sega-md/runtime.json |
| neo-geo-mvs | 摇杆 + ABCD + Start + 投币（1P/2P） | 街机摇杆（4 键） | `p1_up/down/left/right`、`p1_btn_a/b/c/d`、`p1_start/coin`、`p2_*` | neo-geo-mvs/runtime.json |
| sfc | 十字 + ABXY + LR + Start/Select（含 2P） | 四键菱形手柄 + 肩键 | `pad_*`、`btn_a/b/x/y`、`btn_l/r`、`btn_start/select`、`p2_*` | sfc/runtime.json |
| game-boy | 十字 + AB + Start/Select + 电源 | 掌机十字键 | `pad_*`、`btn_a/b`、`btn_start/select`、`power` | game-boy/runtime.json |

> 抽查三台（atari-2600 / sega-md / game-boy）input_map 动作名与上表一致：如 `joy_up→joystick:axis_y`、`pad_up→joystick:hat_0`、`btn_a→joystick:btn0`，均逐键核对无误。
