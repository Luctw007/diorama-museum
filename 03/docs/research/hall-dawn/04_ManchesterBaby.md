# 04 — Manchester Baby（曼彻斯特"婴儿"，SSEM 小规模实验机）

> 章节目标：为"计算机黎明"展厅的 Manchester Baby 设备包提供资料证据、百科文案、装配体层级草案与原理讲解素材。

## (a) 概述与历史地位

Manchester Baby，正式名 SSEM（Small-Scale Experimental Machine，小规模实验机），由英国曼彻斯特大学研制，核心人物为 Frederic C. Williams、Tom Kilburn 与 Geoff Tootill [S25][S19]。它于 1948 年 6 月 21 日运行了世界公认的**第一个存储程序电子数字计算机程序** [S01][S25]。

Baby 的定位极其特殊：它**不是一台"实用计算机"，而是一台"实验台"**——专门用来验证 Williams 与 Kilburn 发明的一种全新存储技术：**Williams 管（Williams–Kilburn Tube）**，即用阴极射线管（CRT）屏幕上的电荷斑点来存储二进制数据的、第一种高速电子随机存取存储器 [S01][S20]。

1948 年 6 月 21 日，由 Kilburn 编写的一段 17 条指令的程序在 Baby 上运行：它的任务是找出 2¹⁸（262,144）的最大真因子，方法是从 262,143 向下逐一尝试每个整数（因机器只有减法/取负两种硬件运算，除法要靠反复相减实现）。程序运行 52 分钟、执行约 350 万次操作后，得出正确答案 131,072——用这场"马拉松"证明了机器的可靠性 [S25][S20]。

Baby 的历史地位可概括为 [S01][S25][S02]：

1. **第一台存储程序机**：它是"程序与数据同存于内存"这一构想的首个**成功运行**实现（注意：历史学者 Haigh 等人主张，1948 年改造后的 ENIAC 更早运行了"存于 ROM 的程序"，可视为对"第一"口径的修正；两说并存，见 [S02]）。
2. **Williams 管的孵化器**：Baby 验证了 CRT 存储，这项技术随后被曼彻斯特 Mark 1、Ferranti Mark 1、EDSAC（后期）、以及海外多台早期机器采用 [S01]。
3. **通向商用机的跳板**：Baby 直接演化为 Manchester Mark 1（1949），进而由 Ferranti 公司工程化量产为 Ferranti Mark 1（1951）——世界上最早的商用电子计算机之一 [S19][S01]。
4. **极简主义的教学样本**：Baby 硬件只实现了减法和取负，其余运算全部靠软件实现，是理解"最小可运行计算机"的最佳范本 [S20]。

原机从未留存——它被拆解以建造 Mark 1。现存的是一台由英国计算机保护协会（CCS）志愿者 Chris Burton 带队、ICL 赞助、于 1995–1998 年为纪念首程序 50 周年而复建的工作复刻机，陈列于曼彻斯特科学与工业博物馆（MOSI，现 Science and Industry Museum）[S19][S21]。

## (c) 工作原理

### 系统框图（ASCII）

```
                    ┌────────────────────────────┐
                    │  控制 CRT（Control Tube）     │
                    │  当前指令地址 CI + 当前指令 PI  │
                    │  （各 32 位，共 2 字）          │
                    └──────────────┬─────────────┘
                                   │ 指令/地址
   ┌──────────┐   ┌────────▼───────┐   ┌────────────────┐   ┌────────────┐
   │ 面板开关  │──▶│  存储 CRT（Store）│──▶│  累加器 CRT       │──▶│  结果观察   │
   │ (键入程序) │   │  32 字 × 32 位   │   │  (Accumulator)   │   │  (看屏读位) │
   └──────────┘   └────────────────┘   │  32 位            │   └────────────┘
                                       └───────┬────────┘
                                               │
                                        ┌──────▼──────┐
                                        │ 减法/取负逻辑 │
                                        │ (位串行)     │
                                        └─────────────┘
```

（三只 CRT 各司其职：Store 存程序与数据、Control 存当前指令与地址、Accumulator 存运算结果 [S19]。）

### 数据流说明

1. **程序进入**：程序与初值由操作员通过面板上的开关逐字写入存储 CRT（无纸带，纯手工键入）[S19]。
2. **取指**：控制 CRT 中的 CI（Control Instruction，当前指令地址）指向存储 CRT 的某个字，该字被读出并暂存到 PI（Present Instruction，当前指令）；随后 CI 加 1 指向下一条 [S19]。
3. **执行**：机器只实现"减法"与"取负"；把某存储字取负后加到累加器，即实现"加法"；由此软件可组合出乘除等更复杂运算 [S20][S19]。
4. **结果去向**：运算结果写回累加器 CRT 或存储 CRT，最终由操作员**直接读取 CRT 屏上的亮点图案**来"看"出二进制结果（亮=1，灭=0）[S19]。

### 关键电路职能

- **Williams 管存储（Williams–Kilburn Tube）**：CRT 屏幕上每个"存储位"对应一个电荷斑；电子束写入/读出时，通过检测束流变化判断该位是 0 还是 1，并周期性刷新（因为电荷会泄漏）。这是第一种高速随机存取电子内存 [S20][S19]。
- **存储 CRT（Store）**：主存，32 字 × 32 位 [S19]。
- **控制 CRT（Control）**：存 CI（当前指令地址）与 PI（当前指令）两个 32 位字 [S19]。
- **累加器 CRT（Accumulator）**：存当前运算结果 [S19]。
- **减法/取负逻辑**：位串行的核心算术单元，是 Baby 唯一的硬件运算 [S20]。
- **面板开关与按键**：程序键入与启动（"手工编程"）[S19]。

## (d) 装配体层级树草案

```
Manchester Baby 整机（约 7 个机架，长 5.23 m）
├── 机架/框架与电源（+300/+200/+50/−150/−1250 V）
├── 存储子系统（Williams 管）
│   ├── 存储 CRT（×1）+ 外围写读/刷新电路
│   ├── 控制 CRT（×1）
│   └── 累加器 CRT（×1）
├── 运算子系统
│   └── 减法/取负逻辑（位串行）
├── 控制子系统
│   ├── 时钟（100 kHz）
│   └── 顺序控制（CI 递增 + PI 暂存）
├── I/O 子系统
│   └── 面板开关与按键（键入 + 启动）
└── 布线/信号互连
```

**逐层要点与建模拆解预算评估：**

- Baby 是四台机器中**最小、最适合"整机完整建模 + 全元件级展开"**的一台：仅约 550 只管、7 个机架 [S19]。
- **推荐粒度**：整机→子系统（约 5 节点）→电路板（约 20–30 节点）→元器件（可做到**逐管展开**，作为"解剖级教学机"）。
- **核心建模亮点**：三只 CRT 的**屏上亮点图案**必须做进模型/动画——这是 Baby 最独特的视觉特征（玩家能直观"看见内存里的 0 和 1"）。
- **难度点**：① Williams 管写读/刷新的电学原理抽象；② 手工键入程序的交互（可做成"玩家拨开关存字"的可玩环节）；③ 复刻机照片的版权（MOSI/CCS，仅视觉参考）。

## (e) 百科卡全文（C1 级成品文案）

**Manchester Baby —— 只装得下 32 个字，却装下了整个未来**

1948 年 6 月 21 日，曼彻斯特大学的一台机器跑出了人类历史上第一个"存储程序"：程序和数据一起存在内存里，由机器自己一条条取出来执行。这台机器被昵称为"Baby"（婴儿）[S01][S25]。

但"Baby"生来不是为了干活，而是为了**验证一种新内存**：Williams 与 Kilburn 发明的"威廉姆斯管"——用示波管屏幕上的电荷斑点来存 0 和 1。所以 Baby 的内存只有区区 32 个字，每个字 32 位，却已经是那个年代最快的内存了 [S20][S19]。

它的首个程序只有 17 条指令，任务是找 2¹⁸ 的最大真因子。因为 Baby 硬件只会"减法"和"取负"，除法得靠一遍遍相减，这个程序整整跑了 52 分钟、350 万次操作，最后亮出答案 131,072 [S25][S20]。这场"马拉松"证明了一件事：电子存储程序机，真的可靠。

原机早被拆掉去造更大的 Mark 1。今天你看到的那台，是志愿者为纪念它 50 岁生日而亲手复刻的工作机，现在还摆在曼彻斯特科学与工业博物馆里，每周运转 [S19][S21]。

**关键参数（面向玩家）：** 二进制 · 32 字 × 32 位 CRT 内存 · 约 550 只管 · 100 kHz · 只会减法和取负 · 长 5.23 米 · 1 吨 [S19]。

**参考来源：** [S01][S19][S20][S21][S25]。

## (f) 原理讲解大纲（C2/C3/C4）

- **C2（框图层）**：标注三只 CRT（Store/Control/Accumulator）与减法逻辑、面板开关；强调"屏上的点=内存里的位"。
- **C3（信号流层）**：标注三类信号——① 地址（CI→Store）；② 数据（Store↔Accumulator）；③ 时序（100 kHz）。建议做"取指→执行→回写"逐拍动画。
- **C4（原理动画）**：
  - **镜头 1（Williams 管原理）**：电子束扫描屏幕，电荷斑的"写、读、刷新"循环，直观解释"为什么屏幕能当内存"。
  - **镜头 2（手工编程）**：操作员拨动面板开关，把二进制数一个字一个字写进 Store 屏——玩家可互动复现。
  - **镜头 3（减法引擎）**：位串行减法/取负的逐位动画。
  - **镜头 4（首程序 52 分钟）**：加速回放"质因数马拉松"，屏幕亮点随运算跳动，最终定格在答案 131,072。

## (g) 模拟器/演示可行性

**已有开源/可用模拟器现状：**

1. **davidpsharp/baby（Manchester Baby Simulator，Java）**：官方复刻机团队使用的模拟器，界面照片级复刻 Baby 控制面板与三只 CRT；以 **GPL-3.0** 许可开源；仓库 `https://github.com/davidpsharp/baby`，在线版 `https://manchesterbaby.com`，主页 `https://www.davidsharp.com/baby/` [S16][S17][S18]。
2. **网页版在线模拟**：`manchesterbaby.com` 提供浏览器直接运行（经 CheerpJ），三步入门 [S17]。
3. **实体复刻机**：MOSI 的 Baby 复刻机（CCS/ICL，Chris Burton 带队），运行演示可作视频素材（版权属 MOSI，仅视觉参考）[S19][S21]。

**结论：能跑（模拟器生态成熟，开源许可友好）。**

- **能跑**：davidpsharp/baby 为 GPL-3.0 开源，可内嵌/再分发（衍生须同以 GPL 开源），功能完整、界面真实，是四台机器中**许可与可玩性双优**的选择。
- **不能跑/不建议**：Baby 指令集极简（仅减法/取负），"编程"门槛虽低但可玩内容少，需靠"手工键入 + 看屏读结果"的仪式感补足体验。
- **混合方案（推荐）**：静态模型 + 原理动画 + **内嵌 davidpsharp/baby 网页模拟器**作为"可玩"主出口（GPL-3.0 许可允许）。

**方案 A/B 与工作量粗估：**
- **方案 A（推荐）**：静态模型 + C2/C3/C4 动画 + 内嵌 manchesterbaby.com 网页模拟器（或自建 GPL 分发）。工作量：模型 1 人周，动画 1 人周，内嵌联调 0.5–1 人周。
- **方案 B（进阶）**：把"手工拨开关键入首程序、看屏读出 131,072"做成完整的**交互式教学关卡**（基于模拟器改造）。工作量：额外 1–2 人周。

> 许可红线提示：davidpsharp/baby 为 GPL-3.0，可内嵌与再分发，但衍生作品须继续以 GPL-3.0 开源；若只想"外链"而不分发代码，则无开源义务。
