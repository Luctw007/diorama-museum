## ① N=1~5 逐档判读规则（字段口径）

| 字段 | 取值与判读口径 |
|---|---|
| N 台 | 同屏激活台数（拆解/真跑混合），逐级 +1，每级 ≥30s 采样 |
| FPS_avg / FPS_min | 采样窗口均值与最低值；判据 FPS≥30 且无连续掉帧（连续两采样点 <30 记掉帧） |
| frame_ms_p99 | 帧耗时 p99（毫秒）；异常尖峰单独记备注，不因单点超界判卡顿 |
| mem_MB | 进程 RSS 峰值 + 稳定值；只记录不判（供预算表对照） |
| 是否卡顿(y/n) | 综合 FPS 判据结论；y 即该级不达标 |
| 激活形态 | 拆解/真跑混合比（如「3 拆解 + 0 真跑」），与 B-4 语义对齐 |

## ② 异常值处理规则

- **丢帧/掉线**：采样窗口内设备掉线（进程退出）→ 该级记为「无效采样」，标注原因后重采，不填入权威值序列；
- **超界**：FPS 单点 <30 但后续恢复 → 不判卡顿，记备注；连续掉帧 → 判卡顿；
- **采集工具差异**：F-15 表 A/B/C 与 B-4 梯度共用采集时，数值直接转录，不二次加工。

## ③ 权威值判读锚点（272-B 口径）

- 「不卡的最大 N」即权威值；**N=3 达标则默认 3 成立**（当前 CO_ACTIVE_MAX_DEFAULT=3 即 N=3 候选值）；
- N=4/5 仍达标 → 权威值上调为实测最大达标 N；N=3 不达标 → 权威值下调并按实测值回写（311-D 三条件齐备后执行）。
