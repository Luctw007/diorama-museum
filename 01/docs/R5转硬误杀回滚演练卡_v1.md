## ② 回滚步骤（误杀时）

1. `R5_HARD = True → False` 单点回置（release_check.py 模块常量行）；
2. 登记漂移：误杀条目 + 复跑时间写入当轮完成报告漂移节 + 台账 F-16 行；
3. 复跑确认：`python 01/scripts/verify_all.py --daily --cache` + `python 01/scripts/release_check.py` → rc=0；
4. 修复误杀根因后按 311-B 预案再次置 True。
