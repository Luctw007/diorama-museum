## 1. 通用生成约定（三卡共同遵守）

1. **交付格式**（20 号 §1.2 对齐）：48 kHz / 24 bit WAV 母带 + 48 kHz OGG Vorbis q5 立体声；每曲另交**步行层/细听层两份 stem** + 一层「2 s 交叉预混样例」（36 号 §4.1 C-07）。
2. **小节换算**：全部 4/4 拍；1 小节 = 240/BPM 秒。小节数为 DAW 网格参考，**秒针表以 36 号 §2 为准**（段落交界容差 ≤2 s，生成时以 36 号秒针表为准，36 号 loop 点为硬约束）；B3 允许末小节 2/4 收尾（§2.3 表内标注）。
3. **loop 双窗规则**（36 号 §2 各曲循环点）：尾门末 2 s 与引子前 2 s 两个窗口内**只允许 pad 长音/底噪**，不得出现任何旋律音头、钟琴起音、鼓点瞬变（否则循环必然露缝）。
4. **母题 M4**：A2→C3→E3→D3（上小三、上大三、下大二；节奏型长—长—短—长）。三曲必须内嵌 M4（36 号 §3.1），出现方式各卡自定。
5. **负提示总则**（三卡通用，各卡再加专属条）：no lyrics/vocals；no recognizable copyrighted melody or motif；avoid over-compressed loudness（禁止集成响度高于 −14 LUFS 的过亮输出）；no crash cymbals/harsh noise bursts；no 16 kHz 以上持续嘶声；no generic "epic trailer" feel；no recorded acoustic orchestra（一律通用合成器音色，防采样权属）。

## 2. 三张生成参数卡（全文）

### 2.1 卡 B1 黎明厅《真空管的呼吸》（bgm_dawn_01）

| 基础参数 | 值 |
|---|---|
| 曲名 | 《真空管的呼吸》/ The Breathing of Vacuum Tubes |
| 调式 | A 自然小调（主音锚 A2 = 55 Hz） |
| BPM | 69（±2 自由微脉动；小节基准约 69.3，落在 36 号容差内） |
| 拍号/时长 | 4/4；**90 s**（= 26 小节@69.3） |
| loop 点 | 1'28.0 → 0'02.0（双窗规则见 §1.3） |
| M4 出现 | C 细听段以钟琴旋律句完整出现一次（0:56–1:27 内） |

- **风格提示词·中**：二十世纪四五十年代老式机房氛围乐：真空管预热般的低频脉冲如心跳，缓慢的模拟合成和弦垫铺底，偶尔一颗水晶钟琴音点像面板指示灯一闪；肃穆、安静、略带神秘，不悲不喜，像深夜被允许参观一座刚通电的早期计算机展厅；器乐纯音乐，无歌词，无打击乐段落，整体像机器的呼吸而非人的演奏。
- **风格提示词·EN**："Vintage 1940s–1950s machine-room ambient; a low, tube-warm sub pulse as heartbeat; slow analog pad chords; sparse crystalline glockenspiel notes blinking like indicator lamps; solemn, quiet, faintly mysterious — like being allowed into a just-powered early-computer hall at midnight; instrumental only, no vocals, no percussion; the piece should breathe like a machine, not perform like a player."

| 乐器音色清单（通用合成术语） | 参数 |
|---|---|
| 低频脉冲 | sine sub @55 Hz（A2）+ 2nd/3rd 谐波各 −12/−18 dB（拟变压器嗡）；起音 30 ms、衰减 400 ms；每 4 拍一击，第 1 拍重音 +3 dB |
| 和声 pad | saw ×2 微失谐 ±12 cent；lowpass 400 Hz；attack 4 s、release 4 s；无合唱，细听层再加一层高八度弱 pad |
| 钟琴 | sine FM（carrier 2 kHz、ratio 3.5、index 0.3）；衰减约 1.2 s；8–12 s 稀疏随机一拍；力度 45–70 |
| 底噪层 | filtered white noise（低通 1 kHz），恒 −30 dB 以下；0.1 Hz 振幅缓变 |
| 空气感（细听层） | high shelf +10 dB@8 kHz 的极轻空气层，−38 dB 以下 |

- **段落结构小节表**（26 小节 ≈90 s；秒针以 36 号 §2.1 为准）：

| 段落 | 小节 | 时长（s） | 内容 |
|---|---|---|---|
| 引子 | 1–2 | 0:00–0:07 | 心跳脉冲 4 拍后钟琴首现（首现位置在 0:02 后，窗内无音头） |
| A | 3–7 | 0:07–0:24 | 主题句第 1 遍：pad 进 + 稀疏钟琴 |
| B | 8–11 | 0:24–0:38 | pad 和弦上行；脉冲不变 |
| A' | 12–16 | 0:38–0:56 | 主题回归，钟琴密度 +1 |
| C 细听段 | 17–25 | 0:56–1:27 | M4 钟琴旋律句（上移五度重现）；底噪层加深；空气感入 |
| 尾门+衔接 | 26 | 1:27–1:30 | 落主音长音，只留 pad/底噪至 loop |

- **动态层切点**：步行层 = 脉冲+pad+稀疏钟琴（4 声部）；细听层 = +M4 旋律句+空气感（6 声部）；切换触发 = 玩家驻足 ≥2 s，交叉 2 s（36 号 §2.1）；两层集成响度均 −22 LUFS ±1。
- **负提示（专属）**：no piano; no strings vibrato; no church organ; avoid "space documentary" voice-pad cliché; 禁止钟琴在 loop 双窗内起音。

### 2.2 卡 B2 大型机厅《机房的夜》（bgm_mainframe_01）

| 基础参数 | 值 |
|---|---|
| 曲名 | 《机房的夜》/ Night in the Machine Room |
| 调式 | D 多利亚调式（主脉冲锚 D2 = 73 Hz） |
| BPM | **120**（4/4 均匀；全程不 rubato） |
| 拍号/时长 | 4/4；**120 s**（= 60 小节整） |
| loop 点 | 1'58.0 → 0'02.0 |
| M4 出现 | 主段披脉冲外衣，每 32 s 完整一次（0:10–0:58 内两次） |

- **风格提示词·中**：凌晨数据中心的机房氛围乐：空调低频像房间自己的呼吸，磁带机般的低音方波把时间切成均匀节拍，弦乐合成垫在设备列之间缓慢涨落，远处每半分钟一声 FSK 数字短鸣像旧传真机在梦里应答；冷静、秩序、宏大，底层有一丝不眠的温柔；无鼓组、无吉他、无人声。
- **风格提示词·EN**："Post-midnight data-centre ambience; air-conditioning sub-bass breathing like the room itself; a tape-drive-like low square pulse dividing time into steady steps; slow string-synth pads swelling between server rows; a distant FSK digital blip every half minute like an old fax answering in its sleep; cool, ordered, vast, with a thread of sleepless tenderness; no drum kit, no guitar, no vocals."

| 乐器音色清单 | 参数 |
|---|---|
| 低音脉冲 | square + lowpass（1 kHz，包络随拍开合）；每拍 −12 dB 短促，起音 <0.02 s；D2 基频 |
| 走带 tick | 8 分音符高频噪声息 −24 dB（bandpass 6–8 kHz、Q 高）；稀疏进出，B 段前静默 8 s |
| 弦乐 pad | saw ×3 大三度堆叠、attack 4 s；lowpass 1.2 kHz；无揉弦 LFO 只做音量起伏 |
| 空调 bed | sine 32 Hz + 低通 200 Hz；恒幅 −30 dB 以下；全程在 |
| FSK 点缀 | 方波移频键控双音（1270/1070 Hz 短响），每 24 s 一次，−20 dB |

- **段落结构小节表**（60 小节 = 120 s）：

| 段落 | 小节 | 时长（s） | 内容 |
|---|---|---|---|
| 进场 | 1–5 | 0:00–0:10 | 开门热噪声 + 脉冲由稀疏到满拍 |
| 主段 A×2 | 6–29 | 0:10–0:58 | 16 小节循环两遍；M4 披脉冲外衣（每 32 s 一次） |
| B | 30–43 | 0:58–1:26 | pad 上行 + FSK 二连发；tick 层休止 |
| A' | 44–54 | 1:26–1:48 | 回归，tick 进满 |
| 尾缩 | 55–59 | 1:48–1:58 | 脉冲脱拍稀疏化 |
| 尾门 | 60 | 1:58–2:00 | 仅空调 bed → loop |

- **动态层切点**：步行层 = 脉冲+pad+空调 bed；细听层 = +走带 tick + FSK 细节 + pad 展宽 10%；驻足 ≥2 s 触发 2 s 交叉。
- **负提示（专属）**：no techno four-on-the-floor kick; no acid bassline; no aggressive sidechain pumping（侧链抽吸感会破坏"秩序冷静"）；脉冲层禁止叠混响（保持干、近）。

### 2.3 卡 B3 个人机厅《卧室里的未来》（bgm_pc_01）

| 基础参数 | 值 |
|---|---|
| 曲名 | 《卧室里的未来》/ Future in the Bedroom |
| 调式 | C 大调五声音阶（主音 C3） |
| BPM | **104** |
| 拍号/时长 | 4/4；**96 s**（= 41 小节 + 末小节 2/4 收尾，约 95.8 s，36 号 96 s 容差内） |
| loop 点 | 1'34.0 → 0'02.0 |
| M4 出现 | 琶音化，每 8 s 一次（主段 0:08–0:40 内 3–4 次） |

- **风格提示词·中**：放学后把游戏机插上客厅电视的下午：8-bit 方波琶音滴答滴答地转（家用机芯片风），三角波低音线稳稳托底，温暖模拟和弦像夕阳从窗帘缝漏进来，轻快的怀旧鼓点提醒你这不是写作业的时间；轻快、怀旧、一点点偷着乐的兴奋；芯片声部必须原创自谱。
- **风格提示词·EN**："An afternoon after school, plugging a game console into the living-room TV: 8-bit square-wave arpeggios ticking away (home-console chip flavour), a solid triangle bass line, warm analog chords like sunset leaking through the curtains, light nostalgic drums saying it's not homework time; breezy, nostalgic, a little guilty excitement; all chip parts must be original compositions, no sampled game audio."

| 乐器音色清单 | 参数 |
|---|---|
| 8-bit 主琶音 | square ×2 通道（通道 2 加轻颤 5 cent、0.5 Hz）；高一个八度回响；原始 NES 式声部（自谱） |
| 三角波低音线 | triangle；4 分音符根音；无失真的圆润低音 |
| 温暖 pad | saw + chorus（rate 0.3 Hz、depth 20%）；attack 2.5 s；lowpass 2 kHz |
| 鼓点 | 白噪爆点军鼓（0.15 s）+ sine drop 底鼓（80 Hz→40 Hz 扫频 0.2 s）；力度轻（见 §3） |
| 磁带饱和 | 全局 0.5 Hz 轻颤 + 高切 12 kHz（卡带转速不匀的年代味） |

- **段落结构小节表**（41 小节 4/4 + 末小节 2/4 ≈96 s）：

| 段落 | 小节 | 时长（s） | 内容 |
|---|---|---|---|
| 引子 | 1–4 | 0:00–0:09 | 琶音起 + 8 分低音进场 |
| 主段 | 5–17 | 0:09–0:39 | M4 琶音化每 8 s 一次；鼓点渐入 |
| 副旋律 | 18–24 | 0:39–0:55 | 方波双通道对答 + pad 上行 |
| 发展 | 25–39 | 0:55–1:30 | 回主题 + 鼓点满拍 |
| 尾门 | 40–41 + 2/4 | 1:30–1:36 | 只留 pad 与三连琶音（窗内无音头）→ loop |

- **动态层切点**：步行层 = 琶音+pad+低音线；细听层 = +鼓点 + 副旋律高八度呼应 + 展宽 8%；驻足 ≥2 s 触发 2 s 交叉。
- **负提示（专属）**：no copyrighted game soundtrack melody; no original console game sample（芯片声部一律方波/三角/噪声合成）；no dubstep wobble bass; 禁止鼓点在 loop 双窗内出现。
