## ② 图鉴入口联动方案（静态口径）

- 前置事实（241-A 已证）：图鉴（encyclopedia_panel.gd 读 CatalogData 全量目录）与大厅（HallNavPanel 读布局文件）
  **无第二套映射**——布局 devices[].id → 内容包（layout_check L-02）→ 目录（catalog_ref）→ 图鉴条目，链条唯一。
- **图鉴 → 大厅**：图鉴条目详情行已有 device_id 状态行；F-7 实装加「定位到厅」按钮：读全部布局文件找含该 id 的布局
  （hall_group + hall_name）→ 调 `ExhibitHost.switch_hall(布局文件)` → 该台高亮（复用 set_device_highlight）。
  多厅同 id（跨厅复用允许，layout_check WARN）时列全部厅供选（待实机）。
- **大厅 → 图鉴**：HallNavPanel 厅按钮旁加「本厅图鉴」入口：按当前布局 devices 过滤目录条目（CatalogData 按 device_id
  反查，需 02 线目录字段支撑，待核实）→ 打开图鉴面板并定位到对应分片（F-7 实装接线点）。
- 边界：不动 CatalogData 数据层（图鉴只读）；「六厅映射」实为五件布局（hub+四翼），第六件（工作台 F-5 实装）落地后
  同链自动纳入。

## ③ 与 256-A 遗留④「拆解中切厅并发视觉」的关系

- 遗留④（双高亮/输入优先级）是**拆解会话与展厅模式并发的视觉问题**；本卡①的续接高亮是**回厅后的单次引导**——
  两者不同时发生（续接高亮在拆解退出后）。实装 F-7 时需保证：续接高亮不与 ExplodeController 锁定态并存
  （is_explode_locked() 为 true 时跳过续接高亮，口径预登记）。
- 输入优先级沿用既有：面板互斥（HallNavPanel/Encyclopedia/DevicePicker close_panel）+ portal 18px 点选消费。
