## 2. 每台设备一页纸结论

| 设备 | 结论 |
|---|---|
| IBM System/360 | 可看（机柜级 3D）、可拆（机柜→机架→板卡三级）、可懂（微程序+通道+家族兼容）、可玩（Hercules 近亲演示）。核心卖点"一套 ISA 覆盖全谱系 + 兼容承诺"。Hercules=QPL（非 GPL），S/370≠S/360 需明示，IBM OS 授权需规避。 |
| DEC PDP-8 | 可看（静态 3D + 前面板）、可拆（板级 Flip Chip）、可懂（12 位磁芯 + 面板拨键）、可玩（SIMH 跑 FOCAL + 前面板交互）。核心卖点"计算机的下放 + 看得见的运算"。SIMH=MIT-style。 |
| DEC PDP-11 | 可看（静态 3D + Unibus 背板）、可拆（Unibus 插卡）、可懂（Unibus + 8 种寻址 + 正交指令）、可玩（SIMH 跑 UNIX/RT-11）。核心卖点"UNIX/C 的孵化平台"。SIMH=MIT-style；Ancient UNIX License 需核实。 |
| DEC VAX-11 | 可看（外观级 3D + 机柜开合）、可拆（机柜级示意）、可懂（32 位虚拟寻址 + 分页）、可玩（SIMH 跑 VMS/BSD）。核心卖点"虚拟内存的主流化 + VAX MIPS"。SIMH=MIT-style；VMS 社区许可需核实。 |
