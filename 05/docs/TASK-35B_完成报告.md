## 三、开放问题（含生成工具选型建议）

1. **生成工具选型**（任务点名）：建议**图像先行**起步——第一批（case+keyboard）外观件用"文生图三视图参考 → 图像转 3D → 精修"路径，造型可控、迭代快；第二批（mainboard/disk_ii/power）内部结构件用"3D 原生生成 → 重拓扑"路径。无论哪条路径，生成结果都必须过 21 号 MR-01~04 与 24 号样例集。
2. **"61 键"笔误**：任务书 35-B"实机 61 键"与权威来源（Wikipedia/DBpedia）的 52 键不符，本库按 **52 键**纠正（Apple II 原版 52 键大写、II Plus 63 键含小写），已在 23 号卷首与事实锚点表注明。
3. **提示词无法保证执行精度**：提示词能约束意图（键数/材质/比例/后缀），不能保证执行（面数/坐标/命名精确性），故必须与参数卡 + model_check 三件套配合（23 号 §九）。
4. **27-A model_check 未产出**：MR 对照按规则写"将如何保证/仍须人工"，待 model_check.py 产出后校准。
