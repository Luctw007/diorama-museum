## 一、ID_RE 规则原文核对

id 格式：`大类码-中分类码(2~4 大写)-6 位序号`，正则 `^([CGMPAEX])-([A-Z]{2,4})-(\d{6})$`。
大类码：C=计算机 / G=游戏机 / M=通讯与移动 / A=家电影音 / P=办公外设 / E=嵌入式 / X=其他。
