## 二、顺序合理性结论（242-A 原顺序维持）

**结论：维持 242-A 原顺序，不建议调整。**

1. **「有模拟器 → 无模拟器」的分段合理**：#1–#4（System/370 / MSX2 / Macintosh Plus / IBM PC XT）为有明确
   模拟器的 4 台，可走真跑/半真跑通道，前置放前面「先跑起来」；#5–#10（Archimedes / ZX81 / SGI Indigo /
   Compaq Portable / Whirlwind / Newton）为 6 台 none（静态+动画），放后面批量产。分段节奏符合「先难后易、
   先跑后静态」的产包经验。
2. **厅归属叙事连贯**：大型机（System/370）打头 → 个人机 4 连（MSX2/Mac/PC XT/Archimedes/ZX81）→ 工作站
   （SGI Indigo）→ 便携（Compaq Portable）→ 黎明厅镇馆（Whirlwind）→ PDA 收尾（Newton），动线不跳跃。
3. **分档不破坏**：7 A（#1–#7）+ 3 B（#8–#10）与 252-B 一致，三档硬底线（validate 0 FAIL / REF 四查 0 /
   THIRD_PARTY 三件套 / id 唯一 / 反链 REF-02）不降，顺序调整不会带来分档收益。
