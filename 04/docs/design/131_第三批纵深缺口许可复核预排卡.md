## 2. 逐台复核动作汇总（三类）

- 隔离形态登记：4 台有模拟器口径（hercules/openmsx/mini-vmac/pc86box）一律按「GPL/QPL 独立进程隔离 + THIRD_PARTY 三件套 + 二进制不进仓 + 用户自备」执行（02 线定案执行卡 v1 §一第 2/3 项口径）；
- 候选成熟度核实：6 台 none 候选（Arculator/ArcEm、EightyOne/sz81、MAME/QEMU、86Box/PCem、Einstein、Whirlwind 无候选）逐台核实后维持 none 或升级，未核实前一律保守 none；
- ROM 红线：BIOS/ROM/系统镜像（PC XT BIOS、ZX81 ROM、Newton OS ROM、S/370 磁盘镜像等）一律不进仓、不下载、用户自备或清单级引用（03 线收尾档案 §四红线同口径）。

## 3. 交付即验判据占位
