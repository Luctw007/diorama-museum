## 一、取机理由（掌机谱系存量 + 未产包）

- **掌机谱系存量**：`console-batch2/GameBoy掌机谱系参考资材清单_20261106.md` 已收录 Game Boy 系全谱系，GBA 属 Game Boy 系主力续作。
- **未产包**：05 线现有 content 包**无 gba 包**（仅 game-boy）。
- **谱系位置**：GBA（2001）是 32 位掌机，横版造型、游戏库庞大，是 Game Boy 系向 32 位过渡的关键一代。
- 结论：取 **Game Boy Advance** 为掌机线下一台低模预研机型。

## 七、识别件与动画候选

- **卡带插拔识别件**：卡带槽（cartridge_slot）为可插拔识别件；**卡带插拔动画**在后续建模卡以该 node 为插拔轴实现。
- **横置双手握持识别件**：横置机身（chassis）为掌机标志性形态，十字键左、AB 键右的布局是 GBA 操作特色。
- **动画候选**：卡带插拔、开机启动（动画制作排期挂起）。

## 八、建模参数建议（低模口径）

- **材质**：全部 `baseColorFactor` 纯色，**无贴图**，对齐 195-A Game Boy 低模口径。
- **LOD**：低模阶段**不分 LOD 档**；后续纹理建模卡再补 3 档 LOD。
- **部件**：按第三节 5 件分解；chassis 为整机主体，cartridge_slot 为可插拔识别件，其余为独立子节点。
