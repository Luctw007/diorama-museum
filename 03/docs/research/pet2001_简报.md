# Commodore PET 2001 研究简报（TASK-83A）

> 03 线 TASK-83A 备料。个人机厅第十台：1977 三杰的最后一台——Commodore PET 2001 入馆，"Apple II / TRS-80 / PET"三元组齐整。

## 一、史实与来源

**Commodore PET 2001** 是 Commodore 公司于 1977 年发布的 8 位个人电脑，与同年发布的 Apple II、TRS-80 Model I 并称"1977 三杰"。PET 是 "Personal Electronic Transactor"（个人电子事务机）的缩写。

| 参数 | 值 |
|---|---|
| 处理器 | MOS Technology 6502，主频 1 MHz |
| 内存 | 4KB（后期 8KB） |
| 显示 | 内置 9 英寸单色 CRT（绿磷光，40×25 字符） |
| 键盘 | 早期 chiclet 计算器式小方键（后期改全尺寸） |
| 存储 | 内置 Datasette 卡式磁带机 |
| 一体机 | 键盘 + 主机 + 显示器一体成型 |
| 售价 | 795 美元起 |
| BASIC | 内置 Commodore BASIC（Microsoft BASIC 授权） |

**形态特点**（任务书指定建模要点）：PET 2001 是**一体机**——金属外壳（早期梯形斜面造型，颇有"外星飞船"感），键盘、主机、9 英寸 CRT 监视器、磁带机全部集成在一个机壳里，是 1977 三杰里唯一"开箱即是一整台电脑"的设计。

**历史地位**：PET 2001 是 Commodore 从计算器制造商转型电脑公司的开山之作，也是 Commodore 后来 C64、Amiga 辉煌的起点。它内置 BASIC、开箱即用，定位教育与商用，是"个人电脑作为一件完整家用电器"的早期典范。

**来源**：Wikipedia — Commodore PET；Wikipedia — MOS Technology 6502；Computer History Museum 时间线（访问日期 2026-11-04）。
