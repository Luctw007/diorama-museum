## 一、史实

**Whirlwind**（旋风计算机）是美国 MIT 于 1951 年投入运行的真空管计算机，由 **Jay Forrester** 领导研发，是计算机黎明厅不可或缺的一台。它的两大历史地位都极具分量：第一，它是**首台使用磁芯内存（magnetic core memory）的计算机**——Forrester 发明的磁芯内存，解决了早期存储介质的可靠性难题，成为此后二十余年计算机主存的标配，直到半导体内存取代它；第二，它是**实时计算（real-time computing）的先驱**——Whirlwind 不是「算完一批再算下一批」的批处理机，而是能对实时输入做出即时响应，这一能力后来直接支撑了 SAGE 半自动防空系统。磁芯内存 + 实时计算，让 Whirlwind 成为「从实验室走向真实世界」的转折点。

**叙事锚点**：
1. **磁芯内存的先驱**：Whirlwind 首用 Forrester 发明的磁芯内存，是「可靠存储」革命的起点，也是黎明厅磁芯内存叙事的核心 [S133]。
2. **实时计算的诞生**：Whirlwind 是首台能对实时输入即时响应的计算机，是「计算机走出批处理」的转折点 [S133]。
3. **SAGE 的底座**：Whirlwind 的实时能力直接支撑了 SAGE 防空系统，是「计算机进入国防关键任务」的早期见证 [S133]。
4. **黎明厅的真空管群像**：Whirlwind 与 ENIAC、UNIVAC I 等共同构成「真空管时代的巨兽」群像，是「计算机黎明」最直观的实体。

- **L1（外观层）**：成排机柜 + 控制台——静态呈现「真空管时代的巨兽」。
- **L2（结构层）**：打开机柜 → 真空管、磁芯内存模块——拆解展示「磁芯内存与真空管长什么样」。
