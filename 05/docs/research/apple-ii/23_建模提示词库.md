> 任务：TASK-35B（05 线 2/2）· 里程碑 M1 · 为"建模交给生成式 AI（图像/3D）"准备可控输入：每个装配体的提示词 + 可验收的标准样例集，让生成质量从"碰运气"变成"可复测"。
> 依据：`19_建模参数冻结表.md`（几何/预算）、`20_材质规格表.md`（材质）、`21_建模任务卡_第一批.md`（执行口径）、02 线 v0.3 草案。

## 一、提示词设计原则与两步生成流程

### 1.1 设计原则

1. **主提示词全英文可直用**：主提示词为英文（生成式 AI 对英文响应更稳），附中文注释说明意图；负提示词同。
2. **事实锚点进提示词**：键数（52 键）、散热槽、芯片型号等实机事实直接写进提示词，防止 AI"自由发挥"。
3. **先几何后贴图两步**：第一步生成几何（低模网格），验收几何后第二步生成贴图（basecolor/metallic_roughness/normal）。两步分离，避免"几何错 + 贴图对"或"几何对 + 贴图错"混在一起返工。
4. **参数卡约束**：每装配体给输出网格密度（三角面目标）、UV 展开要求、贴图通道清单，与 20 号材质表一致。

### 1.2 两步生成流程与验收中间产物

| 步骤 | 输入 | 输出 | 验收中间产物 |
|---|---|---|---|
| 第 1 步 几何 | 主提示词（几何段）+ 参数卡（网格密度） | 低模网格 glTF | 面数 ≤ LOD1 预算、节点名=node_id、米制 Y-up |
| 第 2 步 贴图 | 主提示词（材质段）+ 参数卡（贴图通道） | basecolor/metallic_roughness/normal | 贴图后缀合法、≤2048 且 2 的幂、自产无版权 |

> 第 1 步不过，不做第 2 步；两步各自独立验收，先几何后贴图，避免返工放大。

## 二、case 上盖（lid）提示词卡

### 主提示词（英文可直用）

```
A beige ABS plastic top cover lid for an Apple II personal computer (1977), 
a smooth foam-molded housing with rounded corners and no sharp edges, 
hinged along its rear edge to open upward revealing the interior. 
The lid is a thin shell with a subtle rear vent grille, a recessed badge 
area on the front top surface, and a smooth seam line where it meets the 
bottom case. Surface is matte beige plastic (roughness ~0.85), low saturation, 
slightly yellowed with age. No texture on the top except the badge recess 
and the vent grille slats. Proportions: width 387 mm, depth 445 mm, height 
about 20 mm for the lid alone. Generate a clean quad-dominant low-poly mesh 
with rounded edges, manifold, watertight, outward-facing normals.
```

> 中文注释：米黄 ABS 上盖，圆润无锐角，后缘铰链可掀起，前顶面铭牌凹位，后部通风栅格，哑光米黄带年代感发黄，387×445 mm。

### 负提示词（英文可直用）

```
No sharp right-angle box, no hard edges, no modern slim laptop style, 
no text or logo rendered on the badge (badge is a blank recess only), 
no beveled chrome trim, no visible screws, no one-piece fake seam (the 
lid-bottom seam must be a real parting line, not a painted groove), 
no overly glossy plastic, no baked lighting or shadows in the albedo.
```

> 中文注释：禁止直角方盒、硬边、现代轻薄本风格、商标图案、镀铬饰条、外露螺丝、假缝隙（一体成型画缝）、高光塑料、烘焙光照。

### 参数卡

| 参数 | 值 |
|---|---|
| 输出网格密度 | LOD1 观察档 ≤500 三角面（三档 ≤50/500/3000） |
| UV 展开 | 顶面/侧面分岛，无拉伸；顶面 UV 占比最大 |
| 贴图通道 | basecolor + metallic_roughness + normal（2048，2 的幂） |
| 单位/轴 | 米、Y-up 右手系 |

### 复用注意
先几何（低模 + 铰链轴）→ 验收 → 再贴图（米黄 ABS + 发黄噪声）。铰链轴（Y=+108mm、Z=−222.5mm、沿 +X）必须在几何步写进顶点，不靠运行时偏移。

## 九、与 02 线 model_check MR 规则的对照（提示词如何保证 / 仍须人工）

| 规则 | 提示词如何保证 | 仍须人工 |
|---|---|---|
| MR-01 节点名=node_id、唯一根 | 提示词约束"one mesh root node named <node_id>" | 节点名最终由导出/命名工具保证，人工核对 validate R-090 |
| MR-02 三档面数预算 | 参数卡写"LOD1 ≤ N 三角面" | 生成器不保证精确面数，须 model_check 实测，超预算人工返工 |
| MR-03 贴图后缀/尺寸/2 幂 | 参数卡写后缀 + 2048 | 生成器可能输出任意尺寸，须人工转 2 的幂 |
| MR-04 米制/Y-up/扩展白名单 | 提示词写"meters, Y-up, right-handed" | 生成器坐标系不一，须导出后校验，必要时人工转轴 |

> 结论：提示词能**约束意图**（键数、材质、比例、后缀），但**不能保证执行**（面数、坐标、命名精确性）。因此提示词 + 参数卡 + model_check 三件套缺一不可：提示词定意图、参数卡定规格、model_check 定验收。

## 附录 B：生成工具选型建议（图像先行 or 3D 原生）

本库的提示词同时适配两条生成路径，选型建议如下：

1. **图像先行（推荐起步）**：先用文生图（如 Midjourney/SDXL）生成三视图参考图，人工核对造型/比例/材质，再用图像转 3D（如 TripoSR、CSM、Meshy）生成低模，最后精修。优点：造型可控、迭代快、成本低；缺点：多一步图像到 3D 的精度损失。
2. **3D 原生（进阶）**：直接用文生 3D（如 Meshy/Tripo 的 text-to-3D、Trellis）生成网格。优点：一步到位；缺点：网格拓扑乱、面数不可控、需要重拓扑。

**建议**：第一批（case+keyboard）用**图像先行**——外观件造型重要、几何简单，三视图参考 + 图像转 3D 最稳；第二批（mainboard/disk_ii/power）用**3D 原生 + 重拓扑**——内部结构件几何规则、更适合直接生成后重拓扑。无论哪条路径，生成结果都必须过 21 号任务卡的 MR-01~04 与 22 号验收清单。

## 附录 C：本库统计口径与迭代

本库按"总非空白字符"统计（含英文提示词，因英文提示词是本库的核心交付物），实测约 7900 字符；中文字符约 1800。提示词主/负两段全文不缩写，事实锚点均附来源编号。迭代 2 轮（见 §十）。
