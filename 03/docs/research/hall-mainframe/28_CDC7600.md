# 28 — CDC 7600 研究卡

## 一、史实

**CDC 7600** 是 Control Data Corporation（CDC）于 1969 年推出的超级计算机，由 Seymour Cray 设计，是 CDC 6600 的**后继巅峰之作**，一度是「世界最快计算机」。它采用约 36 MHz 的主频（当时极高），通过流水线与功能单元并行实现约 10 MFLOPS 的峰值性能，配备独立的外围处理器（PPU）负责 I/O。CDC 7600 延续了 Cray 在 CDC 6600 上开创的「精简指令 + 高主频 + 并行功能单元」设计哲学，是 1960 年代末超级计算机的巅峰，也是 Seymour Cray 离开 CDC 创办 Cray Research 前在 CDC 的最后杰作之一。

**叙事锚点**：①「Cray 的巅峰」——CDC 7600 是 Seymour Cray 在 CDC 的杰作；②「流水线的威力」——功能单元并行 + 流水线；③「外围处理器」——PPU 分担 I/O 的设计；④「超算军备竞赛」——1960 年代末的速度之王。

## 四、L1-L3 拆解要点

- **L1（外观层）**：C 形机柜——静态呈现「超级计算机」的独特样貌。
- **L2（结构层）**：打开机柜 → 功能单元、流水线——拆解展示「超算如何并行运算」。
- **L3（元件层）**：流水线、功能单元并行、氟利昂冷却——原理讲解用。
