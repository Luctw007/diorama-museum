## 一、概述与历史地位

Mega Drive 是世嘉于 1988 年 10 月 29 日在日本发售的 16 位家用游戏机，在北美它有个更响亮的名字——Genesis。它是第四世代主机的开篇之作，也是世嘉从"任天堂的挑战者"变成"能与任天堂正面对抗的力量"的关键一步。它的硬件直接脱胎于世嘉自己的 System 16 街机基板：把街机厅里那颗 Motorola 68000 处理器、那套多层卷轴加精灵的图形系统、那枚 Yamaha FM 合成音源，原样搬进了客厅。这决定了 Mega Drive 的性格——它不是一台"家用玩具"，而是一台"街机味道十足"的机器 [S38][S39]。

## 二、双 CPU 与 FM 音源：MD 的声画架构

Mega Drive 的架构，是典型的"双 CPU 分工"：一颗 16 位的 Motorola 68000 做主 CPU，负责游戏逻辑与画面数据的生成；一颗 8 位的 Zilog Z80 做副 CPU，专门驱动声音芯片（Yamaha YM2612 FM 合成器 + SN76489 PSG），同时兼任世嘉上一代 Master System 的兼容。这种"主 CPU 算、副 CPU 响"的分工，加上 YM2612 那六个 FM 通道发出的尖锐、金属感十足的音色，构成了 Mega Drive 标志性的"声画风格"——后世玩家一听到那种锋利的 FM 贝斯与鼓点，就知道"这是 MD 的声音" [S38][S39]。

## 三、16 位时代争霸：主机战争

Mega Drive 最辉煌的时刻，是它与任天堂 Super Famicom 之间那场著名的"主机战争"。世嘉在北美用一句极具挑衅的广告语"Genesis does what Nintendon't"（Genesis 能做到任天堂做不到的），把家用机竞争变成了一场文化对决。而真正让 Mega Drive 站稳脚跟的，是 1991 年《索尼克》的横空出世——这只蓝色刺猬用超高速的卷轴与流畅的关卡，定义了 Mega Drive"速度与态度"的品牌形象，也终于给了世嘉一个能与马里奥分庭抗礼的吉祥物 [S38]。

16 位时代的这场争霸，本质上是两种硬件美学的对决：Mega Drive 用 68000 的运算速度 + FM 音源的尖锐金属音，主打"快、硬、街机味"；Super Famicom 用 Mode 7 的旋转缩放 + 采样音源的丰富音色，主打"色彩、柔和、艺术感"。这场对决最终以 SFC 反超告终（约 4910 万 vs 3075 万台），但它把"主机竞争"本身变成了流行文化的一部分，也为后世的主机世代之争立下了模板 [S38]。

## 四、美日版本差异

Mega Drive 与 Genesis 是同硬件的两个名字，但定位与叙事却大不相同。日本版 **Mega Drive** 以街机移植见长，走"把街机厅搬回家"的路线；北美版 **Genesis** 则被重新包装成"更酷、更快、更反叛"的少年向产品——"Genesis does what Nintendon't"这句广告语，正是世嘉北美营销团队刻意制造的对抗性定位。硬件上两者几乎一致（仅地区制式差异），但"16-BIT"金色铭牌、"Blast Processing"营销口号、黑色圆润机身，构成了 Genesis 在北美独树一帜的文化符号。这种"同硬件、双叙事"的现象，正是主机战争时代最生动的注脚 [S38]。

## 五、游戏库与 6 键手柄

Mega Drive 的游戏库，是"街机移植 + 原创神作"的双线。《街头霸王 II》《怒之铁拳》《战斧》《雷神传说》等街机味十足的作品，加上《索尼克》《梦幻之星》《光明力量》等世嘉原创，构成了一个偏硬朗、偏动作、偏速度的阵容。后期世嘉还推出了 **6 键手柄**（A/B/C/X/Y/Z），专门为格斗游戏的复杂搓招而设计——这也是家用机手柄向"格斗友好"演进的重要一步，后来的格斗游戏手柄无一不脱胎于此 [S38]。

### 5.1 经典作品举隅

Mega Drive 的几款作品各自定义了一种体验：《索尼克》用高速卷轴重新定义了平台跳跃的"速度感"；《怒之铁拳》系列确立了家用机清版动作的标杆；《梦幻之星》系列把日式 RPG 带上了 MD；《光明力量》则把战棋玩法带给了家用机玩家。而大量街机移植作（《街头霸王 II》《战斧》《太空哈利》）则兑现了 MD"把街机厅搬回家"的承诺。这些作品共同塑造了 MD"硬朗、动作、街机味"的独特气质，与 SFC 的"细腻、色彩、叙事"形成鲜明对照。

### 5.2 与第一批（Atari 2600 / Famicom）的叙事衔接

把 Mega Drive 放到游戏机厅的完整时间线上看：Atari 2600（1977）用卡带确立了"主机—软件"分离的范式，Famicom（1983）用授权体系与 PPU 复苏了崩溃后的行业，而 Mega Drive（1988）则用 68000 与 FM 音源把家用机推进到 16 位时代。三台一脉相承——都是"卡带即内容"，但每一代都在"算得更快、画得更好、响得更亮"上迈进一步。MD 是这条线索上"速度"这一支的极致表达，它接过了 Atari 2600 的街机血脉、站在 Famicom 打下的家用机地基上，把游戏带进了"16 位主机战争"的新纪元 [S38]。

## 六、兴衰与遗产

Mega Drive 的后期，成了世嘉"扩展策略"混乱的缩影：Sega CD、32X、LaserActive 等一堆扩展外设让硬件生态变得支离破碎，最终在 16 位时代末期被 Super Famicom 反超。全球累计销量约 3075 万台，虽然不及对手，却足以让它成为世嘉历史上最成功、最具文化符号意义的一代主机 [S38]。

对一座电子博物馆而言，Mega Drive 是"16 位时代"叙事里绕不开的开篇：它以 68000 + FM 音源定义了"街机味家用机"的硬件范式，以《索尼克》定义了"速度"的品牌范式，以"主机战争"定义了整个 16 位时代的竞争格局。它与 Super Famicom 一前一后，构成游戏机厅"16 位双子星"的完整故事。

## 六之补、68000 的街机血统与 FM 音源原理

Mega Drive 的"街机味"，根子在它那颗 Motorola 68000 上。68000 是 1979 年问世的 16/32 位处理器，当年正是街机与高端个人电脑的主流 CPU——世嘉自家的 System 16 街机基板就围绕它构建。把这样一颗"街机之心"装进家用机，意味着 Mega Drive 从出生起就带着街机的运算风格：快速、硬朗、擅长处理动作与卷轴游戏。而 YM2612 FM 音源则给了它另一重身份——FM（频率调制）合成是 1980 年代电子乐器的主流技术，六通道 FM 能合成出贝斯、鼓、金属音色的丰富层次。68000 的速度 + FM 音源的锐利，共同塑造了 MD"快而硬"的声画性格，这正是它区别于 SFC"柔而丰"的关键 [S38][S39]。

## 六之补二、型号沿革

Mega Drive 在近十年的生产史中经历了多次改款：最早的 **Model 1（1988）** 机身圆润、带耳机孔与音量滑杆、金色"16-BIT"铭牌，icon 性最强；**Model 2（1993）** 小型化、去掉耳机孔、改用 AV 输出；此外还有 Sega CD、32X 等扩展外设与 Genesis 3、Nomad 掌机等变体。这些改款的核心（68000 + Z80 + YM2612）自始至终未变，差异集中在机箱造型、输出接口与扩展生态。本设备包垂直切片选定 Model 1 造型，最贴近"1988 年 16 位时代开篇"的叙事定位 [S38]。

## 六之补三、馆方展示定位

在博物馆环境中，Mega Drive 与 Super Famicom 建议**并列展示**，构成"16 位主机战争"专区。MD 的展示重点在**双 CPU + FM 音源**——观众可点选 68000 与 Z80 两颗芯片，看"一颗算、一颗响"的分工；耳机孔（Model 1 特有）可让观众插上耳机，亲耳听 YM2612 那标志性的金属音色。金色"16-BIT"铭牌与"Blast Processing"营销梗可作为文化符号讲解点，与 SFC 的四色 logo 形成对照。这是"可看、可拆、可懂、可玩"四可标准在 16 位主机上的落点，也是游戏机厅第三台（2600/FC/MD）动线里"16 位争霸"章节的物理载体。

### 7.1 与 Super Famicom 的参数对比（16 位双子星）

| 维度 | Mega Drive（1988） | Super Famicom（1990） |
|---|---|---|
| 主 CPU | 68000 @ 7.67 MHz | 5A22（65C816）@ 3.58 MHz |
| 声音 | YM2612 FM 六通道 | S-SMP 采样音源 8 通道 |
| 显示 | 320×224，512 色 | 256×224，32768 色 |
| 图形特色 | 多层卷轴 + 精灵 | Mode 7 旋转缩放 |
| 风格 | 快、硬、街机味 | 柔、丰、艺术感 |

> 这张对比表是"16 位主机战争"的核心讲点：MD 赢在 CPU 主频与 FM 音色的锐利，SFC 赢在调色板与 Mode 7 的图形魔法。两台并置，一台讲速度、一台讲色彩，构成 16 位时代最经典的技术对决。

### 7.2 运行与输入说明（馆方提示）

本设备包 runtime 以 **BlastEm（GPL-3.0）** 为技术基线声明（demo 起步，不接真实二进制）。运行时画面经 `external_crt` sink 投放到 CRT 演示位（320×224 游戏分辨率），声音经 `speaker_0` 输出（MD 的 FM 音色建议保留原声、不做过度混音）。input_map 覆盖十字键（hat_0）与 A/B/C 三键（btn0/1/2）及 Start，六键手柄的 X/Y/Z 键作预留扩展（本包以 3 键为默认、6 键为扩展，对应 Model 1 早期的 3 键手柄）。卡带导入沿用"自备实机备份 + 版权方授权"合规口径，游戏绝不内置。

### 历史评价与文化影响

Mega Drive 的历史地位，常被一句话概括：它让世嘉第一次真正站到了能与任天堂对弈的擂台上。在它之前，世嘉的 SG-1000 与 Master System 都被 Famicom 压得喘不过气；在它之后，世嘉靠《索尼克》与"Blast Processing"营销在北美与任天堂打了个平手，甚至一度领先。它留下的遗产远不止 3075 万台销量——《索尼克》至今仍是世嘉的头号 IP，"Genesis does what Nintendon't"仍是游戏营销史上的经典案例，而"主机战争"这个概念本身，也因 MD 与 SFC 的对决而成为流行文化的一部分。一台 1988 年的黑色主机，定义了整整一个时代的竞争气质，这正是它值得在博物馆里被郑重展示的原因。它与其对手 SFC 的并置，也将是游戏机厅 16 位时代展区最富张力的一个展项，值得观众在两台主机前驻足对比它们的声画风格。
