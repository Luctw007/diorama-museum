## ① 切厅性能口径

| 项 | 口径 |
|---|---|
| 切换耗时目标 | 白模阶段 <100ms/次（单场景多厅方案 A，无 PackedScene 加载帧）；正式资产后按本表复测校准 |
| 清场重建预算 | switch_hall = clear_devices（O(N) remove_child+queue_free）+ spawn_devices（N 台 DeviceLoader 惰性加载，N=单厅台数现 1~4）；PortalHub.refresh_portals 同帧重建门框（_clear_portals remove_child 防同名冲突） |
| 同帧峰值 | 切厅瞬时旧厅 N 台 + 新厅 N 台同帧在内存（queue_free 帧末释放）——同屏预算按 max(旧,新)+1 预留 |
| B-4 关联 | `co_active_max` 同屏激活上限（02 线待办 B-4，默认 3 待实测）——真跑三台 RC 出来后实测定权威值；切厅预算与该值同源（激活≠同屏实例，两口径分别测） |
| LOD 输入 | layout `lod_scale`（L-13）为 F-4 预算表的厅级参数，特写/观察/远景三档阈值 ×lod_scale |
| 帧率保护 | exhibit_host.refresh_budget_hint = placed×2 流程位（讲解+演示）预留接口 |

## ② 白模灰盒校准清单（逐条待实机校准）

1. hub 门框尺寸 1×2.4×0.2 与玩家身高/视高的比例观感；
2. 门框半透明色（0.85,0.9,1.0,α0.35）在环境光下的可读性；
3. 四门框间距（x=±2.5/±7，z=-5）与「一眼可见三步可达」动线吻合度；
4. 子厅反向门位置（z=+5.5）与各厅入口对齐；
5. 设备占位盒在 hub/四厅的朝向（rotation 缺省；04 线朝向角转换 `rotation.y=deg_to_rad(-朝向角)` 待核对）；
6. 调试圈（audience_radius=2.2）与围观站位/导览站位匹配；
7. 相机高度 1.7、移动速度 3.0 与各厅尺寸（20×12 等）的穿厅耗时——「三步可达」实测校验。
