## 一、新增三机键位表（Wii U / PlayStation 4 / Xbox One）

三机 `input_map` 枚举动作名一致，均为 `d_pad_up/down/left/right`、`button_a`、`button_b`、`button_x`、`start`，全部映射到键盘：

| 动作 | Wii U（GamePad） | PlayStation 4（DualShock 4） | Xbox One |
|---|---|---|---|
| 上 | d_pad_up → KEY_UP | d_pad_up → KEY_UP | d_pad_up → KEY_UP |
| 下 | d_pad_down → KEY_DOWN | d_pad_down → KEY_DOWN | d_pad_down → KEY_DOWN |
| 左 | d_pad_left → KEY_LEFT | d_pad_left → KEY_LEFT | d_pad_left → KEY_LEFT |
| 右 | d_pad_right → KEY_RIGHT | d_pad_right → KEY_RIGHT | d_pad_right → KEY_RIGHT |
| 主键 1 | button_a → KEY_A | button_a → KEY_A | button_a → KEY_A |
| 主键 2 | button_b → KEY_B | button_b → KEY_B | button_b → KEY_B |
| 主键 3 | button_x → KEY_X | button_x → KEY_X | button_x → KEY_X |
| 开始 | start → KEY_ENTER | start → KEY_ENTER | start → KEY_ENTER |

> 三机键名均符合 `^KEY_[A-Z0-9_]+$`；动作名与各包 runtime.json 逐键核对一致。
> 三机 `input_map` 均只登记上述 8 个动作名；触屏、双摇杆、肩键/扳机、Home/Options/Xbox 等实体键均无枚举动作名（见下节）。
