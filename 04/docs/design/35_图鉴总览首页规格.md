## 2. 推荐位「今天看哪台」

### 2.1 推荐分公式（具体系数）

```
S(i) = 0.40·IN(i) + 0.35·PR(i) + 0.25·RAND(i)          （各项 ∈ [0,1]，S 高者先出）
```

| 分量 | 定义 | 换算规则（全量） |
|---|---|---|
| IN(i) 影响力 | 目录 `reason` 文本长度 L（字，schema ≤60 字） | IN = min(1, L/50)；status 加成：done +0.25、researching +0.15、planned +0（封顶 1.0）；`booking_count`>0 再加 min(0.15, 次数×0.01) |
| PR(i) 未参观进度 | 足迹与收藏联合档 | 从未看过且未收藏 = 1.0；看过 1 次 = 0.6；看过 ≥2 次未收藏 = 0.3；已收藏 = 0.15（收藏者少推重复，收藏走 §3.1 入口） |
| RAND(i) 随机 | 每日种子伪随机 | seed = hash(本地日期 + id 前 8 字符，FNV-1a)，当日恒定；[换一组] 时 seed 拼接轮次号重摇，产出 ∈ [0,1) |

### 2.2 冷启动与补位规则

1. **冷启动**（无 profile.json 或首次进入）：PR 全 1.0，只比 IN 与 RAND；抽样分两层——done 层必出 1 台（镇馆位），另 2 卡从非 done 池按 S 取高 2 名。
2. **done 保底**：任何一天的三卡组**至少含 1 台 status=done 且 device_id 非空**（可直达展厅）；若按 S 取前三无 done，用第 4 名 done 顶替分数最低卡；done 池 = 目录实算 19 行（去重 16 台）。
3. **快速翻动去抖**：三卡组与上一组完全同名时强制重摇，最多 3 次；3 次后允许重复并出提示「已看完全部推荐」。
4. **空库容错**：目录 0 条 → 三卡位渲染「目录筹备中」三引导（同 §3.3 文案降级版），不崩。

## 3. 收藏与足迹

### 3.1 收藏夹入口

- 位置：首页右上角徽章钮 `[收藏 n 台]`（n = 当前收藏数，0 时显示「收藏 0」不隐藏）；点击进收藏列表页（复用 31 号 §1.4 虚拟滚动池 40）。
- 收藏动作：31 号 §2.2 详情页动作区**新增 [收藏/已收藏] 切换钮**；收藏成功播 sfx_badge（04 号 §1.1）+ toast「已收藏，可在首页收藏夹找到」。
- 收藏页每行 = 名称/年代/状态徽章/移除 ×（33 号 token 胶囊同型）；全删后显示空态「还没有收藏。去逛逛环图或让『今天看哪台』带你发现第一台吧。」

### 3.2 最近参观历史（8 条）

- 首页底部「最近参观」条带，**容量 8 条**（FIFO 淘汰，同设备合并计 n 次）；每行 = 缩略 32²/名称 t-small/相对时间（「2 分钟前 / 昨天 / 11-02」三档粒度）/上次状态徽章；点击进详情。
- 参观记录时机：详情页停留 ≥2 s 计 1 次（防误触点进即计数）；[进展厅] 跳转与展厅内开机运行 ≥10 s 亦计 1 次（双源写入，取并集去重）。
- 空态：「足迹还没有印子。点一张推荐卡，或从环图进一个分类看看。」（t-caption c-text-2）。

### 3.3 首次进入空态引导

- 触发：profile.json 不存在或 `guide_done=false`；页面左下弹引导卡（m-paper，radius-m，三行三步）：
  1. 「点环图任一扇区＝按大分类浏览目录」；
  2. 「点『今天看哪台』推荐卡＝直接进那台机器」；
  3. 「进详情页点 [收藏]，常看的机器留进首页收藏夹」。
- [知道了] 关闭并写 `guide_done=true`（不再弹）；[稍后] 关闭本次会话，下次进入再弹。
