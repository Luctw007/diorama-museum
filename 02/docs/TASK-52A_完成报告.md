## 三、taxonomy 树全文摘录（三级结构）

**7 大分类**：C 计算机 / G 游戏机 / M 通讯与移动 / A 家电影音 / O 办公与计算外设 / E 嵌入式与工业 / X 其他。

**31 中分类**（每类代表性机型）：
- 计算机（8）：早期计算机（ENIAC/EDVAC/EDSAC/Manchester Baby）、大型机（System/360/CDC 6600）、小型机（PDP-8/11/VAX/Nova）、个人机（Apple II/C64/IBM 5150/PC-98）、工作站（Sun/SGI/NeXT）、服务器、手持计算（Psion/HP LX）、超级计算机（Cray）；
- 游戏机（4）：家用机（FC/MD/PS/Xbox）、掌机（GB/GBA/PSP）、街机（Neo-Geo MVS）、游戏电脑（MSX/Amiga）；
- 通讯与移动（4）：手机、寻呼机、固定电话、PDA；
- 家电影音（4）：影碟播放、录像机、音响、电视；
- 办公与计算外设（5）：打印机、显示器、键鼠输入、存储外设、计算器；
- 嵌入式与工业（4）：单板机、工控机、PLC、单片机开发；
- 其他（2）：未分类、教具/模型。

## 四、目录条目 schema（11 字段）

`id`（必填，全库唯一）· `name`（必填）· `aliases[]`（可选）· `maker`（可选）· `origin`（可选）·
`year`（可选，[1880,当年+1]）· `path[]`（必填，三级落在 taxonomy 树内）· `reason`（必填，≤60 字非空）·
`status`（必填，planned/researching/package/wip/done）· `device_id`（条件：done/package 必填）·
`sources[]`（可选）。
