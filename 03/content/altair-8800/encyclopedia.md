# MITS Altair 8800 — 百科

> 本文以研究卡（`docs/research/hall-personal-batch2/09_Altair8800.md`）(a) 节史实底稿为底本改写扩容，保留来源编号 [S94]–[S97]。

## 一台机器，点燃一场革命

1975 年 1 月，一份名为《Popular Electronics》的大众电子杂志，把一台其貌不扬的机器放上了封面。那是一个蓝灰色的金属箱子，前面是一排拨动开关和一排红色的小灯。杂志编辑给它的标题很直白——「世界第一台微型电脑套件，足以与商用机媲美」[S94]。

这台机器叫 **Altair 8800**，出自美国新墨西哥州阿尔伯克基一家名叫 MITS 的小公司之手。它的名字取自当时热播科幻剧《星际迷航》里的一颗星球「牛郎星」（Altair）。谁也不会想到，这个浪漫的名字，会在日后成为「个人电脑革命」的起点。

在那之前，计算机是庞然大物，属于政府、大学和大企业，普通人只能隔着玻璃窗仰望。而 Altair 8800 第一次说：**你，也可以拥有一台属于自己的电脑**。它的广告一出，订单像雪片一样飞来，MITS 这家濒临倒闭的小公司，一夜之间被救活了 [S94]。

## 它到底是一台什么样的机器

Altair 8800 的核心，是一颗 **Intel 8080** 处理器——8 位、约 2 MHz 的运算心脏 [S94]。以今天的眼光看，这点算力连一块电子表都比不上，但在 1975 年，它意味着「一台真正的电脑」可以被压缩进一个机箱里。

它的内存小得可怜，标配只有 256 字节，连存一首歌的前奏都不够；扩展之后也不过几千字节 [S94]。它没有显示器，没有键盘，没有鼠标，更没有我们今天习以为常的操作系统。要和它「对话」，你只能靠前面板。

前面板是 Altair 8800 最有辨识度的部分，也是它最迷人的地方。左边是一排拨动开关，往上拨是 1，往下拨是 0；右边是一排红色 LED 灯，亮代表 1，灭代表 0 [S94]。想往机器里输入一条指令，你得先拨动开关设定好这串二进制，再按下一个按钮把它「存进去」，然后看着那排灯一闪一闪，确认它真的记住了。整个过程，一字节、一字节，慢得像在跟一台机器说悄悄话。可正是这种笨拙的仪式感，让无数当年的爱好者第一次「看见」了计算机最底层的心跳。

## 一条总线，一个开放的生态

Altair 8800 能走红，还因为一个看似不起眼的设计——它的扩展总线。MITS 为了让机器能加内存、能接外设，在机箱里留了一排扩展插槽。这个总线后来被整个行业采纳，成了大名鼎鼎的 **S-100 总线**标准 [S95]。

S-100 的意义，不亚于 Altair 本身。它意味着：任何一家厂商，只要照着这个标准做一块卡，就能插进 Altair 里用。于是，内存卡、串口卡、软盘控制器、各种稀奇古怪的外设卡如雨后春笋般冒了出来。IMSAI 8080 等一批「兼容机」也应运而生 [S95]。一个**开放的硬件生态**，就这样在这台蓝灰色箱子上生根发芽——这几乎是「开放架构」理念在个人电脑史上最早的实践，几十年后，它依然回荡在每一台兼容机、每一块扩展卡的血脉里。

## 微软的第一行代码

如果说 Altair 8800 是硬件革命的起点，那么它还顺手点燃了另一场革命——软件革命。

1975 年，两个年轻人看到 Altair 8800 的广告，动了心思。他们写信给 MITS，声称自己为 Altair 写了一个 BASIC 解释器，问对方想不想要。MITS 说想。于是这两个年轻人——Paul Allen 和 Bill Gates——在连一台真机都没有的情况下，用手写汇编，硬是在模拟器上把 **Altair BASIC** 写了出来 [S96]。

当 Allen 带着一卷打孔纸带飞到阿尔伯克基，把程序装进真机、第一次跑通时，这台机器上亮起了一行字：**「READY」**。那是微软（当时还叫 Micro-Soft）的第一款产品，也是两个年轻人改变世界的开始 [S96]。

今天回头看，这个故事几乎带着神话色彩：一台套件机、两个年轻人、一卷纸带，催生了一家日后统治软件行业的公司。可以说，微软帝国的第一块地基，就是打在 Altair 8800 这台机器上的。

## 深度解读

**解读一：套件的浪漫。** Altair 8800 是作为「套件」发售的——你收到的不是一台装好的机器，而是一堆散件、一块主板、一袋元件，外加一本厚厚的组装手册 [S94]。你得自己拿起电烙铁，一个焊点一个焊点地把它们拼起来。对今天的用户来说，这近乎不可想象；但对 1975 年的爱好者来说，这恰恰是最大的魅力——**亲手把一台电脑「造」出来**的成就感，是任何成品机都给不了的。这种「从零件到机器」的过程，让第一批个人电脑用户，天然地成了最懂电脑的一批人。

**解读二：拨键时代的虔诚。** 在 Altair 8800 上输入程序，是一场近乎宗教仪式的过程：拨动开关、按下按钮、核对灯亮，一字节一字节，错一位就得从头再来 [S94]。这种笨拙，逼着程序员去理解计算机最底层的东西——什么是地址，什么是数据，什么是取指与执行。今天我们用着高度抽象的开发工具，几行代码就能完成当年几天的工作，但那份对机器「每一根线、每一盏灯」的敬畏感，却随着抽象的加深而逐渐淡去。Altair 8800 提醒我们：抽象之上，永远有最朴素的原理值得被看见。

**解读三：开放生态的种子。** S-100 总线之所以能成为标准，不是因为 MITS 多么高瞻远瞩，而是一个朴素的商业现实：一家小公司做不出所有外设，不如把接口公开，让整个行业一起做 [S95]。这个被逼出来的决定，意外地长成了「开放硬件」的种子。后来的 IBM PC 之所以能催生整个兼容机产业，走的正是同一条路——开放总线、开放接口、让生态自己生长。追根溯源，这条路的第一个脚印，就是 1975 年印在 Altair 8800 背板上的。

**解读四：车库里的火种。** Altair 8800 点燃的，不只是几个人的热情，而是一整片社区的星火。围绕它成立的 Homebrew Computer Club，汇聚了当时最狂热的电脑爱好者 [S94]。在这间车库里，Wozniak 展示过 Apple I 的雏形，无数未来的创业者在交换代码、分享电路、互相启发。硅谷的传奇，有很大一部分，就是在「因为一台 Altair」而聚到一起的这些人中间开始的。一台机器，改变的不只是技术，还有人与人连接的方式。

**解读五：软件与硬件的同源。** Altair 8800 最动人的地方，在于它同时见证了硬件革命与软件革命的起点——前面板拨键是硬件的原始图腾，Altair BASIC 则是软件的滥觞 [S96]。同一台机器，一头连着「个人电脑」这个硬件梦想，一头连着「软件公司」这个后来的万亿产业。这种同源性，让 Altair 8800 在科技史上占据了几乎独一无二的位置：它是两场革命共同的发令枪。

## 它为什么值得被记住

Altair 8800 不是最好的电脑，甚至不是最实用的电脑。它难用、易错、容量小、没有软件。但它做对了一件最重要的事：**它让「个人电脑」这个概念，从一个遥不可及的幻想，变成了一件可以买回家、亲手组装、亲手编程的真实物品** [S94]。

在它之前，计算机属于机构；在它之后，计算机开始属于每一个人。正是 Altair 8800 掀起的这波热潮，吸引来了 Steve Wozniak 和 Steve Jobs，催生了 Apple II；吸引了无数爱好者俱乐部，催生了 Homebrew Computer Club——那间孕育了硅谷无数传奇的车库俱乐部 [S94]。

所以，当你站在这台蓝灰色箱子前，请别急着评价它「落后」。去看它前面板那排拨键和那排红灯——那是一个时代的起点。拨一下开关，看一盏灯亮起，你亲手触碰的，正是「个人计算」从零到一的那一瞬间。

## 在展厅里怎么看它

站在 Altair 8800 前，先把目光停在两处：**那排拨键开关**，和**那排红色 LED 灯**。这两样东西，就是 1975 年一整代程序员与电脑「对话」的全部。没有屏幕，没有键盘，只有 0 和 1 的开关，与 0 和 1 的灯光。看懂这两处，你就看懂了「计算机最原始的样子」。

然后去看它机箱里的 S-100 背板。那一排扩展插槽，是「开放硬件」最早的雏形——正是这份开放，让 Altair 从一个产品，长成了一个生态，进而长成了整个个人电脑产业。

最后，请听一段「微软第一行代码」的故事：1975 年，两个年轻人，一卷打孔纸带，一台 Altair 8800，屏幕上亮起「READY」。那一刻，硬件革命与软件革命在同一个盒子里交汇，数字时代的两条巨流，就此奔涌而出。

## 术语小词典

- **Altair 8800**：MITS 1975 年推出的微型电脑套件，个人电脑革命的起点 [S94]。
- **Intel 8080**：Intel 出品的 8 位微处理器，Altair 8800 的运算核心 [S94]。
- **S-100 总线**：由 Altair 扩展总线演化而来的行业标准，开放硬件生态的早期范本 [S95]。
- **Altair BASIC**：Allen 与 Gates 为 Altair 8800 编写的 BASIC 解释器，微软的首款产品 [S96]。
- **前面板拨键 + LED**：没有键盘与显示器时代的手工编程方式，拨键输入、看灯观察 [S94]。
- **MITS**：Micro Instrumentation and Telemetry Systems，Altair 8800 的制造商，创始人 Ed Roberts [S94]。
- **Homebrew Computer Club**：由 Altair 热潮催生的爱好者俱乐部，孕育了早期硅谷的众多传奇 [S94]。
- **套件（Kit）**：以散件形式发售、由买家自行焊接组装的产品形态 [S94]。
