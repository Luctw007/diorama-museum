## 1. 模拟器选型对比与建议

### 1.1 候选对比

| 维度 | AppleWin | MAME apple2 |
|---|---|---|
| 许可 | **GPL-2.0**（源码 `LICENSE`，S09） | **GPL-2.0**（整体；部分文件 BSD-3 双许可，S07/S08） |
| 覆盖机型 | II、II Plus、IIe、Enhanced IIe + 克隆（Pravets/TK3000/Base64A）；**不支持 //c、IIgs** | apple2（II）、apple2p（II Plus）、apple2e/ee/ep、apple2c 系、apple2gs 系 + 大量克隆（S07） |
| 成熟度 | 1994 年起，长期维护（Tom Charlesworth），v1.32.1.0（2026-10），内置符号调试器 | MAME 官方长期维护，0.287（2026-03）持续改进 Apple II 光栅效果与软件清单（S16） |
| 跨平台 | **官方仅 Windows**；Linux/macOS 为非官方移植（LinApple 另立） | **Windows/macOS/Linux 官方支持**（含 SDL2/SDL3） |
| 扩展卡支持 | Mockingboard/Phasor/SAM、Disk II、硬盘、SSC、Z80 SoftCard、Uthernet 等（非常全） | 语言卡、Mockingboard、Disk II、CFFA 等（槽位可配置） |
| 磁盘/媒体格式 | .dsk/.do/.po/.nib/.woz/.2mg/.hdv 等 | 软盘 -flop1/-flop3、硬盘 -hard1、软件清单 |
| 作为网关后端难度 | 官方无头/脚本化控制接口较少；以 GUI 为主，进程+协议集成需另接（Libretro 核心可作接口） | **有成熟命令行 + `-listdevices`/`-listslots` + LUA console + 输出参数**，天然适合"进程 + 控制协议"集成 |
| 与 PROTOCOL.md 契合 | 需自建后端适配层 | 需自建后端适配层（两者都要写 `gw/emulators/*` 后端） |

### 1.2 建议

**建议首选 MAME（`apple2`），AppleWin 作为备选/交叉验证。**

理由：
1. **跨平台**：项目首发 Windows/Linux/macOS（FR-I I3），MAME 三平台官方支持，AppleWin 官方仅 Windows，与平台矩阵冲突。
2. **进程 + 控制协议集成**：MAME 的命令行 + 输出系统 + 可扩展性更适合作为 `gw` 的独立后端进程（与现有 `simh-pdp8` 后端架构同构）；AppleWin 偏 GUI，需要绕行（Libretro 核心是可行但增加一层依赖）。
3. **许可同档**：两者均 GPL-2.0，进程隔离（ADR D1）即可，无许可优势差异。
4. **机型覆盖**：MAME 覆盖 II/II Plus/IIe/IIgs 全家族，若日后垂直切片升级到 IIe 或做"II→IIe 演进"展厅，无需换模拟器。

**保留 AppleWin 的价值**：扩展卡生态极全、内置符号调试器强，适合作为**验证/调试**工具与"运行档交叉验证"；其 GPL-2.0 与 Libretro 核心也便于 Windows 用户本地对照。**最终 `[TBD]` 由作者拍板**（本建议写入 07 章完成报告）。

## 2. 媒体与固件研究

### 2.1 最小媒体集合（运行一台 Apple II 所需）

| 类别 | 内容 | 必要性 | 备注 |
|---|---|---|---|
| 系统 ROM | 12 KB 系统 ROM（Monitor + BASIC，芯片 341-0011…341-0015 + 341-0020） | **必需** | 无 ROM 无法开机 |
| 字符发生器 | chargen 341-0036（2 KB） | **必需** | 视频字形 |
| 磁盘引导 ROM | Disk II 341-0027（P5，16 扇区） | 仅磁盘机型需要 | 磁带机型不需要 |
| 启动媒体 | DOS 3.3 系统盘镜像 / 或磁带引导 | 二选一 | 演示"开机"体验用 |

### 2.2 授权现状与合法获取渠道（逐项核查）

| 项 | 授权现状 | 合法获取渠道 | 判定 |
|---|---|---|---|
| Apple II 系统 ROM（341-xxxx 系列） | **Apple 版权**；Apple v. Franklin（1983）确立 ROM/固件可受版权保护（S11）。Apple **未**发布免费再分发许可 | ① 用户从自有 Apple II 实机读取（自备份）；② 版权方许可的来源 | **不可随游戏分发**；引导文案指向"自有实机备份"，不得指向盗版镜像站 |
| 字符发生器 ROM | 同上（Apple 版权） | 同上 | 同上 |
| Disk II 引导 ROM | 同上（Apple 版权） | 同上 | 同上 |
| Apple DOS 3.3 / 系统盘 | Apple 版权；但 **CHM 已获 Apple 许可公开 1978 DOS 源码（仅限非商业使用）**（S06） | CHM Software Gems（非商业）；用户自备份 | 源码可作研究参考；**可运行磁盘镜像仍不可随游戏分发** |
| 第三方软件（游戏/工具） | 各自版权（多数仍受版权保护，"abandonware" 不是法律豁免） | 版权方授权、Internet Archive 4am 收藏等存档（法律灰色，S15 引证） | **不提示盗版渠道**；仅引导至官方/授权源 |

### 2.3 引导文案要点（FR-E3 运行向导）

1. 说明 Apple II 的 ROM/固件仍受 Apple 版权保护，游戏本身不内置、不提供。
2. 指引玩家**从自己拥有的 Apple II 实机读取 ROM**（这是合法自备份路径）。
3. 说明 Apple 已通过 CHM 公开 DOS 源码供**非商业研究**（附链接），但可运行镜像需自行取得。
4. 明确"本游戏不怂恿、不提供任何盗版渠道"；缺失媒体时设备降级为静态展示（可看/可拆/可懂）。
5. 给出导入目录与文件名约定（对接 `content/<device-id>/media/` 规范，待 TASK-02 定稿）。

> 合规底线（FR-J1）：**仓库永不含任何 ROM/固件/受版权保护磁盘镜像**；本任务只研究授权与渠道，不下载（红线 §六 2）。

## 4. 与 TASK-01 假模拟器验证的衔接

1. **第一步（已具备）**：TASK-01 的 `fake_emulator.py` 已能产出彩条帧，经 `gw` 流回 Godot 投到"屏幕"表面。用它验证 **Apple II 内屏 CRT 的投放链路**：即把 fake 帧投到 Apple II 模型的 9" 内屏材质上，确认 `output_sinks[].surface="crt:internal"` 的路由正确（FR-E4）。
2. **第二步（M1 接入真实模拟器）**：新增 `gw/emulators/apple2.py` 后端，复用 fake 后端同款 stdio 协议（PROTOCOL.md §5），把 MAME `apple2` 的帧/音频/输入转成网关消息；此时屏幕投放链路已用彩条帧验证过，切换只替换后端，风险集中、可回滚。
3. **验收脚本**：在 M0 的 `scripts/m0_check.py` 基础上新增 `apple2_check.py`（启动 → 出画面 → 注入 `key_a` → 快照 → 退出），作为 M1 该设备的"可玩"自动验收（FR-E）。
4. **降级路径**：若 ROM 缺失（未就绪），设备保持静态展示，运行向导引导用户导入（FR-E3/E9，状态机 §3.3）。
