## 4. 响度分级定稿（核心数字）

| 层级 | 类别 | LUFS | 峰值 dBFS |
|---|---|---|---|
| 前景 | 解说 vo | −16 ±1 | ≤ −3 |
| 交互 | 效果音 sfx | −18 ±1 | ≤ −12 / −6 |
| 底乐 | BGM | −24 ±1 | ≤ −12 |
| 氛围 | 环境 bed amb | −30 ±2 | ≤ −24 |

混音优先级：错误/警告 > 确认/提示 > 拆装/交互 > 环境（并发 ≤4，挤最低）；vo 播时 BGM 闪避 −8 dB。
