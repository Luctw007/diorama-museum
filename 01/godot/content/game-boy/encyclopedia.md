## 一、概述与历史地位

Game Boy 是任天堂于 1989 年 4 月 21 日在日本发售的 8 位掌上游戏机，是横井军平"枯萎技术的水平思考"哲学的集大成之作 [S44]。它以"够用的硬件 + 杀手级软件"开辟了手提机这一全新品类，靠《俄罗斯方块》捆绑版与《宝可梦》系列席卷全球，累计销量约 1.18 亿台（含 Game Boy Color），是有史以来最畅销的掌机之一，开创了"手提机第一王朝" [S44]。它也奠定了任天堂在掌机市场长达三十年的统治地位——从 GB 到 GBA、DS、3DS、Switch，任天堂掌机线的每一次成功，都能追溯到 GB 确立的"耐用、省电、软件生态"三大范式。

## 二、横井哲平线：枯萎技术的水平思考

Game Boy 的设计哲学，源自横井军平的著名理念——**"枯萎技术的水平思考"**：用成熟、廉价、已被"用枯萎"的技术，做全新的产品。横井军平深知，掌机的胜负不在硬件参数的堆砌，而在"能不能随时随地带在身上玩"。

于是 Game Boy 做到了：一块 2.6 英寸、160×144 像素、4 级灰度的**无背光反射式点阵屏**（黄绿色），一颗 Sharp LR35902 定制处理器，4 声道声音，4 节 AA 电池供电——这些在当时都是"枯萎"的技术，但组合起来，就是一台坚固耐摔、电池续航十几到几十小时、价格亲民的掌机。这份"克制"，正是 GB 能成为一代人第一台掌机的原因 [S44]。

"横井哲平线"（横井军平的手持设备线）从 Game & Watch 起步，经 Game Boy 走向巅峰，再到后来的 DS——这条线一以贯之的，就是"用枯萎技术做新东西"的哲学。Game Boy 是这条线最辉煌的一站，也是"枯萎技术的水平思考"最经典的注脚。

## 三、俄罗斯方块捆绑：杀手级应用的典范

让 Game Boy 真正起飞、并成为文化现象的，是**《俄罗斯方块》的捆绑**。1989 年，任天堂拿下《俄罗斯方块》在家用机与掌机的版权，把这款由苏联程序员阿列克谢·帕基特诺夫发明的拼图游戏随 Game Boy 捆绑发售。这一商业决策堪称神来之笔——《俄罗斯方块》规则极简、上手即玩、永不过时，又完美契合掌机"碎片时间消遣"的场景。无数原本不玩游戏的人，为了在通勤路上、午休时玩一局《俄罗斯方块》而买下了 Game Boy。"Game Boy + 俄罗斯方块"从此成为电子游戏史上最著名的捆绑组合之一 [S44]。

### 3.1 硬件细节：LR35902 与四声道声音

GB 的心脏是 Sharp 生产的 **LR35902** 处理器，这是一颗 GB 专用的定制芯片，内核类似 Z80 与 Intel 8080 的混合体，主频 4.19 MHz。它把 CPU 与图形、声音控制集成在一起，是"枯萎技术"的典型——用成熟的 8 位架构做定制，而非追逐新技术。声音方面，GB 有 **4 声道**：两个方波声道、一个可编程波形声道、一个噪声声道，四路合成出 GB 标志性的"叮咚"音效——那一声《俄罗斯方块》的消除音，和开机时的"叮"的一声，是无数人记忆深处的声音。这套"够用就好"的声画系统，正是 GB 能省电、耐用的硬件基础。而它也证明了一个道理：掌机的成功，从来不靠参数，而靠"恰到好处"——把每一分硬件都用在了刀刃上。

## 四、更换卡带生态与宝可梦

Game Boy 的生命力，远超它朴素的硬件。它的卡带可自由更换，数千款游戏构成庞大游戏库，这是掌机长寿命的秘密。而 1996 年，《宝可梦 红/绿》在日本发售，靠"收集、对战、交换"的玩法与 Game Link 联机线，让 Game Boy 的销量在发售七年后再次爆发，也定义了"掌机联机对战"的范式。《俄罗斯方块》与《宝可梦》一先一后，把 Game Boy 从"一台能玩的掌机"推向"一代人的共同记忆" [S44]。

### 4.1 经典作品举隅

GB 的游戏库，是"简单玩法 + 极致耐玩"的典范。《俄罗斯方块》是捆绑传奇，七种方块的消除玩法至今无人能超越；《宝可梦 红/绿》开创了收集养成对战交换的掌机范式，其双版本设计（红/绿、金/银）催生了"交换才能集齐"的社交玩法；《超级马力欧大陆》把马力欧搬上掌机；《塞尔达传说 梦见岛》证明了掌机也能承载深度冒险；《卡比》《银河战士 II》等则各自在掌机上确立类型范式。这些作品共同证明了 GB 的"够用硬件"足以承载伟大游戏——它们用 160×144 的点阵屏与 4 级灰度，画出了无数玩家心中最难忘的游戏世界。

### 4.2 与 Game & Watch 的手持双雄

GB 与 G&W 是任天堂手持线的"双雄"：G&W 是起点（段码 LCD、预制图形、专用游戏），GB 是巅峰（点阵屏、任意画面、可换卡带）。两者并置，恰好讲完手持机从"固定图形"到"任意画面"、从"一台一游戏"到"换卡换游戏"的演进，也是横井军平"枯萎技术的水平思考"在手持线上一脉相承的两个里程碑。G&W 的段码屏讲"够用就好"，GB 的点阵屏讲"够用且能承载伟大"，二者共同构成"手提机破题"专区的完整叙事。

### 4.3 历史沿革与停产

Game Boy 初代（DMG-01）自 1989 年发售，一直生产到 1990 年代末，其后续机型持续迭代至 2003 年 Game Boy 系列正式停产。在这十四年里，GB 见证了掌机从"奢侈品"到"人手一台"的普及，也见证了任天堂掌机霸主地位的确立。2001 年 Game Boy Advance 接棒，把掌机带入 32 位时代；而 GB 初代那台灰白机身、绿屏点阵，则作为"手提机第一王朝"的开国者，永远留在了电子游戏史的开篇位置。

### 5.1 绿点阵屏技术细节

GB 的屏幕是"无背光反射式液晶屏"，这是它省电耐用的技术关键。它靠环境光反射显示，没有背光模组，因此在阳光下反而更清晰，而耗电极低——这正是 GB 能用 4 节 AA 电池续航十几到几十小时的原因。屏的显示是 **160×144 点阵、4 级灰度**：不同于 G&W 的段码预制图形，点阵屏能显示任意画面，四档灰阶让画面有了层次。这块黄绿色的反射屏，成了 GB 初代最标志性的视觉符号——无数玩家的第一眼"游戏画面"，就是这块绿屏上跳动的《俄罗斯方块》。

### 5.2 型号沿革

Game Boy 系列在十四年的生产史中经历了多次迭代：最早的 **初代（DMG-01，1989）** 灰白机身、无背光绿屏，icon 性最强；**Pocket（1996）** 小型化、屏幕更清晰；**Light（1998）** 增加背光；**Color（1998）** 升级为彩色屏；此后 Game Boy Advance 系列（2001）把掌机带入 32 位时代。这些迭代的核心（LR35902 + 点阵屏）一脉相承，差异集中在机身尺寸、屏幕背光与彩色。本设备包垂直切片选定初代 DMG-01 造型，最贴近"1989 年手提机破题"的叙事定位 [S44]。

### 5.3 运行与输入说明（馆方提示）

本设备包 runtime 以 **SameBoy（MIT）** 为技术基线声明（demo 起步，不接真实二进制；SameBoy 是 MIT 许可，无聚合风险）。运行时画面经 `handheld_lcd` sink 投放到掌机屏模组（160×144 点阵，绿屏显示），声音经 `speaker_0` 输出（GB 四声道音效）。input_map 覆盖十字键（hat_0）、A/B 键（btn0/1）与 Start/Select。卡带导入沿用"自备实机备份 + 版权方授权"合规口径，游戏绝不内置——GB 的"换卡带换游戏"生态，正是这一合规口径在掌机侧的呼应。

### 5.4 历史评价与文化影响

GB 的历史地位，常被一句话概括：它开创了"口袋里的游戏"。在它之前，游戏属于客厅或街机厅；在它之后，"随时随地带在身上玩"成了掌机的定义。它用枯萎技术的水平思考证明了掌机的成功不靠参数而靠"恰到好处"，用俄罗斯方块捆绑证明了"软件定义硬件价值"的真理，用宝可梦联机证明了"掌机社交"的可能。它对后世的影响，远不止 1.18 亿台的销量——它确立了掌机"耐用、省电、软件生态"的成功范式，这条范式至今仍是掌机设计的金科玉律。

## 六、馆方展示定位

在博物馆环境中，Game Boy 是"手提机破题"专区的核心设备，也是与 Game & Watch 构成"手持双雄"的一对。G&W 是手持线的起点（段码 LCD），GB 是手持线的巅峰（点阵屏 + 卡带生态），两者并置，恰好讲完"从固定图形到任意画面、从专用游戏到可换卡带"的手持演进。

GB 的展示重点在**绿点阵屏与《俄罗斯方块》捆绑**——观众可点选 LR35902 芯片与 LCD 控制器，看 160×144 点阵 4 级灰度屏如何逐行刷新；一台可玩的 Game Boy 模拟器（SameBoy，MIT）让观众亲手玩一局《俄罗斯方块》，体会"规则极简 + 碎片时间"的掌机魅力。Game Link 联机线可展示两台 GB 对战《宝可梦》的场景，是"掌机社交"叙事的物理锚点。

### 掌机社交与联机文化

Game Boy 的 Game Link 联机线，是掌机社交的开端——两台 GB 用一根线相连，就能对战、交换、协作。这在 1989 年是前所未有的掌机体验，也让"面对面联机"成为掌机文化的一部分。后来《宝可梦》把它发挥到极致：玩家必须交换才能集齐全部宝可梦，联机成了游戏玩法本身。这种"掌机社交"——两个人在现实中坐在一起、连线对战——是掌机与家用机、街机厅都不同的一种"现场感"，也是 GB 留给掌机文化最独特的一份遗产。
