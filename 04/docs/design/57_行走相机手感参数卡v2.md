## 2. 手感红线（禁止区间成文）

| 参数 | 禁止区间 | 理由/出处 |
|---|---|---|
| 转身角速度 | >200°/s | 晕动红线（12 号舒适参数口径） |
| FOV | >100 或 <50 | 畸变/管窥双害 |
| 俯仰常驻 | ≥85° 且无柔化 | 抬头裂画面；v2 建议钳制 70° |
| 速度突变 | 无阻尼瞬时 3.0→0 | 急停晕动；须加 0.15 s 阻尼 |
| 行走中 FOV 自变 | 引擎自动奔跑 FOV 放大 | 走动时禁用自动 FOV（博物馆节奏） |
