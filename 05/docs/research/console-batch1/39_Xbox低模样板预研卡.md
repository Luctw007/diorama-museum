> 任务 305-D（05 线）· 完成日期：2026-11-25。
> 性质：**轻量预研/备料卡**——游戏机线继续回归：为下一轮 `xbox` 低模样板建模（占位→低模）备好尺寸/配色/面板布局证据包；**本卡不做 gltf、不动装配体、不改 meta/annotations/目录**。

## 一、取机理由（研究卡存量 + 未产包）

- **研究卡存量**：`console-batch2/18_第二批主机研究卡.md` 已收录 Microsoft Xbox 完整参数（Pentium III 级 CPU / DVD + 硬盘 / 64MB 内存 / Xemu 模拟器），为 10 台第二批主机名单第 5 台。
- **未产包**：05 线现有 content 包**无 xbox 包**。
- **谱系位置**：Microsoft Xbox（2001）是微软入局游戏主机的首台，内置硬盘与以太网，是「微软入局三足鼎立」这一叙事的关键锚点。
- 结论：取 **Microsoft Xbox** 为游戏机线下一台低模预研机型。

## 七、识别件与动画候选

- **光驱托盘弹出识别件**：光驱（dvd_drive）为可弹出识别件，低模以黑色盒 + 光盘示意；**托盘弹出动画**在后续建模卡以该 node 为抽拉轴实现（本卡仅备静态低模）。
- **手柄识别件**：Xbox 手柄（controller）为可选识别件，含双模拟摇杆，可作「手柄操作」示意（本卡仅备静态低模参数）。
- **动画候选**：托盘弹出、开机启动、电源环点亮（动画制作排期挂起）。

## 八、建模参数建议（低模口径）

- **材质**：全部 `baseColorFactor` 纯色，**无贴图**，对齐 195-A Game Boy 低模口径。
- **LOD**：低模阶段**不分 LOD 档**；后续纹理建模卡再补 3 档 LOD。
- **部件**：按第三节 8 件分解；chassis 为整机主体，dvd_drive 为可弹出识别件（托盘弹出动画），其余为独立子节点。

## 九、模拟器 / 演示行

- **模拟器**：Xemu（Xbox 模拟器候选）——许可标 [需核实]；不下载 BIOS/ROM 红线。
- **演示**：**静态 + 托盘弹出动画**——光盘机叙事线「弹出托盘 → 放碟 → 进仓 → 开机」。动画制作排期挂起。

## 十、目录方案预告 + BIOS/ROM 红线

- **目录条目**：游戏机目录 `G-HC-000067「Xbox」`（Microsoft、2001、planned）产包时回填 device_id，**无需新建条目**。
- **Xbox BIOS/ROM 红线**：Xbox 系统 BIOS 与游戏 ROM（DVD）受版权保护，**不入库、不下载**，本卡仅清单级引用；无 BIOS 时 `runtime.emulator` 保守 `none`（对齐 PlayStation/Saturn/N64/Dreamcast/PS2/GameCube 先例）。
