## 1. 音效 id 命名规范（实现层）

### 1.1 规则

```
sfx_<device>_<action>
```

- `<device>`：绑定到某台设备内容包的音效用 `device-id`（kebab-case，如 `apple-ii`）；**全局 UI 音效用 `ui`**；环境 bed 音效用 `amb`。
- `<action>`：动作名，snake_case，动词+对象（如 `lid_open`、`key_single`、`restore_done`）。
- 完整示例：`sfx_ui_confirm`、`sfx_apple-ii_lid_open`、`amb_hall`。
- 禁止：中文、大写、无前缀裸名、`sfx_01` 这类无义编号。

## 2. 两条音频链路（模拟器音频 ≠ UI 音效）

```
链路 1：模拟器音频（设备本体发声）            链路 2：UI/环境音效（引擎层）
 后端(audio sink)                                引擎 AudioManager
   │  stdout JSON (audio 消息)                      │  play(sfx_id)
   ▼                                                ▼
 网关包装 audio_chunk{s16le}                     AudioStreamPlayer(2D/3D)
   │  TCP 广播                                     │  坐标锚定/头部锁定
   ▼                                                ▼
 客户端 AudioStreamGenerator 直放                主总线(音量/分轨)
```

| 对比项 | 链路 1（audio_chunk） | 链路 2（音效系统） |
|---|---|---|
| 数据来源 | 模拟器后端 audio sink（MAME 直出） | 内容包 sounds/ + 程序化合成 |
| 传输 | gateway 广播 `audio_chunk{seq,sample_rate,channels,format:"s16le",data_b64}` | 本地加载，不经过网关 |
| 时序 | seq 从 1 递增；仅 running 态产出；崩溃即止 | 由 04 号 §1.6 调度规则（≤4 并发+互斥组） |
| 空间化 | 挂设备坐标的 AudioStreamPlayer3D（点声源，见 §3 参数） | UI 音头部锁定；拆装音挂交互点 |
| 音量轨 | 设置页「模拟器音频」轨（默认 90%） | 「音效」「环境声」「设备运行声」轨 |
| 崩溃行为 | 停流（后端进程死亡） | crash 音由音效系统补播（sfx_ui_crash） |
| FR 对应 | FR-E1/FR-E6（输出画面/声音） | FR-H4（触觉联动）/FR-D（拆装反馈） |

**集成要点**：Godot 对 `audio_chunk` 使用 `AudioStreamGenerator` 持续喂 PCM；`s16le` → float 归一化后入流；`sample_rate` 与后端不一致时重采样。两条链路的**同步容差**：音效响应 ≤50 ms；设备音频与画面由网关同帧时序保证（PROTOCOL §6 帧/音频时序约定）。

## 3. AudioStreamPlayer3D 布置规格（Godot）

> 对应 04 号 §2.5 六类声源的衰减数值换算为 Godot 3D 音频参数。

| 声源类别 | Godot 衰减模型 | unit_size | unit_db | max_db | max_distance | panning_strength | 混响总线 |
|---|---|---|---|---|---|---|---|
| 展厅环境（全向） | DISABLED（无衰减，双声道宽化） | — | 0.0 | 0.0 | — | 0.15 | amb_reverb(20%) |
| 设备运行声（点） | INVERSE_DISTANCE_CLAMPED | 1.0 | 6.0 | −3.0 | 8.0 | 0.5 | dev_reverb(12%) |
| CRT 大屏扬声器 | INVERSE_DISTANCE_CLAMPED | 1.5 | 6.0 | −3.0 | 12.0 | 0.6 | dev_reverb(25%) |
| 拆装交互点 | INVERSE_DISTANCE | 0.5 | 12.0 | −6.0 | 4.0 | 0.8 | 无 |
| 面板 UI 音 | 头部锁定（AudioStreamPlayer2D 或 Node 直挂 Camera3D） | — | — | — | — | 0.0 | 无 |
| 设备喇叭（链路 1） | INVERSE_DISTANCE_CLAMPED | 0.8 | 6.0 | −3.0 | 9.0 | 0.4 | dev_reverb(10%) |

**实现要点**：
1. 每种声源一个 `AudioStreamPlayer3D` 池（运行声池 4 个、交互点池 2 个、喇叭 1 个），避免频繁 add/remove 节点。
2. 距离曲线在 `INVERSE_DISTANCE_CLAMPED` 下由 unit_size/unit_db 共同决定：目标声压 = max_db − unit_db × log2(d/unit_size)，在 max_distance 处截断。
3. 运行声 6 m 外仍可闻但 ≤ −24 dB：由 max_db=−3、unit_db=6 计算，6 m 处 ≈ −3 − 6×log2(6) ≈ −18.5 dB [TBD 复算]，如需压到 −24 可下调 max_db 至 −8。
4. CRT 行频（15.75kHz）单挂窄带滤波 + 限幅 −24 dB，进「设备运行声」轨。
5. 听障「音频雷达」（H3 可选项）：在链路 1/2 各源挂方向角+强度色环 HUD，与引擎音量无关、独立开关。

## 4. VR 头部音频设置

| 项 | 规格 |
|---|---|
| HRTF | 引擎 3D 音频全局 HRTF 开启（Godot 默认集成）；不加第三方 HRTF 插件 [TBD] |
| 头部锁定 | 面板 UI 音全部 `Camera3D` 直挂；不做空间化（等同双耳正中） |
| 声源相对头部的更新 | 每物理帧更新 listener 位姿（头显 6DoF 直取）；不做平滑（防滞后感） |
| 近场提升 | 距离 <0.5 m 时对交互点声源 +3 dB 近场增益（近耳效应补偿） |
| 防疲劳 | 连续同音效 10 s 内不重复播放（如 slayer_tick 防泵），改为合并/静音并计日志 |
| 舒适性联动 | H3 晕动防护开启时，环境 bed 增益 −3 dB（减轻感官负载）；关闭自动恢复 |

## 5. 音频总线结构与分轨默认值（dBFS）

> 引擎主总线树（Godot Audio Bus），设置页音量滑杆（02 章界面 8 / 04 章 §4）映射到各总线增益。

```
Master（0 dB，总音量轨 100% -> 80% 默认）
 ├─ UI   （-3 dB，音效轨 80%，头部锁定声全走此总线）
 ├─ SFX3D（-3 dB，音效轨 80%，拆装交互点/界面空间声）
 ├─ AMBIENT（-6 dB，环境声轨 70%，amb_hall/cabinet/workbench/crt_room）
 ├─ MACHINE（-8 dB，设备运行声轨 70%，amb_apple-ii_*）
 └─ DEVICE_AUDIO（-1 dB，模拟器音频轨 90%，audio_chunk 直放）
```

| 总线 | 默认增益 | 设置页滑杆 | 包含音效（实现命名前缀） | 备注 |
|---|---|---|---|---|
| UI | −3 dB | 音效 80% | sfx_ui_* 头部锁定部分 | 面板音 |
| SFX3D | −3 dB | 音效 80% | sfx_ui_snap/pick/approach…（空间化交互点） | 拆装音 |
| AMBIENT | −6 dB | 环境声 70% | amb_hall/cabinet/workbench/crt_room | bed 层 |
| MACHINE | −8 dB | 设备运行声 70% | amb_apple-ii_transformer/fan/floppy_motor/crt_whine | CRT 行频再内嵌窄带限幅 |
| DEVICE_AUDIO | −1 dB | 模拟器音频 90% | audio_chunk 流 | 链路 1 |

规则：崩溃时 MACHINE 与 DEVICE_AUDIO 两总线自动哑音 50 ms 内（急停），UI 总线保留以播 crash/error 音。

## 6. 性能预算表（M1 验收口径）

| 项 | 预算 | 说明 |
|---|---|---|
| 常驻 AudioStreamPlayer3D 节点 | ≤ 8 个 | 环境 4 + 机器 3 + 喇叭 1（§3 池） |
| 同屏并发音效 | ≤ 4 | 04 号 §1.6；超量挤最低优先级 |
| 同屏活跃循环音轨 | ≤ 5 | ambient 2 + machine 2 + 喇叭 1 |
| 音频内存（解码后） | ≤ 24 MB [TBD] | 程序化合成≈0；实录 OGG 按 4×时长×码率估算 |
| audio_chunk 缓冲水位 | ≤ 200 ms | 防止音频滞后画面；超过即丢老 chunk（PROTOCOL seq 递增可校验） |
| 音效触发→发声延迟 | ≤ 50 ms | VR 下触觉+听觉同步容差 30 ms（04 §3.1） |

## 7. 音频资产文件规格（入库标准）

| 项 | 规格 |
|---|---|
| 格式 | 源：WAV 24bit/96kHz；交付：OGG Vorbis（q5，约 160 kbps） |
| 响度 | 单条峰值 ≤ −3 dBTP；音效组综合响度 −14 LUFS [TBD 实听校准] |
| 循环点 | 所有 bed/循环条目必须带无缝循环点（OGG LOOPSTART/LOOPLENGTH 标签） |
| 命名 | `sfx_<device|ui>_<action>.ogg` 与 §1.2 一致；禁中文/空格 |
| 时长 | 单条 ≤ 4 s（超长实录裁切为事件段+循环段两文件） |
| 采样对齐 | audio_chunk 非 48k 时客户端重采样，UI 音效一律 48k |

## 11. 音效与网关事件触发点对照（01 线接线表）

| 网关消息/本地事件 | 触发音效（实现命名） | 触觉 |
|---|---|---|
| start_device_ack{ok:true} | sfx_apple-ii_power_on（与开机动画同帧） | 中 30 ms |
| input_ack | sfx_apple-ii_key_single（单发）/key_repeat（连发合并 ≤100 ms 窗口） | 无 |
| save_state_ack{ok:true} | sfx_ui_snapshot（确认音尾随 90 ms） | 短 10 ms |
| error{NOT_RUNNING} | sfx_ui_deny | 长 80 ms |
| error{PROCESS_CRASHED} | 急停（§5 规则）+ sfx_ui_crash | 长 80 ms×2 |
| status{restarting} | （静默，恢复进度 UI 声-less） | 无 |
| status{running}（恢复后） | sfx_ui_auto_recover_ok | 中 30 ms |
| error{RESTART_EXCEEDED} | sfx_ui_degrade_advice | 长 80 ms |
| stopped{reason:"user"} | sfx_apple-ii_power_off | 中 30 ms |
| audio_chunk 流启动 | —（链路 1 直放，不触发音效系统） | 无 |

> 对接准则：**网关事件只做触发，音效系统自治**（自己去重/互斥/衰减），01 线接线时不得把协议字段当音效参数透传。
