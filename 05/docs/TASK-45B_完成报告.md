## 三、手提机建模要点总结

1. **屏幕是核心**：内置屏幕分层（玻璃→偏光片→液晶→反光）是掌机独有难点，屏幕模块专项覆盖。
2. **机身一体化**：拆解路径"拆后盖→取主板→拆屏幕"，前后壳扣合缝 + 背板 6 螺丝位是拆解叙事关键。
3. **按键是交互**：十字键高度（1–1.5mm）、十字凹槽、橡胶导电垫是手感来源。
4. **叙事锚点**：《俄罗斯方块》捆绑（屏幕可玩演示）与《宝可梦》联机（Game Link 口）两条主线，建模须预留展示位。
