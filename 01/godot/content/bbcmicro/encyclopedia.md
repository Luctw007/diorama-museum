# BBC Micro —— 那台"为了教育"而生的国民电脑

1981 年底，英国广播公司（BBC）做了一个大胆的决定：为全国观众推出一档"计算机扫盲"电视节目，并配套一台专门的计算机，教全国人民编程。中标的，是剑桥一家小公司 Acorn 设计的机器——BBC Micro。

这台机器的使命从一开始就与众不同。C64 想做"人人都买得起的家庭娱乐"，IBM PC 想做"开放标准的商用机器"，而 BBC Micro 想做的是"让人人都学会编程"。它内建了当时最先进的 BBC BASIC 之一——支持结构化编程、命名变量、过程调用，远不是"玩具语言"。英国的中小学大量配备这台机器，整整一代英国孩子，是在 BBC Micro 上敲下人生第一段程序的。

BBC Micro 的工程也透着一种超前的认真。它有一个叫 Tube 的接口，允许外接协处理器——第二颗 6502、一颗 Z80、甚至后来的 32 位处理器，让这台 8 位机能"长"出更强大的算力。它还有 Econet 网络接口，能让教室里的多台机器互联。在那个年代，这种"为未来留接口"的设计眼光，实在罕见。

---

## 深度解读一：6502 的 2 MHz 时代

BBC Micro 的心脏，是一颗运行在 2 MHz 的 MOS 6502。6502 是 1970 年代最成功的 8 位处理器之一，被 Apple II、Atari、NES 等无数机器采用，靠的就是"便宜、够用、易编程"。BBC Micro 把它跑在 2 MHz——比同时代许多机器更快——这为它流畅运行 BBC BASIC、渲染多模式显示提供了底气。一块被无数机器共享的通用芯片，在 Acorn 手里被调校成了一台教育机器的可靠心脏。

## 深度解读二：MODE 0–7 的多模式显示

BBC Micro 的 Video ULA 芯片支持从 MODE 0 到 MODE 7 共八种显示模式：从高分辨率的单色图形，到低分辨率的多色图形，再到 MODE 7 的 Teletext 文本模式。这种"一台机器、八种显示"的灵活设计，让 BBC Micro 既能画精细的图形，又能显示色彩丰富的文字页。尤其 MODE 7，直接复用了英国电视系统的 Teletext 标准，堪称"把电视技术搬进电脑"的巧思。这种多模式的能力，也让 BBC Micro 成为当时显示最灵活的 8 位机之一。

## 深度解读三：BBC BASIC 的先进之处

BBC Micro 内建的 BBC BASIC，是当时最先进的内建 BASIC 之一。它支持结构化编程——命名变量、过程（PROC）与函数（FN）、`REPEAT...UNTIL` 循环——这些在同期家用机的 BASIC 里几乎看不到。这意味着，BBC Micro 教给孩子们的不是"玩具代码"，而是真正的编程思想。许多人正是从 BBC BASIC 的结构化语法里，第一次理解了"程序 = 数据 + 流程"的真谛。这套为教育而生的语言，堪称早期编程教育的范本。

## 深度解读四：Tube 接口与协处理器

BBC Micro 最前瞻的设计，是那个叫 Tube 的接口。它允许外接一颗"第二处理器"——可以是第二颗 6502、一颗 Z80，甚至是后来的 32 位处理器——通过高速通道与主机协作。这意味着，这台 8 位机天生就"为升级留好了路"。Acorn 后来正是沿着这条"协处理器"的思路，为 BBC Micro 设计 32 位协处理器时，创办了 RISC 项目。Tube 接口，因此成了 ARM 架构诞生的技术伏笔。

## 深度解读五：ARM 的诞生——从课堂到全球

BBC Micro 最深远的影响，藏在它之后的故事里。Acorn 在为 BBC Micro 设计 32 位协处理器时，萌生了自研精简指令集（RISC）处理器的念头，创办了 Acorn RISC Machine 项目——这就是 ARM。这颗为英国课堂设计的机器，最终孕育出了今天统治手机、平板与嵌入式世界的 ARM 架构。从一台"教孩子编程"的国民电脑，到全球几十亿设备的芯片心脏，这条因果链，堪称计算机史上最浪漫的"传承"。看 BBC Micro 的时候，你看到的不仅是一台老电脑，更是整个移动计算时代的起点。

## 深度解读六：英国计算机扫盲计划的影响

BBC Micro 是 BBC"计算机扫盲计划"的官方机型。这个计划通过电视节目、教材与配套机器，系统地把计算机知识普及给了英国大众——从"什么是编程"到"怎么写一段 BASIC 程序"，覆盖了整整一代人的基础教育。它的意义，不止于培养了几代程序员，更在于确立了一种信念：计算机素养，应该是一种全民基本素养。这种"为所有人而教"的理念，至今仍在影响全球的计算机教育，也让 BBC Micro 超越了一台机器，成为一场教育运动的象征。

## 在展厅里怎么看它

BBC Micro 是"个人计算机厅"的第三台，也是"互不兼容年代"里最"有教育理想"的那一台。它的旁边，是走"家庭娱乐"路线的 Commodore 64，和走"开放标准"路线的 IBM PC 5150——三台机器，三种理念。但唯有 BBC Micro，把目光投向了"下一代"：它想做的不是卖机器，而是教人编程。看它的时候，请把目光停在两处：那排红色的功能键，和那个通往"第二处理器"的 Tube 接口。一个代表了"教育"，一个代表了"未来"——看懂这两处，你就看懂了 BBC Micro 的全部理想。

- **BBC BASIC**：BBC Micro 内建的结构化 BASIC 语言。
- **Tube 接口**：BBC Micro 连接第二处理器的高速接口，是 ARM 诞生的技术伏笔。
- **MODE 7**：BBC Micro 的 Teletext 文本显示模式，复用英国电视标准。

## 一句话总结

BBC Micro 之所以伟大，在于它是一台"为了教育"而生的机器——它教会了整整一代英国人编程，并在不经意间，孕育出了今天统治移动世界的 ARM 架构。

## 附：BBC Micro 技术档案速览

BBC Micro 于 1981 年 12 月推出，由英国 Acorn 公司为 BBC"计算机扫盲计划"设计，有 Model A（16 KB）与 Model B（32 KB）两个型号。它采用 MOS 6502 处理器（2 MHz），配定制 Video ULA 图形芯片（支持 MODE 0–7 多模式显示），内建 32 KB 的 BBC BASIC 与 MOS 操作系统 ROM。其标志性接口是 Tube 协处理器接口与 Econet 网络接口，前者后来成为 Acorn 自研 RISC 处理器、进而诞生 ARM 架构的技术伏笔。它可接磁带机或 5.25 英寸软驱，运行 BBC BASIC、DFS/ADFS 文件系统与大量教育软件与游戏，是 1980 年代英国计算机教育普及的标志性机型。

## 深度解读七：Elite——BBC Micro 上的游戏传奇

BBC Micro 虽然主打教育，却也诞生了一款载入史册的游戏——Elite。这款 1984 年的太空贸易与战斗游戏，以线框 3D 图形、庞大的可探索星系与开放式的玩法，惊艳了整个游戏界。它在一台 32 KB 内存的机器上，硬是塞进了一个有八个星系、数千个星球的宇宙，靠的是极其精巧的算法与内存优化。Elite 证明了"教育机器也能孕育伟大的游戏"，也成了后来无数开放世界游戏的启蒙。直到今天，它仍被许多人视为史上最伟大的游戏之一。

## 深度解读八：Acorn 与 RISC 的诞生之路

BBC Micro 的成功，给了 Acorn 一笔宝贵的"学费"和底气。当 Acorn 为下一代机器寻找更强处理器时，它发现市面上的芯片都难以满足需求，于是做了一个惊人的决定：自己设计。Acorn 的工程师们在一间小办公室里，从无到有地设计出了一款精简指令集（RISC）处理器——这就是 ARM 的起点。这个"被逼出来"的自研决定，后来让 Acorn 从一家教育电脑公司，转型为一家芯片设计公司，最终孕育出全球移动计算的基石。一台国民电脑，就这么无意间改写了半导体的历史。

## 深度解读九：Econet 与教室里的网络

BBC Micro 还有一个超前得令人惊讶的能力——Econet 网络。通过这个接口，一间教室里的多台 BBC Micro 可以互联，共享磁盘、传输文件、甚至玩联网游戏。在那个"网络"还是实验室概念的年代，英国的孩子们已经能在课堂里体验到"多台电脑互联"是什么感觉。这种"把网络带进教室"的前瞻设计，让 BBC Micro 成了许多人人生中第一次"上网"的起点——尽管那时的"网"，还只是同一间教室里的一根根电缆。

## 结语

从 IBM 的大型机，到 PDP 的小型机，再到这台 BBC Micro——计算机走过了一条"从专用到通用、从少数人到全民"的漫长旅程。而 BBC Micro 正是这条旅程上最特别的一站：它不为卖机器而生，而为"教人编程"而生。它教会了整整一代英国人编程，也在不经意间，孕育出了今天统治移动世界的 ARM 架构。站在它面前，你不只是在看一台老电脑，更是在看"教育如何改变技术"这段历史里，最动人的一章。

## 深度解读十：磁带与软驱——BBC Micro 的存储生态

BBC Micro 的存储，从最朴素的磁带开始：把程序录在普通录音磁带上，用时再"滋滋"地读回来。后来，DFS（磁盘文件系统）与 ADFS（高级磁盘文件系统）让它接上了 5.25 英寸软驱，存取速度和可靠性都大幅提升。从磁带到软驱，BBC Micro 的用户亲历了"存储"这件事的进化——今天动辄几个 TB 的硬盘，其"文件系统"这个概念的早期实践，就发生在这台机器的软驱上。这种从磁带一步步走向磁盘的体验，也成了英国一代人关于"电脑"的共同记忆。
