# 12 — CDC 6600 研究卡

> 03 线 TASK-188-B 交付。第二批第 6 台（目录 `C-MF-000043`）的预研卡，为后续设备包领取备料。体例对齐 hall-mainframe 研究卡。模拟器可行性标「需核实」，不下发二进制、不下 ROM。

## 一、史实

**CDC 6600** 是 Control Data Corporation（CDC）于 1964 年推出的超级计算机，由天才设计师 **Seymour Cray** 主持设计，被公认为世界上首台「超级计算机」。它以超前的超标量设计（多个功能单元可同时工作）与 10 个外围处理器（PPU）分工协作，把算力提升到同时代机器难以企及的高度，长期稳坐「世界最快计算机」的宝座，也让 CDC 一跃成为超级计算机领域的霸主。

**叙事锚点**：
1. **首台超级计算机**：CDC 6600 定义了「超级计算机」这个品类，是超级计算纪元的开端 [S106]。
2. **Seymour Cray 的成名作**：天才设计师 Cray 用 CDC 6600 一战成名，此后 Cray 系列延续了这条传奇血脉 [S106]。
3. **超前的超标量设计**：多个功能单元并行工作，这种设计思路多年后才成为主流，CDC 6600 超前了时代 [S106]。
4. **外围处理器分工**：10 个 PPU 负责 I/O 与调度，让中央处理器专注计算，是「分工协作」架构的早期典范 [S106]。

## 二、尺寸依据（标「需核实」）

- 主机：多个大型机柜组成，整机呈「加号」或「十字」布局（「需核实」）。
- 中央处理机柜：约 1.8 m 高（「需核实」）。
- 控制台：操作员控制台 + 显示器（「需核实」）。
- 冷却：需专门冷却系统（「需核实」）。

## 三、部件分解草图清单

```
CDC 6600（整机系统）
├── 中央处理机柜（central_processor，超标量功能单元）
├── 外围处理器（ppu，10 个 I/O 处理器）
├── 内存（memory，磁芯内存）
├── 控制台（console，操作员控制台）
└── 冷却系统（cooling，氟利昂冷却）
```

## 四、L1-L3 拆解要点

- **L1（外观层）**：成排机柜 + 控制台 + 冷却系统——静态呈现「首台超级计算机的庞然体量」。
- **L2（结构层）**：机柜打开 → 中央处理器功能单元、外围处理器、磁芯内存——拆解展示「超标量架构长什么样」。
- **L3（元件层）**：超标量功能单元、磁芯存储阵列、I/O 通道——原理讲解用（多单元如何并行、PPU 如何分工是讲点）。

## 五、模拟器行

**无成熟模拟器**（需核实，槽位 dedicated 预留，不下发二进制）。CDC 6600 结构复杂、专有性强，现无广泛可用的开源模拟器；展厅以「静态 + 原理动画（超标量/外围处理器分工）」为主。若后续有可考模拟器，再走合规流程接入。

## 七、展呈叙事建议（三行）

1. **超级计算机的诞生**：用 CDC 6600 定义「超级计算机」品类的故事，讲「算力竞赛」的起点，是超算厅的开篇锚点。
2. **天才设计师 Seymour Cray**：把 CDC 6600 与后来的 Cray-1 连成一条「Cray 传奇」血脉，是超算厅最有人格魅力的叙事线。
3. **超前的架构**：用超标量设计与外围处理器分工，讲「一个超前时代的架构如何成为后来主流」，是计算机体系结构史的重要一课。
