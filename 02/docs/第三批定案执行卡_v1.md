## 三、步骤 3：02 allocate 执行细节（id_registry 续号实算）

**续号实算规则**（id_registry.py allocate：续号纳入「台账 ∪ 目录已用 id」，不与既有 id 撞号；本卡序号为
2026-11-24 实测最大值 + 1 起点，allocate 实算为准）：

| 分组 | 设备 | 当前最大序号（实测） | allocate 续号起点 |
|---|---|---|---|
| C MF 1 | System/370 | 84 | C-MF-000085 |
| C PC 6 | MSX2/MacPlus/PC XT/Archimedes/ZX81/Compaq Portable | 208 | C-PC-000209~214 |
| C WS 1 | SGI Indigo | 54 | C-WS-000055 |
| C EC 1 | Whirlwind | 13 | C-EC-000014 |
| M PD 1 | Apple Newton | 69 | M-PD-000070 |

执行命令（02 线，用户点头 + 01 登记后）：
```
python tools/index/id_registry.py allocate C MF 1
python tools/index/id_registry.py allocate C PC 6
python tools/index/id_registry.py allocate C WS 1
python tools/index/id_registry.py allocate C EC 1
python tools/index/id_registry.py allocate M PD 1
```
台账回写格式：allocate 返回的 10 个真实 id 写入 registry.jsonl（`source_file=None` 预留行），再由 03 线产包
时回填目录条目 `source_file`（对齐 217-A 回填先例）。
