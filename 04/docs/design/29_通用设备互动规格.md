## 1. 影碟机三幕规范（开仓 → 放碟 → 播放，逐秒动作表全文）

> 适用对象：VCD/DVD 影碟机展品（白模+仿真屏幕，无真机；内容包缺件 G1）。三幕 = 通用设备互动的「操作-介质-输出」范式。

### 1.1 第一幕 开仓（Grab 托盘 / 按钮语义）

| 秒 | 动作 | 输入合成 | 反馈（视觉/声音） |
|---|---|---|---|
| 0.0 | 玩家 Point [出仓] 按钮 | Point（桌面单击 / VR 扳机短按，热区 ≥0.04 m） | `sfx_ui_confirm` + 按钮压下 50 ms 回弹 |
| 0.3 | 托盘向外滑出 | （系统动画，非玩家输入） | 托盘线性推出 0.12 m，耗时 0.8 s；`sfx_disc_tray`（马达+滑动，新增 G2） |
| 1.1 | 托盘到限位 | — | 到位咔哒 `sfx_slider_snap`；托盘面 45° 俯视好光（26 号 m-paper 卡片底概念不适用，用面板 c-panel 金属质） |
| 1.2+ | 玩家可 Grab 托盘边缘（可选交互） | Grab：托盘 ∈ 允许脱离集合（仅限在轨滑动 ±0.03 m，防拔出） | 拖动力回弹阻尼 0.6；越限 `sfx_boundary` + 轻震 |

**按钮语义备选**（G2b）：面板 [开仓/关仓] 实体键 Grab 拨动同语义；托盘居中圆凹槽 = 媒体 drop 落点高亮（c-accent 呼吸 0.3 s 一次，01 号 §2.3 呼吸提示）。

### 1.2 第二幕 放碟 / 卡带（媒体对象 drop · 光影反馈）

| 步 | 动作 | 判定 | 反馈 |
|---|---|---|---|
| 1 | Grab 碟片/卡带（持握手型=平掌托举，01 号 §2.2 VR 抓取姿态） | 命中碟片对象 | 放大 1.05× + `sfx_pick` |
| 2 | 移到托盘凹槽上方 | 投影高亮圈（实时投影到托盘面，直径=碟片 1.0×） | 圈色 c-accent（可落）→ 到位闪 0.2 s |
| 3 | 松手 drop | 落点距凹槽中心 ≤0.03 m 且水平 → 吸附落座 0.3 s 动画；不满足 → 回弹悬空，落回台面 `sfx_drop_settle` | 落座：`sfx_disc_seat`（新增 G2）+ 单面反光扫过（光影反馈：顶光对碟面 30° 入射，反射带沿碟面扫一次） |
| 4 | 碟面确认 | 碟面朝上判定（印字面/读面正反，[需实机核对：正反识别的实现=贴图法线]） | 反放 → toast「翻个面」+ `sfx_ui_hint_toast`，不吞碟 |

### 1.3 第三幕 播放（激光头寻道光点、读盘音、画面亮起——逐秒）

| 秒 | 事件 | 反馈 |
|---|---|---|
| 0.0 | 托盘回仓（自动或 [关仓]） | 0.8 s 回收 + `sfx_disc_tray` |
| 1.0 | 主轴起转 | 碟片旋转加速至 500 rpm（视觉线性过渡 1.5 s）；`sfx_disc_spin`（马达低鸣，G2） |
| 1.5 | 激光头寻道 | 机芯内红点沿径向移动（透过舱盖半透窗可见，红光点 1 mm 亮斑）；`sfx_disc_seek`（步进咔嗒，G2） |
| 2.5 | TOC/菜单读取完成 | 屏显「READING…」→ VCD 直接出菜单/节目；DVD 出菜单页（见 1.4 差异表） |
| 3.0 | 画面亮起 | 主画面淡入 0.5 s；`sfx_disc_play_start`（短提示），后接播放内容声（测试卡/彩条循环，G3 资产） |
| 3.5+ | 稳定播放 | 播放态 HUD（26 号 §3 组件）：时长/轨道号/画质徽标；激光点停留径向外缘（读外层 TOC 后回内圈） |
| 结束 | 出片尾/停止 | 自动回盘停转；[停止]/[出仓] 随时可用 |

### 1.4 VCD/DVD 共性与画质差异表达参数

| 表达参数 | VCD | DVD |
|---|---|---|
| 分辨率表达 | 屏幕内 352×240 像素块感：演示叠「块状像素滤镜」（8×8 亮度块检知可见） | 720×480 锐利表达：不叠滤镜，边缘清晰 |
| 画质徽标 | 26 号 c-warn 黄标「VCD · 标准画质」 | c-accent-2 青标「DVD · 高画质」 |
| 菜单表达 | 无菜单（直接播）[需实机核对：VCD 2.0 菜单取舍] | 菜单页九宫格导航（Point 四向+确认） |
| 章节点 | 时间码进度条 | 章节缩略帧行（Grab 左右拨动选章） |
| 共性 | 激光点寻道、读盘音、画面亮起三件套共用（§1.3） | 同 |

## 2. 手持游戏机（Game & Watch 类）

### 2.1 把玩姿态 anchor 点表（VR 抓持 + 桌面等效）

| 持握方式 | 掌心 anchor（右手坐标系，单位 m） | 适用展品 | 备注 |
|---|---|---|---|
| 双手持握（横屏 G&W） | 左手 anchor (−0.045, 0.000, 0.002)；右手 anchor (+0.045, 0.000, 0.002)（机体局部系，机长 0.11 m） | Game & Watch 横版 | 双 anchor 同时 grab 时角度联动（机体绕连线段轴 0°~±15° 阻尼 0.8） |
| 单手持握（竖屏手持） | 单 anchor (0.000, −0.015, 0.005)，grab 后机体随手腕 pose，可视面锁向玩家 −10° 倾 | PDA/掌机竖版 | 手背菜单镜像键位（12 号 §3 第三路径） |
| 桌面等效 | 无需 anchor：鼠标左键按住机体任意处拖动=平移；滚轮=拉近 | 同 | 与 01 号 §2.1 Inspect 桌面语义一致 |

### 2.2 段码 LCD 透射渲染要求（G&W 屏）

| 项 | 要求 |
|---|---|
| 发光模型 | **透射式**：段未开=灰色段影（环境光被吸收 40%）；段开=深灰近黑（对比度 3:1，无自发光）；整屏不发亮 [需实机核对：G&W 显示屏为反射式银底，本规格按可读性优先取「环境光照+段翻转」表达，偏离真机处标展签] |
| 视角 | 屏面法线 ±40° 内段可视；超角段对比降至 1.5:1（教学「偏光视角」点） |
| 刷新 | 段翻转瞬时 16 ms；无扫描线；多点同时翻转支持 |
| 光照联动 | 厅内顶光强度 → 屏背景亮度线性映射（0.3~1.0），段对比不变 |

### 2.3 按键（双拇指）映射与电源/音量滑块

| 控件 | 桌面输入 | VR 输入 | 原语合成 | 语义 |
|---|---|---|---|---|
| 左键（D-pad 左半边功能键） | 键盘方向键（绑定页可改，23 号） | 左手拇指按压：`primary_btn_left` 单击 | Point | 游戏内方向/选择 |
| 右键 | 其余键（Space 等） | `primary_btn_right` | Point | 游戏内动作 |
| 电源滑块 | 鼠标左右拖（Inspect 横向） | Grab 滑块沿导槽滑动（±0.01 m） | **Inspect-Grab**：按住为 Grab、位移解释为滑块值（混合参数见 §4） | 拨到 OFF=段全灭；拨到 GAME/TIME=切换演示模式 |
| 音量滑块 | 同上（纵向或侧边） | 同 | 同上 | 联动音效轨（sfx_ui_slider_tick 每档） |

## 3. PDA（Palm 类）

### 3.1 触控笔 TraAxes 交互（Point 描画 Graffiti 笔画教学演示）

| 项 | 规格 |
|---|---|
| 输入通道 | 触控笔 pose → 笔尖在屏幕面的投影轨迹 TraAxes（桌面=鼠标轨迹；VR=`point_aim_pose` 投影至屏面 [需实机核对：笔尖锚点偏移]） |
| 采样 | ≥60 Hz；起笔/运笔/抬笔三事件；抬笔判定 = 轨迹抬离投影面 >2 mm 或悬停 >0.5 s |
| 教学演示 | 屏上显示 Graffiti 笔画描红：目标笔画淡影 + 玩家描画轨迹实线叠加；偏差 ≤30% 路径（DTW 简化判定 [需实机核对：判定算法]）= 通过，笔画变 c-ok |
| 笔画集 | 26 字母 + 数字 0-9 + 常用符号（.@#?）；教程只教 A/B/C/0~9 共 13 笔，其余入图鉴只读 |
| 反馈 | 描画中笔迹 c-accent；判对 `sfx_confirm` + 笔迹闪 0.3 s；判错 `sfx_deny` + 提示句 + 可重描 3 次 |

### 3.2 同步底座「放上即连」触发

| 项 | 规格 |
|---|---|
| 判定 | PDA 底部触点与底座槽口对齐（水平 ±0.005 m、偏角 ≤8°）且下降最后 0.01 m 由 drop 完成 → 触发 |
| 动画 | 0.4 s 落座吸附 + 底座指示灯 c-ok 亮 + 屏幕弹「正在同步…」→ 3 s 后「同步完成」 |
| 可演示内容 | 名片交换演示（两台演示机对同步：A 机名片出现在 B 机，教学「HotSync」概念） |
| 音效 | `sfx_pda_cradle`（新增 G4）+ `sfx_confirm` |

## 4. 三原语 + 12 号 VR 映射增量表（本规格新增项）

| 新增动作 | 桌面合成 | VR 合成（12 号 action） | 增量说明 |
|---|---|---|---|
| 媒体 drop（放碟/卡带） | Grab 松手（落点判定） | `grab_pose` + `point_trigger_click` 释放 | Grab 松手回弹语义的「落座成功」扩展（01 号 §2.2 回装判定同源，阈值改为凹槽 0.03 m） |
| 笔迹描画（PDA） | Point 拖拽轨迹（鼠标按住移动） | `point_aim_pose` 投影轨迹 + `point_trigger_click` 按住 | Point 新增「pen-press 轨迹」参数（press_duration 无限 + 轨迹串） |
| 滑块 Inspect-Grab | 左键按住拖（Inspect） | `grab_squeeze` 按住 + `grip_pose` 位移 | 01 号 §2.4「Grab-移动 delta」与「Inspect-桌面旋转 delta_px」之间新增混合参数 `slider_value` |
| 底座落座触发 | drop 判定（同媒体） | 同左 | 「放上即连」=落座成功事件回调 |
| 手持 anchor 联动 | — | 双 `grip_pose` anchor 角联动 | 12 号未定义「双 anchor 刚体联动」，本规格新增（参数 §2.1） |

**12 号补充声明**：以上不新增 OpenXR action 名（复用 §1.1 闭集）；仅新增第 2 层合成参数。待实机项全标 [需实机核对]。
