# 游戏机图鉴短卡（40 张）

> 任务 158 · 每张正文 60–90 字，机型/年代/厂商取自目录 v2。

## 1. Magnavox Odyssey（1972，Magnavox）
史上第一台家用视频游戏机，由拉尔夫·贝尔发明。它没有微处理器，靠分立元件与覆盖在屏幕上的塑料贴膜显示画面，玩法简陋却为整个家用游戏机产业立下了第一块基石，让游戏第一次走进了客厅。

## 2. Atari 2600（1977，Atari）
把游戏程序装进可换 ROM 卡带并做成大众商品的机器。它确立了主机与卡带分离的产业模式，靠《太空侵略者》主机版引爆销量，也因垃圾游戏泛滥而亲手把行业送进 1983 年的大崩溃，是奠基与警钟并存的一代。

## 3. Intellivision（1979，Mattel）
以 16 位图形与运动游戏见长的二代机，曾是 2600 最有力的对手。它的手柄带数字键盘与旋转盘，广告里直接对标雅达利逐项对比，是主机营销战的早期经典，也是美式家用机黄金年代的标志。

## 4. ColecoVision（1982，Coleco）
以接近街机画面的移植能力著称的二代机，把《大金刚》等街机名作原味搬回家。它是 2600 之后最强的二代机之一，展现了美式家用机最后的辉煌，也见证了雅达利冲击来临前行业的最后繁荣。

## 5. Famicom（1983，Nintendo）
复苏了 1983 年崩溃后的北美游戏业。它用严格的授权体系与《超级马力欧兄弟》这样的过硬游戏重建秩序，确立了现代主机的授权商业模式，红白配色成为一代人的共同记忆，是家用机从废墟走向成熟的转折点。

## 6. Sega Master System（1985，Sega）
世嘉的 8 位家用机，在欧洲与巴西大获成功，孕育了索尼克的前身。它硬件强于 FC，却因软件阵容与授权策略输掉了 8 位时代，是世嘉主机战争的序章，也为世嘉积累了挑战任天堂的宝贵经验。

## 7. PC Engine（1987，NEC/Hudson）
用 8 位 CPU 配 16 位显卡的巧妙设计，在日本一度压制 FC。它是首台用 CD-ROM 扩展的家用机，证明了硬件参数不是胜负的全部，成本与生态同样关键，是日本家用机史上最被低估的机器。

## 8. Sega Mega Drive（1988，Sega）
68000 与 Z80 双 CPU 配 YM2612 FM 音源，把街机味原样搬进客厅。它靠《索尼克》与高速卷轴挑战任天堂，喊出主机战争的号角，是世嘉最成功的一代主机，也是 16 位时代速度与态度的代表。

## 9. Super Famicom（1990，Nintendo）
16 位时代的巅峰之作。Mode 7 旋转缩放画出伪 3D 赛道，采样音源把游戏音乐变成交响，四键菱形与肩键成为现代手柄鼻祖，靠《塞尔达》《最终幻想》赢下主机战争后半程，是 2D 游戏的艺术高峰。

## 10. Neo Geo AES（1990，SNK）
把街机 MVS 硬件原样搬进客厅的天价主机。它与街机共用同一卡带规格，在家就能玩到真正的街机游戏且毫无缩水，代价是主机与卡带都贵得惊人，是街机家用同源这一独特商业模式的典范之作。

## 11. PlayStation（1994，Sony）
索尼首台主机，用 CD 介质与 3D 图形重新定义了游戏。它把游戏从儿童玩具推向大众娱乐，让无数成年人第一次走进游戏世界，销量破亿，是索尼从家电巨头转型为游戏霸主的起点。

## 12. Sega Saturn（1994，Sega）
世嘉的 32 位主机，双 CPU 架构复杂难开发。它在日本一度成功，却在欧美彻底败给 PlayStation，是世嘉主机事业由盛转衰的转折点，也是世嘉从硬件巅峰走向谢幕的开始。

## 13. Nintendo 64（1996，Nintendo）
以《超级马力欧 64》确立 3D 平台游戏范式，首次在主流手柄上引入模拟摇杆。它坚持卡带介质，在 CD 时代逆流而行，却留下了 3D 游戏设计的教科书级范本，影响深远。

## 14. Sega Dreamcast（1998，Sega）
世嘉最后一台主机，首台内置调制解调器，支持联网对战。它硬件均衡、理念超前，却因市场环境与对手挤压而被迫谢幕，是世嘉三十年主机事业的悲壮句号，也是无数玩家心中的意难平。

## 15. PlayStation 2（2000，Sony）
史上最畅销游戏机，销量超 1.5 亿台。DVD 播放功能助推其普及，庞大的游戏库覆盖各类型，是第六代主机毫无争议的霸主，也把 PlayStation 品牌推上了世界之巅。它定义了一个时代的游戏标准。

## 16. Xbox（2001，Microsoft）
微软首台主机，内置硬盘与以太网，靠《光环》与 Xbox Live 确立欧美三足鼎立格局。它把 PC 基因带入主机，用在线服务重塑主机生态，是微软游戏帝国的起点。在线联机从此成为主机标配。

## 17. GameCube（2001，Nintendo）
任天堂首台用光盘的主机，采用迷你 DVD 介质。它造型小巧、性能出色，却在销量上落后于 PS2，是任天堂探索差异化路线的一次过渡，也留下了许多口碑极佳的第一方名作。

## 18. Wii（2006，Nintendo）
体感遥控器把游戏带进大众家庭，销量破亿的现象级主机。它证明了游戏机不必拼性能，拼玩法创新也能赢得最广的人群，是蓝海战略的经典案例，让全家一起挥动手柄成为可能。

## 19. PlayStation 4（2013，Sony）
以 x86 架构回归易开发路线，销量破亿。它靠强大的第一方与第三方阵容赢得第八世代，是索尼主机事业最稳健的一代，也奠定了现代主机 x86 架构的主流。

## 20. Nintendo Switch（2017，Nintendo）
主机掌机二合一，可接电视也可随身携带。它融合了任天堂两条产品线的优势，销量破亿，是任天堂史上最畅销主机之一，也重新定义了主机的形态。

## 21. Game & Watch Ball（1980，Nintendo）
G&W 系列首款，横井军平枯萎技术的水平思考的起点。用段码 LCD 与纽扣电池做出便宜省电耐用的掌上游戏机，开创了任天堂手持线的先河，也为后来的 Game Boy 埋下了设计哲学的种子。

## 22. Game Boy（1989，Nintendo）
以够用硬件与《俄罗斯方块》捆绑开辟手提机品类。无背光点阵屏省电耐用，卡带生态庞大，累计销量约 1.18 亿台，是最畅销掌机之一，也是横井军平设计哲学的集大成之作。

## 23. Atari Lynx（1989，Atari）
首台彩色背光掌机，技术超前但商业失败。它硬件强于 Game Boy，却因体积大、续航短与软件阵容薄弱输掉了掌机竞争，是性能路线败给续航路线的早期案例。

## 24. Game Gear（1990，Sega）
世嘉的彩色背光掌机，硬件全面强于 Game Boy。但 6 节 AA 电池只能撑几小时，输给了省电耐用的 GB，是掌机史上技术先进不等于市场成功的经典案例。彩屏的代价是续航的短板。

## 25. Game Boy Color（1998，Nintendo）
Game Boy 的彩色升级版，向下兼容 GB 卡带。它延续了 GB 的庞大生态，是掌机从单色走向彩色的过渡，也为《宝可梦 金·银》提供了彩色舞台，巩固了任天堂的掌机霸主地位。

## 26. Neo Geo Pocket Color（1999，SNK）
SNK 的彩色掌机，格斗游戏阵容强、摇杆手感极佳。它是 SNK 破产前的绝唱，虽销量不高，却因格斗爱好者的追捧成为小众经典，摇杆的手感至今仍被玩家称道。

## 27. Game Boy Advance（2001，Nintendo）
32 位掌机，横版造型、游戏库庞大。它把掌机带入 32 位时代，向下兼容 GB/GBC，是掌机性能与便携平衡的成功之作，也让掌机游戏第一次有了接近家用机的画面。它让掌机游戏第一次有了家用机级画面。

## 28. Nintendo DS（2004，Nintendo）
双屏加触控加麦克风，史上最畅销掌机，销量超 1.5 亿。它用触控玩法吸引大众，证明掌机创新不必拼性能，是任天堂蓝海战略的又一胜利，也让触控成为掌机标配。

## 29. PlayStation Portable（2004，Sony）
索尼首台掌机，多媒体能力强，全球销量可观。它用大屏与 UMD 光盘带来掌机前所未有的视听体验，是掌机性能路线的代表，也把家用机级别的游戏体验带到了掌上。

## 30. Nintendo 3DS（2011，Nintendo）
裸眼 3D 掌机，向下兼容 DS。它延续了 DS 的双屏触控，加入裸眼 3D，是掌机时代最后的繁荣，也为 Switch 的融合路线铺路，见证了专用掌机时代的落幕。这台掌机之后，任天堂转向了主机掌机合一的新形态。

## 31. Pong 街机（1972，Atari）
首款成功的商用街机，奠定街机产业。两颗挡板一颗球的极简玩法，让酒吧顾客第一次为对着屏幕打球投币，是电子游戏商业化的起点，也是整个街机时代的开端。

## 32. Space Invaders（1978，Taito）
引发街机热潮的现象级作品，日本一度硬币短缺。一排排外星人缓缓逼近的压迫感，让投币射击成为全球文化现象，是街机黄金时代的开端，也证明了电子游戏的大众魅力。

## 33. Pac-Man（1980，Namco）
史上最知名街机之一，开辟角色 IP 与迷宫追逐类型。黄色圆脸吃豆人成为游戏业第一个大众偶像，衍生出无数周边与续作，是街机文化的永恒符号。吃豆人的形象至今仍在流行文化中活跃。

## 34. Donkey Kong（1981，Nintendo）
马里奥首秀，平台跳跃类型奠基之作。它用多层平台与攀爬开创了动作游戏新范式，也让任天堂第一次在街机市场站稳脚跟，为后来的家用机帝国埋下伏笔。

## 35. Street Fighter II（1991，Capcom）
定义格斗游戏类型的现象级街机。六键搓招与角色平衡设计奠定了格斗游戏的规则，掀起街机厅的格斗热潮，是格斗年代的起点，也是格斗游戏竞技化的开端。

## 36. Neo Geo MVS（1990，SNK）
可换多卡带的街机基板，双槽位支持换卡不停机。它孕育了拳皇、侍魂、合金弹头等名作，与家用机 AES 共用卡带规格，是街机黄金年代的见证，也是街机厅首台进入博物馆的设备。

## 37. Capcom CPS-1（1988，Capcom）
街霸 II 等格斗名作的基板。它是 Capcom 街机黄金时代的硬件底座，定义了 90 年代格斗游戏的标准配置，也是街机基板史上最重要的平台之一。它是街机基板史上的里程碑平台。

## 38. Sega Model 2（1994，Sega）
3D 街机基板，Daytona 与 VF2 的平台。它把多边形 3D 带入街机厅，是 3D 街机游戏的奠基之作，也是世嘉 3D 技术路线的起点，让街机画面从 2D 跃入 3D 时代。街机画面由此从 2D 跃入 3D 时代。

## 39. Cave CV1000（2004，Cave）
弹幕射击专用基板，怒首领蜂的平台。它是 2D 弹幕街机的最后堡垒，用铺天盖地的弹幕与精准的判定定义硬核射击，是弹幕文化的圣地。无数弹幕玩家心中的圣地。

## 40. Psikyo SH-2（1995，Psikyo）
打击者 1945 等竖屏射击的基板。它以高速竖屏卷轴射击著称，是彩京街机风格的硬件底座，也是 90 年代竖屏射击的代表平台。竖屏射击的黄金平台之一，是无数街机玩家心中的经典。
