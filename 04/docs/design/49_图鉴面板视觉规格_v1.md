## 1. 布局（面板尺寸 / 锚点 / 栏比例 / 详情行位置）

```
┌────────────────────────── 面板 960×600（2K：1920×1200）──────────────┐
│ 图鉴目录 中分类 28 · 条目 1484          [✕]     ← 标题栏 h=48/96      │
├───────────────┬───────────────────────────────────────────────────────┤
│ 左栏 200/400  │ 右栏 条目列表（三列：名称/年代/厂商）                    │
│ [计算机]      │  ENIAC     1945   宾夕法尼亚大学                          │
│ [通讯与移动]  │  Apple II  1977   Apple Computer                        │
│ …中分类列表   │  …（虚拟滚动，31 号 §1.4 池策略）                          │
├───────────────┴───────────────────────────────────────────────────────┤
│ 详情行（底部通栏 h=96/192）：目录全称 · 状态徽章 · 关联包 · 影响力前 80 字 │
└─────────────────────────────────────────────────────────────────────────┘
```

| 项 | 桌面 720p | 桌面 2K | 规则 |
|---|---|---|---|
| 面板尺寸 | 960×600 px | 1920×1200 px | 高 ≤ 视高 75%（不遮挡行走中心区） |
| 锚点 | 左下角停靠，距边 safe=24 px | 左下，safe=48 px | HUD 内；行走中心区=视口中央 40% 净空 |
| 左/右栏比例 | 200 : 760（≈1:3.8） | 400 : 1520 | 中分类 28 项左栏一屏可示 ≥18 行 |
| 行高 | 左栏 28 px / 右栏 32 px | 56 / 64 px | 右栏可视 12 行 + overscan 上下各 6 |
| 详情行 | 面板底部通栏高 96 px | 高 192 px | 内容=§2.4 字段序（对齐 106-A） |
| 标题栏 | 高 48 px | 高 96 px | 左标题右关闭钮 |

- 打开态面板不抢焦点行走（键鼠：面板聚焦时 WASD 移交光标；关闭即还）[实机核对：焦点管理与 23 号绑定页同源]。

## 3. 交互约定（键盘 + 滚轮 + 联动）

| 键/操作 | 行为 | 备注 |
|---|---|---|
| Tab | 面板开合（复用 input_profile 习惯键位，106-A 同） | 与 23 号绑定页 Tab 语义不冲突（不同界面域） |
| ↑/↓ 或滚轮 | 移动光标（左栏/右栏分焦点） | 滚轮 3 行/格；光标行即时高亮 |
| ←/→ | 焦点切换左右栏 | — |
| Enter | 选中 = 打开条目详情态（走 31 号 §2.2 详情结构） | 详情态内 Enter 回列表 |
| Esc | 关闭面板（详情态先退列表态，再 Esc 关面板） | 同 23 号层叠返回语义 |
| 选中联动 | 选中条目 → 展厅内该设备**橙色高亮**（c-accent 琥珀描边 + 15% 提亮，26 号选中反馈）；设备不在当前厅 → 仅面板高亮 + 右下提示「该设备不在本厅」 | 高亮清退=Esc/关闭面板时同帧清除 |

- 打开面板期间玩家可继续行走（面板非模态）；输入拦截仅限按键冲突集（Tab/Esc/方向键）。

## 4. 空态 / 加载态文案

| 态 | 触发 | 文案 |
|---|---|---|
| 加载中 | load_meta 未返回（>500 ms） | 「目录载入中…」（c-text-2） |
| 加载失败 | load_meta=false | 「图鉴暂不可用（目录数据未就绪），请稍后重试」+ [重试] 按钮（c-accent） |
| 空分片 | 选中分类无条目 | 「该分类暂无条目。」 |
| 搜索无结果（预留） | 21/31 号搜索接入后 | 「没有找到『<q>』。试试：年代筛选 / 分类浏览 / 查看全部预订中条目」+ [重置筛选]（31 号 §1.3 同文） |

## 5. 给 01 线的一句话接口约定

面板脚本**只调用 `catalog_data.gd` 既有函数**（`load_meta()`/`get_taxonomy()`/`get_shards()`/`load_shard(big,mid)`/`search()`），**不新增任何数据契约**；三列显示字段映射 = 目录归一键 `name`→名称、`year`→年代、`maker`→厂商（106-A 任务书所写 era/manufacturer 为显示列头名，取数键以 33 号 §3 归一键为准）。
