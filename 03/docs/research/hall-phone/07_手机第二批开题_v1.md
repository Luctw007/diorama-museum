# 手机第二批开题 v1

> 03 线 TASK-173-A 交付。手机厅第二批开题卡：从 3 台（DynaTAC / iPhone / Nokia 3310）向「大哥大 → GSM → 智能机」完整谱系推进。

## (a) 开题定位

手机厅当前已入馆 3 台（DynaTAC 8000X「大哥大」、Nokia 3310「国民手机」、iPhone「触屏革命」）。第二批的目标是**补全「大哥大 → GSM 功能机 → 智能机」的完整谱系**，把手机从「少数人的砖头」到「人手一部的国民设备」再到「掌上电脑」的演进弧线讲完整。第二批优先补 GSM 功能机时代的「形态/品牌多样性」——翻盖（StarTAC）、滑盖（8110）、换壳普及（5110）、邮件拇指键盘（BlackBerry）。

## (d) 模拟器结论总述

功能机（非 Symbian）普遍**无成熟专用模拟器**，固件受版权保护；演示走「静态高精度 3D + 短信/换壳/翻盖原理动画」，「可玩」用自研复刻小游戏承载（如贪吃蛇、来电铃声交互）。相关 Symbian/MAME 手持等候选许可一律标「需核实」，不下载、不留二进制。
