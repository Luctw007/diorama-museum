## 1. 级联爆炸规范（L0 → L1 → L2 → L3）

### 1.1 各级定义与预算

| 级 | 语义 | 范围 | 渲染预算（0.5 M tri 基准设备 [需实机核对：以 apple-ii 包面数实测为准]） |
|---|---|---|---|
| L0 | 整机闭合 | 外壳+名牌 | 全部可见件 100% |
| L1 | 整机爆炸 | 沿既有公式分离：offset_i = explode_value × depth(i) × STEP（STEP=0.12，depth≤8） | 同 L0 |
| L2 | 子树爆炸 | 点选 L1 部件后，其子装配沿子树局部轴再分离：offset_j = explode_value×depth_sub(j)×0.5×STEP（0.06 档，子树深度 ≤4） | 仅子树 ≤50 件渲染高精，外域降 2× 纹理/LOD |
| L3 | 元件级 | **不做全拆**：仅「代表元件」高亮+浮动解说（每部件 ≤3 个代表元件） | 高亮 ≤3 元件 / 部件；外域全 LOD1 |

**L3 只做代表元件的预算依据**：万级设备 ×深度 ×元件数全拆的 draw/tri 与教学收益不成比例——0.5M tri 机若 L3 全拆需 3× 顶点；代表元件方案恒定 ≤+30k tri（教育心理学口径：一次只看 3 个）。

### 1.2 L1→L2 相机轨迹表（点选 L1 部件 → 子树爆炸）

| 项 | 参数 |
|---|---|
| 轨迹阶段 | ① 目标框（0.3 s）：选中部件外框高亮，相机不动 |
| | ② 推进（0.5 s）：相机沿选中部件法向拉近至子框充满视口 60%，缓动 easeInOutQuad |
| | ③ 子爆（0.3 s）：子树按 §1.1 L2 公式展开，子框保持居中 |
| | ④ 稳定（0.1 s）：运镜结束入交互 |
| 总时长 | **0.9–1.2 s**（0.3+0.5+0.3+0.1，低配档 1.5 s 上限） |
| 相机约束 | 距选中部件 0.4–1.5 m；可动范围绕子框 ±45° 摆角；爆炸期间玩家输入进入过渡锁（01 号 §4.7 语义） |

### 1.3 L2 返回 L1 轨迹

| 项 | 参数 |
|---|---|
| 返回 | 0.6 s 逆向插值（缓动 easeOutQuad）回 L1 视角与位移；子树归位（复用 explode_value 归 0 动画，SLIDER_SPEED=2.5 不加速） |

## 3. 操作映射双形态状态机

### 3.1 状态机（ASCII 全量）

```
        ┌────────────┐ 双击部件 / VR捏取         ┌────────────┐
        │  L1 整机爆炸 │ ────────────────────────▶ │  L2 子树爆炸 │
        └────────────┘                           └────────────┘
          ▲    │                                       │ ▲
  面包屑/挥手 │    │ 双击空处 / 挥手                    │ │ 双击更深L1节点
          │    ▼                                       ▼ │
        ┌────────────┐  ESC / 挥手  ──▶ 同左          ┌────────────┐
        │  L0 闭合    │ ◀──────────────────────────── │ L3 代表元件 │
        └────────────┘     （任何层 ESC 两连）        └────────────┘
                                                        （只读浮动解说）
 规则：L2 内 ESC 一次=L1；L1 内 ESC 一次=L0；双层 ESC=L0（T-071 层叠语义）
       面包屑条常驻顶部：[整机 / 主板 / 南桥] 任意段点击直达该层（深层返回后状态保持）
```

### 3.2 双形态操作表

| 操作 | 桌面 | VR（12 号 action） |
|---|---|---|
| 进入 L2 | 双击 L1 部件 | 「捏取」：`point_trigger_click` 短按选中后 `grab_squeeze` 捏合 0.4 s [需实机核对：捏取阈值] |
| 返回上级 | ESC | 「挥手」：持握手柄向视野外水平挥 >0.3 m/s 一次 |
| 面包屑直达 | 点击面包屑段 | 手背菜单链选层（12 号 §3 第三路径） |
| L3 代表元件 | 单击部件 | 射线点选（热区 ≥0.04 m） |
| 深层返回状态保持 | 返回后 L1 位移/选中/相机视角全部保留（§3.3） | 同左 |

### 3.3 状态保持清单（用例 T-387 判定依据）

进入 L2 前保存快照：`explode_value`、当前选中部件 id、相机 orbit（yaw/pitch/radius）、面包屑路径；返回 L1 时逐项恢复；切设备时快照按设备 id 归档（两台设备两层爆炸同时开启 = 各自快照独立，用例 T-388）。
