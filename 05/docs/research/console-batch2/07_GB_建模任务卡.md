### 〇.1 交付链路总览

本批是 Game Boy 正式建模的第一批，范围覆盖整机六件（front_shell/back_shell/mainboard/screen_module/dpad_module/cartridge）。GB 是游戏机厅"手提机破题"专区的核心设备，也是三台游戏机线设备里**唯一有内置屏幕**的机型——屏幕模块（绿点阵屏 + 偏光片分层）是掌机独有的建模难点，本批专设屏幕模块专项（卡片 4）与两级方案。

本批完整链路：执行方拿到本任务卡（07 号）与验收清单（08 号）→ 逐件建模 → 自查返工点清单 → 提交到验收点 A（外观壳两件）→ 审查者三关验收 → 合入 → 继续验收点 B（内部四件）→ 合入。两个验收点独立。

### 〇.2 本批质量红线

1. 任何一件网格**超 LOD1 预算 1.5 倍**即 FAIL，不因"做得细"而豁免。
2. 任何一处**商标（"GAME BOY" 字样）被渲染**即退回（FR-J2 红线）。
3. 任何一张**版权照片/字体/标签图**被用作贴图即退回。
4. 屏幕模块**做成实心块无分层**即退回——绿点阵屏的玻璃/偏光/液晶/反光分层是掌机"像不像"的核心。

### 〇.3 本批实机细节验收重点（人工必查六项）

1. **屏视差**：显示内容与外层玻璃有微小间距（视角变化时有视差），若屏幕是贴死的实心块即退回。
2. **像素级网格**：160×144 点阵有像素级网格（纹理或几何），若纯色平面即退回。
3. **按键高度**：十字键高于机壳约 1–1.5 mm，若与机壳齐平即退回。
4. **背板螺丝位**：背板 6 个十字螺丝位，若缺失即退回。
5. **电池仓**：4 节 AA 电池凹位两两排列，若缺失即退回。
6. **卡带 32 针金手指**：卡带底部 32 针镀金金手指，若排针数错即退回。

### 枢轴约定（屏的视角层）
GB 屏幕有**视角层（视差）**：屏幕内容位于最内层（反光层之上），外层玻璃有一定厚度，观看角度变化时内容与外层玻璃之间有轻微视差。建模须分层：外层玻璃 → 偏光片 → 液晶层（显示内容）→ 反光层，各层之间有微小间距。

### 命名表
`screen_module`（根）；子节点 `screen_module_glass`（外层玻璃）、`screen_module_polarizer`（偏光片）、`screen_module_lcd`（液晶显示层）、`screen_module_reflector`（反光层）。

### 验收核对行
MR-01 根节点名 `screen_module`；MR-02 LOD1 ≤5000（纹理模拟方案）；MR-03 贴图合法；MR-04 米制 Y-up。

### 屏幕模块专项：像素级网格与玻璃反射的两级方案

GB 屏幕是 160×144 点阵、4 级灰度的绿点阵屏，建模的核心难点在"像素级网格"与"玻璃反射"如何表达。本卡给出两级方案，执行方二选一：

| 维度 | 方案 A：几何网格 | 方案 B：纹理模拟（推荐默认） |
|---|---|---|
| 像素网格 | 160×144 = 23040 像素，每个像素一个面片 | 屏幕一个平面（2 三角面）+ 像素网格纹理 |
| 三角面成本 | 23040×2 ≈ 46000 面（仅 LOD0 特写可承受） | 2 面 + 纹理 |
| 玻璃反射 | 几何 + 清漆/透明材质 | 法线贴图 + 反射贴图模拟 |
| 偏光片分层 | 4 层几何（玻璃/偏光/液晶/反光） | 2 层（玻璃 + 屏幕平面），分层用纹理/法线 |
| 预算占用 | LOD0 特写 12500 面几乎全用于像素网格 | LOD1 观察 5000 面即可，LOD0 加玻璃分层 |
| 适用 | 极近距离特写、原理讲解"逐像素" | 默认交付、观察距离 |

**推荐**：默认用**方案 B（纹理模拟）**——屏幕是平面 + 像素网格纹理 + 玻璃反射法线贴图，LOD1 观察档即可；仅在"点阵屏逐像素"原理讲解需要极近特写时，才用方案 A 的几何像素网格（LOD0 特写档）。

### 错误示例 vs 正确示例

| 维度 | 错误示例 | 正确示例 |
|---|---|---|
| 像素网格 | 屏幕做成纯色平面，无像素网格 | 有像素级网格（纹理模拟或几何） |
| 玻璃反射 | 屏幕无玻璃层/无反射 | 外层玻璃 + 反射（法线贴图模拟） |
| 偏光片分层 | 屏幕是一层实心块 | 玻璃/偏光/液晶/反光分层（或纹理表达分层） |
| 视角层 | 显示内容与外层玻璃无间距 | 各层有微小间距，产生视角视差 |

## 附录 A：手提机建模要点总结

手提机（Game Boy）相对家用机（MD/FC）的建模差异，集中在三点：

1. **屏幕是核心**：家用机的画面在外部 CRT，掌机的画面在机身内置屏幕里——屏幕模块（绿点阵屏 + 偏光片分层 + 玻璃反射 + 视角视差）是掌机独有的建模难点，本卡卡片 4 已给两级方案（纹理模拟默认、几何网格特写）。屏幕分层的顺序是"外层玻璃 → 偏光片 → 液晶显示层 → 反光层"，各层有微小间距；默认用纹理模拟表达像素级网格与玻璃反射，只有"逐像素"原理讲解才需要几何像素网格。
2. **机身一体化**：掌机前后壳扣合、电池仓/卡带仓在后盖，无家用机的"开盖看内部"结构，拆解路径是"拆后盖 → 取主板 → 拆屏幕"。因此 front_shell 与 back_shell 的扣合缝、背板螺丝位（6 个十字螺丝）是拆解叙事的关键，建模须保留真实螺丝位。
3. **按键是交互**：十字键与 AB 键是掌机的主要输入，按键高度（十字键高于机壳 1–1.5 mm）、十字凹槽、橡胶导电垫是"手感"的来源，建模须还原——这是"可玩"体验（玩家在 GB 上按出《俄罗斯方块》的操作感）的物理基础。

> 手提机建模要诀：**屏幕分层、机身一体、按键手感**，三者做好，掌机就"像"了。而这三点的共同指向，是 Game Boy"便携、耐用、手感好"的硬件哲学——正是横井军平"枯萎技术的水平思考"在建模层面的落点。

## 附录 L：GB 的叙事衔接（俄罗斯方块捆绑与掌机社交）

本卡虽是几何建模任务卡，但建模的最终目的是服务叙事。Game Boy 的展示叙事有两条主线，建模须为之预留展示位：

1. **《俄罗斯方块》捆绑传奇**：屏幕模块是可玩演示的核心——CRT 演示位（或屏幕模块自身）轮播《俄罗斯方块》，观众看 160×144 点阵上七种方块落下消除。建模须保证屏幕模块的显示层清晰、像素网格可见，让"规则极简的方块游戏如何统治世界"这一叙事有物理载体。
2. **《宝可梦》联机社交**：Game Link 联机口是掌机社交的锚点，建模须保留背部的联机口位（与卡带仓相邻），供展示"两台 GB 对战/交换宝可梦"的场景。

这两条叙事线一先一后，把 GB 从"一台能玩的掌机"推向"一代人的共同记忆"，也是游戏机厅"手提机破题"专区与"家用机"各区最根本的区别——GB 讲的是"口袋里的游戏"，不是"客厅里的游戏"。

## 附录 E：逐件建模要点详解

### E.1 front_shell（前壳）

front_shell 是 Game Boy 的"脸面"。几何上，它是灰白 ABS 前壳，左侧是十字键区、右侧是 A/B 键区、中间偏上是方形屏幕窗、右下角是扬声器格栅。屏幕窗是**凹陷的方形窗框**，四周有倒角，是 screen_module 的配合面——窗框尺寸须与屏幕模块精确匹配，留装配间隙。扬声器格栅是右下角的一排斜向孔位（LOD0 真实孔，远景 alpha 贴图）。AB 键位是两个圆形凹位，十字键位是一个十字形凹位，二者都与对应模块对齐。材质灰白 ABS（metallic=0，roughness≈0.8）。面数 LOD1 ≤6000。

### E.2 back_shell（后壳）

back_shell 是 Game Boy 的"背面"。几何上，它是灰白 ABS 后壳，有电池仓（4 节 AA 电池凹位，两两排列）、卡带仓（背部插卡口）、6 个背板螺丝位。电池仓盖与卡带仓盖可开合（绕底部轴微幅旋转）。电池仓内部有弹簧电极与电池凹位。材质同前壳。面数 LOD1 ≤4000。

### E.3 mainboard（主板）

mainboard 是掌机的心脏。几何上，它是绿色 PCB，承载 LR35902（GB 专用定制 CPU）与 LCD 控制器两颗核心芯片，另有 8KB 工作 RAM、8KB VRAM 与声音电路。LR35902 居中、LCD 控制器邻近屏幕连接，丝印标注位号。走线用丝印贴图表达。面数 LOD1 ≤8000。

### E.4 screen_module（屏幕模块）

screen_module 是掌机独有、也是本卡的核心难点。几何上，它分四层：最外层玻璃 → 偏光片 → 液晶显示层（160×144 点阵、4 级灰度）→ 反光层。各层之间有微小间距（产生视角视差）。默认用纹理模拟方案（屏幕平面 + 像素网格纹理 + 玻璃反射法线贴图），LOD1 观察档即可；"逐像素"原理讲解需要极近特写时才用几何像素网格方案。面数 LOD1 ≤5000。

### E.5 dpad_module（十字键模块）

dpad_module 是横井军平"十字键"的实物。几何上，它是灰黑十字键 + 橡胶导电垫底座。十字键高于机壳约 1–1.5 mm（按键高度），有真实十字凹槽，四向可按，中心支点微幅摆动。橡胶导电垫是按键回弹的手感来源，LOD0 特写可见。面数 LOD1 ≤2000。

### E.6 cartridge（卡带）

cartridge 是 GB 的"内容载体"。几何上，它是灰白卡带外壳（比家用机卡带小一号），顶部标签区，底部 32 针镀金金手指。卡带可剖面展示（外壳→PCB→ROM 芯片），是"卡带式游戏机"叙事的掌机版锚点。背部 −Y 竖直插入 back_shell 卡带仓。面数 LOD1 ≤3000。

## 附录 I：本批三档预算数字的来源与推导

本批六件的三档 LOD 预算，来源与推导如下：

1. **单装配体上限**（引用 02 线 v0.3 定稿 §5.2）：LOD0 特写 ≤50,000、LOD1 观察 ≤20,000、LOD2 远景 ≤8,000，整机 ≤400,000。
2. **整机分配**：GB 是掌机，整机远小于家用机，六件观察档（LOD1）分配：mainboard 8000（信息密度高，LR35902+LCD 控制器）、front_shell 6000（屏窗+按键位+扬声器格栅）、screen_module 5000（屏幕分层）、back_shell 4000（电池仓）、cartridge 3000（卡带剖面）、dpad_module 2000（十字键），整机观察档合计约 28,000，远在整机 400,000 上限内。
3. **三档换算**：远景档（LOD2）≈ 观察档 ×0.4，特写档（LOD0）≈ 观察档 ×2.5，均在单装配体上限内。
4. **screen_module 的预算特殊性**：屏幕模块默认用纹理模拟方案（LOD1 观察 5000 面即可）；若改几何像素网格方案，160×144=23040 像素需约 46000 面，仅 LOD0 特写档（≤50,000）可承受，且需走 v0.3 §10.4 全局对冲（在其它件上压缩等量面数）。
5. **dpad_module 给最低**（2000）：十字键几何简单，但按键高度与凹槽须准确。

> 预算是"整机总量约束"，不是"单件硬上限"；mainboard 可以高，已通过 dpad_module 低预算全局对冲。

## 附录 K：GB 与家用机（MD/FC/Atari）的建模差异要点

手提机（GB）与家用机（MD/FC/Atari）的建模差异，决定了本卡与前三张卡的差异：

| 维度 | 家用机（MD/FC/Atari） | 掌机（GB） |
|---|---|---|
| 屏幕 | 外部 CRT（`external_crt` sink） | 机身内置屏幕（screen_module 分层） |
| 拆解路径 | 开盖看内部 / 顶部插卡 | 拆后盖 → 取主板 → 拆屏幕 |
| 输入 | 手柄（独立或焊死） | 机身一体按键（十字键 + AB） |
| 卡带 | 顶部/前插 | 背部插卡 |
| 电源 | 外接电源 | 4 节 AA 电池（电池仓） |
| 尺寸 | 数十厘米级 | 掌上可握（约 148×90×32 mm） |

> 差异核心：掌机"屏幕内置、机身一体、电池供电"三点，决定了它"便携"的本质；建模上屏幕分层（卡片 4）是唯一的新难点，其余（外壳/主板/卡带）与家用机同构。

## 附录 M：屏幕模块专项补充说明（偏光片与玻璃反射技术细节）

屏幕模块的"偏光片分层"与"玻璃反射"，是 GB 区别于所有家用机的建模独有项，补充技术细节如下：

1. **偏光片**：GB 原版是反射式液晶屏，没有背光，靠偏光片 + 反光层利用环境光显示。建模时偏光片是一层极薄的半透明灰膜，位于液晶层与外层玻璃之间；反光层是屏幕最内侧的浅灰反射面。这两层让屏幕在关机态呈灰绿色（绿反射式），开机态呈绿色像素，是"绿屏"得名的物理来源。
2. **玻璃反射**：外层玻璃有镜面反射，建模用低粗糙度（roughness≈0.05）+ 法线贴图模拟，不建真透明玻璃（避免移动渲染透明排序开销，v0.3 §7.7 开放问题）。反射强度在 LOD0 特写档才需要强调，观察档用一张法线贴图即可。
3. **像素级网格**：160×144 点阵的像素网格，纹理模拟方案下用一张 160×144 的像素网格贴图（每个像素一个色块）表达 4 级灰度的绿点阵；几何网格方案下才逐像素建模。两者预算差异见卡片 4 专项表。
4. **视角层**：显示内容（液晶层）与外层玻璃之间约 0.5–1 mm 间距，是"屏视差"的来源——这是 GB 屏幕区别于现代全贴合屏的关键，建模务必保留这层间距，否则屏幕"贴死"会失去掌机屏幕的质感。
