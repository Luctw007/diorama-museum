## 1. 甲/乙两案利弊对照表（动线/体例/编号链/维护四维）

| 维 | 甲案：并入 82 号 v3 | 乙案：独立 PDA 线 |
|---|---|---|
| 动线 | 利：Newton 站 8 直接接驳手机厅「移动设备进化线」（站 3B 8110 并置），游客动线连续不折返；弊：PDA 与手机品类叙事需在口播中区分（「PDA 不是手机」补一句），停留账并入手机厅总时长 | 利：PDA 叙事独立成线（Newton→Palm→BlackBerry 扩展空间大），动线自洽；弊：新增一厅/区需新入口/导语/出口三件套，动线成本最高 |
| 体例 | 利：沿用 82 号站体例（口播表/音频 id 表/需补清单），零新体例；弊：82 号 v2 站 0~7 需升 v3，站 8 章节为新增段落 | 利：PDA 线体例可全新定义（触控笔交互判据独立成章）；弊：无既有 PDA 台本体例母本，需新立一份（体例成本） |
| 编号链 | 利：用例并入手机厅段（47 号手机厅行加行），编号链 T-668 起连续不跳号；弊：手机厅行条数膨胀，段内分类需加注 | 利：PDA 线独立用例段（T-668 起另起行段），分类清晰；弊：85 号跨馆总表需加「PDA 线」行，对账表结构变化 |
| 维护 | 利：只维护 82 号一份台本，升级链路短；弊：手机厅每次升级连带 PDA 站回归 | 利：PDA 线独立升级互不牵动；弊：维护面 +1 份台本 + 1 份用例，长期维护成本高 |

## 2. 裁决判据清单（建议权值，只备底不裁决）

- 判据使用口径：定稿裁决时逐维打分（1~5 分）× 权值加权，总分高者定案；若加权后并列，以判据 1（动线）为决胜负项。

## 3. 两案各自定稿骨架占位

- **甲案骨架（82 号 v3）**：站 8 PDA 展区 = 站 3B 8110 后插入；口播要点 [S135]（PDA 词源/ARM 610 20MHz/Newton OS/手写识别/商业失败 1998 停产/「早熟的先知」）；动线台前 1.2 m、停留 45 s；互动 = 手写识别演示动画（触控笔书写→识别成字，1-2 段，静态+动画）；Einstein 候选需核实、Newton OS ROM 红线不入库；
- **乙案骨架（独立 PDA 线）**：新线 = 入口/总导语/Newton 展项/出口三问四站起步；口播与互动提示同甲案；新增音频 id（bgm_pda_01/vo_pda_* 口径占位，不新增 id 号）；用例段另起行段（T-668 起，不产编号）。
