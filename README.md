# 箱庭电子博物馆（Diorama Computer Museum）— monorepo

开源独立游戏项目（MIT License）：3D 复刻历史电子设备，可拆解到元器件、查看原理，并用开源模拟器让设备真实运行（VR / 多平台）。**所有内容与工程由五条 AI 工作线协作产出，人工审查合入。**

## 仓库结构（五线子目录）

| 目录 | 线 | 职责 |
|---|---|---|
| `01/` | 工程线 | 模拟器网关、引擎侧脚本、一键门禁 verify_all、槽位系统、GitHub/CI 收口 |
| `02/` | 管线线 | 内容包与目录规范、校验器工具链、索引/台账、贡献指南 |
| `03/` | 内容线 | 计算机黎明厅/大型机小型机/个人机厅 设备内容包与目录 |
| `04/` | 体验线 | 交互/UI/台本用例/发布验收清单 |
| `05/` | AppleII·游戏机线 | 游戏机/掌机/家电外设内容包与外部生态调研 |

## 新手入口（按顺序读）

1. `02/docs/内容包与目录规范_v0.6.md`（+ 增补 v0.6.1/v0.6.2）——内容包规范；
2. `02/docs/CONTRIBUTING.md`——贡献流程与红线（**ROM/二进制永不进仓**）；
3. `02/docs/ROADMAP.md`——v0.1 demo → v0.2 开源 → v1.0 全馆；
4. `01/docs/github_setup.md`——本仓推送/凭证铁律（PAT 永不落盘）。

## 快速验证

```bash
cd 01 && python scripts/verify_all.py --daily --cache
```

门禁步骤：m0/m1b 断言 + 槽位一致性 + 目录摄取对账 + 目录↔内容包反链 + Godot 符号自检 + 全部内容包 validate 0 FAIL。
