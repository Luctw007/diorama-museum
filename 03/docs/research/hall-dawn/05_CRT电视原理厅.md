# 05 — CRT 电视原理厅设计稿

> 章节目标：为"计算机黎明"展厅附设的 CRT 电视机原理厅提供原理演示设计与展陈设计。
> 背景：电视机无对应模拟器方案，用"原理动画"承载（任务书 §一）；本厅与"游戏机接 CRT 电视"的馆联动是重点衔接场景。
> 引用编号沿用 `07_证据包索引.md` 的 [Sxx] 体系；电视原理部分为通用物理/工程常识，不涉及版权素材，具体参数标注「需核实」者以"分区域制式"处理。

---

## (a) 展厅定位与目标

CRT 电视原理厅不是一台"计算机"，而是一条**从"电子束"到"活动影像"的物理链路**展项。它的角色有三：

1. **承上**：EDSAC 的 OXO（1952）与 Manchester Baby 的 Williams 管都用到 CRT——CRT 既是早期计算机的**内存**，又是早期游戏机的**显示器**，本厅把"显像管"这个被四台计算机反复用到的器件单独讲透。
2. **启下**：为后续"游戏机厅"提供**显示原理铺垫**——当玩家看到红白机/街机接 CRT 电视时，能理解画面是怎么被"扫"出来的。
3. **可玩**：用一个"信号注入演示"，让任意视频源（模拟器画面、展厅摄像头、玩家自选图）实时投到 CRT 屏幕，形成**可交互的"电视"**。

---

## (b) CRT 电视机结构：装配体层级树 + 职责

```
CRT 电视机整机
├── 外壳（木壳/塑料壳 + 前面板）
├── 显像管（CRT，含玻璃玻壳 + 荧光屏 + 电子枪）
│   ├── 电子枪（灯丝 + 阴极 + 栅极 G1 + 加速极 + 聚焦极 + 阳极）
│   ├── 荧光屏（涂敷红/绿/蓝荧光粉；单色机为单色荧光粉）
│   └── 荫罩/偏转系统安装位
├── 偏转线圈（Deflection Yoke，套在管颈）
│   ├── 行（水平）偏转线圈
│   └── 场（垂直）偏转线圈
├── 高压部分（高压包/FBT + 高压帽）
│   ├── 行输出变压器（生成阳极高压，约 10–25 kV 级，量级「需核实」）
│   └── 聚焦/帘栅电压
├── 信号处理部分
│   ├── 调谐器（高频头，选台 + 变频）
│   ├── 中频放大（图像中频 + 伴音中频）
│   ├── 视频检波（解调出亮度信号）
│   ├── 同步分离（从复合信号中分出 H/V 同步脉冲）
│   ├── 行/场扫描振荡与驱动
│   └── 伴音通道（伴音解调 + 音频放大 → 喇叭）
└── 电源（低压 + 高压）
```

**职责速览（对应"每块板/每个组件讲什么"）：**
- **电子枪**：把电信号变成聚焦的电子束——"一支会画画的电子笔"。
- **偏转线圈**：用磁场让电子束左右（行）、上下（场）扫描——"这支笔怎么动"。
- **荧光屏**：电子打到哪里哪里亮——"画布"。
- **高压部分**：给电子束足够的动能飞向屏幕。
- **同步分离**：让"笔的扫描节奏"与"广播里的画面节奏"锁在一起——**这是电视区别于示波器的关键**。

## (c) 原理演示设计（核心）

### 1. 电子束扫描动画脚本（C2/C3/C4）

**C2（框图层）**：整体框图——信号进入 → 同步分离 → 行/场扫描 → 偏转线圈 → 电子束 → 荧光屏，外加"伴音支路"。

**C3（信号流层）**：标注三类信号——① 视频亮度信号（控制电子束强弱）；② 行/场同步脉冲（控制扫描节奏）；③ 偏转电流（锯齿波，控制电子束位置）。

**C4（原理动画脚本，逐镜头）：**

- **镜头 1：一支会移动的笔（水平扫描）**
  - 画面：管颈电子枪发出一个亮点，沿屏幕**从左到右**快速移动。
  - 箭头/时序：锯齿波电流驱动水平偏转；标注"回扫（消隐）"——从右跳回左的瞬间亮点熄灭。
- **镜头 2：一笔一笔铺满（垂直扫描 + 隔行）**
  - 画面：亮点从上到下一行行铺满屏幕，形成"光栅"。
  - 强调**隔行扫描**：先扫奇数行（1、3、5…），再扫偶数行（2、4、6…），两场合成一帧（NTSC 525 线/60 Hz、PAL 625 线/50 Hz，「需核实」按展示制式标注）。
- **镜头 3：亮度 = 图像（辉光点模拟）**
  - 画面：同一扫描过程中，电子束强弱随"图像信号"变化，屏幕逐点亮暗不同，拼出一幅静止画面。
  - 关键句："扫描决定**位置**，信号决定**亮暗**。"
- **镜头 4：消隐与同步**
  - 画面：行回扫与场回扫期间亮点熄灭（消隐）；同步脉冲把"接收端的扫描"与"发射端的扫描"锁到同一节奏，画面不滚动。

### 2. 辉光点模拟（"亮点 = 像素"）

- 用一个**可调速度的慢动作辉光点**，让玩家看清"一个点怎么变成一整幅画"。
- 交互：玩家可拖动滑块放慢扫描、或暂停在某一瞬间，看到"此刻其实只有一个亮点在跑，是视觉暂留让它看起来是整幅画面"。
- 与计算机厅联动：把"Williams 管存储"的电荷斑读写动画放在旁边对照，说明"同一根管子，既能当内存（Baby/EDSAC），也能当显示器（电视/游戏机）"。

### 3. 信号注入演示（给这台"电视"喂画面）

- **概念**：复用手册/网关的 **Sink** 概念——展厅里有一个"视频 Sink 接口"，任何视频源（fake_emulator、展厅摄像头、玩家上传的图/短视频）都能被实时编码成模拟电视信号，投到这台 CRT 电视上。
- **演示流程（发射端 → 接收端）**：
  1. 视频源（画面）→ 编码为亮度 + 行场同步 + 伴音；
  2. 调制到射频载波（模拟"广播"）；
  3. 电视调谐器接收 → 解调 → 分离同步 → 驱动扫描 → 荧光屏成像。
- **互动点**：
  - 玩家点"换台"切换不同视频源；
  - 玩家拖一个"干扰滑块"（模拟信号衰减/雪花），看画面变差——直观理解"电视信号为什么会花屏"；
  - 玩家可把自己的笑脸（摄像头）投到 CRT 上，成为"上电视的人"。

## (d) 展陈设计：从"声音→电磁波→影像"的电视广播链路

**链路图（发射端 → 接收端，简化）：**

```
 [摄像机/视频源] → [视频放大] → [亮度+同步 编码] → [射频调制] → [发射天线]
                                                        │
                                          （电磁波在空气中传播）
                                                        ▼
                    [接收天线] → [调谐/变频] → [中频放大] → [视频检波]
                                        │                    ├→ [亮度信号 → 电子枪]
                                        │                    └→ [同步分离 → 行/场扫描]
                                        └→ [伴音解调 → 音频放大 → 喇叭]
```

**展陈节奏（建议三段）：**

1. **第一段"声音"**：先讲广播——声音如何变成电磁波（AM/FM），建立"信号在空中传播"的直觉。
2. **第二段"影像"**：影像如何被拆成"位置（扫描）+ 亮暗（信号）"，再合回画面。
3. **第三段"这一台电视"**：落到展厅实体 CRT 电视，让玩家亲手完成"注入信号 → 出画面"。

**关键讲解句**：
- "电视不是把一幅画'整个'传过来的，而是把画拆成一束来回跑的电子束。"
- "同步是电视的灵魂：接收端必须和发射端跑得一样快、对齐得一样准，画面才不滚动。"

## (e) 与其他展厅设备的关系（馆联动）

- **游戏机厅（未来）**：红白机/街机输出的是"视频 + 同步"信号，直接接到 CRT 电视——本厅的"扫描 + 同步"讲解正是理解"游戏画面怎么上电视"的前置知识。可设计**跨厅彩蛋**：游戏机厅的街机柜 CRT 上，玩家可切换到"原理视图"，看到同一画面的行扫描分解（复用本厅动画资产）。
- **计算机黎明厅（本厅旁）**：EDSAC 的 OXO 用 CRT 显示棋盘、Baby/Williams 管用 CRT 存数据——三处 CRT 共用同一套"电子束"底层动画，**资产可复用**，成本低、认知连贯。
- **联动主线**：一条"电子束"故事线贯穿四台计算机 + 电视厅 + 游戏机厅，作为展厅叙事的暗线。

## (f) 需核实与风险清单

- **需核实**：① 具体制式参数（NTSC 525/60、PAL 625/50）是否在展陈中标注，取决于目标地区；② 阳极高压量级（10–25 kV）的精确展示数字；③ 若复刻实体 CRT 电视，其高压安全、显像管货源与环保处置需专项评估。
- **风险**：① 实体 CRT 电视含高压（数万伏）与真空玻壳，安全与维护成本高——**建议优先用"高仿真屏幕模拟 + 1 台真机静态陈列"**，避免真机长期通电；② 隔行扫描等概念对普通玩家偏难，动画务必做"慢动作 + 暂停"。

## (g) 小结（本厅一页纸结论）

| 维度 | 结论 |
|---|---|
| 可看 | 静态 CRT 电视 + 扫描原理动画（辉光点、光栅、隔行） |
| 可拆 | 显像管/偏转线圈/高压包/信号板 四级装配树，可做分层爆炸图 |
| 可懂 | "扫描=位置、信号=亮暗、同步=对齐"三条主线，配合慢动作动画 |
| 可玩 | 信号注入演示（换台、投摄像头、加雪花干扰）+ 与游戏机厅联动 |
| 技术方案 | 原理动画为主，无需模拟器；可复用 EDSAC/Baby 的电子束动画资产 |
| 主要风险 | 实体机高压安全；隔行概念理解门槛 |
