# DEFECT-RUN-06（实机首验缺陷 · closed）

> 状态：**closed（2026-11-05 修复提交 02dd2d7）** · 修复已入 main
> 复现环境：Godot 4.4 · 用户实机按 F5 · 项目"警告即错误"开启
> 档案补登：本档案由 06 线 debug 专员按 git 提交记录补登（原档欠登）；现象为按修复 diff 与项目已知前科反推，用户原始报屏未存留。

## 现象（表现错误 · 无报错但不对）

滚轮拉远视野时透视畸变明显（鱼眼/拉伸感），FOV 可一路放大到 100；初始视野
依赖相机默认值而非设计值。

## 根因

player.gd 滚轮 FOV 钳制上限为 100.0（`clampf(fov ± 3.0, 20.0, 100.0)`），
广角端透视失真超出博物馆导览观感可接受范围；且 `_ready` 未显式设置初始 fov。

## 修复（提交 02dd2d7 后半）

```gdscript
const FOV_DEFAULT := 70.0
const FOV_MAX := 85.0
# _ready: fov = FOV_DEFAULT
# 滚轮: fov = clampf(fov ∓ 3.0, 20.0, FOV_MAX)
```

默认 70、上限 85，畸变受控。

## 复盘

- 表现类缺陷（无红字）只能靠用户画面描述/照片收单，归类时勿因"没报错"跳过。
- 视角类参数（FOV/速度/高亮色）散落为魔法数字，后续宜聚到 player.gd 顶部常量区
  （本轮已顺手收敛 FOV 两值）。
