## 二、跨线视图误报根因说明（如实）

1. **表面现象**：03 线 243-B/248-A 跑 `catalog_ref_check` 报 `REF-02 完工包 walkman-tpsl2 无目录反链 FAIL 1`。
2. **根因 = 跨线时序差（非"目录未纳入扫描"）**：walkman-tpsl2 是 **05 线新产包**（`05/repo/content/walkman-tpsl2`），
   `content_packages()` 扫到它 → 纳入"完工包"集合；但**05 线家电影音目录的反链回填（250-B）滞后于产包**，
   在回填前跑 catalog_ref，REF-02 把"已产包但无反链"判为缺失。
3. **为何是误报**：walkman-tpsl2 属 05 线家电影音，其反链责任在 05 线（非 03 线）；03 线活跃目录（计算机/通讯）
   REF-02 缺失 0，此 FAIL 1 是跨线时序差，非 03 线目录缺陷。
4. **已闭环**：05 线 250-B 回填 5 条反链后，实测 `catalog_ref_check` **REF-01~04 全 0、FAIL 0**（内容包 46 个 /
   目录 1583 行），误报消除。

## 三、扫描修复口径 + 过渡期降级

### 3.1 修复口径（已达成，无需再改代码）

- `catalog_ref_check.catalog_files()` 已扫描 05 线家电影音目录，字段键英文、`scan_catalog()` 已兼容英文键
  `device_id`（并兜底中文键 `关联包`）。**无需改扫描代码**；反链责任=产包线（05 线），产包线须在产包完成后
  同步回填目录反链，否则 REF-02 判缺失（符合 v0.6.2 §六反链义务）。

### 3.2 过渡期降级口径（跨线时序差窗口）

- **`--no-ref-hard`**：跨线时序差窗口（他线新产包已入库、反链未回填）期间，本线门禁可用
  `verify_all --daily --no-ref-hard` 降级复跑（250-B 已用，实测 53/53 通过、catalog_ref 只提示不硬判 FAIL）。
- **降级窗口约束**：降级只覆盖"他线新产包反链未回填"的时序差，**不得跨轮次**——反链回填后须立即恢复
  `--daily --cache` 硬判（与 `镜像收口口径_v2.md` §三的"降级窗口不得跨轮次"同款红线）。
- **责任归属**：反链回填责任 = 产包线（05 线家电影音、03 线计算机/通讯），catalog_ref 只报告、不改他线文件。
