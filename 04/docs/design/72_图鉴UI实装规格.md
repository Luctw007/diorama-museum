## 1. 数据绑定（图鉴卡片 ← 短卡/研究卡/encyclopedia 字段映射）

| 卡片字段 | 数据源 | 缺失兜底 |
|---|---|---|
| device_id | 包 `meta.json`（目录行 device_id 键） | 无包 → 显示「—」+ 不可进[拆解/运行]入口 |
| 目录 id | 03 线目录（C-xx-000xxx 真实 id；Apple IIe 待 allocate 占位） | 占位 id → 卡片脚注「待分配」 |
| 年代 | 目录 `year`（或短卡首句年代） | 缺失 → 标「年代待补 [需核实]」 |
| 类别 | 目录 `path[0]` 大分类 | 映射配色见 §3 类别色表 |
| 短卡文本 | 短卡卷 60–90 字全文 | 无短卡 → 用 encyclopedia.md 首段前 80 字截断 |
| 百科链接 | `encyclopedia.md` 同包路径（全文/关键参数/术语词典） | 无 → 「百科撰写中」占位态 |
| 反链 | 短卡「来源编号」→ 研究卡路径 + `THIRD_PARTY.md`/`meta.json` 来源登记 | 反链缺 → 卡片显示「来源待登记 [需核实]」 |

- 卡片**只读**：全部字段由 01 线 `catalog_data.gd` 既有函数与包内文件读取，**不新增数据契约**（37 号 §5 一句话接口约定沿用）。

## 2. 交互（展厅点选 → 卡片弹层导航）

| 动作 | 规格 | 出处 |
|---|---|---|
| 打开 | 展厅内点选设备（准星 Point）→ 图鉴卡片从设备旁 0.3 m 弹层（不切场景） | 12 号三原语 Point |
| 卡片导航 | 卡片内分页：[短卡] [百科] [参数] [术语] 四页签；左右方向键或滚轮翻页 | 49 号 §3 键位同族 |
| 回到设备 | 卡片 [回到设备] 按钮 → 关闭卡片，镜头回设备观察态 | — |
| 返回展厅 | Esc 关闭卡片回展厅（不关 Tab 列表面板） | encyclopedia_panel 同 Esc 语义 |
| 互斥 | 卡片打开时 Tab 图鉴列表面板不可开；DevicePicker/其他面板互斥沿用 encyclopedia_panel `_sync_panel_mouse` 模式 | 01 线占位实现现状 |
| 无障碍 | 卡片弹层热区 ≥0.04 m（12 号 §2.4）；Esc 一档一档退出（卡片→展厅） | 12/49 号 |

- 与既有 Tab 面板分工：**Tab 面板 = 全量列表浏览；点选卡片 = 单机详情**。两者共用 CatalogData 与 encyclopedia.md，不重复实现。

## 3. 视觉（卡片布局 + 类别配色 + 占位图兜底）

**卡片布局（720p 基准，2K ×2）**：卡 420×560（居中偏设备侧）；顶条 = 类别色带 6 px + 名称（t-h2 c-text）；中部 = 短卡文本（t-body c-text，自动换行）；底部 = 四页签（t-small）+ 反链行（t-caption c-text-2）。

**类别配色（26 号 token 扩展，分档色）**：

| 类别（path[0]） | 色带 | 语义 |
|---|---|---|
| 计算机（大/小/超级/工作站） | m-blue #2C4A6E | 蓝=算力 |
| 游戏机 | c-accent #FFC859 | 琥珀=客厅娱乐 |
| 手持/通讯（手机/PDA） | c-accent-2 #4FC3F7 | 青=随身 |
| 家电外设（05 线品类） | c-ok #66BB6A | 绿=生活电器 |
| 未定档/占位 | c-dim #6E6C69 | 灰=待定 |

**占位图 vs 实拍图兜底**：有实拍/渲染图 → 顶图 180×120 实图；无 → 白模剪影占位图 + 角标「占位图」（决策记录 #14：封版用白模不加模型——图鉴沿用同口径，不伪造实拍）。

## 4. 验收（每台一张卡的可验收口径）

| 验收项 | 判据 | 达标 |
|---|---|---|
| 数据完整性 | 卡片七字段（§1 表）无空值；空值处均为兜底文案而非空白；反链行可点开研究卡路径 | 第二批 34 台逐台 |
| 交互可达性 | 点选 → 卡片弹层 ≤0.5 s；四页签全部可翻；Esc 关闭；[回到设备] 回观察态 | 同上 |
| 视觉一致 | 类别色带与 §3 色表一致；占位图角标就位；2K 下不糊不裁 | 同上 |
| 互斥 | 卡片与 Tab 面板/DevicePicker 同开 0 次（RUN-08 同模式） | 抽检 ≥5 台 |

- 与 47 号图鉴相关用例（52 号 T-547~T-554）衔接：本规格卡片层为 L2 链「详情卡字段」的实装口径，T-547/T-548 断言按 §1 字段映射回填。
