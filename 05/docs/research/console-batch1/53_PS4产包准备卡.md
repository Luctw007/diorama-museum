## 一、产包字段清单（逐件口径）

| 件 | 字段 | 建议值 | 口径说明 |
|---|---|---|---|
| meta | id | `playstation-4` | 建议命名，待与 02 线目录规范对齐 |
| meta | era | 2013 | 50 号预研卡「2013」，整数无需化 |
| meta | category | `game-console` | 对齐 05 线游戏机谱系 |

| runtime | emulator | `none`（保守） | PS4 BIOS/ROM 红线，无固件时保守 none（静态 + 光盘吸入动画） |
| runtime | media_hint | `cd_rom` | 蓝光介质；**schema media_hint 枚举无 blu_ray，取最接近的 cd_rom**（显式标注） |
| runtime | bios_required | false（保守 none） | 取决于 emulator 取值 |

> 字段清单对齐 `playstation-3`（310-I 完整包体例）；PS4 与 PS3 同属索尼系，区别在于 **7 件拆分（含 hard_drive、controller）、Jaguar CPU** 与 **media_hint 取 cd_rom（蓝光无枚举降级，同 PS3 先例）**。

### components 拆分建议

| component | 名称 | 挂载 | 说明 |
|---|---|---|---|
| jaguar | Jaguar CPU | mainboard | PS4 主 CPU（AMD 八核） |
| gpu | GPU | mainboard | PS4 图形芯片（AMD GCN） |
| ram | 主内存芯片 | mainboard | 8GB GDDR5 主内存 |
| cd_motor | 光盘电机 | blu_ray_drive | 蓝光光驱电机 |

### media_hint 口径说明（蓝光 → cd_rom）

- PS4 使用 **蓝光（Blu-ray）** 介质，schema `media_hint` 枚举无 blu_ray，产包时取最接近的 **`cd_rom`** 代指，并在 THIRD_PARTY 显式标注（对齐 PS3 蓝光降级先例）。

## 二、目录条目方案

- **设备包 id**：`playstation-4`（建议命名，待 02 线目录规范对齐）。

## 三、PS4 BIOS/ROM 红线

- PS4 系统固件与游戏 ROM（蓝光）受版权保护，**不入库、不下载**，产包仅做清单级引用。
- 真跑模拟器（shadPS4）时固件/ROM 由**用户自备**，获取与授权单独走合规流程。
- 若无法合规获取固件，`runtime.emulator` 保守取 `none`（静态 + 光盘吸入动画演示）。
