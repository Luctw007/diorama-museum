## 一、总则

### 1.1 内容包定义

一个「设备内容包」（下称内容包）是对**一台设备**的完整数字化描述，供博物馆引擎加载、装配、标注、动画与模拟。一个内容包 = 一个目录，目录名即 `device-id`，位于 `content/<device-id>/` 之下。内容包由「契约数据」（meta.json/runtime.json/annotations/THIRD_PARTY.md）+「资产数据」（assemblies/meshes/materials/audio）构成。

### 1.2 版本规则

内容包 `meta.version`（SemVer）、`meta.spec_version`（本规范 `"0.2"`）、`meta.engine_min_version`（SemVer）。v0.4 为规范文档版本，不改变 `spec_version` 取值。

### 1.3 度量与坐标系

- **单位**：米（SI），1:1 真实比例；**坐标系**：Y-up 右手系（+X 右、+Y 上、+Z 朝观察者），与 Godot 4 一致。
- **旋转**：单位四元数 `[x,y,z,w]`。DCC（Blender +Z 上）导出 glTF 由导出器自动 +Z→+Y，单位比例 1.0 + Apply Transforms。

### 1.4 glTF 要求

glTF 2.0；米制、Y-up；场景根节点名 = 装配体 `node_id`（R-090），mesh 名 `<node_id>_mesh` 惯例。

## 二、目录结构

```
content/<device-id>/
├── meta.json / runtime.json / THIRD_PARTY.md / README.md
├── assemblies/ 或 meshes/     # 装配体/网格 glTF（R-090）
├── materials/                 # 材质定义（可选）
├── audio/                     # 音频资产（v0.4 起，替代旧 sounds/）
│   ├── bgm/                   # bgm_*.ogg 背景音乐
│   ├── sfx/                   # sfx_*.ogg 效果音 + run_*.ogg 运行声 + amb_*.ogg 环境 bed
│   ├── vo/                    # vo_*.ogg 解说
│   └── SYNTH.md               # 程序化合成配方（有合成件时必填）
└── annotations/annotations.json
```

| 文件/目录 | 必填 | 说明 |
|---|---|---|
| `meta.json`/`runtime.json`/`THIRD_PARTY.md`/`annotations/` | 是 | 契约数据 |
| `assemblies/`、`meshes/` | 否 | 装配体级 / 网格级 glTF，`mesh_ref` 指向哪个以哪个为准 |
| `materials/` | 否 | 材质定义 |
| `audio/bgm`、`audio/sfx`、`audio/vo`、`audio/SYNTH.md` | 否 | 音频资产（三层子目录；命名即路由） |

> **音频资产包落位约定**：音频按类别分目录——`audio/bgm/`（底乐）、`audio/sfx/`（效果音，含设备运行声
> `run_*` 与环境 bed `amb_*`）、`audio/vo/`（解说）。文件名前缀与目录类别一致（A-01 校验）。
> THIRD_PARTY 挂靠：实际入包的外部音频在 `THIRD_PARTY.md` 登记「分档+URL+日期」三件套；
> 程序化合成件在 `audio/SYNTH.md` 记配方；自录件标「原创」。

**路径约定**：资源引用一律相对 `content/<device-id>/` 的 POSIX 路径，禁止绝对路径或 `..` 跳出。

## 十四、音频资产（v0.4 新增）

> 本章为 32-B 草案定稿，吸收 04 线 20_音频工程规格.md 量化参数。适用于 `audio/` 下的全部音频资产。

### 14.1 资产格式

- **母带 WAV**（24bit/48kHz，96kHz 自录母带降采样）→ **交付 OGG Vorbis**（48kHz，q5 效果音 / q6 解说+BGM）。
- 统一采样率 **48 kHz**；不选 MP3（专利/瞬态）、不选 FLAC 交付（体积）。
- **位深**：WAV 24bit；OGG 有损按码率档。

| 场景 | 格式 | 采样率 | 码率/位深 |
|---|---|---|---|
| 自录/委约母带 | WAV | 96/48 kHz | 24 bit |
| 交付·效果音 | OGG | 48 kHz | q5 立体声（点源单声道） |
| 交付·解说 | OGG | 48 kHz | q6 单声道 |
| 交付·BGM/环境 | OGG | 48 kHz | q6/q5 立体声 |

### 14.2 响度分级（LUFS 目标 + dBFS 峰值双层）

| 层级 | 类别 | LUFS | 峰值 dBFS |
|---|---|---|---|
| 前景 | 解说 vo | −16 ±1 | ≤ −3 |
| 交互 | 效果音 sfx | −18 ±1 | ≤ −12（单）/ −6（并发） |
| 底乐 | BGM | −24 ±1 | ≤ −12 |
| 氛围 | 环境 bed amb | −30 ±2 | ≤ −24 |

- **时长上限**：sfx ≤4s（amb 循环 60–120s 例外）；BGM 1'30–2'00 成曲 + 循环点；vo 按台本（语速 180 字/分）。
- **立体声/单声道**：UI/面板/解说/点声源单声道；环境 bed/BGM 立体声。
- **混音优先级**（并发 ≤4 挤最低）：错误/警告 > 确认/提示 > 拆装/交互 > 环境。vo 播时 BGM 闪避 −8 dB。

### 14.3 命名规则

| 类别 | 结构 | 示例 |
|---|---|---|
| BGM | `bgm_<厅>_<序号>` | `bgm_dawn_01`、`bgm_crt_01` |
| 效果音 | `sfx_<设备\|ui>_<动作>` | `sfx_apple_ii_power_on`、`sfx_ui_confirm` |
| 解说 | `vo_<厅>_<站>_<句>` | `vo_dawn_s2_01` |
| 环境 bed | `amb_<厅\|场景>` | `amb_hall`、`amb_crt_room` |
| 设备运行声 | `run_<设备>_<部件>` | `run_apple_ii_fan` |

命名正则（A-01）：`^(bgm|sfx|vo|amb|run)_[a-z0-9_]+$`。

### 14.4 授权与登记（THIRD_PARTY 三件套延伸）

- 四档 + 原创 + 程序化合成；外部音频「分档+URL+日期」三件套；CC-BY 逐条署名。
- 红线：不得 YouTube/B 站翻录商用；不得游戏原声提取；不采用 Pixabay 2019 后条目。
- `audio/SYNTH.md` 记合成配方（波形/基频/时长/包络），升格为规范要求。

### 14.5 校验规则（A-01~04）

### 14.6 与引擎/runtime 的衔接

- 文件名前缀路由到母线（bgm→厅-bgm、vo→厅-narr、amb→厅-bed、sfx→设备/UI、run→设备-run）。

- 设备运行声优先走网关 `audio_chunk` 直通；直通可用时本地合成件静音。
- 距离衰减/母线结构沿用 04 线 20 号 §4.1/4.2（见 32-B 草案）。
