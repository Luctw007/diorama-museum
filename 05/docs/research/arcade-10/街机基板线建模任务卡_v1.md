# 街机基板线建模任务卡 v1（CPS-1 / Sega System 16 起步）

> 任务 305-M（05 线）· 完成日期：2026-11-25。
> 性质：**街机基板线建模任务卡**——为 CPS-1、Sega System 16 两块基板各出一份建模任务卡（节点分解 + 三档 LOD 预算 + 识别件 + 验收清单口径）；**纯文档任务卡，不建模、不产包、不改 jsonl。**
> 口径：沿用低模样板「不贴图、只用 baseColorFactor」，三档 LOD 预算对照 MR-02；街机 ROM/BIOS 红线 FR-E3。

## 一、CPS-1 基板建模任务卡

### 目标
`content/cps1/assemblies/` 下按节点分解建低模 gltf（纯色无贴图、顶点 100-4000），节点名 = node_id。

### 节点分解（5 件）

| # | 部件 | node_id | 草图说明 |
|---|---|---|---|
| 1 | 主板 PCB | mainboard | 绿色 FR-4 基板，承载各芯片 |
| 2 | 主 CPU | cpu | 68000 处理器，DIP 封装 |
| 3 | 图形芯片 | graphics_chip | 图形处理芯片 |
| 4 | 音源模块 | sound_module | 音源处理模块 |
| 5 | ROM 插槽板（可选） | rom_board | ROM 插槽，供卡带/ROM 板插拔识别件 |

### 三档 LOD 三角预算

| 档 | mainboard | cpu | graphics_chip | sound_module | rom_board |
|---|---|---|---|---|---|
| LOD2 远景 | ≤ 60 | ≤ 10 | ≤ 10 | ≤ 10 | ≤ 15 |
| LOD1 观察（默认） | ≤ 400 | ≤ 100 | ≤ 100 | ≤ 100 | ≤ 120 |
| LOD0 特写 | ≤ 3000 | ≤ 800 | ≤ 800 | ≤ 800 | ≤ 900 |

### 识别件
- **rom_board ROM 插拔识别件**：ROM 板可插拔，是街机「换卡不停机」叙事的物理锚点（对齐展签资材 1「换卡不停机」）。

## 三、两块基板验收清单口径

| 项 | 口径 | 规则 |
|---|---|---|
| 节点名 | 根节点名 = node_id | MR-01 / R-090 |
| 三角预算 | LOD1 观察档 ≤ 各件预算，超 1.5 倍 FAIL | MR-02 |
| 贴图 | 低模阶段纯 baseColorFactor、**无贴图** | MR-03（无贴图即合规） |
| 单位与轴 | 米制、Y-up 右手系 | MR-04 |
| 纯色 | baseColorFactor 全 0–1 | 静态验收 |
| 顶点 | 每件 >100 且 <4000 | 静态验收 |

> 基板参数（CPU 型号、主频、分辨率）沿用 `arcade-10/街机10台_参数卡_v1.md`，敏感值一律标 [需核实]；正式建模前按 MAME 源码/基板文档复核。

## 四、街机 ROM/BIOS 红线（FR-E3）

- 街机基板 ROM/BIOS 受版权保护，**不入库、不下载**，仅清单级引用（对齐 `emu-eco/03_街机ROM_BIOS清单级引用.md` 红线 FR-E3）。
- 本任务卡只做低模网格（纯几何、无 ROM 内容），真跑模拟器（MAME cps1/sys16 驱动）时 ROM 由用户自备、走合规流程。
- 不随附任何模拟器二进制、ROM 文件。
