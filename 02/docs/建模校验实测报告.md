## 3. 关键观察

1. **pdp8 / atari-2600 使用 `assemblies/` 目录存放 glTF**（其余包用 `meshes/`）。`model_check.py`
   按 `meta.json` 的 `mesh_ref` 定位文件，天然兼容两种目录，无需特判。
2. **edsac 的 `console.gltf` 节点名已为 `control_subsystem`**（TASK-18A 修复），MR-01 通过。
3. **占位盒三角面为 1 或 12**（单位三角或手写组合体），远低于 LOD1 观察档 20000 上限，
   故 MR-02 全过——正式建模开产后该规则才真正生效（卡超预算）。
4. **无贴图、无扩展**：占位盒阶段 MR-03/MR-04 均 PASS；正式贴图（basecolor/ORM/normal）入库后
   MR-03 的命名/尺寸/2 幂检查才起作用，未知 KHR_* 扩展入库后 MR-04 才起 WARN。
