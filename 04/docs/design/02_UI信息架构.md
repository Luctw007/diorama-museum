## 1. 线框符号约定（全篇通用）

```
┌───────────────┐  · = 可点选目标      ▓ = 主视觉/插画占位
│面板/弹层边界  │  × = 关闭按钮        ▣ = 3D 场景视口
├───────────────┤  [安钮] = 可点按钮    ── = 分隔线
│ 信息文本      │  (灰)  = 置灰不可用    ▲/▼ = 展开/收起
└───────────────┘
```

平台差异呈现说明统一用「桌面：」「VR：」小段标注；三态 = 正常态 / 空态 / 异常态。

## 2. 界面总览与层级

全局 UI 分三层：**HUD 常驻层**（顶部状态条：当前展厅、就绪徽标、图鉴入口、设置入口）→ **场景层**（3D 展厅 + 设备）→ **浮层**（导览卡/原理浮层等，一次最多 2 层，规则：导览卡与原理浮层可同屏，拆解面板与运行 HUD 可与导览卡同屏；弹层互斥）。桌面为「屏幕分区」呈现（场景左、浮层右）；VR 为「空间面板」呈现（面板悬浮于场景内，可 Grab 拉近/推开）。

## 3. 界面 1：主大厅（展厅选择 + 图鉴入口）

**用途**：玩家入场后的空间门户；选择要进入的展厅，或转入图鉴浏览。

**对应 FR**：FR-A（展厅选择/主大厅域）[推断·待核]。

**信息层次**：
1. 标题区：展馆名「箱庭电子博物馆」+ 副标题。
2. 主区：展厅卡列表（横向滚动）。每卡含：展厅名（如「Apple II 展厅」）、主设备缩略、状态徽标（可运行/可拆解/施工中）。
3. 辅助区：右侧竖排入口——图鉴、设置、离开。
4. 动作按钮：卡片点选即进入展厅；「图鉴」入口按钮。

```
┌────────────────────────────────────────────────────────┐
│ 箱庭电子博物馆                     ·图鉴  ·设置  ·离开   │
├────────────────────────────────────────────────────────┤
│                                                        │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐            │
│   │★★★★★★★│  │          │  │ 施工中   │            │
│   │ Apple II │  │ PDP-8    │  │  · · ·   │            │
│   │ [可运行] │  │ [可拆解] │  │ [未开放] │            │
│   └──────────┘  └──────────┘  └──────────┘            │
│                                                        │
│   [进入展厅]（随选中卡亮起；无选中时置灰）              │
└────────────────────────────────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 已安装内容包的展厅卡全部亮起；当前默认选中第一张卡 |
| 空态 | 无任何已安装内容包：主区显示一条引导信息「还没有可参观的展厅。请在内容管理中导入内容包」（入口→设置），导入按钮为主视觉 |
| 异常态 | 某厅内容包版本低于引擎最低版本：该卡显示黄色「需更新」徽标 + 点击弹「内容包版本不符」弹层（见 §12 界面 10） |

**桌面/VR 差异**：桌面=满屏网格布局（3 列 [TBD/建议值]）；VR=卡片立板悬浮于大厅空间，Point 可选中，Grab 可翻页（左右拨动）。

## 4. 界面 2：图鉴（筛选 + 条目状态）

**用途**：脱离展厅浏览全部设备条目，按年代/类别/厂商筛选，了解收藏进度。

**对应 FR**：FR（图鉴域）[推断·待核，条目态对应 FR-F 内容包安装状态]。

**信息层次**：
1. 标题区：图鉴标题 + 已收集计数（x / 总数）。
2. 筛选区：年代（十年档下拉）、类别（handheld/console/computer…取自 content meta.category）、厂商（取自来源数据 [TBD]）、重置。
3. 主区：条目网格（缩略 + 名称 + 条目态徽标）。
4. 辅助区：右下「从图鉴进入对应展厅」按钮（仅当设备在已开放展厅）。

条目态五级：**可玩**（就绪可运行）/ **可拆可懂**（有内容包可拆解+原理）/ **静态**（仅展示模型）/ **未安装**（图鉴条目存在本地目录但无内容包，置灰+「安装指引」）/ **置灰不可用**（版本不兼容、损坏——点击弹异常弹层）。

```

│ 图鉴（3/12）                            [×] 关闭        │
├────────────────────────────────────────────────────────┤
│ 筛选： 年代[1970s ▾]  类别[computer ▾]  厂商[Apple ▾]   │
│        [重置筛选]                                      │
├────────────────────────────────────────────────────────┤
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐      │
│  │ Apple II │ │ PDP-8   │ │ (灰)    │ │ (灰)    │      │
│  │ [可玩]   │ │[可拆可懂]│ │[未安装] │ │[版本不符]│      │
│  └─────────┘ └─────────┘ └─────────┘ └─────────┘      │
│                              [从图鉴进入展厅]           │
└────────────────────────────────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 有条目显示条目；无条目的筛选结果见空态 |
| 空态 | 筛选无结果：「没有符合条件的设备。试试重置筛选。」+ 重置按钮；全库为空：「图鉴还是空的。导入内容包后即可在此检索。」 |
| 异常态 | 条目数据损坏/版本不符：该条目置灰+警示角标，点击弹异常弹层（§12） |

**桌面/VR 差异**：桌面=全屏面板+鼠标滚轮滚动；VR=面前大面板（2 m × 1.2 m 阅读面 [TBD/建议值]），Point 点选、Grab 边缘拖动翻页，手柄滚轮语义映射为摇杆上下。

## 5. 界面 3：导览卡（FR-C1）

**用途**：设备旁的说明面板，回答「这是什么、何时、谁造的、能怎么玩」。

**信息层次**：
1. 标题区：设备名（中文 + 英文名）+ 状态徽标（可运行/可拆解/就绪中）。
2. 摘要区：一句话定位（类别、年代、厂商），不超 2 行。
3. 详情区（默认收起）：分段——「设备故事」（description）、「规格要点」（规格表，字段来自内容包 meta：类别/年代/精度分级等）[TBD 具体字段]、「运行提示」（media_hint 等）、「来源」（sources 脚注位：标题 + 链接 + 许可档）。
4. 动作区：[详情/收起] 切换、[打开原理]（跳原理浮层）、[拆解] / [运行] 快捷入口。

```
┌──────────────────────────────┐
│ Apple II        [可运行]  ×  │
│ Apple //e (EN)               │
├──────────────────────────────┤
│ 1977 年 Apple 推出的 8 位     │
│ 个人计算机。分类：computer    │
│                              │
│ ▼ 详情                       │
│  · 设备故事：……（description）│
│  · 规格要点：表               │
│  · 来源：[来源: URL] (许可档) │
│                              │
│ [详情/收起] [打开原理]        │
│ [拆解]  [运行]                │
└──────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 内容包数据齐全：如上 |
| 空态 | 内容包缺 description/来源：对应分段落显示「（该设备暂无此项介绍）」；整卡无数据则仅显示名称+「该设备介绍资料缺失」 |
| 异常态 | 内容包解析失败：显示「介绍加载失败」+ [重试]；版本不符：徽标位显示黄色「需更新」 |

**桌面/VR 差异**：桌面=右侧浮窗 380 px 宽 [TBD/建议值]；VR=立在设备旁的实体「立牌」面板，随玩家走动保持面向玩家（仅绕 Y 轴），1 m 内自动放大到可读尺寸。

## 6. 界面 4：原理浮层（FR-C2 装配体 / FR-C3 元器件）

**用途**：选中某装配体（C2）或元器件（C3）后，展示「它在整机中起什么作用」+「信号如何流动」。

**信息层次**：
1. 标题区：对象名（装配体/元器件名）+ 所属层级面包屑（整机 › 主板 › 中央处理器）。
2. 主区（示意图占位）：左 2/3 为 3D 高亮视口——选中对象发光（琥珀描边），关联框图高亮，其余半透明；C3 额外在视口上叠加「信号流箭头」（flow 标注的起点→路径→终点动画）。
3. 文本区：role 标注正文（20–200 字，来自内容包 annotations）；flow 标注（若有）以「起点 → 途经 → 终点」小字呈现。
4. 辅助区：「相关元器件」横排缩略（C2 时列出其下 components）；来源脚注位（sources URL + 许可档）。
5. 动作区：[上一个/下一个标注]、[关闭]。

```
┌──────────────────────────────────────────────┐
│ ·中央处理器      整机 › 主板 › 中央处理器   × │
├──────────────────────────────────────────────┤
│ ┌────────────────────────────┐  ┌─────────┐ │
│ │ ▣ 3D 高亮视口（琥珀描边）  │  │ 文本区  │ │
│ │   信号流箭头：盘点→执行→…  │  │ role 正文│ │
│ │   （flow 动画）            │  │ ……(200字)│ │
│ └────────────────────────────┘  │ flow 小字│ │
│ 相关元器件：[处理器][内存][…]   │ 来源脚注 │ │
│ [上一个标注] [下一个标注] [关闭] └─────────┘ │
└──────────────────────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 标注齐全：如上 |
| 空态 | 该对象无任何标注（内容包未给 role/flow）：文本区显示「暂无该部件的说明」；示意图仍可用（标注缺失不影响高亮） |
| 异常态 | 标注文本加载失败/超长溢出：显示「说明加载失败 [重试]」；sources URL 非法：不显示链接仅显示来源标题 |

**桌面/VR 差异**：桌面=右 1/3 浮层 + 场景内同步高亮；VR=悬浮于设备上方的「讲解板」，讲解板与高亮对象间画一条发光细线连线（防迷失），讲解板可 Grab 拉到任意位置。

## 7. 界面 5：拆解面板（FR-D3）

**用途**：拆解状态下的总控——零件清单、层级分离、复原、剖切/透视。

**信息层次**：
1. 标题区：拆解面板 + 当前拆解数（已拆 n / 总件 m）+ 关闭（挡板不改变拆解状态）。
2. 零件清单区：装配树列表（缩进层级），每行=对象名 + 状态点（● 在位 / ○ 散件 / ◐ 部分在位）；行点击=原理浮层（C2/C3）。
3. 层级滑杆区：0–100%「分层展开度」滑杆——拉动使各装配层按百分比偏移分离（爆炸图），拖动即时生效，松手保留。
4. 开关区：[剖切]（切面显示，切面法向可选三轴）/ [透视]（外壳半透明）——互斥二选一，可同时关闭。
5. 动作区：[一键复原]（主按钮，醒目）+ [提示连接线开/关]。

```
┌──────────────────────────────┐
│ 拆解面板  已拆 3/14        × │
├──────────────────────────────┤
│ 整机                         │
│   ● 上盖（开）               │
│   主板                        │
│     ○ 中央处理器            │
│     ◐ 内存芯片（1/8 拆）     │
│     ● 电源                    │
│  ……更多（滚动）              │
├──────────────────────────────┤
│ 分层展开度 [━━━━●━━━━━] 60%  │
│ [剖切 ●/○] [透视 ●/○] [连线 ○]│
│ [      一键复原      ]        │
└──────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 已拆 ≥1 件：如上 |
| 空态 | 拆解中但清单加载失败：清单区显示「零件清单加载失败 [重试]」；0 件已拆（开盖后即拆 0 件）：面板可开、复原按钮置灰并标注「尚未拆下任何零件」 |
| 异常态 | 装配树数据错误（悬空引用，即校验 R-014 类问题）：该行显示「零件数据异常」+ 跳过；整体不可用则提示返回完整态 |

**桌面/VR 差异**：桌面=左侧竖面板 320 px [TBD/建议值]；VR=设备右侧的「工作台面板」，滑杆用摇杆上下拨 OK + 手上 Grab 拉动，按钮均满足 0.04 m 热区。

## 8. 界面 6：运行向导（FR-E3）

**用途**：把「未就绪」变为「就绪」的分步向导（选择介质 → 合法获取渠道说明 → 定位文件 → 就绪确认）。

**步骤流**（与 01 章 §5.2 一致）：

```
①选择介质 ─▶ ②获取渠道说明 ─▶ ③定位文件 ─▶ ④就绪确认
   (media_hint 若 bios_required 则出现      (校验+列表)
    枚举选择)   该步，否则跳过)
```

**各步信息层次**：

- ① 选择介质：标题「要让 Apple II 运行什么？」；选项卡 = media_hint 枚举（无介质/卡带/磁盘/固件/磁带/光盘/软盘）+ 说明文字；[下一步]（未选置灰）。
- ② 合法获取渠道说明：仅 bios_required=true 或介质受版权保护时出现。标题「获取 ROM 的合法途径」；正文列出官方/授权渠道说明与 bios_guide_url 展示；「我已持有合法文件」复选框 + [上一步][下一步]。
- ③ 定位文件：预留文件位（拖放/浏览）；文件类型过滤（按 media_hint）；[浏览本地文件]；校验失败：红字注明原因 + [重试]。
- ④ 就绪确认：回显设备名、介质、来源标注（「本地文件」）、BIOS 状态；[完成并返回展厅] / [上一步]。

```
┌────────────────────────────────────────────┐
│ 运行向导（2/4）  获取 ROM 的合法途径     × │
├────────────────────────────────────────────┤
│ 可运行 Apple II 需要系统 ROM 文件。      │
│ 合法获取渠道：                           │
│  · 渠道说明一（官方/授权来源）            │
│  · 渠道说明二（bios_guide_url 展示）      │
│  [■] 我已持有合法获得的文件               │
│         [上一步]        [下一步]          │
└────────────────────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 步骤完整如上 |
| 空态 | media_hint 无枚举值（内容包未声明）：向导提示「该设备未声明可运行介质，无法继续」+ [返回展厅] |
| 异常态 | 文件校验失败：红字「文件校验未通过，请确认所选文件」+ [重试]；模拟器引擎缺失：向导第一步页面插入红条「未检测到模拟器引擎 AppleWin [TBD 引擎名]，请先在设置中安装」+ [去安装] |

**桌面/VR 差异**：桌面=居中模态窗口；VR=实体「桌面台」上方悬浮面板，文件选择在 VR 为「虚拟文件架」（展示系统扫描到的候选文件卡），桌面为系统文件对话框。

## 9. 界面 7a：运行 HUD（FR-E6）

**用途**：运行中状态下的常驻工具条：输入映射提示、快照、退出确认。

**信息层次**（横条，位于屏幕/视场下缘）：
1. 状态区（左）：就绪徽标 ●（绿=运行正常，黄=降级，红=异常）+ 当前介质名 + 模拟器负载（百分比/热度过高提示）。
2. 输入映射区（中）：当前设备核心键提示（键盘映射图入口，点击放大为 7b）。桌面显示「键盘：F2 开机 · F1 复位 [映射图]」；VR 显示「手柄键 = Apple II 键盘键 提示条 [映射图]」。
3. 动作区（右）：[快照]（单键，快门声即时反馈）、[退出确认]（二次确认弹层：┌确定退出运行？[取消][退出]┐）。

```
┌────────────────────────────────────────────────────────┐
│ ●运行中 · 软盘《demo.dsk》· 模拟器 60fps         │
│ 键盘映射提示…[映射图]        [快照]  [退出确认]      │
└────────────────────────────────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 如上 |
| 空态 | 无已保存快照时，[快照] 正常可用（与列表空态无关——列表空态见 §11） |
| 异常态 | 模拟器掉帧/过热：黄徽标+「性能不足，可在设置中降低画质分级」；模拟器无响应 3 s：红色脉冲「模拟器无响应」+ [强制退出] |

**桌面/VR 差异**：桌面=屏幕下缘固定条（不遮设备输出画面，画面在其上方独立窗口/投影屏）；VR=腕部可翻出的小面板（左手腕内侧按钮翻出，避免遮挡视线）+ 设备旁实体屏常显状态灯。

## 13. 界面 10：异常弹层

**用途**：全局错误统一容器。三类内容：模拟器崩溃（FR-E8）、模拟器/面板失联、内容包版本不符（FR-F2）。每类均含：错误图标 + 标题 + 原因一行 + 可选动作 + [关闭/返回]。

| 类型 | 标题 | 正文要点 | 动作 |
|---|---|---|---|
| 模拟器崩溃 E8 | 「模拟器异常退出」 | 最后画面已冻结；最近快照时间；建议重试或查看日志 | [重试][查看日志][返回展厅] |
| 失联 | 「与设备运行面板失去连接」 | 网络/进程失联判定（等待重连 10 s [TBD]） | [等待重连][返回展厅] |
| 版本不符 F2 | 「内容包版本不符」 | 包版本 vs 引擎最低版本数值；说明升级方式 | [了解更新][仍要打开(仅查看)][关闭] |

```
┌────────────────────────────────────────────┐
│ ⚠ 模拟器异常退出                        × │
├────────────────────────────────────────────┤
│ 最后画面已冻结。最近快照：2026-10-31 21:04 │
│ 连续失败次数：2/3（第 3 次将建议降级配置）  │
│                                            │
│   [重试]   [查看日志]   [返回展厅]          │
└────────────────────────────────────────────┘
```

| 态 | 内容 |
|---|---|
| 正常态 | 以当前异常填充如上（本界面无「无异常」驻留形态） |
| 空态 | 日志为空时的「查看日志」：日志查看器中显示「暂无日志输出」 |
| 异常态 | 弹层本身加载失败（日志模块不可用）：降级为仅含 [返回展厅] 的最小弹层 |

**桌面/VR 差异**：桌面=居中模态；VR=悬浮在设备前方的警示牌（黄色外框），随运行区位置出现，不随头动。

## 14. 文案基调规范（通用词汇表）

与设计文档 §3.2 意向对齐；以下为本任务确定的 UI 通用词汇（全篇唯一写法，禁同义替换）：

| 词 | 唯一写法与用义 | 禁用写法 |
|---|---|---|
| 复原 | 把拆下的零件放回整机 | 恢复/归位/重装 |
| 一键复原 | 拆解面板主按钮 | 全部复原/自动复原 |
| 开机 / 关机 | 运行开始/结束 | 启动/关闭设备/电源开关 |
| 复位 | 模拟器 reset 键 | 重启 |
| 快照 | 运行态保存 | 存档/截图/存档点 |
| 拆解 / 回装 | 零件取下/放回 | 拆卸/拆开/安装 |
| 开盖 / 关盖 | 上盖掀开/合上 | 开壳/开箱 |
| 导览卡 | 设备说明面板（C1） | 说明卡/信息牌 |
| 原理浮层 | 装配体/元器件说明（C2/C3） | 讲解框/说明弹窗 |
| 图鉴 | 全馆设备目录 | 百科/收藏 |
| 就绪 / 未就绪 | 运行就绪流状态 | 可用/不可用 |
| 介质 | 运行载体（软盘等）；任务书 E3 原文作「媒体」，本规范统一为「介质」 | 媒体/卡带文件 |
| 内容包 | 设备数字化描述包 | 设备包/模组/插件 |
| 展厅 | 单设备展室 | 房间/关卡 |

句式要求：按钮 ≤ 6 字；提示句禁止感叹号连用；错误信息先给「发生了什么」再给「可做什么」。所有错误文案不得出现未定标记（同内容包规范 R-060）。
