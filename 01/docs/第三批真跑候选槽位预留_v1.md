## 二、预留口径裁决

1. **backend_type 统一建议 `dedicated`**：四台均非既有家族枚举（native/mame/simh/stella/mesen/mobile）；
   实装时经 manifest 显式 `module`（后端骨架转正体例，对齐第二批 SIMH 先例）绕过家族映射，
   无需提前扩展 BACKEND_TYPE_MODULE。
2. **本任务不建 manifest 预留**（任务书两可，选「仅登记方案」）：预留 manifest（module=null）会出现在
   `slot_loader --list`，无后端却可见易误导；待产包定案（03 线过闸）后按第二批先例一步建 manifest 转正。
3. **许可隔离**：四台全部「二进制不进仓」；QPL（hercules）与 GPLv2（openmsx/86Box）分条款记录，
   mini-vmac 许可版本未定——README 登记表标注 [需核实]，不预写许可结论。
4. **ALIASES**：若 03 线 runtime 语义名写 `hercules`/`openmsx`/`mini-vmac`/`86Box`，实装时在
   slot_loader.ALIASES 补归一映射（同 simh-altair8800 先例），本任务不动 slot_loader 代码。
