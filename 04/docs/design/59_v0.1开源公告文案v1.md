## 1. 公告正文

**一句话定位**：箱庭电子博物馆——一座把电子计算史的 1484 台机器，装进可走、可看、可拆、可上手运行的开源数字博物馆。

**当前可跑什么（实机事实，截至 2026-11-06）**：你能在馆内自由行走、环视，看到按黎明厅动线摆放的四台白模设备与正常工作的光照与 HUD；点选对准的修复（RUN-07）已完成待最终确认。目录数据库已有 1484 条设备条目在库，全馆规格与四厅台本、81 条导览用例齐备。

**已知未闭环项（已登记缺陷，不隐瞒）**：按 v0.1 封版清单 16 项实机对照（绿 1/黄 3/红 12/灰 0）——拆解体验未实机验证；三台真机运行（MAME Apple II / SIMH PDP-8 / Stella 2600）尚未装二进制跑通；图鉴 UI 尚未实装。以上均为「已登记缺陷」，对应修复与解锁路径在其缺陷台账中逐条可见。

**路线图**：v0.1 = 黎明厅实机流程 + 三台真跑 + 图鉴可用（进行中）；v0.2 = 开源准备（许可台账复核、贡献指南、路线图正式化）。

**如何参与**：仓库即文档——先读《内容包与目录规范》与设计文档库，能跑 verify_all 全绿、会写内容包、会挑史实毛病的人，都欢迎。
