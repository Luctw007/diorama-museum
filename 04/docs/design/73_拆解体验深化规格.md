## 1. 拆解层级（assemblies 装配体 → 拆解层映射）

**层级模型（与 02 线装配体/gltf 契约对齐）**：

| 层 | 语义 | 映射 | 32 号对齐 |
|---|---|---|---|
| L0 | 整机观察态 | 整包根节点（完整 mesh） | 32 号 §1.1 L0 |
| L1 | 部件层 | 每件 assemblies/*.gltf = 一个可拆部件（6 件组） | 32 号 §1.1 L1（整机爆炸） |
| L2 | 子件层 | 部件内 gltf 网格节点（node_id 对应 MESHES.md 名录） | 32 号 §1.2 L2（子树） |
| L3 | 代表元件 | 子件中带 role 标注的节点（≤3/部件） | 32 号 §1.1 L3 |

- 装配体件数规则：大型机柜/小型机 6 件组为基线；游戏机/手持包按其 assemblies 实际件数（以仓库为准，不虚拟 6 件）；无 assemblies 的包 → 拆解入口显示「该设备拆解待产」（占位，不崩）。
- 与 gltf 契约对齐：R-090「网格节点名与 node_id 对应」即 L2 子件的标识来源；MESHES.md 为 L2/L3 名录，标注不动。

## 2. 交互（点选进入 / 开盖 / 拆解 / 复原 / 滑杆 / 零件清单）

| 交互 | 规格 | 出处 |
|---|---|---|
| 进入拆解 | 观察态点选设备 → [拆解] 动作（或 explode_panel 现有入口）→ 进拆解视图 | 32 号 L0→L1 |
| 开盖/合盖 | 有盖机型（如机柜门）：L0 态 [开盖] 先行，盖开到 ≥60% 才可 L1 爆炸 | 32 号 §3 开盖语义 |
| 拆解（爆炸） | 拆解键 → L1 整机爆炸（offset_i = v×depth×0.16，沿各自法向） | 32 号 §5 G1 公式（0.12→0.16 为本规格建议值，标 [需实机核对]） |
| 子树展开 | L1 态双击某部件 → L2 子树爆炸（0.9–1.2 s 运镜） | 32 号 §1.2 |
| 代表元件 | L2 态点选带 role 节点 → L3 高亮（≤3/部件）+ role 文案浮动 | 32 号 §1.1 L3/§5 G5 |
| 滑杆展开系数 | explode_panel 内滑杆控制展开系数 0~1（0=观察态、1=全爆）；滚轮步进 0.05 | 29 号 §4 滑块语义 + 57 号滚轮步进口径 |
| 零件清单勾选脱离 | 拆解视图右栏零件清单：勾选某部件 → 该部件单独脱离整体（v×depth 另置）+ 可回插 | 32 号「零件归位」族交互 |
| 复原 | 复原键 → 逐层逆放（L3→L2→L1→L0）；Esc 层叠返回一层 | 32 号 §3.1/§3.3 |
| 状态保持 | 拆解进度/选中/相机存档于设备状态；回观察态再进恢复 | 32 号 §3.3（T-560 同源） |

- L1-only 替代路径（44 号 B2）：若 L2/L3 未达验收，先上线 L0/L1 两级 + 「制作中」提示，L2 子树转 v0.2——本规格层级表不因替代路径删减。

## 3. 视觉（多形态设备拆解动线差异化）

| 形态 | 代表 | 拆解动线 | 差异化要点 |
|---|---|---|---|
| 大型机柜 | UNIVAC I/CDC 6600/Cray-1/System/370 | 机柜门 → 柜内立板（竖排爆炸） | L1 爆炸沿**竖直**展开（机柜高 > 深）；柜门独立开盖判定 |
| 小型机 | Data General Nova/HP 2100 | 前面板 → 机箱内 6 件（横排爆炸） | 6 件组基线；前面板先脱离（拨键/灯组是教学焦点） |
| 游戏机 | 2600/FC/MD/MVS 等 | 上盖 → 主板/卡带槽（俯视爆炸） | 卡带槽独立件；爆炸半径收紧（机箱小） |
| 手持 | 手机/PDA（3310/Palm 等） | 背壳 → 屏幕/键盘/主板（薄层爆炸） | 层厚薄 → 法向位移减小为 ×0.5；零件清单以层命名 |

- 共性：爆炸动画 0.9–1.2 s；选中件 c-accent #FFC859 描边 + 15% 提亮（26 号选中反馈）；L3 高亮件 m-stamp #A63A2B 描边（区别选中态）；白模阶段一律白模剪影（决策记录 #14 口径）。

## 4. 验收（每台可拆解口径）

| 验收项 | 判据 | 达标 |
|---|---|---|
| 装配体层可达 | 每台可拆到 L1 全部 assemblies 件（件数 = 该包实际 assemblies 数）；L2 子件与 MESHES.md 名录一致 | 第二批有 assemblies 的包逐台 |
| role 可达 | L3 代表元件 role 标注可显示、件数 ≤3/部件 | 同上 |
| 复原可达 | 任意深度复原一次成功回观察态；Esc 层叠返回每档正确 | 同上 |
| 交互流畅 | 滑杆 0~1 全程无穿透（白模阶段允许占位视觉）；勾选脱离/回插各一次成功 | 同上 |
| 无 assemblies 包 | 拆解入口显示「待产」占位不崩 | 全量走查 |

- 与 47 号拆解用例（58 号 T-555~T-566）衔接：本规格为 T-555~T-560（L 级）与 T-561~T-566（G1~G7）的实装口径；L1-only 替代路径对 T-559。
