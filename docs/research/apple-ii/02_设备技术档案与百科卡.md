## 1. 历史背景

### 1.1 地位一句话
Apple II（1977）是**第一台成功的、面向普通消费者的大规模量产个人电脑**之一，与 Commodore PET 2001、TRS-80 Model I 并称 Byte 杂志命名的"1977 三巨头（Trinity）" [S01]。它把彩色图形、集成键盘、内置 BASIC、开关电源与开放扩展槽装进同一个塑料机箱，让个人电脑从"组装套件"变成"开箱即用的家用电器"。

### 1.2 关键人物与分工
- **Steve Wozniak**：主电路设计（含 1.023 MHz 视频时钟方案、8 芯片软驱控制器的思路雏形）[S01][S06]。
- **Jerry Manock**：泡沫成型塑料机箱设计（借鉴厨电的平滑外壳）[S01]。
- **Rod Holt**：开关电源（switching power supply）设计 [S01]。
- **Howard Cantin**：印制电路板布局 [S01]。
- **Steve Jobs**：不参与电路设计，主导产品定位（面向家庭/消费者的"整机家电"）与发布 [S01]。

### 1.3 时间线
| 时间 | 事件 | 来源 |
|---|---|---|
| 1976 | 立项；Apple I 后续机型 | S01 |
| 1977-04 | West Coast Computer Faire 首展（Jobs & Wozniak 发布） | S01/S05 |

### 1.4 版本差异与垂直切片选定【建议 + TBD】
| 机型 | 年份 | 关键差异 | 备注 |
|---|---|---|---|
| **Apple II（原版）** | 1977 | Integer BASIC 在 ROM；6502；4–48 KB 内存 | 最 icon、§2.1 所指"Apple II（1977）" |
| Apple II Plus | 1979 | ROM 换成 Applesoft BASIC（微软授权）；Autostart ROM 支持自动启动卡 | 硬件与原版几乎一致（仅 ROM） |
| Apple IIe | 1983 | 65C02/6502；IOU+MMU 两枚定制芯片；64 KB 板载；80 列、双高清 | 最流行、寿命最长 |
| Apple IIc | 1984 | 集成化便携"比萨盒" | — |
| Apple IIGS | 1986 | 65C816 16 位；Ensoniq 音源 | — |

**建议**：垂直切片选定 **Apple II（1977 原版）** 作为物理展示对象。理由：
1. 与设计文档 §2.1 的"Apple II（1977）"一致，icon 性最强；
2. 原版 II 与 II Plus 物理外壳/主板几乎相同，一台 3D 模型可同时覆盖两个 ROM 变体的运行档；
3. 模拟器（AppleWin / MAME）对 `apple2`（Integer BASIC）与 `apple2p`（Applesoft）均有成熟支持 [S07][S09]。

**运行档建议**：物理模型用 1977 原版；运行时 ROM 选 `apple2`（Integer BASIC）为主、`apple2p`（Applesoft）为备选，最终 **`[TBD]` 由作者拍板**（详见 05 章）。

## 3. 工作原理（供 FR-C 原理展示）

### 3.1 系统框图（ASCII）

```
                        ┌───────────────────────────────────────────────┐
  键盘(52键) ──────►    │                    主板 (Main Board)             │
                        │                                                │
  游戏接口(摇杆)──►      │   ┌───────────┐    16-bit 地址总线              │
                        │   │   6502    │◄───────────────────────────────┤
  磁带 I/O ◄──────────► │   │  (1.023M) │                                │
                        │   └─────┬─────┘    8-bit 数据总线               │
  扩展槽 0–7 ◄────────► │         │                                      │
  (Language Card /      │   ┌─────▼─────┐   ┌───────────┐  ┌──────────┐  │
   Disk II 控制器等)     │   │  RAM 阵列  │   │  ROM 区    │  │ 视频电路  │──► NTSC 复合视频
                        │   │(4–48 KB)  │   │ (12 KB)   │  │ +字符发生器│    (电视/监视器)
                        │   └───────────┘   └───────────┘  └──────────┘  │
                        │        时钟: 14.318 MHz 晶振 ÷ 14              │
                        └───────────────────────────────────────────────┘
                                       ▲
                                  喇叭(1-bit, $C030)
```

### 3.2 数据流（FR-C 的"信号流动画"素材）

1. **开机自检/复位**：上电 → 6502 从复位向量（$FFFC/$FFFD）取 Monitor 入口 → 进入 ROM Monitor（`]` 提示符）或 Autostart ROM 扫描槽位固件 [S02][S12]。
2. **键盘输入**：按键 → 键盘编码器 → 数据总线 → 6502 经键盘 I/O 读入 → 存入 RAM [S03]。
3. **显示输出**：6502/视频电路按 1.023 MHz 逐行读显存 → 字符发生器（文本）或位图（低清/高清）→ 合成 NTSC 复合信号 → RCA 输出 [S08][S03]。
4. **声音**：CPU 写地址 $C030 翻转喇叭电平 → 8 Ω 扬声器发声 [S12]。
5. **磁盘读写**（选配 Disk II）：6502 → Disk II 控制器卡（Slot 6）→ 5.25" 软驱，按 16 扇区读写 140 KB [S06]。
6. **扩展槽**：CPU 通过 50-pin 槽位总线访问外设卡（内存、串口、磁盘等）[S12]。

| 子系统 | 职能（一句话草稿） | 来源 |

## 4. 百科卡全文（C1 成品文案）

### 4.1 标题区

**Apple II**（样式 `apple ][`）
1977 年 · Apple Computer, Inc.（美国）
个人计算机 · 8 位

### 4.2 正文文案

Apple II 是苹果公司第一台面向普通家庭与学校的大规模量产个人电脑，1977 年 4 月在首届西岸计算机展（West Coast Computer Faire）上由史蒂夫·乔布斯与史蒂夫·沃兹尼亚克发布。沃兹尼亚克设计了它的电路，把彩色图形、集成键盘、内置 BASIC、开关电源和八个开放扩展槽，全部装进一个由杰里·马诺克设计的、像厨房电器一样圆润的塑料机箱里——这让个人电脑第一次成为"开箱即用"的家用电器，而不再是工程师的组装套件。

它与康懋达 PET 2001、TRS-80 Model I 一起，被 Byte 杂志称为"1977 三巨头"。凭借能显示彩色画面的能力，苹果还因此把公司标志重新设计成了彩虹色。1978 年的 Disk II 软驱和 1979 年的 VisiCalc 电子表格，让 Apple II 在商业与教育市场大获成功，成为个人电脑史上最具影响力的机器之一。

（文案依据 S01/S05/S06；发布前由人工审查核准。）
