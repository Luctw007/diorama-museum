## (a) 概述与历史地位

EDVAC（Electronic Discrete Variable Automatic Computer，离散变量自动电子计算机）是继 ENIAC 之后由宾夕法尼亚大学摩尔学院为美国陆军弹道研究实验室（BRL）研制的第二台大型电子计算机，1944 年 8 月即提出建造计划，在 ENIAC 尚在建造时便已启动设计 [S23]。其设计者与 ENIAC 相同——John Mauchly 与 J. Presper Eckert [S23]。

EDVAC 在计算史上的核心地位，不是"第一台"，而是**"第一种架构"**：它是把"程序与数据同存于可写内存"这一思想落实为正式设计方案的机器。1945 年 6 月 30 日，作为摩尔学院技术顾问的约翰·冯·诺依曼撰写了一份 101 页的《EDVAC 报告初稿》（First Draft of a Report on the EDVAC），系统描述了这台机器的逻辑设计：以**二进制**运算、**串行**处理、把**指令当作可存取的数据**存于内存、由五大部分（运算器、控制器、存储器、输入、输出）组成 [S26][S23]。这份报告被广泛传抄，成为此后几乎所有计算机的蓝图，也就是今天所说的"冯·诺依曼架构" [S26]。

其历史地位可概括为 [S23][S26][S02]：

1. **架构奠基**：EDVAC 是"EDVAC 式/冯·诺依曼式"机器的原型，直接影响了 EDSAC、Manchester Baby、IAS 机及其众多仿制机。
2. **作者权争议**：《EDVAC 报告初稿》由冯·诺依曼署名，但其思想很大程度上源于 Eckert 与 Mauchly 的 ENIAC 后续设计工作；报告未充分署名 EDVAC 全体贡献者，成为 ENIAC/EDVAC 专利纠纷的重要导火索之一 [S22][S23]（此争议在 1973 年 Honeywell 诉 Sperry Rand 案与多份口述史中均有记载 [S02]）。
3. **"第一"的辩证**：公众常把"第一台现代通用计算机"归给 EDVAC，但它**并非第一台真正运行的存储程序机**——那项纪录通常归属 1948 年的 Manchester Baby（或按 Haigh 等人的新观点上溯至 1948 年改造后的 ENIAC）[S02][S25]。EDVAC 因人才流失与专利纠纷严重延误，1949 年交付后直到 1951 年才开始有限运行 [S23]。

EDVAC 于 1949 年 8 月交付弹道研究实验室，1951 年开始运行；此后历经升级（1953 打孔卡 I/O、1954 磁鼓、1958 浮点单元），直到 1961 年被 BRLESC 取代 [S23]。

## (c) 工作原理

### 系统框图（ASCII）

```
                        ┌─────────────────────────────────────┐
                        │           中央控制（CC）              │
                        │  顺序控制、指令寄存器、程序计数器       │
                        └──────────────┬──────────────────────┘
                                       │ 控制信号
        ┌─────────────┐         ┌──────▼──────┐        ┌─────────────┐
        │  输入（I）   │────────▶│  存储器（M） │◀──────▶│ 运算器（CA） │
        │  程序/数据   │         │ 汞延迟线     │        │ 串行二进制    │
        │  进入        │         │ 1,024×44 位 │        │ 加/减/乘     │
        └─────────────┘         └──────┬──────┘        └──────┬──────┘
                                       │                      │
                                       └──────────┬───────────┘
                                                  ▼
                                          ┌─────────────┐
                                          │  输出（O）   │
                                          │  结果/记录    │
                                          └─────────────┘
```

（五大部件 CA/CC/M/I/O 即《EDVAC 报告初稿》确立的结构 [S26][S23]。）

### 数据流说明

1. **程序进入**：程序（一串指令码）作为数据，经输入设备进入内存，与数据同等对待 [S26]。
2. **取指**：中央控制（CC）按程序计数器地址，从汞延迟线内存中取出下一条指令；因延迟线是串行循环存储，取某个字需等到它"流过"读取窗口的时刻（即存在平均等待延时）[S14]。
3. **执行**：指令经译码后，驱动运算器（CA）对操作数做串行二进制运算；结果写回内存 [S23][S26]。
4. **结果去向**：结果存回内存，再经输出设备送出（示波器显示或记录设备打印）[S23]。

### 关键电路职能

- **汞延迟线存储器（Mercury Delay Line Memory）**：把二进制位以声波脉冲形式送入装有汞的金属管，利用声波在汞中传播慢的特点"暂存"数据；脉冲经放大、整形后重新注入形成循环。这是 EDVAC/EDSAC 一代机器的主存储技术 [S14]。
- **中央运算器（Central Arithmetic, CA）**：串行二进制加、减、乘；除法由软件子程序完成 [S23]。
- **中央控制（Central Control, CC）**：产生时序与顺序控制，维持程序计数器与指令寄存器，是所有现代 CPU 控制逻辑的原型 [S26]。
- **定时器/分发单元**：产生主脉冲时序，并把来自控制器与内存的指令分发到各部件 [S23]（细节「需核实」）。
- **磁性记录仪（输入侧）**：早期程序与数据输入的载体 [S23]（具体介质「需核实」）。

## (d) 装配体层级树草案

```
EDVAC 整机（多机柜）
├── 机柜/框架与电源（56 kW 供电、散热）
├── 存储器子系统（汞延迟线）
│   ├── 延迟线水槽/金属管阵列
│   ├── 换能器（声-电转换）
│   └── 再循环放大与整形电路
├── 运算子系统（CA）
│   ├── 串行加法器电路板
│   ├── 乘法器电路板
│   └── 移位/门控电路
├── 控制子系统（CC）
│   ├── 主脉冲发生器/定时器
│   ├── 指令寄存器/译码器
│   ├── 程序计数器（顺序控制）
│   └── 分发单元
├── I/O 子系统
│   ├── 输入（磁性记录/纸带，1953 起打孔卡）
│   └── 输出（示波器显示 + 记录设备）
└── 布线/信号互连
```

**逐层要点与建模拆解预算评估：**

- EDVAC 规模远小于 ENIAC（约 6,000 管 [S23]），**整机建模可做更细的逐板展开**。
- **推荐粒度**：整机→子系统（约 5–6 节点）→电路板（约 30–50 节点）→元器件（关键板做逐元件展开，如"串行加法器"教学板）。
- **难度点**：① 汞延迟线的"内部声波"无法直观看清，需用动画表现"脉冲串在管内传播→整形→再注入"的循环；② 串行运算逐位流动的可视化（对玩家理解"二进制串行"很关键）；③ EDVAC 存世原始影像与图纸远少于 ENIAC，建模参考「需核实」来源的完备度。

## (e) 百科卡全文（C1 级成品文案）

**EDVAC —— 图纸上诞生的现代计算机蓝图**

在 ENIAC 尚未完全运转时，它的设计者们已经开始谋划下一代：一台不用插拔电缆、而是把"程序"像数据一样存进内存、由机器自己依次取出执行的计算机。1945 年，冯·诺依曼写下 101 页的《EDVAC 报告初稿》，把这套构想系统化：二进制、串行处理、五大部件、指令即数据 [S26][S23]。

这份报告流传极广，几乎定义了此后所有计算机的骨架——也就是我们今天所说的"冯·诺依曼架构" [S26]。但历史的另一面是：这台蓝图上的明星机器，实际建造却一波三折。因 Eckert 与 Mauchly 离职创业引发的专利纠纷与人才流失，EDVAC 直到 1949 年才交付、1951 年才勉强运行 [S23]。

所以 EDVAC 的传奇不在"第一个跑起来"，而在"第一个写进了教科书"：它是现代通用计算机的**设计原型**。真正把这份蓝图变成可用的机器、并率先跑出结果的，是大西洋彼岸的两台小兄弟——1948 年的 Manchester Baby 和 1949 年的 EDSAC [S01][S25]。

**关键参数（面向玩家）：** 二进制串行 · 约 6,000 真空管 · 汞延迟线 1,024 字 × 44 位 · 加法约 864 µs · 重约 7.8 吨 · 约 56 kW [S23]。

**参考来源：** [S02][S23][S26][S14]。

## (f) 原理讲解大纲（C2/C3/C4）

- **C2（框图层）**：标注五大部件（CA/CC/M/I/O），强调"程序=数据，同存内存"这一核心思想；用一条环线把 CC→M→CA→M 连起来，表示"取指—执行—回写"循环。
- **C3（信号流层）**：标注三类信号——① 地址/控制（CC→M）；② 数据（M↔CA）；③ 时序（主脉冲）。建议做"取指—译码—执行—回写"四拍的逐拍高亮。
- **C4（原理动画）**：
  - **镜头 1（串行 vs 并行）**：对比 ENIAC 的并行十进制与 EDVAC 的串行二进制——同一串脉冲"一个位一个位"流动。
  - **镜头 2（延迟线）**：声波脉冲在汞管中传播、被放大整形、重新注入的循环动画。
  - **镜头 3（取指执行）**：程序计数器地址 → 内存取出指令 → 译码 → 运算器执行 → 回写，用发光箭头串起整条路径。
  - **镜头 4（指令即数据）**：同一段内存内容，一会儿被当作"要运算的数据"、一会儿被当作"要执行的指令"，直观呈现存储程序思想。

## (g) 模拟器/演示可行性

**已有开源/可用模拟器现状：**

- **未发现专门针对 EDVAC 的成熟开源模拟器**（截至调研日 2026-10-31，「需核实」后续再复查）。EDVAC 的模拟生态明显弱于 ENIAC/EDSAC/Manchester Baby，主因是其存世资料少、且"第一台存储程序机"的历史焦点常被 EDSAC 与 Baby 分流。
- **可借用的相邻实现**：
  1. 架构同源的 **IAS 机模拟器**（冯·诺依曼在普林斯顿主持的 EDVAC 后续机型）——「需核实」具体项目名与许可。
  2. **EDSAC 模拟器**（Warwick 大学 Martin Campbell-Kelly 版，见 03 章）在"串行二进制 + 延迟线 + 存储程序"上高度同构，可作为 EDVAC 演示的原理近亲 [S11]。
  3. **ENIAC 模拟器**（见 01 章）用于对照"布线编程 vs 存储程序"的差异 [S06][S07]。

**结论：只能"静态 + 原理动画 + 近亲模拟"（混合），无专用可跑模拟器。**

- **能跑**：无 EDVAC 专用模拟器；可退而用 EDSAC 模拟器演示"同类架构"的取指执行。
- **不能跑**：无法直接以"真 EDVAC 行为"运行。
- **混合方案（推荐）**：以"静态高精度 3D + 五大部件原理动画"为主，用 EDSAC 模拟器作"近亲"互动出口，并明确标注"本演示基于与 EDVAC 同构的存储程序架构，非 EDVAC 原机仿真"。

**方案 A/B 与工作量粗估：**
- **方案 A（推荐）**：静态模型 + C2/C3/C4 动画（重点做延迟线循环、取指执行）+ 旁挂 EDSAC 模拟器作对照。工作量：模型 1 人周，动画 1–2 人周，对照演示 0.5 人周。
- **方案 B（进阶，可选）**：基于 EDSAC/串行机模拟器代码，自研一个"EDVAC 指令集兼容"的最小模拟内核（44 位字、串行位流）。工作量：2–4 人周（风险高，且需先补齐 44 位字位域定义等「需核实」资料）。

> 许可红线提示：若采用方案 B，自研模拟器可规避第三方许可问题；若复用 EDSAC 模拟器二进制/代码，须遵守其各自许可（见 03 章，Warwick 版为免费闭源、QEdsac 为开源）。
