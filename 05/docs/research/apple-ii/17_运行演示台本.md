## 序幕 · 引入（开场白）

**画面**：黑屏渐亮，一台 Apple II 静静置于展厅的展台上，机箱的米黄 ABS 外壳在柔和的顶光下泛着温润的光泽。镜头以极慢的速度环绕机身一周，最后停在正面键盘与彩虹苹果 logo 的位置。

**解说词（全文）**："在个人电脑的历史上，有一台机器被称作"第一台开箱即用的个人电脑"。它诞生于 1977 年，有着圆润的米黄色外壳、能显示彩色的画面，以及一套让无数孩子第一次学会编程的 BASIC 语言。今天，我们要把它真正地"开起来"——不是看它，也不是拆它，而是让它像四十多年前一样，真实地运行一次。请跟我来。"

**画面提示（转场）**：镜头推进到机箱左后侧的电源开关，特写定格，随后进入第一幕。

## 第一幕 · 开机（电源键 → 自检 → DOS 3.3 引导）

### 镜头 1-1（0:00–0:10）· 通电瞬间

**画面**：特写机箱左后侧电源开关。镜头缓推到一台完整的 Apple II，右侧连接着一台 9 英寸单色监视器（CRT 投放位）。玩家的手（或 VR 手柄射线）拨动电源开关。

**解说词（全文）**："欢迎回到 1977 年。这是一台 Apple II，苹果公司第一台真正走向大众的个人电脑。现在，请把手放到机箱左后侧的电源开关上，拨到 ON——我们按下这台机器的第一盏灯。"

**模拟器能力清单**：`state:starting` → `state:running` [M13:3.2 state]；`light_state`（电源灯 sink 亮起）[M13:3.2 light_state]；开机过渡音 [M13:3.2 audio]。

### 镜头 1-2（0:10–0:20）· 自检与花屏

**画面**：CRT 屏幕亮起，短暂显示随机的点阵花屏（RAM 未初始化的像素噪声），左上角出现闪烁的方块光标。电源指示灯保持常亮。

**解说词（全文）**："屏幕上这片一闪而过的噪点，是刚刚上电时内存里随机数据被扫描出来的画面。Apple II 没有复杂的开机动画，它做的第一件事，是复位处理器，然后等待——等待你去告诉它，接下来要做什么。"

**模拟器能力清单**：首帧 `frame`（format `rgb8`，本台本投放侧转 `rgba8`）[M13:3.2 frame]；帧持续产出以呈现"花屏 → 光标"变化。

### 镜头 1-3（0:20–0:30）· Disk II 引导开始

**画面**：Disk II 软驱（外置于机身右侧）的红色指示灯亮起，盘片开始转动，发出轻微的电机转动声与磁头步进声。屏幕下方出现一行滚动文字。

**解说词（全文）**："注意听——软驱响了。这台机器正在从一张 5.25 英寸软盘上读取 DOS 3.3 操作系统。在 1977 年，软件就是这么"装"进电脑的：一张可以捏弯的塑料盘片，容量 140 KB，还不如今天半张手机照片大。"

**模拟器能力清单**：`light_state`（Disk II 指示灯 sink）[M13:3.2 light_state]；`audio_chunk`（盘片转动/步进音）[M13:3.2 audio]。

### 镜头 1-4（0:30–0:40）· DOS 3.3 载入完成

**画面**：屏幕清屏，显示 DOS 3.3 的版权提示行，随后进入 Applesoft BASIC，出现 `]` 提示符与闪烁光标。Disk II 指示灯熄灭，盘片停转。

**解说词（全文）**："看，那个方括号和闪烁的光标——这就是 Applesoft BASIC 的提示符，意思是：机器准备好了，正在等你输入指令。从这一刻起，这台四十多年前的电脑，开始真正地"运行"了。"

**模拟器能力清单**：`frame` 持续产出（用于识别"提示符 `]` 出现"这一开机画面特征）[M13:3.2 frame]；若缺 ROM/盘 → `error(MEDIA_MISSING)` 转运行向导 [M13:五]。

## 第二幕 · 操作（键盘输入 → 目录 → 运行 BASIC 程序）

### 镜头 2-1（0:40–0:55）· 查看目录 CATALOG

**画面**：镜头对准键盘。玩家的手依次按下 `C`、`A`、`T`、`A`、`L`、`O`、`G`，最后敲下回车。屏幕逐字回显键入内容，回车后列出软盘文件目录。

**键入内容（脚本级全文）**：`CATALOG` + 回车。

**解说词（全文）**："现在，我们输入一个 DOS 命令——CATALOG，意思是"请把这张软盘上的文件列出来"。注意我每敲一个键，屏幕上就回显一个字母。回车之后，DOS 会列出这张盘上的每一个程序。"

**模拟器能力清单**：`input_event`（keyboard，逐键注入）→ `input_ack` [M13:3.1 input keyboard]；`frame` 持续产出（回显 + 目录列表）。

### 镜头 2-2（0:55–1:10）· 键入 BASIC 小程序

**画面**：镜头切到键盘特写。玩家逐行键入下面这段 Applesoft BASIC 程序（脚本级全文，含键入内容）：

```
10 HOME
20 PRINT "WELCOME TO APPLE II"
30 PRINT
40 FOR I = 1 TO 5
50 PRINT "COUNT: "; I
60 PRINT CHR$(7);
70 NEXT I
80 PRINT
90 PRINT "THANK YOU!"
100 END
```

**解说词（全文）**："我们直接写一段程序。这五行代码的意思是：清屏，打印一行欢迎语，然后从 1 数到 5，每数一个数就"滴"地响一声。在 1977 年，写程序就是这么直接——你不需要任何开发工具，开机就是编程环境。"

**BASIC 例程自检说明**：本程序为 AppleSoft BASIC 语法自检通过——`HOME` 清屏、`PRINT` 输出、`FOR/NEXT` 循环、`CHR$(7)` 触发系统蜂鸣（Apple II 写 `$C030` 的字符化封装）、`END` 结束，均属 Applesoft 标准语句，无语法错误；`;` 使后续输出紧跟不换行，`I` 为循环变量合法。

### 镜头 2-3（1:10–1:30）· 运行 RUN

**画面**：玩家键入 `RUN` 并回车。屏幕清屏，显示 `WELCOME TO APPLE II`，随后逐行打印 `COUNT: 1` … `COUNT: 5`，每行伴随一声蜂鸣，最后打印 `THANK YOU!`，回到 `]` 提示符。

**键入内容（脚本级全文）**：`RUN` + 回车。

**解说词（全文）**："输入 RUN，回车——程序跑起来了。屏幕清空，欢迎语出现，计数器从 1 走到 5，每一响都是 CPU 通过写一个内存地址、翻转喇叭电平发出的声音。这就是 Apple II 最迷人的地方：从敲下第一个键到看到结果，中间没有任何黑箱。"

**模拟器能力清单**：`input_event` + `input_ack` [M13:3.1]；`audio_chunk`（蜂鸣 `s16le`）[M13:3.2 audio]；`frame` 持续产出（程序输出画面）。

### 镜头 2-4（1:10–1:25）· LIST 回看程序

**画面**：玩家键入 `LIST` 并回车。屏幕逐行列出刚才输入的全部程序行号与内容，`10 HOME` 到 `100 END` 完整重现。

**键入内容（脚本级全文）**：`LIST` + 回车。

**解说词（全文）**："LIST 会把你刚写的程序一行行列出来。注意每一行开头的数字——那是行号，AppleSoft BASIC 靠行号来组织程序，从 10 开始、每行加 10，这样以后想插一行代码时，就能插在中间。这种'用行号写程序'的方式，如今看来很古老，但正是它教会了整整一代人什么叫编程。"

**模拟器能力清单**：`input_event` + `input_ack` [M13:3.1]；`frame` 持续产出（程序清单回显）。

## 第三幕 · 外设（Disk II 存取音效与指示灯联动）

### 镜头 3-0（1:25–1:40）· 认识软盘介质

**画面**：镜头给到一张 5.25 英寸软盘的特写——黑色方形封套，中央的圆孔，露出里面的棕色盘片。玩家的手（或 VR 手柄）轻轻捏住软盘一角，示意它的柔软。

**解说词（全文）**："在继续之前，我们先看一眼这张 5.25 英寸软盘。它真的很软——你甚至可以把它对折。中间那个棕色圆盘才是真正存数据的磁介质，外面的黑色封套保护它不被弄脏。刚才引导系统的 DOS 3.3，就存在这样一张盘上。接下来，我们要把写好的程序也存进去。"

**模拟器能力清单**：本镜头为实物展示，不涉及模拟器；可叠加软盘插拔音效 [M13:3.2 audio，可选]。

### 镜头 3-1（1:30–1:50）· SAVE 存盘

**画面**：玩家键入 `SAVE HELLO` 并回车。Disk II 红色指示灯亮起，盘片转动，磁头发出步进声；屏幕短暂停顿，提示符重新出现，指示灯熄灭。

**键入内容（脚本级全文）**：`SAVE HELLO` + 回车。

**解说词（全文）**："我们把刚写的程序存到软盘上。注意软驱的红灯亮了，盘片在转——这是程序正被写入磁介质的声音。SAVE 完成，红灯熄灭，程序已经永久地留在了这张 140 KB 的盘片上。"

**模拟器能力清单**：`light_state`（Disk II 指示灯联动）[M13:3.2 light_state]；`audio_chunk`（写入音）[M13:3.2 audio]；`input_event`/`input_ack`。

### 镜头 3-2（1:50–2:05）· LOAD 读盘

**画面**：玩家先键入 `NEW` 回车清空内存，再键入 `LOAD HELLO` 回车。Disk II 指示灯再次亮起、盘片转动，随后提示符重新出现——程序已从磁盘读回内存。

**键入内容（脚本级全文）**：`NEW` + 回车；`LOAD HELLO` + 回车。

**解说词（全文）**："NEW 先清空内存，再 LOAD HELLO 把程序从磁盘读回来。你听到的每一次盘片转动、看到的每一次红灯闪烁，都是一次真实的磁盘存取。这台机器的"记忆"，就藏在这一张张软盘里。"

**模拟器能力清单**：`light_state` + `audio_chunk`（读盘音）[M13:3.2]；`save_state`/`load_state` 亦可在此幕演示（快照语义，见 18 号 M2.3）。

## 第四幕 · 关机归档

### 镜头 4-1（2:05–2:20）· 快照归档

**画面**：玩家按下运行 HUD 的 [快照] 键，快门声响起，快照列表新增一条记录（设备名 + 存档名 + 时间）。画面定格当前状态。

**解说词（全文）**："在关机之前，我们按一下快照。这一帧画面、内存里的程序、软驱的状态，都会被完整地保存下来。下次开机，你可以从这一刻继续，而不是从头再来。"

**模拟器能力清单**：`save_state` → `save_state_ack`（frame_id 回传）[M13:3.1 save_state]。

### 镜头 4-2（2:20–2:35）· 关机

**画面**：玩家按下电源开关拨回 OFF（或点 HUD [退出确认] → [退出]）。画面熄灭、关机音响起、电源指示灯熄灭，设备回到"完整"态。

**解说词（全文）**："现在，把电源开关拨回 OFF。屏幕暗下去，硬盘停转，一切都安静下来。这台 Apple II 又回到了展厅里等待下一位参观者的样子。谢谢你，陪它完整地运行了一次。"

**模拟器能力清单**：`stop` → `state:stopped`（reason=user）[M13:3.1 stop]；`light_state`（电源灯熄灭）；关机音。

**画面**：镜头缓缓拉远，Apple II 重新归于展台上的静止状态，顶光柔和。屏幕黑着，电源指示灯在暗处渐渐熄灭。

**解说词（全文）**："我们刚刚完整地跑了一次这台 1977 年的电脑：开机、引导 DOS、写程序、运行、存盘、读盘，最后关机归档。这中间没有一句现代化的"加载中"，也没有一次黑箱——每一个步骤，你都能看见、听见、理解它在做什么。这正是这台机器的魅力所在：它足够简单，简单到你能够完全理解它；它又足够深刻，深刻到整个个人电脑时代都从这里起步。感谢观看，欢迎随时回到这里，亲手再开一次机。"

## 附一：VR / 桌面两种呈现的安全与节奏注意事项

1. **节奏**：全片控制在 2.5–3 分钟，每镜头 10–15 秒；VR 下略缩短单镜头时长（晕动防护），桌面可放宽到 15 秒。
2. **安全（VR）**：开机/存盘的"指示灯 + 盘片转动"是高频闪烁与转动的视觉元素，VR 下应避免在视野边缘快速闪烁；建议把 Disk II 指示灯亮度做柔和过渡，盘片转速降低为可辨认的慢速示意，避免诱发晕动。
3. **安全（桌面）**：蜂鸣与盘片音效需设音量上限，避免长时间高频蜂鸣刺耳；字幕默认开启（FR-H2），音效与字幕同步。
4. **交互保护**：运行中禁止拆解（FR-B4），镜头切换期间锁定手柄输入（过渡锁，同 T-030）；快照/关机均为可逆或二次确认（FR-E7）。
5. **呈现一致性**：内屏 CRT 与外接大屏（`external_crt`）画面同步，延迟 ≤100 ms（T-053）；扫描线伪影为可选后处理，不干扰程序文字可读性。

## 附四：制作口径说明（摄影 / 灯光 / 音效 / 字幕 / 双平台）

**摄影与灯光**：全片以"博物馆展台"的柔和顶光为基调，突出机箱米黄 ABS 的哑光质感与 CRT 屏的磷光。屏幕特写镜头建议在后期叠一层极轻的扫描线伪影（FR-E4 可选后处理），但要保证程序文字清晰可读；软驱特写时打一盏侧逆光，让盘片转动的反光与指示灯的红光有层次。

**音效口径**：键盘敲击、盘片电机、磁头步进、蜂鸣、快门、关机六类音效均需与画面严格对位（音文同步，FR-H2）。蜂鸣与步进声属高频，混音时压低至不刺耳；蜂鸣音量设上限，避免连响时尖锐。

**字幕口径**：解说词与字幕分离——字幕为解说词的逐句精简版，默认开启（FR-H2），可开关。英文语境下术语唯一写法需对齐设计文档附录 B 词汇表（如 Restore 对应"复原"）。

**双平台差异**：桌面版固定机位、可暂停/回看、字幕可选；VR 版镜头运动放缓、避免视野边缘高频闪烁、交互锁定（过渡锁，同 T-030）。两版共享同一份解说词与分镜，仅节奏与安全参数不同。

**审核要点**：① 键入内容与屏幕回显逐字一致；② BASIC 程序真实可跑、无语法错误；③ 每幕"模拟器能力清单"与 13 号映射表条目对应无误；④ 解说词不含未定标记 `[TBD]`、不含盗版渠道；⑤ 商标（彩虹苹果 logo、`apple ][` 字样）仅作历史引用呈现，按 FR-J2 待法律意见。
