# 01 — NeXT Computer 研究卡

## 一、史实

**NeXT Computer**（后更名 NeXTcube）是史蒂夫·乔布斯离开苹果后创立的 NeXT 公司于 1988 年推出的高端工作站。它以标志性的**黑色镁合金立方体机箱**（一英尺见方）、**磁光盘（MO）驱动**与 **NeXTSTEP 操作系统**闻名。尽管商业上未能成功，它却是**万维网诞生的机器**——1990 年，蒂姆·伯纳斯-李在 CERN 的一台 NeXT 上写下了万维网的第一行代码，搭建了第一个 Web 服务器与第一个浏览器。

**叙事锚点**：
1. **乔布斯的黑盒子**：离开苹果后的乔布斯，用一台黑色立方体宣告「重新开始」——极致的设计、昂贵的成本、不肯妥协的姿态，是乔布斯个人气质的物化。
2. **万维网首行代码诞生地**：蒂姆·伯纳斯-李在 NeXT 上写下了 HTML、HTTP 与 URL 的原型，让「万维网」从构想变成现实——这台商业失败的机器，孕育了改变全人类的网络。
3. **磁光盘的先声**：NeXT 率先在个人工作站上采用 256MB 磁光盘，容量远超当时软盘，是「可擦写大容量存储」的早期先锋。
4. **失败的技术，成功的血脉**：NeXT 商业失败，但 NeXTSTEP 后来成为 macOS 的基石，Objective-C 成为苹果生态的主力语言——「失败的硬件，孕育了改变世界的软件」。

## 四、L1-L3 拆解要点

- **L1（外观层）**：黑色立方体机箱、灰度显示器、方形鼠标——「黑盒子」的极简工业设计即可静态呈现。
- **L2（结构层）**：机箱打开 → 主板、磁光盘驱动、电源、扩展槽——拆解展示「一英尺见方的黑盒里装了什么」。
- **L3（芯片层）**：68030 处理器、DSP56001 数字信号处理器——原理讲解用（DSP 专责音频、为多媒体工作站铺路的架构是讲点）。

## 七、工作站厅「序厅定位」三行（NeXT→SGI→Sun 预研预告）

1. **NeXT 作序厅**：用「万维网诞生地」这根情感锚点，把观众从个人机厅的「个人计算」故事，引入工作站厅「专业计算改变世界」的叙事——一台商业失败的机器，如何孕育出连接全人类的网络。
2. **后续预研预告**：NeXT（黑盒与网络）→ SGI（图形工作站的视觉革命）→ Sun（「网络即计算机」），构成工作站厅「从黑盒到图形到网络」的三段式主线，供后续设备包领取。
3. **收束句**：NeXT 用「失败的硬件、成功的血脉」证明——在计算史上，最贵的硬件不一定最成功，但最极致的设计，往往孕育出最长远的遗产。
