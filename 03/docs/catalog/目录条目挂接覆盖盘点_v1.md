## 四、盘点依据与红线声明

- **盘点依据**：目录活跃版本（计算机 v2 + 通讯 v3）+ 02 线 allocate 预案（267-A 第三批、302-C 第四批）+ BlackBerry 补录预案（302-D）+ 研究卡总索引 v2。
- **挂接状态定义**：`done` = 已产包回填（device_id + status=done）；`planned` = 真号在册待产包；`0xx` = 占位待 allocate；`缺失` = 无目录条目。
- **红线**：只盘点不改 jsonl、不产包、不 allocate、不新建条目；目录版本唯一治理（仅活跃版本）；零联网零下载。

> 反链回填责任 = 产包线（252-A 口径），03 线目录侧负责回填 + 复核 catalog_ref；本盘点仅为全景记录。
