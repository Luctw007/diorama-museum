## ① 工作台布局方案（exhibit_workbench 第六件布局）

| 项 | 方案 |
|---|---|
| 布局文件 | `godot/content/exhibit_workbench.json`（第六件布局，exhibit_ 前缀进 layout_check --all） |
| hall_group | **不加**（227-A 五值 {hub,dawn,mainframe,personal,console} 未含 workbench；缺省视为子厅。若需独立分组须 02 线扩枚举——留待 04 线子区定案） |
| 与 hub 衔接 | hub 布局补一条 portal `{target:"exhibit_workbench", position:[…]}`——**先建 exhibit_workbench.json 再加 portal**（P-01 要求 target 可解析，顺序不可反） |
| 设备占位 | 1~2 台 L2/L3 高精度设备（depth_model L0-L3 按台分批加载），候选以 04 线子区定案为准；拆解演示复用单机直连 DeviceRoot 通道 |
| 尺寸 | 沿用 20×12 缺省（工作台子区若需独立尺寸，实装时在布局写 width/depth） |
| 传送 | PortalHub.refresh_portals 通用解析——工作台布局带 portals 即自动生成门框，无需新代码 |

## ② 拆解台衔接收口（静态核对结论）

- **切厅不打断拆解**（已证，241-A §三）：clear_devices 只清 ExhibitHost _placed 子树，Inspect/ExplodeController 挂 DeviceRoot 不受切厅影响——无需「切厅 exit_explode」钩子；
- **最近拆解台续接**（F-6 预口径）：Exit 拆解（Esc/B，inspect_controller._exit_explode_to_walk）时把最近台 did 记入 PortalHub/ExhibitHost 记忆位 → 回厅续接高亮该台。本方案只定口径，实装属 F-6；
- 待实装验证：①拆解中切厅的双高亮/输入优先级；②Exit 后「回厅续接」的视觉引导（F-6）；③工作台设备与 DeviceRoot 目标切换的互斥。
